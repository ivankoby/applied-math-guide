📋 Шпаргалка формул

Главная формула каждой карточки. Нажми на тему — перейдёшь к объяснению.

1

Матрицы и определители

ТемаФормулаКак читать
Матрица — таблица чиселA = (aᵢⱼ), размер m × naᵢⱼ — конфетка в строке i и столбце j. Строк m, столбцов n.
Определительdet A = a₁₁·a₂₂ − a₁₂·a₂₁Пример: |2 3; 5 7| = 2·7 − 3·5 = −1.
Обратная матрицаA⁻¹ = (1 / det A) · A∨A∨ — присоединённая: из алгебраических дополнений, транспонированная. A · A⁻¹ = E.
Ранг матрицыr(A) — ранг: максимальный порядок ненулевого минораПроще: сколько строк остаётся после упрощения.
2

Системы уравнений

ТемаФормулаКак читать
Что такое система уравненийA · X = BA — таблица коэффициентов, X — столбец неизвестных, B — столбец свободных членов.
Крамер и матричный способxᵢ = Δᵢ / ΔΔ — определитель системы. Δᵢ — определитель с заменённым i-м столбцом. Нужно Δ ≠ 0.
Метод Гаусса и теорема Кронекера–Капеллиr(A) = r(Ā)Ранг основной матрицы равен рангу расширенной — система совместна (Кронекер–Капелли).
Однородные системы и ФСРX = c₁e₁ + c₂e₂ + … + cₖeₖ, k = n − re₁…eₖ — фундаментальная система решений (ФСР). c₁…cₖ — любые числа. n — число неизвестных.
3

Векторные пространства

ТемаФормулаКак читать
Линейное пространствоx + y = y + x; α(x + y) = αx + αyПервое: порядок сложения не важен. Второе: число «раскрывает скобки».
Линейная зависимостьλ₁a₁ + λ₂a₂ + … + λₙaₙ = 0Если хотя бы одно λ не ноль, набор зависимый. Если все λ нули, независимый.
Базис и координатыx = x₁f₁ + x₂f₂ + … + xₙfₙЧитается: «икс равно икс-один эф-один плюс…». Числа x₁…xₙ — координаты x.
Переход к другому базисуξ = C·η; η = C⁻¹·ξСтарые координаты получаем умножением на C. Обратно — на обратную матрицу C⁻¹.
4

Произведения векторов

ТемаФормулаКак читать
Скалярное произведение(x, y) = α₁β₁ + α₂β₂ + … + αₙβₙПеремножь числа с одинаковыми номерами и сложи всё. Получится число.
Векторное произведение|a × b| = |a|·|b|·sin φДлина новой стрелки равна площади параллелограмма на a и b. φ — угол между ними.
Смешанное произведениеV = |(a × b) · c|Объём параллелепипеда. Знак «плюс» — правая тройка, «минус» — левая.
Ортонормированный базисb₂ = a₂ − ((a₂, b₁) / (b₁, b₁))·b₁Так b₂ становится перпендикулярен b₁. Остальные векторы — по тому же правилу.
5

Линейные отображения

ТемаФормулаКак читать
Линейное отображениеA(λ₁v₁ + λ₂v₂) = λ₁A(v₁) + λ₂A(v₂)Одна формула заменяет два правила: сложение и умножение на число. Ноль переходит в ноль.
Ядро и образdim(Ker A) + dim(Im A) = dim VРазмер ядра плюс размер образа равен размеру исходного пространства.
Матрица отображенияw = A·vКоординаты образа w получаем умножением матрицы A на координаты прообраза v.
Линейные операторыA_f = S⁻¹ · A_e · SS — матрица перехода от базиса e к базису f. Такие матрицы называют подобными.
6

Пределы

ТемаФормулаКак читать
Логика, множества, кванторы¬(∀x A(x)) = ∃x ¬A(x)«Не у всех верно» значит: найдётся хотя бы один, у кого нет.
Метод математической индукцииk ∈ A ⇒ k + 1 ∈ AЕсли верно для k, то верно и для k + 1.
Предел последовательности∀ε > 0 ∃N ∀n > N: |xₙ − a| < εДля любого малого ε найдётся номер N. Дальше все xₙ ближе к a, чем на ε.
Предел функции∀ε > 0 ∃δ > 0: 0 < |x − x₀| < δ ⇒ |f(x) − A| < εДля любого малого ε найдётся δ. Если x близко к x₀, то f(x) близко к A.
7

Непрерывность функций одной переменной

ТемаФормулаКак читать
Непрерывность в точкеlim x → x₀ f(x) = f(x₀)Предел в точке равен значению в точке. Так пишут «без дырок».
Точки разрываx₀ — разрыв 1-го рода ⇔ существуют оба односторонних пределаЕсли оба предела есть — первого рода. Иначе — второго рода.
Свойства непрерывных функцийf(a) · f(b) < 0 ⇒ f(ξ) = 0 для некоторого ξ ∈ (a, b)Знаки на концах разные — внутри точно есть ноль.
Элементарные функцииlim x → 0 sin x = 0Синус подходит к нулю, когда x подходит к нулю. По этому доказывают непрерывность синуса.
8

Дифференцируемость функций одной переменной

ТемаФормулаКак читать
Что такое производнаяy′ = lim Δx → 0 Δy / ΔxПредел отношения приращения функции к приращению аргумента.
Правила дифференцирования(u / v)′ = (u′·v − u·v′) / v²Производная дроби. Знаменатель v не должен быть нулём.
Касательная и скоростьy − y₀ = f′(x₀) · (x − x₀)Уравнение касательной в точке (x₀; y₀), где y₀ = f(x₀).
Сложная, обратная, неявная функцииy′(x) = y′(u) · u′(x)Производная сложной функции: производная снаружи умножить на производную внутри.
9

Теоремы о производных

ТемаФормулаКак читать
Высшие производные(fg)⁽ⁿ⁾ = Σ(k=0..n) Cₙᵏ · f⁽ⁿ⁻ᵏ⁾ · g⁽ᵏ⁾, где Cₙᵏ = n!/(k!(n−k)!)Формула Лейбница: производная n-го порядка от произведения. Читается как сумма слагаемых с числами C.
Теоремы Ферма, Ролля, Лагранжа, Кошиf(b) − f(a) = f′(ξ) · (b − a), ξ ∈ (a; b)Формула Лагранжа (конечных приращений). Читается: есть точка ξ между a и b, где наклон касательной равен наклону хорды.
Формула Тейлораf(x) = Σ(k=0..n) f⁽ᵏ⁾(x₀)/k! · (x − x₀)ᵏ + rₙ(x)Функция = многочлен Тейлора + остаток rₙ. При x₀ = 0 это формула Маклорена.
Правило Лопиталяlim (x→a) f(x)/g(x) = lim (x→a) f′(x)/g′(x)Правило Лопиталя: если предел f′/g′ существует, то предел f/g такой же. Рядом с точкой g′ ≠ 0.
10

Применение производных

ТемаФормулаКак читать
Возрастание и экстремумыf′(x) ≥ 0 на (a; b) ⇔ f возрастает на (a; b)Читается: если производная не отрицательная, функция растёт. Для убывания нужен знак f′ ≤ 0.
Выпуклость и перегибыf′(x₀) = 0 и f″(x₀) > 0 ⇒ x₀ — минимум; f″(x₀) < 0 ⇒ x₀ — максимумПризнак экстремума через вторую производную. Сначала находим точку, где f′ = 0.
Асимптотыk = lim(x→∞) f(x)/x, b = lim(x→∞) (f(x) − k·x), y = k·x + bНаклонная асимптота y = kx + b. Если k = 0, она горизонтальная: b = lim f(x).
Наибольшее и наименьшее значениеmax[a; b] f = max{ f(xкрит), f(a), f(b) }Работает на замкнутом отрезке, где функция непрерывна. Берём все кандидаты и сравниваем.
11

Неопределённый интеграл

ТемаФормулаКак читать
Первообразная и интеграл∫f(x)dx = F(x) + CИнтеграл от эф от икс дэ икс равен эф от икс плюс цэ. Цэ — любое число.
Таблица интегралов∫xᵅ dx = xᵅ⁺¹ / (α + 1) + C, α ≠ −1Икс в степени альфа: степень поднимаем на один и делим на новую степень. Альфа не равна минус единице.
Замена переменной∫f(x)dx = ∫f[φ(t)]·φ′(t)dtИкс заменяем на фи от тэ, дэ икс — на фи штрих от тэ, умножить на дэ тэ. В конце возвращаемся к иксу.
Интегрирование по частям∫u dv = u·v − ∫v duИнтеграл от u дэ вэ равен u умножить на вэ минус интеграл от вэ дэ у.
12

Интегрирование рациональных функций

ТемаФормулаКак читать
Рациональные дробиP(x) / Q(x) = R(x) + P₁(x) / Q₁(x)Пэ от икс на ку от икс равно эр от икс плюс пэ один на ку один. Дробь пэ один на ку один — правильная.
Разложение на простые дробиA / (x − a)ᵅ + (Mx + N) / (x² + px + q)ᵝЭто элементарные дроби. Буквы A, M, N — числа, которые надо найти.
Интегралы простых дробей∫A/(x − a) dx = A·ln|x − a| + CИнтеграл от А на икс минус а дэ икс равен А умножить на логарифм модуля икс минус а, плюс цэ.
Интеграл рациональной дроби∫ x dx / ((x²−1)(x−2)) = −½·ln|x−1| − ⅙·ln|x+1| + ⅔·ln|x−2| + CИнтеграл от икс на икс квадрат минус один, умножить на икс минус два, равен сумме трёх логарифмов с коэффициентами. Плюс цэ.
13

Интегрирование иррациональных функций

ТемаФормулаКак читать
Корни и подстановка ttᵐ = (ax + b) / (cx + d)Тэ в степени эм равно дробь: а икс плюс бэ на це икс плюс дэ. Эм — общий знаменатель степеней корня.
Подстановки Эйлера√(ax² + bx + c) = ±x·√a ± tКорень из а икс квадрат плюс бэ икс плюс цэ равен плюс-минус икс корень из а, плюс-минус тэ. Знаки можно брать любые.
Тригонометрические: u = tg(x/2)sin x = 2u / (1 + u²), cos x = (1 − u²) / (1 + u²)Синус икс равен два у на один плюс у квадрат. Косинус икс равен один минус у квадрат на один плюс у квадрат. Здесь у — тангенс половины икса.
Синус, косинус и экспонента∫ e^(αx)·cos βx dx = e^(αx)·(β·sin βx + α·cos βx) / (α² + β²) + CИнтеграл от е в степени альфа икс, на косинус бэ икс, равен дроби: е в степени альфа икс, на скобку из бэ синус бэ икс плюс альфа косинус бэ икс, делённое на альфа квадрат плюс бэ квадрат. Плюс цэ.
14

Определённый интеграл

ТемаФормулаКак читать
Интегральная сумма и площадь∫ₐᵇ f(x) dx = lim(λ→0) Σ f(x̄ₖ)·ΔxₖЧитается: «интеграл от а до б». Это предел суммы полосок, когда они очень тонкие.
Свойства интеграла∫ₐᵇ f dx = ∫ₐᶜ f dx + ∫ᶜᵇ f dxОтрезок от а до б можно разрезать точкой c. Площади кусков складываются.
Формула Ньютона–Лейбница∫ₐᵇ f(x) dx = F(b) − F(a)Формула Ньютона–Лейбница. Здесь F′(x) = f(x): F — первообразная для f.
Несобственные интегралы∫ₐ^(+∞) f(x) dx = lim(A→+∞) ∫ₐᴬ f(x) dxСчитаем обычный интеграл до числа A. Потом смотрим, к чему он стремится, когда A растёт.
15

Прямая на плоскости

ТемаФормулаКак читать
Линии на плоскостиF(x, y) = 0F — формула линии. Точка лежит на линии, если её x и y подходят.
Уравнения прямойAx + By + C = 0«А икс плюс бэ игрек плюс цэ равно нулю». Так записывается любая прямая.
Угол между прямымиk₁ · k₂ = −1Наклоны перемножили — вышел минус единица. Значит, прямые пересеклись под прямым углом.
Расстояние до прямойd = |Ax₀ + By₀ + C| / √(A² + B²)Подставь координаты точки. Возьми модуль. Раздели на длину вектора n.
16

Кривые второго порядка

ТемаФормулаКак читать
ОкружностьAx² + 2Bxy + Cy² + 2Dx + 2Ey + F = 0Хотя бы один из коэффициентов A, B, C не равен нулю.
Эллипсx²/a² + y²/b² = 1Икс в квадрате на а в квадрате, плюс игрек в квадрате на бэ в квадрате, равно единице.
Гиперболаx²/a² − y²/b² = 1Минус между слагаемыми: ветки уходят влево и вправо, по оси OX.
Параболаy² = 2pxИгрек в квадрате равно два пэ икс. Фокус (p/2; 0), директриса x = −p/2.
17

Трёхмерная геометрия

ТемаФормулаКак читать
ПлоскостьAx + By + Cz + D = 0Читается: «А икс плюс бэ игрек плюс цэ зет плюс дэ равно нулю». Буквы A, B, C — координаты нормали n.
Расстояние и углыd = |Ax₀ + By₀ + Cz₀ + D| / √(A² + B² + C²)«Дэ» равно модулю выражения, делённому на корень из суммы квадратов A, B, C. Это короткий путь от точки до плоскости.
Прямая в пространстве(x − x₀)/m = (y − y₀)/n = (z − z₀)/p = tЧитается: «икс минус икс нулевое, делить на эм» — и так же для игрека и зета. Вектор S {m; n; p} задаёт направление.
Прямая и плоскостьsin φ = |Am + Bn + Cp| / (√(A² + B² + C²) · √(m² + n² + p²))φ — угол между прямой S {m; n; p} и плоскостью с нормалью {A; B; C}.
18

Поверхности 2-го порядка

ТемаФормулаКак читать
Эллипсоид и сфераx²/a² + y²/b² + z²/c² = 1Читается: «икс квадрат на а квадрат, плюс игрек квадрат на бэ квадрат, плюс зет квадрат на цэ квадрат, равно единице». Буквы a, b, c — полуоси.
Гиперболоидыx²/a² + y²/b² − z²/c² = 1Читается: «икс квадрат на а квадрат, плюс игрек квадрат на бэ квадрат, минус зет квадрат на цэ квадрат, равно единице». Это однополостный гиперболоид.
Параболоиды и конусz = x²/a² + y²/b²Эллиптический параболоид — чаша, открытая вверх. Читается: «зет равно икс квадрат на а квадрат, плюс игрек квадрат на бэ квадрат».
Цилиндры и вращениеz → ±√(x² + z²)Вращаем кривую вокруг оси Oy: вместо z ставим ±√(x² + z²). Знак выбирай тот же, что у z на исходной кривой.
