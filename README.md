# Прикладная математика — пособие для первоклассника

Пособие по 18 лекциям курса «Прикладная математика»: линейная алгебра, математический анализ, аналитическая геометрия.

**Лекции 1–12** — подробные статьи с разобранными примерами, графиками и заданиями для самопроверки (ответы проверяются прямо в браузере, у каждой ошибки своя подсказка), плюс краткие карточки, словарик и шпаргалка формул. **Лекции 13–18** скоро будут.


Статический сайт без сборки: откройте `index.html` или опубликуйте через GitHub Pages.

> Это личный пересказ лекций для повторения. Лекции принадлежат их авторам; для строгих определений и доказательств смотрите оригиналы.
