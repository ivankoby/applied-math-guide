# Прикладная математика — пособие для первоклассника

Конспект-пособие по 18 лекциям курса «Прикладная математика»: линейная алгебра, математический анализ, аналитическая геометрия — простыми словами, со схемами, формулами, словариком и вопросами для самопроверки.

Статический сайт без сборки: откройте `index.html` или опубликуйте через GitHub Pages.

> Это личный пересказ лекций для повторения. Лекции принадлежат их авторам; для строгих определений и доказательств смотрите оригиналы.
