Задачи 1–3: многочлены и матрицы

Задача 1из лекции, стр. 12
Пусть Q — множество всех многочленов степени не выше n. Суммой многочленов A = a₀xⁿ + a₁xⁿ⁻¹ + … + aₙ и B = b₀xⁿ + b₁xⁿ⁻¹ + … + bₙ называют многочлен с коэффициентами aᵢ + bᵢ, произведением A на число λ — многочлен с коэффициентами λaᵢ. Доказать, что Q — линейное пространство; найти размерность и базис.

  1. Замкнутость. При сложении и умножении на число степень не растёт, поэтому результат снова многочлен степени не выше n. Нуль и противоположный. Нулевой многочлен (все коэффициенты нулевые); противоположный к A — многочлен с коэффициентами −aᵢ. Остальные аксиомы (1, 2, 5–8) выполняются, потому что операции — поэлементные над коэффициентами, а для чисел аксиомы верны (статья 3.1).

  2. Размерность и базис. Многочлену A сопоставим набор его коэффициентов (a₀, …, aₙ) из ℝⁿ⁺¹. Операции в Q превращаются в покомпонентные, соответствие взаимно однозначно: это изоморфизм (статья 3.4). Значит, dim Q = n + 1. Базис — прообраз канонического базиса: 1, x, x², …, xⁿ. Проверка напрямую: многочлен λ₀ + λ₁x + … + λₙxⁿ нулевой, только если все λᵢ = 0 (независимость), и любой многочлен степени не выше n — комбинация этих степеней.

Q — линейное пространство, dim Q = n + 1, базис 1, x, …, xⁿ.

Задача 2из лекции, стр. 12
Доказать, что множество Q′ всех многочленов степени ровно n линейного пространства не образует (операции как в задаче 1).

  1. Достаточно одного контрпримера. Возьмём A = xⁿ (степень n) и B = −xⁿ (степень n). Сумма A + B = 0 — нулевой многочлен, а у него степень не определена, значит, она не равна n. Сложение выводит из множества: Q′ не замкнуто.

  2. Дополнительно: нулевого многочлена в Q′ нет вовсе, значит, не выполнена и аксиома 3 (нуль-вектор). Другой контрпример: xⁿ + (−xⁿ + 1) = 1 при n ≥ 1 имеет степень 0.

Не линейное пространство: сумма двух многочленов степени n может иметь меньшую степень (и нуль не лежит в множестве).

Задача 3из лекции, стр. 12
Доказать, что все квадратные матрицы второго порядка с обычными операциями образуют четырёхмерное пространство; указать базис.

  1. Сумма матриц 2×2 и произведение матрицы на число — снова матрицы 2×2 (замкнутость); аксиомы выполнены, потому что операции поэлементные, а для чисел они верны (статья 3.1). Нуль-вектор — нулевая матрица, противоположная к A — матрица −A.

  2. Базис — четыре матрицы с одной единицей: 1000, 0100, 0010, 0001. Любая матрица abcd равна a·E₁₁ + b·E₁₂ + c·E₂₁ + d·E₂₂, а нулевая матрица получается только при a = b = c = d = 0: матрицы независимы и порождают всё пространство. Значит, dim = 4.

dim = 4, базис E₁₁, E₁₂, E₂₁, E₂₂.

Задачи 4–5: необычные операции

Задача 4из лекции, стр. 12
На множестве M всех упорядоченных пар (u, v) положительных чисел заданы операции: (u₁, v₁) + (u₂, v₂) = (u₁·u₂, v₁·v₂), λ(u, v) = (uλ, vλ), где λ — вещественное число. Доказать, что M — линейное пространство; найти: а) нулевой элемент; б) пару, противоположную (u, v); в) размерность и базис.

  1. Замкнутость. Произведение положительных чисел положительно и степень положительного числа положительна: обе операции не выводят из M.

  2. Аксиомы. 1: (u₁u₂, v₁v₂) = (u₂u₁, v₂v₁). 2: ассоциативность умножения чисел. 3: нуль (1, 1), так как (u, v) + (1, 1) = (u·1, v·1) = (u, v). 4: для (u, v) противоположна (1/u, 1/v): (u·(1/u), v·(1/v)) = (1, 1) — нуль, и 1/u > 0. 5: 1·(u, v) = (u¹, v¹). 6: α(β(u, v)) = ((uβ)α, (vβ)α) = (uαβ, vαβ) = (αβ)(u, v). 7: (α + β)(u, v) = (uα+β, vα+β) = (uα·uβ, vα·vβ) = α(u, v) + β(u, v). 8: α((u₁, v₁) + (u₂, v₂)) = ((u₁u₂)α, (v₁v₂)α) = (u₁α·u₂α, v₁α·v₂α) = α(u₁, v₁) + α(u₂, v₂). Все восемь выполнены.

  3. Ответы. а) нулевой элемент (1, 1). б) противоположная пара (1/u, 1/v). в) Векторы e₁ = (10, 1) и e₂ = (1, 10): комбинация x·e₁ + y·e₂ = (10x, 10y). Равенство (10x, 10y) = (u, v) решается единственным образом: x = lg u, y = lg v. Значит, каждая пара однозначно раскладывается по e₁, e₂, а нулевая пара (1, 1) получается только при x = y = 0 (независимость). Размерность 2, базис (10, 1), (1, 10). Пример: пара (100, 1/10) имеет координаты (2, −1), потому что lg 100 = 2, lg (1/10) = −1. То же вытекает из изоморфизма (u, v) ↔ (lg u, lg v) с ℝ² (статья 3.4).

а) (1, 1); б) (1/u, 1/v); в) dim M = 2, базис (10, 1), (1, 10).

Задача 5из лекции, стр. 12–13
На множестве пар (u, v) вещественных чисел операции введены одним из способов: а) (u₁, v₁) + (u₂, v₂) = (u₁ + 2u₂, v₁ + 2v₂), λ(u, v) = (λu, λv); б) (u₁, v₁) + (u₂, v₂) = ((u₁ + v₁)/2, (u₂ + v₂)/2), λ(u, v) = (λu, λv) (так напечатано в лекции, см. замечание); в) (u₁, v₁) + (u₂, v₂) = (u₁ + u₂, v₁ + v₂), λ(u, v) = (u, v). Будет ли множество линейным пространством? Если нет, какие аксиомы не выполняются?

  1. а) Аксиома 1: (1, 0) + (0, 0) = (1, 0), но (0, 0) + (1, 0) = (2, 0). Аксиома 2: ((0, 0) + (0, 0)) + (1, 0) = (2, 0), а (0, 0) + ((0, 0) + (1, 0)) = (0, 0) + (2, 0) = (4, 0). Аксиома 7: (1 + 1)(u, v) = (2u, 2v), а 1·(u, v) + 1·(u, v) = (u + 2u, v + 2v) = (3u, 3v). Остальные выполнены: нуль (0, 0) (в смысле x + 0 = x), противоположный (−u/2, −v/2), аксиомы 5, 6, 8. Не линейное пространство; нарушены аксиомы 1, 2, 7.

  2. б) Сумма записана так: x + y = (m(x), m(y)), где m(u, v) = (u + v)/2. Аксиома 1: при x = (1, 2), y = (3, 4) получаем x + y = (3/2, 7/2), а y + x = (7/2, 3/2). Аксиома 2: при x = (2, 0), y = z = (0, 0) имеем (x + y) + z = (1/2, 0), а x + (y + z) = (1, 0). Аксиома 3: равенство x + 0 = x требует u = (u + v)/2, то есть u = v для любого x; единого нуля нет (значит, теряет смысл и аксиома 4). Аксиома 7: (1 + 1)(1, 2) = (2, 4), а 1·x + 1·x = x + x = (3/2, 3/2). Аксиомы 5, 6, 8 выполнены. Не линейное пространство; нарушены аксиомы 1, 2, 3, 7 (и 4, поскольку нет нуля).

  3. в) Аксиомы 1–4 выполнены (это обычное сложение пар), 5 выполнена (1·(u, v) = (u, v)), 6: α(β(u, v)) = (u, v) = (αβ)(u, v) и 8: α(x + y) = x + y = αx + αy. Аксиома 7 нарушена: (1 + 1)x = x, а 1·x + 1·x = 2x; при x ≠ 0 это разные векторы. Не линейное пространство; нарушена аксиома 7.

а) нет, нарушены 1, 2, 7; б) нет (как напечатано), нарушены 1, 2, 3 (и 4), 7; в) нет, нарушена 7.

Замечание

В лекции (стр. 13) в варианте б) напечатана сумма ((u₁ + v₁)/2, (u₂ + v₂)/2): так мы её и разобрали. Возможно, имелось в виду ((u₁ + u₂)/2, (v₁ + v₂)/2) (опечатка, но это лишь догадка). Для такого варианта коммутативность выполнена, а нарушены аксиомы 2, 3 (и 4), 7: например, ((0, 0) + (4, 4))/2 = (2, 2), ((2, 2) + (8, 8))/2 = (5, 5), а ((4, 4) + (8, 8))/2 = (6, 6), ((0, 0) + (6, 6))/2 = (3, 3).

Задачи 6–8: линейная зависимость

Задача 6из лекции, стр. 13
Доказать, что любая система векторов линейного пространства, содержащая два одинаковых вектора, линейно зависима.

  1. Пусть в системе a₁, …, aₖ векторы с номерами i и j равны: aᵢ = aⱼ. Положим λᵢ = 1, λⱼ = −1, остальные коэффициенты нулевые. Тогда λ₁a₁ + … + λₖaₖ = aᵢ − aⱼ = 0, и среди коэффициентов есть ненулевые. По определению (3.1) система зависима. (Другой путь: подсистема из двух одинаковых векторов зависима, теорема 3 из статьи 3.2.)

Доказано: aᵢ − aⱼ = 0 — нетривиальная зависимость.

Задача 7из лекции, стр. 13 (условие исправлено)
Пусть векторы a и b линейно независимы. Исходя из определения, доказать, что векторы a − 2b и a + 2b также линейно независимы.

  1. Допустим, λ₁(a − 2b) + λ₂(a + 2b) = 0. Раскроем скобки и сгруппируем: (λ₁ + λ₂)·a + (−2λ₁ + 2λ₂)·b = 0. Так как a, b независимы, оба коэффициента нулевые: λ₁ + λ₂ = 0 и −2λ₁ + 2λ₂ = 0.

  2. Из первого λ₂ = −λ₁; подставляем во второе: −2λ₁ − 2λ₁ = −4λ₁ = 0, откуда λ₁ = 0 и λ₂ = 0. Нулевая комбинация возможна только при нулевых коэффициентах: векторы независимы.

Векторы a − 2b и a + 2b независимы.

Замечание

В тексте лекции (стр. 13) условие напечатано как «a − 2b и a − 2b»: такое утверждение ложно: два одинаковых вектора зависимы (задача 6). Вероятно, имелась в виду другая пара. Мы разобрали пару a − 2b и a + 2b (это наша догадка); тот же метод работает для любой пары вида a + pb, a + qb при p ≠ q.

Доказать, что векторы a, b, 2a + 3b линейно зависимы.

Задачи 9–10: подпространство и оболочка

Задача 9из лекции, стр. 13
Доказать, что множество L векторов (x, y, z) пространства ℝ³ с условием x + y + z = 0 — подпространство. Указать размерность и базис.

  1. Подпространство. Нуль (0, 0, 0) входит. Если x₁ + y₁ + z₁ = 0 и x₂ + y₂ + z₂ = 0, то для суммы (x₁ + x₂) + (y₁ + y₂) + (z₁ + z₂) = 0 + 0 = 0, а для α(x, y, z) имеем αx + αy + αz = α·0 = 0. Условия выполнены (статья 3.5).

  2. Размерность и базис. Из условия x = −y − z, а y, z произвольны: (x, y, z) = y·(−1, 1, 0) + z·(−1, 0, 1). Векторы (−1, 1, 0) и (−1, 0, 1) лежат в L (суммы координат равны 0), порождают L и не пропорциональны, то есть независимы. Значит, dim L = 2, базис (−1, 0, 1), (−1, 1, 0) (как в ответе лекции). Это плоскость через начало координат.

dim L = 2; базис (−1, 0, 1), (−1, 1, 0).

Частые ошибки

Так нельзя

В задачах про необычные операции проверять только две-три аксиомы.

Так правильно

Чтобы доказать, что это пространство, нужно проверить все восемь аксиом и замкнутость. Чтобы опровергнуть — найти и показать одну нарушенную.

Так нельзя

Искать нуль-вектор в необычной структуре как число 0 (например, (0, 0) в задаче 4).

Так правильно

Нуль-вектор находят из равенства x + 0 = x с данной сложением: в задаче 4 это (1, 1), потому что роль сложения играет умножение.

Так нельзя

Базис оболочки в задаче 10 взять из столбцов приведённой матрицы.

Так правильно

Базис образуют исходные векторы с номерами ведущих столбцов (a₁, a₂, a₄).

Так нельзя

Переносить координаты в другой базис умножением в «привычную» сторону, не думая, что старое, а что новое.

Так правильно

Сначала определи, какой базис старый, какой новый. Затем: ξ = C·η, η = C⁻¹ξ. В задаче 14 путаница направления даёт печатный ответ (58, 34).

Кратко для повторения

Кратко для повторения

  • Задачи на «пространство или нет»: замкнутость, нуль, противоположный, затем аксиомы 1, 2, 5–8. Один нарушенный пункт — отказ. Размерность и базис находят изоморфизмом с ℝⁿ (через координаты).
  • Многочлены степени не выше n образуют пространство размерности n + 1; степени ровно n — не пространство. Матрицы 2×2 — размерность 4.
  • Зависимость доказывают по определению (3.1) или по теореме 1: покажи нетривиальную комбинацию, равную нулю.
  • Подпространство: нуль, сумма, число. dim оболочки — ранг матрицы из координат; базис — исходные векторы с ведущими столбцами.
  • Смена базиса: C из столбцов новых векторов, ξ = C·η, η = C⁻¹ξ; для двух неканонических базисов C = A⁻¹B. Расхождения лекции: в задаче 7 печатное утверждение ложно, в задаче 12 потерян x; в 5(б) возможна опечатка; в 14 напечатанный ответ (58, 34) отвечает обратной постановке, для печатного условия верно (34, −14).
