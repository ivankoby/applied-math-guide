Практика № 5 называется «Аффинные векторные пространства». Аффинное пространство статьи 3.6 (точки и векторы) она как структуру не вводит, но линейное многообразие L + x₀ — это и есть аффинное подпространство: множество точек M₀ + L (в ℝⁿ, как в статье 3.6), где L — векторы между его точками. Кроме многообразий, практика охватывает сумму, пересечение и прямую сумму подпространств, зависимость системы векторов или функций и новый базис. В статьях 3.1–3.8 многообразий и операций над подпространствами нет; здесь они разобраны, а заодно показан мост «базис пространства решений = ФСР» (он нужен задаче 1 «теста» практики 4).

Линейное многообразие

Линейное многообразие

Пусть L — подпространство, x₀ — вектор (оболочку практика обозначает Lin(a, b, …), в статье 3.5 это L(a, b, …)). Множество P = L + x₀ = {x + x₀ : x ∈ L} — линейное многообразие, полученное параллельным сдвигом L на x₀. Размерность P — это dim L; одномерные многообразия называют прямыми, двумерные — плоскостями.

  • L определяется по P. L — множество разностей двух элементов P: (x + x₀) − (y + x₀) = x − y ∈ L, а любой x ∈ L равен (x + x₀) − x₀ (в терминах статьи 3.6, L — векторы между точками P). Поэтому размерность не зависит от записи P: это и есть «корректность» определения практики, на которую она ссылается как на «утверждение задачи 1331» (студенту недоступное).
  • В роли x₀ годится любой элемент P. Если p₀ = y₀ + x₀ (y₀ ∈ L), то x + x₀ = (x − y₀) + p₀, и x − y₀ ∈ L: значит, P = L + p₀.
  • P — подпространство ⇔ x₀ ∈ L ⇔ 0 ∈ P. Если 0 = x + x₀, то x₀ = −x ∈ L; обратно, при x₀ ∈ L сдвиг ничего не меняет.

Связь с системами. Множество решений совместной системы AX = B — линейное многообразие X₀ + L: X₀ — частное решение, L — решения AX = 0 (статья 2.7), а dim P = n − r (n — число неизвестных, r = rang A). Несовместная система даёт пустое множество, не многообразие. Это подпространство только при B = 0 (тогда X₀ = 0).

Пример 2дополнительно
Записать множество решений системы x₁ + 2x₂ − x₄ = 3, x₂ + x₃ + 2x₄ = 1 как линейное многообразие.

  1. Вычтем из первой строки удвоенную вторую:

    120−1301121R1 − 2·R210−2−5101121

    Отсюда x₁ = 1 + 2x₃ + 5x₄, x₂ = 1 − x₃ − 2x₄. При x₃ = x₄ = 0 получаем X₀ = (1, 1, 0, 0); при x₃ = 1, x₄ = 0 и x₃ = 0, x₄ = 1 — решения однородной системы v₁ = (2, −1, 1, 0), v₂ = (5, −2, 0, 1) (ФСР).

  2. Проверка: A·X₀ = (3, 1), A·v₁ = A·v₂ = 0.

P = (1, 1, 0, 0) + Lin(v₁, v₂), dim P = 4 − 2 = 2 (плоскость в ℝ⁴).

Сумма, пересечение, прямая сумма

Сумма, пересечение, прямая сумма

Сумма L₁ + L₂ — все векторы x₁ + x₂, где x₁ ∈ L₁, x₂ ∈ L₂. Пересечение L₁ ∩ L₂ — векторы, лежащие в обоих. Оба множества — подпространства. Если L₁ ∩ L₂ = {0}, сумму называют прямой и пишут L₁ ⊕ L₂ (в пособии просто L₁ + L₂).

  • Объединение — не сумма. Две оси на плоскости: (1, 0) + (0, 1) = (1, 1) не лежит в объединении. L₁ + L₂ — наименьшее подпространство, содержащее оба.
  • Сумма. Если L₁ = Lin(a₁, …, aₖ), L₂ = Lin(b₁, …, bₘ), то L₁ + L₂ = Lin(a₁, …, aₖ, b₁, …, bₘ), и dim — ранг матрицы из всех этих векторов (статья 3.5).
  • Пересечение. Подпространства, заданные уравнениями, пересекают объединением уравнений в одну систему (решения — ФСР). Для оболочек с независимыми a₁, …, aₖ и b₁, …, bₘ (иначе сначала выброси лишние) решают Σxᵢaᵢ = Σyⱼbⱼ относительно коэффициентов; векторы Σxᵢaᵢ по базису решений — базис пересечения.
  • Формула размерностей (дополнительно): dim(L₁ + L₂) = dim L₁ + dim L₂ − dim(L₁ ∩ L₂). Базис пересечения дополняют до базисов L₁ и L₂ (теорема о дополнении, статья 3.9); все добавленные векторы вместе с базисом пересечения образуют базис суммы.
  • Прямая сумма: L₁ ∩ L₂ = {0} ⇔ dim(L₁ + L₂) = dim L₁ + dim L₂ ⇔ каждый вектор суммы единственным образом равен x₁ + x₂. Единственность: из x₁ + x₂ = y₁ + y₂ следует x₁ − y₁ = y₂ − x₂ ∈ L₁ ∩ L₂ = {0}. Объединение базисов L₁ и L₂ тогда — базис суммы.
Пример 3дополнительно: оболочки
В ℝ⁴ даны L₁ = Lin(a₁, a₂), L₂ = Lin(b₁, b₂), где a₁ = (1, 0, 1, 2), a₂ = (0, 1, −1, 1), b₁ = (1, 2, −1, 4), b₂ = (0, 0, 1, 1). Найти dim(L₁ + L₂) и L₁ ∩ L₂.

  1. Вектор b₁ = a₁ + 2a₂ лишний, а a₁, a₂, b₂ независимы (минор из первых трёх координат равен 1). Значит, ранг четырёх векторов равен 3 и dim(L₁ + L₂) = 3.

  2. Пересечение: x₁a₁ + x₂a₂ = y₁b₁ + y₂b₂ (пары a₁, a₂ и b₁, b₂ независимы: условие способа выполнено). Столбцы системы — a₁, a₂, −b₁, −b₂; приведённый вид (статья 2.8):

    10−1001−2000010000

    Откуда x₁ = y₁, x₂ = 2y₁, y₂ = 0; свободна y₁. Вектор пересечения y₁b₁, и L₁ ∩ L₂ = Lin(b₁).

  3. Проверка по формуле: 2 + 2 − 1 = 3. Сумма не прямая: пересечение не нулевое.

dim(L₁ + L₂) = 3, L₁ ∩ L₂ = Lin((1, 2, −1, 4)).

Пример 4дополнительно: подпространства-уравнения
В ℝ⁴ L₁: x₁ + x₂ + x₃ + x₄ = 0, L₂: x₁ − x₂ + x₃ − x₄ = 0. Найти L₁ ∩ L₂ и dim(L₁ + L₂).

  1. Пересечение — решения обоих уравнений. Приведём матрицу системы:

    11111−11−1R2 − R111110−20−2R2 · −1/211110101R1 − R210100101

  2. Откуда x₁ = −x₃, x₂ = −x₄, базис пересечения (−1, 0, 1, 0), (0, −1, 0, 1), dim = 2. Каждое Lᵢ задано одним уравнением, dim Lᵢ = 3, поэтому dim(L₁ + L₂) = 3 + 3 − 2 = 4.

L₁ ∩ L₂ = Lin((−1, 0, 1, 0), (0, −1, 0, 1)), L₁ + L₂ = ℝ⁴ (сумма не прямая).

Пример 5дополнительно: прямая сумма
L₁ — плоскость x + 2y − z = 0, L₂ = Lin((1, 1, 1)). Показать, что ℝ³ = L₁ ⊕ L₂, и разложить x = (4, 0, 2).

  1. Вектор (1, 1, 1) не лежит в L₁ (1 + 2 − 1 = 2 ≠ 0), поэтому L₁ ∩ L₂ = {0}, а 2 + 1 = 3 = dim ℝ³: сумма прямая и равна ℝ³.

  2. Ищем x = x₁ + t(1, 1, 1) с x₁ ∈ L₁: условие (4 − t) + 2(0 − t) − (2 − t) = 2 − 2t = 0 даёт t = 1. Тогда x₂ = (1, 1, 1), x₁ = (3, −1, 1); проверка: 3 − 2 − 1 = 0.

x = (3, −1, 1) + (1, 1, 1).

Пересечение многообразий. Подпространства всегда имеют общий нуль, а многообразия P₁ = L₁ + a и P₂ = L₂ + b могут не пересекаться. Если общая точка c есть, то P₁ = L₁ + c, P₂ = L₂ + c и P₁ ∩ P₂ = (L₁ ∩ L₂) + c (условие x ∈ P₁ и x ∈ P₂ — это x − c ∈ L₁ и x − c ∈ L₂). На языке систем: объединяем уравнения; несовместная система — пересечение пусто. На плоскости прямые y = x/2 и y = x/2 + 2 (рисунок выше), то есть x − 2y = 0 и x − 2y = −4, не пересекаются; прямые x + y = 2 и x − y = 0 пересекаются в точке (1, 1): здесь L₁ ∩ L₂ = {0}, поэтому P₁ ∩ P₂ = (1, 1) + {0}.

Смешанное пересечение: L₁ задано оболочкой, L₂ — уравнениями. Подставь x = t₁a₁ + t₂a₂ в уравнения и реши систему на t. Пример: a₁ = (1, 1, 0, 2), a₂ = (0, 1, 1, −1), L₂: x₁ − x₂ + x₃ + x₄ = 0. Вектор x = (t₁, t₁ + t₂, t₂, 2t₁ − t₂), уравнение даёт 2t₁ − t₂ = 0, t₂ = 2t₁, x = t₁(a₁ + 2a₂) = t₁(1, 3, 2, 0): L₁ ∩ L₂ = Lin((1, 3, 2, 0)).

Подпространство решений и ФСР

Решения однородной системы AX = 0 образуют подпространство ℝⁿ (статья 3.5). Базис этого подпространства — фундаментальная система решений (ФСР), dim = n − r, где r — ранг A (статья 2.6). Почему так: в общем решении каждая свободная неизвестная входит только в «свой» вектор eⱼ, где она равна 1, а в остальных 0; поэтому Σcⱼeⱼ = 0 даёт все cⱼ = 0, а любое решение — комбинация eⱼ. Это задача 1 «теста» практики 4: найти какой-нибудь базис и размерность пространства решений. Для системы 3 × 5 всегда r ≤ 3, то есть dim ≥ 2; если все три уравнения пропорциональны, r = 1 и dim = 4. Любые n − r независимых решений тоже образуют базис, поэтому твой ответ может отличаться от чужого: проверяй подстановкой в систему и независимостью.

Пример 6дополнительно: пять неизвестных
Найти базис и размерность пространства решений: x₁ + 2x₂ + x₄ − x₅ = 0, 2x₁ + 4x₂ + x₃ + 3x₅ = 0, 3x₁ + 6x₂ + x₃ + x₄ + 2x₅ = 0.

  1. Вычтем из второй строки удвоенную первую, из третьей — утроенную первую, затем из третьей вторую:

    1201−12410336112R2 − 2·R11201−1001−2536112R3 − 3·R11201−1001−25001−25R3 − R21201−1001−2500000

  2. Ранг 2: ведущие неизвестные x₁ и x₃ (не x₁, x₂!), свободные x₂, x₄, x₅; dim = 5 − 2 = 3. Из строк x₁ = −2x₂ − x₄ + x₅, x₃ = 2x₄ − 5x₅.

  3. Свободным по очереди даём (1, 0, 0), (0, 1, 0), (0, 0, 1): (−2, 1, 0, 0, 0), (−1, 0, 2, 1, 0), (1, 0, −5, 0, 1). Подстановка в три уравнения даёт нули.

dim = 3, базис (−2, 1, 0, 0, 0), (−1, 0, 2, 1, 0), (1, 0, −5, 0, 1).

Дроби

Если в выражении ведущих неизвестных появились дроби, умножь свободные на общий знаменатель: вектор можно умножать на число ≠ 0, это по-прежнему базис. Например, для 3x₁ + x₂ − 2x₃ + x₅ = 0, x₁ + 2x₂ + x₃ − x₄ = 0 знаменатель 5, и годится (1, −1, 1, 0, 0), (−1, 3, 0, 5, 0), (−2, 1, 0, 0, 5). Дроби в самих уравнениях убирают умножением уравнения на общий знаменатель.

Опечатки и неясности в пособии практики

  • Теория, стр. 2 (пересечение). Напечатано D = L₁ ∩ P₂; верно D = L₁ ∩ L₂: P — обозначение многообразий, а пересекаются два подпространства.
  • Задача 4, варианты 4.17 и 4.18 (повтор базиса). Базис напечатан одинаково (e′₁ = e₁ + e₂ − 3e₃, e′₂ = (3/4)e₁ − e₂, e′₃ = −e₁ + e₂ + e₃), различаются только x. Возможна опечатка: у 24 вариантов из 31 есть «парный», где коэффициенты при e₃ в e′₁ и при e₁ в e′₂ поменялись местами (для 4.18 это был бы e′₁ = e₁ + e₂ + (3/4)e₃, e′₂ = −3e₁ − e₂). Но при напечатанном базисе x′ = (2, −4, −2) целый, как во всех остальных вариантах, а при «парном» вышли бы дроби, так что, скорее всего, напечатано верно. Частые ошибки

Так нельзя

Сумма подпространств — это их объединение; dim(L₁ + L₂) = dim L₁ + dim L₂.

Так правильно

Сумма — оболочка объединения. Размерности складываются только для прямой суммы; в общем случае вычитается dim(L₁ ∩ L₂).

Так нельзя

Два многообразия, как и два подпространства, всегда пересекаются.

Так правильно

У подпространств есть общий нуль, а у многообразий общей точки может не быть: параллельные прямые, несовместная система уравнений.

Так нельзя

Линейное многообразие L + x₀ — подпространство при любом x₀.

Так правильно

Только при x₀ ∈ L, то есть когда 0 ∈ P. Множество решений AX = B с B ≠ 0 через нуль не проходит.

Так нельзя

В базис решений берут ведущие неизвестные или столбцы приведённой матрицы.

Так правильно

ФСР: по одному вектору на каждую свободную неизвестную, всего n − r. Ведущими неизвестными не обязательно будут x₁, x₂, ….

Кратко для повторения

Кратко для повторения

  • Линейное многообразие P = L + x₀; dim P = dim L; любой элемент P годится в роли x₀; P — подпространство ⇔ x₀ ∈ L.
  • Решения совместной AX = B: X₀ + L, где L — решения AX = 0, dim = n − r.
  • L₁ + L₂ = Lin объединения порождающих; L₁ ∩ L₂ — общая система уравнений (или система на коэффициенты); dim(L₁ + L₂) = dim L₁ + dim L₂ − dim(L₁ ∩ L₂).
  • Прямая сумма: L₁ ∩ L₂ = {0}, разложение x₁ + x₂ единственно, dim складываются. Пересечение многообразий пусто (несовместная система) или равно (L₁ ∩ L₂) + c.
  • Базис пространства решений — ФСР: свободные неизвестные по очереди равны 1; дроби убирают умножением.
