Функции как векторы

Все непрерывные функции ℝ → ℝ образуют пространство C(ℝ). Операции поточечные: (f + g)(x) = f(x) + g(x), (λf)(x) = λ·f(x); результаты снова непрерывны. Нуль-вектор — функция 0(x) ≡ 0, противоположный к f — −f. Аксиомы 1–8 верны в каждой точке как равенства чисел. Так же устроены Cᵏ(ℝ) (функции с k непрерывными производными) и ℝˣ (все функции на множестве X).

Размерность. Если в X ровно N точек, функция — набор (f(x₁), …, f(x_N)), и dim ℝˣ = N (статья 3.4). У C(ℝ) размерность бесконечна: 1, x, …, xⁿ независимы при любом n (ненулевой многочлен степени ≤ n имеет не больше n корней). У ℝˣ при бесконечном X тоже: индикаторы n различных точек (1 в одной, 0 в остальных) независимы. Не пространство: монотонные функции (x и −x³ монотонны, а x − x³ нет: её производная 1 − 3x² меняет знак).

Зависимость функций

Зависимость функций на интервале

Функции f₁, …, fₖ зависимы на интервале I, если есть числа λ₁, …, λₖ, не все нулевые, с λ₁f₁(x) + … + λₖfₖ(x) = 0 для всех x из I. Это определение статьи 3.2: нуль-вектор — нулевая функция, равенство должно быть тождеством, а не уравнением.

Заметь

«На интервале» входит в условие: x и |x| зависимы на (0, 1) (там они равны), но независимы на (−1, 1) (подстановка x = ±1/2).

  • Тождество (доказывает зависимость). Ищи готовую связь: sin²x + cos²x = 1, cos 2x = 1 − 2sin²x, ch²x − sh²x = 1, eˣ = sh x + ch x, формулы сложения. Для многочленов выпиши коэффициенты в базисе 1, x, x², … и найди ранг (статья 3.4).
  • Значения в точках (доказывает независимость). Тождество Σλᵢfᵢ(x) = 0 в k выбранных точках интервала (там все fᵢ определены) даёт однородную систему на λ с матрицей [fᵢ(xⱼ)]. Если определитель ≠ 0, все λ = 0: функции независимы. Если он = 0, ничего не доказано: смени точки или ищи тождество.
  • Рост и предел (степени, показательные) работает, если интервал неограничен сверху, то есть содержит луч (a, +∞), где тождество тоже верно. Раздели равенство на самую быструю функцию (остальные, делённые на неё, стремятся к нулю) и устреми x → +∞: остаётся её коэффициент, он нулевой. Повтори для оставшихся. Делить и умножать на функцию без нулей можно. На ограниченном интервале (1/x, x, 1 на (0, 1)) приём не годится: см. «Приём» ниже.
Пример 1дополнительно: тождество
Исследовать на зависимость 1, cos 2x, sin²x на (−∞, +∞).

  1. cos 2x = 1 − 2sin²x, то есть 1·1 − 1·cos 2x − 2·sin²x = 0 при всех x. Проверка при x = π/6: 1 − 1/2 − 2·1/4 = 0.

Зависимы: λ = (1, −1, −2).

Пример 2дополнительно: значения в точках
Исследовать на зависимость sin x, cos x, sin x·cos x на (−∞, +∞).

  1. Тождества не видно. Точки x = 0, π/4, −π/4; строки — значения sin, cos, sin·cos:

    010√2/2√2/212−√2/2√2/2−12= 0

    Нуль ничего не доказывает: тройка неудачная. Возьмём x = 0, π/4, π/2:

    010√2/2√2/212100= 1/2 ≠ 0

  2. Система Σλᵢfᵢ(xⱼ) = 0 имеет лишь нулевое решение, а тождество её влечёт: λ = 0.

Независимы.

Пример 3дополнительно: рост и предел
Исследовать на зависимость e⁻ˣ, 1, e⁴ˣ на (−∞, +∞).

  1. Пусть λ₁e⁻ˣ + λ₂ + λ₃e⁴ˣ = 0 при всех x (интервал неограничен сверху, x → +∞ допустимо). Разделим на e⁴ˣ: λ₁e⁻⁵ˣ + λ₂e⁻⁴ˣ + λ₃ = 0. При x → +∞ первые два слагаемых стремятся к нулю, поэтому λ₃ = 0. Остаётся λ₁e⁻ˣ + λ₂ = 0; снова x → +∞ даёт λ₂ = 0, и тогда λ₁e⁻ˣ = 0, то есть λ₁ = 0.

Независимы.

Приём

Дроби сводят к многочленам умножением на функцию без нулей: 1/x, 1, x² на (0, 2) умножим на x, получим λ₁ + λ₂x + λ₃x³ = 0 при всех x интервала. Многочлен с бесконечным числом корней нулевой: все λ = 0. Так же 1, tg x, ctg x на (0, π/2): t = tg x пробегает все t > 0, λ₁ + λ₂t + λ₃/t = 0, умножаем на t.

Разложение вектора по векторам фигуры

Нужно выразить вектор через рёбра треугольника, параллелограмма, параллелепипеда. Рёбра независимы (два не коллинеарны, три не компланарны), поэтому коэффициенты единственны (теорема 4, статья 3.3). Справочник:

Справочник
Что нужноФормула

Параллелограмм ABCDAC = AB + AD, BD = AD − AB (разность идёт от вычитаемого к уменьшаемому)
Середина M отрезка BCAM = (AB + AC)/2

Точка пересечения медиан O (центроид; в 1.8 практики — «центр») треугольника ABCAO = (AB + AC)/3; в пирамиде SABC для основания M: SM = (SA + SB + SC)/3

(Центроид: AO = (2/3)·AD, AD = (AB + AC)/2.) Трапеция ABCD, AD ∥ BC, AD = 2BC, M — середина CD: векторы BC и AD сонаправлены, BC = AD/2, AC = AB + BC = AB + AD/2, AM = (AC + AD)/2 = (1/2)·AB + (3/4)·AD. Приём «косые координаты»: вершина — начало, три выходящих из неё ребра — базис. Вершины параллелепипеда получают координаты из 0 и 1, точка на ребре — дробь, середина — полусумму, вектор — конец минус начало (статья 3.6).

Пример 4дополнительно: деление в отношении
В треугольнике ABC точка M лежит на BC, BM : MC = 4 : 3. Выразить AM через AB и AC.

  1. BM = (4/7)·BC = (4/7)(AC − AB), затем AM = AB + BM = (3/7)·AB + (4/7)·AC.

  2. Проверка: сумма коэффициентов 1; M ближе к C, и коэффициент при AC больше.

AM = (3/7)·AB + (4/7)·AC.

Пример 5дополнительно: система для коэффициентов
В параллелограмме ABCD точки K и L — середины BC и CD. Разложить AC по AK и AL.

  1. Пусть AB = b, AD = d: AK = b + d/2, AL = b/2 + d, AC = b + d. Для AC = α·AK + β·AL приравняем коэффициенты при независимых b и d: α + β/2 = 1, α/2 + β = 1. Вычитание даёт α = β, тогда α = β = 2/3.

AC = (2/3)·AK + (2/3)·AL.

Пример 6дополнительно: косые координаты
В параллелепипеде ABCDA₁B₁C₁D₁ точка P лежит на DD₁, DP : PD₁ = 1 : 3, а N — середина B₁C₁. Разложить PN по AB, AD, AA₁.

Параметр и коллинеарность

Параметр при k < n (три вектора в ℝ⁴). Определителя нет: приводим строки к ступенчатому виду, зависимость есть, если появилась нулевая строка.

Пример 8дополнительно
При каких a векторы d₁ = (1, −1, 2, 1), d₂ = (2, 1, 0, 3), d₃ = (4, −1, 4, a) зависимы?

  1. R₂ − 2R₁ = (0, 3, −4, 1), R₃ − 4R₁ = (0, 3, −4, a − 4), R₃ − R₂ = (0, 0, 0, a − 5):

    1−12103−41000a − 5

  2. «Комментарии» (какая комбинация стоит в строке): d₂ − 2d₁, d₃ − 4d₁, а в последней — (d₃ − 4d₁) − (d₂ − 2d₁) = d₃ − 2d₁ − d₂. Нулевая строка при a = 5 даёт d₃ − 2d₁ − d₂ = 0, то есть d₃ = 2d₁ + d₂. При a ≠ 5 ранг равен 3.

  3. Иначе: первые две координаты d₃ = λd₁ + μd₂ дают λ + 2μ = 4, −λ + μ = −1, то есть λ = 2, μ = 1. Третья координата сошлась (2λ = 4), четвёртая даёт a = λ + 3μ = 5. Не сойдись третья, зависимости не было бы ни при каком a: d₁, d₂ не пропорциональны (минор 1·1 − (−1)·2 = 3 ≠ 0), λ, μ определены однозначно, а a в первые три координаты не входит.

Зависимы при a = 5, независимы при a ≠ 5.

Абстрактные векторы. Пусть a, b, c некомпланарны (независимы). Вектор x₁a + y₁b + z₁c в базисе a, b, c — строка коэффициентов, и изоморфизм (статья 3.4) сохраняет зависимость: три вектора компланарны ⇔ определитель из коэффициентов равен нулю. Для a + b + c, a + kb + 2c, a + 2b + kc:

1111k212k= (k² − 4) − (k − 2) + (2 − k) = k(k − 2)

Компланарны при k = 0 и k = 2 (при k = 2 второй и третий векторы совпадают).

Коллинеарность c₁ = αa + βb и c₂ = γa + δb. Сначала проверь, что a и b независимы (иначе всё лежит на одной прямой, ответ «да»). Тогда c₁ ∥ c₂ ⇔ αδ − βγ = 0 (пропорциональность координат в базисе a, b). Пример: a = (2, 0, 1), b = (1, 1, −1), c₁ = 3a − 2b, c₂ = −9a + 6b: 3·6 − (−2)(−9) = 0; действительно c₁ = (4, −2, 5), c₂ = (−12, 6, −15) = −3c₁.

Коллинеарность с параметрами при независимых a, b, c. Вектор c₁ = a + p·b + 2c не нулевой (при a стоит 1), поэтому c₂ = q·a − 3b + 4c коллинеарен ему ⇔ c₂ = μc₁. Приравняем коэффициенты при a, b, c: q = μ, −3 = μp, 4 = 2μ. Отсюда μ = 2, q = 2, p = −3/2.

Теорема о дополнении до базиса

Теорема о дополнении (практика, стр. 14)

Любую независимую систему из k < n векторов n-мерного пространства можно дополнить до базиса (в пособии 1 ≤ k ≤ n; при k = n система уже базис, см. «Опечатки»). Идея: пока оболочка Lₖ меньше пространства, возьми вектор вне неё: независимость сохранится. Следствие: базис — максимальная независимая система.

Лемма (свойство 5, стр. 11). Если a₁, …, aₙ независимы, а a₁, …, aₙ, aₙ₊₁ зависимы, то aₙ₊₁ единственным образом раскладывается по a₁, …, aₙ. В зависимости Σλᵢaᵢ = 0 коэффициент λₙ₊₁ ≠ 0 (иначе зависимы a₁, …, aₙ), на него делим; два разложения вычитаем, и независимость даёт равенство коэффициентов.

В ℝⁿ: приведи векторы-строки к ступенчатому виду и добавь стандартные eⱼ для номеров j, где в ступенчатом виде нет ведущих элементов.

Сама теорема при k = n тривиальна и верна, ошибочна лишь эта строка доказательства.
  • Теория, стр. 11 (пример 2). Напечатано «k₁ = −2, k₂ = 1» как корни k² + k − 2 = 0, выведенного при k ≠ 1. Верно: определитель коэффициентов равен (1 − k) − (k − 1) + k(k² − 1) = (k − 1)(k² + k − 2) = (k − 1)²(k + 2); k = −2 — случай k ≠ 1, а k = 1 — случай k − 1 = 0 (все три вектора равны a + b + c). Частые ошибки

Так нельзя

M делит BC в отношении 4 : 3, значит, AM = (4/7)·AB + (3/7)·AC. Диагональ BD = AB − AD.

Так правильно

Вес стоит у противоположного конца: AM = (3/7)·AB + (4/7)·AC. Диагональ идёт от вычитаемого к уменьшаемому: BD = AD − AB, а AC = AB + AD.

Так нельзя

Определитель значений равен 0, значит, функции зависимы.

Так правильно

Зависимость — тождество при всех x. Определитель ≠ 0 в какой-то тройке точек доказывает независимость, = 0 — ничего.

Так нельзя

Коэффициенты соотношения e′₂ = e₁ − e₂ записать строкой T или пропустить отсутствующий e₃.

Так правильно

Коэффициенты формулы для e′ⱼ — j-й столбец T; отсутствующий вектор — коэффициент 0: (1, −1, 0).

Кратко для повторения

Кратко для повторения

  • Аксиомы 5–8 в практике идут в обратном порядке (5 ↔ 8, 6 ↔ 7).
  • Зависимость функций — тождество на всём интервале. Приёмы: тождество, значения в точках интервала (определитель ≠ 0 — независимы), рост и предел (интервал неограничен сверху).
  • BM : MC = m : n: AM = (n·AB + m·AC)/(m + n); точка пересечения медиан (AB + AC)/3; трапеция AD = k·BC: BC = AD/k; AB = (AC − BD)/2, AD = (AC + BD)/2.
  • Параметр при k < n — нулевая строка в ступенчатом виде; абстрактные векторы — определитель из коэффициентов (коллинеарность: c₂ = μc₁); базис дополняют eⱼ для столбцов без ведущих. Новый базис: коэффициенты формулы для e′ⱼ — столбец T, x′ = T⁻¹x.
