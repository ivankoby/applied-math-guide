Статья 10.2

Экстремумы: условие Ферма и два достаточных признака

Экстремум — это вершина холма или дно впадины на графике. Найти их помогает производная: вершины и впадины ищут среди критических точек (условие Ферма), а потом проверяют двумя признаками — по смене знака f′ и по знаку f″. Главное в статье — условия: у каждого признака они свои, и без них вывод ложен. Разберём контрпримеры лекции (экстремум без смены монотонности, функция x²(2 + cos(1/x))), гладкие и острые экстремумы, обобщение на старшие производные и закончим экстремумами примера 1.

Определение: экстремум локален

Определение 4.4.1 (лекция, стр. 1)

Пусть f определена в точке x₀ и в некоторой её окрестности U(x₀). Если f(x₀) ≥ f(x) для всех x ∈ U(x₀), то x₀ — точка максимума. Если f(x₀) ≤ f(x) для всех x ∈ U(x₀), то x₀ — точка минимума. Обе называют точками экстремума. Если в проколотой окрестности x ≠ x₀ неравенства строгие (f(x₀) > f(x) или f(x₀) < f(x)), экстремум строгий.

Слова «в некоторой окрестности» принципиальны: максимум в точке не обязан быть наибольшим значением функции (локальный максимум). Наибольшие и наименьшие значения на промежутке — отдельная задача (статья 10.3). Из определения ещё следует, что у конца отрезка окрестности внутри области определения нет, поэтому экстремумом в смысле определения конец отрезка не является. В дополнительных материалах в определение добавлено требование непрерывности f в точке; в лекции его нет (максимум в точке разрыва — пример 2 ниже), и здесь экстремум понимается как в лекции.

Необходимое условие: теорема Ферма

Теорема Ферма (теорема 4.4.1, лекция 9; в этой лекции — стр. 3)

Если функция дифференцируема в точке x₀ и имеет в ней экстремум, то f′(x₀) = 0.

Условие необходимое, но не достаточное: у f(x) = x³ производная 3x² обращается в нуль при x = 0, а экстремума нет (функция возрастает). Вывод для практики: экстремумы функции находятся среди её критических точек — нулей f′ и точек из D(f), где конечной производной нет (угол, острие, вертикальная касательная). В точках без производной Ферма молчит, и экстремум там возможен: минимум |x| в нуле. Внутренние точки области определения, где f′ существует и не равна нулю, экстремумов не дают.

Первый достаточный признак: смена монотонности

Теорема 4.7.2

Пусть f определена в точке x₀ и в окрестности (x₀ − δ, x₀ + δ), возрастает на (x₀ − δ, x₀] и убывает на [x₀, x₀ + δ). Тогда x₀ — точка максимума. Если f убывает на (x₀ − δ, x₀] и возрастает на [x₀, x₀ + δ), то x₀ — точка минимума.

Доказательство (максимум). Для x ∈ (x₀ − δ, x₀] по возрастанию f(x) ≤ f(x₀), для x ∈ [x₀, x₀ + δ) по убыванию f(x) ≤ f(x₀). Значит, f(x₀) ≥ f(x) во всей окрестности. Минимум — зеркально.

Следствие (в таком виде признак применяют)

Пусть f непрерывна в точке x₀ и дифференцируема в проколотой окрестности x₀. Если f′ ≥ 0 на (x₀ − δ, x₀) и f′ ≤ 0 на (x₀, x₀ + δ), то x₀ — точка максимума. Если f′ ≤ 0 слева и f′ ≥ 0 справа, то x₀ — точка минимума.

Доказательство: по теореме 4.7.1 f монотонна на (x₀ − δ, x₀), а так как f непрерывна в x₀, то (замечание 1 статьи 10.1) монотонность продолжается на (x₀ − δ, x₀]; справа так же. Дальше работает теорема 4.7.2. Говорят: в точке x₀ производная меняет знак с «+» на «−» (максимум) или с «−» на «+» (минимум). Читают слева направо, как идёт ось x. Если f непрерывна в x₀ и по обе стороны от x₀ производная одного строгого знака, то f строго монотонна в окрестности и экстремума нет. Для разрывной f это не так: в примере 2 ниже f′ > 0 по обе стороны от 1, а x = 1 — точка максимума.

Условия признака и контрпримеры лекции

  • 1. Если в теореме или следствии монотонность строгая, экстремум получается строгим.
  • 2. Без непрерывности в x₀ следствие неверно (рисунок на стр. 4).
  • 3. Условия только достаточные: экстремум бывает и без смены монотонности (пример 2) или при бесконечно частой смене знака (пример 3).

Пример 3. Функция f(x) = x²(2 + cos(1/x)) при x ≠ 0, f(0) = 0, имеет в нуле минимум: f(x) ≥ x² > 0 при x ≠ 0, f(0) = 0. Производная при x ≠ 0: f′(x) = 2x(2 + cos(1/x)) + sin(1/x), а f′(0) = lim x(2 + cos(1/x)) = 0. Знак f′ у нуля определяет слагаемое sin(1/x) (первое слагаемое мало). В точке x = 1/(20π + π/2) ≈ 0,0155 оно равно 1, и f′ ≈ 1,06 > 0; в точке x = 1/(20π − π/2) ≈ 0,0163 получаем sin = −1 и f′ ≈ −0,93 < 0. Такие точки есть сколь угодно близко к нулю, значит, f′ меняет знак бесконечно много раз. Признак по смене знака тут не применим, а экстремум есть: признаки лишь достаточные.

Гладкие и острые экстремумы

Гладкий и острый экстремум (лекция, стр. 5)

Экстремум в стационарной точке (f′(x₀) = 0, касательная горизонтальна) называют гладким. Экстремум в точке, где конечной производной нет, называют острым.

Примеры: x = 1/2 и x = 4 в примере 1 — гладкие максимумы; x = 3 — острый минимум (острие: f′ → −∞ слева и +∞ справа, касательная вертикальна); |x| в нуле — острый минимум с углом; x₃ на первом рисунке — острый максимум (угол). Слово «острый» относится к любому экстремуму без конечной f′ (угол, острие, разрыв); «острие» в статьях 10.1 и 10.4 — только случай, когда f′ бесконечна с разными знаками по сторонам.

Второй достаточный признак: знак второй производной

Теорема 4.7.3

Пусть x₀ — стационарная точка функции f (f′(x₀) = 0) и существует f″(x₀). Если f″(x₀) > 0, то x₀ — точка строгого минимума; если f″(x₀) < 0, то x₀ — точка строгого максимума.

Доказательство (лекция, стр. 6). По формуле Тейлора f(x) = f(x₀) + f′(x₀)(x − x₀) + f″(x₀)/2·(x − x₀)² + o((x − x₀)²). Так как f′(x₀) = 0, а f″(x₀) ≠ 0, получаем f(x) − f(x₀) = f″(x₀)/2·(x − x₀)²·(1 + α(x)), где α(x) → 0 при x → x₀. Выберем δ, чтобы |α(x)| < 1/2 при |x − x₀| < δ: тогда 1 + α > 0, и знак разности f(x) − f(x₀) совпадает со знаком f″(x₀). Для f″(x₀) > 0 это минимум, для f″(x₀) < 0 — максимум.

Обобщение (замечание на стр. 6)

Пусть существует f⁽ⁿ⁾(x₀) и f′(x₀) = f″(x₀) = … = f⁽ⁿ⁻¹⁾(x₀) = 0, но f⁽ⁿ⁾(x₀) ≠ 0. Если n нечётно, экстремума в x₀ нет. Если n чётно, экстремум есть: минимум при f⁽ⁿ⁾(x₀) > 0, максимум при f⁽ⁿ⁾(x₀) < 0.

Причина: f(x) − f(x₀) = f⁽ⁿ⁾(x₀)/n!·(x − x₀)ⁿ·(1 + α(x)), а степень (x − x₀)ⁿ меняет знак в x₀ при нечётном n и не меняет при чётном. Если f″(x₀) = 0, второй признак молчит: x⁴ (минимум), −x⁴ (максимум), x³ (нет экстремума) имеют в нуле f″ = 0.

Первый признак применим во всех этих случаях, кроме последнего, но требует таблицы знаков; второй короче, но нужны f′(x₀) = 0 и f″(x₀) ≠ 0.

Разобранные примеры

Пример 1 (продолжение): экстремумы ∛((x − 3)²)/(x² − 4)из лекции, стр. 5
Найти точки экстремума функции f(x) = ∛((x − 3)²) / (x² − 4) (таблица знаков f′ в статье 10.1, пример 1).

  1. Критические точки: 1/2, 3, 4; знаки f′ слева направо: + + − − + − (границы −2, 1/2, 2, 3, 4). Функция в этих точках непрерывна, так что следствие из теоремы 4.7.2 применимо.

  2. x = 1/2: знак меняется с + на − — максимум, f(1/2) = ∛(25/4)/(−15/4) ≈ −0,4912. Точка стационарная: максимум гладкий, касательная горизонтальна.

  3. x = 3: знак меняется с − на + — минимум, f(3) = 0. Конечной производной в этой точке нет (∛(x − 3) в знаменателе): f′ → −∞ слева и f′ → +∞ справа (острие, как у ∛(x²)), касательная вертикальна, минимум острый. Второй признак здесь неприменим: f′(3) не существует.

  4. x = 4: знак меняется с + на − — гладкий максимум, f(4) = 1/12 ≈ 0,0833. В x = ±2 экстремумов нет: этих точек нет в D(f).

максимумы в x = 1/2 и x = 4, острый минимум в x = 3.

Пример 2: f″(x₀) = 0, второй признак молчитдополнительно
Найти экстремумы функции f(x) = x⁴ − 4x³.

  1. D(f) = ℝ, f′ = 4x³ − 12x² = 4x²(x − 3). Стационарные точки: x = 0 и x = 3. Вторая производная f″ = 12x² − 24x.

  2. x = 3: f″(3) = 108 − 72 = 36 > 0, значит, строгий минимум, f(3) = 81 − 108 = −27.

  3. x = 0: f″(0) = 0, признак молчит. Применим первый: множитель 4x² положителен при x ≠ 0, а x − 3 < 0 левее 3, поэтому f′ < 0 по обе стороны от нуля, знак не меняется — экстремума нет. Сверка: f‴ = 24x − 24, f‴(0) = −24 ≠ 0, n = 3 нечётно — экстремума нет.

минимум f(3) = −27; в x = 0 экстремума нет (хотя f′(0) = 0).

Частые ошибки

Так нельзя

«f′(x₀) = 0, значит, там экстремум».

Так правильно

Нужен признак. x³ и x⁴ − 4x³ в нуле имеют f′ = 0 без экстремума.

Так нельзя

«f″(x₀) = 0, значит, экстремума нет».

Так правильно

Второй признак молчит: у x⁴ в нуле f″ = 0, а минимум есть. Смотри знак f′ или старшую производную.

Так нельзя

Применять второй признак в точке, где f′ не существует (острый экстремум).

Так правильно

Теорема 4.7.3 требует f′(x₀) = 0 и f″(x₀). В угловой точке или остриё действует только первый признак.

Так нельзя

Читать смену знака справа налево или не следить за ориентацией.

Так правильно

Знак f′ читают слева направо: + → − — максимум, − → + — минимум.

Так нельзя

Применить следствие без проверки непрерывности: «f′ с + на −, значит, максимум».

Так правильно

На разрывной функции вывод ложен (замечание 2): f = x при x ≤ 1, f = 3 − x при x > 1.

Кратко для повторения

Кратко для повторения

  • Экстремум локален: f(x₀) ≥ f(x) (максимум) или ≤ (минимум) в окрестности x₀; строгий — для x ≠ x₀ неравенства строгие.
  • Ферма: экстремум и f′(x₀) существует ⟹ f′(x₀) = 0. Кандидаты — критические точки.
  • Первый признак: f непрерывна в x₀, дифференцируема в проколотой окрестности; + → − — максимум, − → + — минимум; без смены знака (строго) — экстремума нет. Условия достаточные.
  • Второй признак: f′(x₀) = 0, f″(x₀) > 0 — минимум, < 0 — максимум; при f″(x₀) = 0 молчит.
  • Старшие производные: первая ненулевая f⁽ⁿ⁾(x₀): n нечётно — нет экстремума, n чётно — минимум при > 0, максимум при < 0.
  • Гладкий экстремум — f′ = 0; острый — конечной f′ нет.

Найдите значение функции f(x) = 2x³ − 9x² + 12x в точке её локального минимума.

Показать решение
