Экстремум — понятие локальное, а в задачах спрашивают другое: какое значение функции наибольшее (наименьшее) на данном промежутке. Для непрерывной функции на отрезке ответ даёт короткое правило: посчитать значения в критических точках и на концах и сравнить числа. В статье — правило со всеми условиями и обоснованием, пример 4 лекции (прямоугольник в треугольнике) с проверкой концов, числовые примеры (в том числе острая критическая точка) и текстовые задачи на оптимум. Числовые примеры и задачи на оптимум — дополнительно к лекции, стандартным методом.

Локальный экстремум и наибольшее значение

Наибольшее значение функции на множестве X — число M = f(x*), x* ∈ X, для которого f(x) ≤ M при всех x ∈ X; наименьшее — зеркально. Экстремум сравнивает значение только с соседними, наибольшее — со всеми значениями на X. Лекция (стр. 6) отмечает, что эти числа могут не совпадать с экстремальными, и поэтому экстремумы называют локальными.

Существование гарантирует теорема Вейерштрасса (лекция 7, статья 7.6, «Теорема 1»; в лекции 10 её часть о достижении граней названа второй теоремой Вейерштрасса, 4.4.5): функция, непрерывная на отрезке [a, b], достигает на нём наибольшего и наименьшего значений. Без условий вывод ложен: x на (0; 1) не имеет ни наибольшего, ни наименьшего значения; 1/x на (0; 1] не ограничена сверху; f(x) = x при x < 1, f(1) = 0 разрывна, и на [0; 1] у неё нет наибольшего. Теорема даёт достаточное условие, не необходимое: 1/x на [1; +∞) не отрезок, но наибольшее значение 1 есть.

Правило и алгоритм

Правило (лекция, стр. 6)

Пусть промежуток замкнутый [a, b], функция f непрерывна на нём, имеет конечную или бесконечную производную, и отрезок можно разбить на конечное число частей, на каждой из которых f′ сохраняет постоянный знак. Тогда найди критические точки f на [a, b], вычисли значения f в них и на концах a, b. Наибольшее из этих чисел — наибольшее значение, наименьшее — наименьшее значение f на [a, b].

Почему так (дополнительно): критические точки режут отрезок на части, где f монотонна (теорема 4.7.1). Монотонная непрерывная функция принимает наибольшее и наименьшее значения на концах части. Концы частей — это концы [a, b] и критические точки, поэтому кандидатов конечное число. Классифицировать критические точки (максимум это или минимум) не нужно: достаточно сравнить числа.

  • Шаг 1. Проверь условия правила: промежуток — замкнутый отрезок, f непрерывна на нём (нет разрывов внутри), производная конечная или бесконечная, а участков знакопостоянства f′ конечное число (у элементарных функций это выполнено).
  • Шаг 2. Найди f′ и критические точки: нули f′ и точки без конечной f′, в которых f определена.
  • Шаг 3. Оставь только критические точки, лежащие в [a, b]; точки вне отрезка отбрасывай.
  • Шаг 4. Вычисли f в оставшихся критических точках и в a, b.
  • Шаг 5. Выбери наибольшее и наименьшее число; запиши значения и точки, где они достигаются (их может быть несколько).

Пример 4 лекции: прямоугольник в треугольнике

Пример 4: наибольшая площадь вписанного прямоугольникаиз лекции, стр. 7
В треугольник с основанием a и высотой h вписан прямоугольник: основание прямоугольника лежит на основании треугольника, две другие вершины — на боковых сторонах. Найти стороны прямоугольника наибольшей площади.

  1. Переменные. Пусть PQ = x — основание прямоугольника, MP = y — его высота. Площадь S = xy. Две переменные связаны подобием треугольников ABC и MBN (MN ∥ AC): AC/MN = BE/BF, то есть a/x = h/(h − y), откуда x = a(h − y)/h.

  2. Одна переменная и её область. S(y) = (a/h)(h − y)y, y ∈ [0; h]: высота прямоугольника не меньше нуля и не больше высоты треугольника. Функция непрерывна на отрезке, правило применимо.

  3. Критические точки. S′(y) = (a/h)(h − 2y); нуль один, y = h/2 ∈ [0; h]. Значение в нём S(h/2) = (a/h)(h/2)(h/2) = ah/4.

  4. Концы. S(0) = S(h) = 0 (вырожденные прямоугольники: высота нуль или основание нуль). Наибольшее из чисел 0, ah/4, 0 — ah/4.

  5. Стороны. y = h/2, x = a(h − h/2)/h = a/2. Площадь ah/4 — ровно половина площади треугольника ah/2, форма треугольника на ответ не влияет. Проверка числами a = 8, h = 6: y = 3, x = 4, S = 12, а перебор значений S по y ∈ [0; 6] не даёт больше 12.

x = a/2, y = h/2, наибольшая площадь ah/4.

Числовые примеры (дополнительно к лекции)

Пример 5: наименьшее значение достигается в двух точкахдополнительно
Найти наибольшее и наименьшее значения f(x) = x³ − 6x² + 9x + 1 на [0; 5].

  1. f — многочлен, непрерывна. f′ = 3x² − 12x + 9 = 3(x − 1)(x − 3), критические точки x = 1 и x = 3, обе в [0; 5].

  2. Значения: f(0) = 1, f(1) = 5, f(3) = 27 − 54 + 27 + 1 = 1, f(5) = 125 − 150 + 45 + 1 = 21.

  3. Наибольшее 21 (в конце x = 5), наименьшее 1, и достигается оно дважды: в конце x = 0 и во внутренней точке x = 3. Локальный максимум f(1) = 5 наибольшим значением не является.

наибольшее 21 при x = 5; наименьшее 1 при x = 0 и x = 3.

Пример 6: острая критическая точкадополнительно
Найти наибольшее и наименьшее значения f(x) = 2x − 3∛(x²) на [−1; 2].

  1. f непрерывна на ℝ. f = 2x − 3x2/3, f′ = 2 − 2x−1/3 = 2(∛x − 1)/∛x. Нуль f′: x = 1. Конечной производной нет в x = 0, но f(0) = 0 определена: критическая точка. Обе точки лежат в [−1; 2].

  2. Значения: f(−1) = −2 − 3 = −5, f(0) = 0, f(1) = 2 − 3 = −1, f(2) = 4 − 3∛4 ≈ −0,762.

  3. Наибольшее значение 0 достигается в острой критической точке x = 0, наименьшее −5 — в конце x = −1.

наибольшее 0 при x = 0; наименьшее −5 при x = −1.

Задачи на оптимум: алгоритм

  • 1. Выбери одну переменную x (если их две, выражай одну через другую по условию задачи).
  • 2. Запиши величину, которую оптимизируешь, как функцию f(x).
  • 3. Найди область изменения x из смысла задачи (длины неотрицательны, форма должна существовать): чаще всего получится отрезок.
  • 4. Примени правило для отрезка. Если область — интервал, теорема Вейерштрасса не работает: найди критические точки и проверь знак f′. Если f непрерывна на интервале, критическая точка на нём единственна и f′ меняет в ней знак с − на +, то в ней наименьшее значение на всём интервале (с + на − — наибольшее): f убывает левее неё и возрастает правее.
  • 5. Ответь на вопрос задачи (стороны, радиус, площадь): после нахождения x найди все остальные величины.
Пример 7: коробка из квадратного листадополнительно
Из квадратного листа картона со стороной 12 см по углам вырезают одинаковые квадраты со стороной x и загибают края, получая коробку без крышки. При каком x объём наибольший?

  1. Основание коробки — квадрат со стороной 12 − 2x, высота x: V(x) = x(12 − 2x)². Область: x ≥ 0 и 12 − 2x ≥ 0, то есть x ∈ [0; 6].

  2. V′ = (12 − 2x)² + x·2(12 − 2x)·(−2) = (12 − 2x)(12 − 6x) = 12(x − 2)(x − 6). Критические точки x = 2 и x = 6, обе в [0; 6].

  3. V(0) = 0, V(2) = 2·8² = 128, V(6) = 0. Наибольший объём 128 см³ при x = 2 (сторона основания 8 см).

x = 2 см, наибольший объём 128 см³.

Пример 8: банка заданного объёма, интервалдополнительно
Закрытая цилиндрическая банка должна вмещать 54π см³. При каком радиусе r площадь поверхности наименьшая? Чему равна высота?

  1. V = πr²h = 54π, h = 54/r². Площадь S = 2πr² + 2πrh = 2πr² + 108π/r. Область: r ∈ (0; +∞) — интервал, поэтому Вейерштрасс не применим.

  2. S′ = 4πr − 108π/r² = 4π(r³ − 27)/r². Единственная критическая точка r = 3; левее неё S′ < 0, правее S′ > 0. Значит, в r = 3 наименьшее значение на всём интервале: S убывает на (0; 3] и возрастает на [3; +∞). Пределы на границах: S → +∞ при r → 0 + 0 (слагаемое 108π/r) и при r → +∞ (слагаемое 2πr²), так что наибольшего значения у S нет.

  3. h = 54/9 = 6 = 2r, S(3) = 18π + 36π = 54π ≈ 169,6 см².

r = 3 см, h = 6 см, наименьшая площадь 54π ≈ 169,6 см².

Число корней уравнения f(x) = c (дополнительно). Горизонталь y = c пересекает график столько раз, сколько позволяют значения в критических точках. Для f(x) = x³ − 12x локальный максимум f(−2) = 16, минимум f(2) = −16, f → ±∞ на концах. Поэтому x³ − 12x = c имеет три различных корня при |c| < 16, два (один из них двойной) при |c| = 16 и один при |c| > 16.

Частые ошибки

Так нельзя

Взять в ответ только значения во внутренних критических точках: «наибольшее — это локальный максимум».

Так правильно

Концы отрезка тоже кандидаты. У x³ − 6x² + 9x + 1 на [0; 5] наибольшее 21 лежит на конце, а локальный максимум 5 не наибольший.

Так нельзя

Вычислять значение в критической точке, лежащей вне отрезка.

Так правильно

Критические точки, не принадлежащие [a, b], отбрасывают (шаг 3). Значение в них к отрезку отношения не имеет.

Так нельзя

Применять правило на интервале или к разрывной функции.

Так правильно

Нужны условия шага 1, прежде всего отрезок и непрерывность. На интервале проверяют знак f′ и пределы на границах (пример 8): они показывают, есть ли наибольшее значение.

Так нельзя

Забыть ответить на вопрос задачи: нашли x, а просят площадь.

Так правильно

После x найди то, о чём спрашивают, и проверь, что x лежит в области (в примере 4 y ∈ [0; h]).

Так нельзя

Не заметить, что наибольшее значение достигается в двух точках, или потерять острую критическую точку (знаменатель f′).

Так правильно

Точки, где f′ не существует, но f определена, — тоже кандидаты (пример 6). Значения сравнивай все.

Кратко для повторения

Кратко для повторения

  • Наибольшее и наименьшее значения сравнивают со всеми значениями на промежутке; экстремумы — только с соседними (локальные).
  • Вейерштрасс: f непрерывна на [a, b] ⟹ наибольшее и наименьшее значения достигаются. На интервале и у разрывных функций вывод не гарантирован.
  • Правило (условия — шаг 1): критические точки внутри [a, b] + концы; вычислить, сравнить, записать значение и точку. Классифицировать критические точки не нужно.
  • Оптимум: одна переменная → функция → область (из смысла задачи) → правило → ответ на вопрос задачи. На интервале с единственной критической точкой знак f′ решает дело.
  • Число корней: значения в экстремумах и пределы на концах показывают, сколько раз горизонталь y = c пересекает график.

Проверь себя

Задания для самопроверки

Решено: 0 из 6

Выберите вариант, заполните пропуски или введите число (допустимы дроби вида 1/3 и десятичные 0,25), затем «Проверить».

1
Найдите наибольшее значение функции f(x) = x³ − 3x на отрезке [−2; 3].

Показать решение

f′ = 3x² − 3, критические точки x = ±1 (обе в [−2; 3]). f(−2) = −8 + 6 = −2, f(−1) = 2, f(1) = −2, f(3) = 27 − 9 = 18. Наибольшее 18 — на конце x = 3, а локальный максимум 2 его не даёт.

2
Найдите наименьшее значение функции f(x) = x + 9/x на отрезке [1; 6].

Показать решение

f′ = 1 − 9/x² = 0 при x = 3 (внутри отрезка; x = −3 не лежит в [1; 6] — отбрасываем). f(1) = 10, f(3) = 6, f(6) = 7,5. Наименьшее значение 6, наибольшее 10.

3
Ищем наименьшее значение f(x) = x³ − 3x² на отрезке [0; 3/2]. В каком шаге допущена первая ошибка?
Варианты ответа

Показать решение

Точка x = 2 не принадлежит отрезку [0; 3/2], её нужно было отбросить. Кандидаты: f(0) = 0, f(3/2) = 27/8 − 27/4 = −27/8. Наименьшее значение −27/8 на правом конце, наибольшее 0 на левом.

4
Для каких пар «функция — промежуток» наибольшее значение существует? Отметьте все верные.
Варианты ответа; можно выбрать несколько

Показать решение

1/x убывает на [1; +∞), наибольшее значение 1 в точке x = 1 — хотя промежуток не отрезок. sin x достигает 1 в x = π/2 ∈ (0; π). У остальных пар точная верхняя граница не достигается или значения не ограничены. Теорема Вейерштрасса — только достаточное условие.

5
Участок прямоугольной формы примыкает к стене. Три стороны ограждают забором длиной 60 м, сторона у стены не ограждается. Найдите наибольшую возможную площадь участка (в м²).

Показать решение

Пусть x — две стороны, перпендикулярные стене; третья 60 − 2x. S(x) = x(60 − 2x), x ∈ [0; 30]. S′ = 60 − 4x = 0 при x = 15. S(0) = S(30) = 0, S(15) = 15·30 = 450. Наибольшая площадь 450 м².

6
Сколько различных действительных корней имеет уравнение x³ − 12x = 16?

Показать решение

f = x³ − 12x, f′ = 3x² − 12, f(−2) = 16 (локальный максимум), f(2) = −16 (минимум). Горизонталь y = 16 касается графика в x = −2 (двойной корень) и пересекает его ещё в x = 4 (64 − 48 = 16). Различных корней два: x³ − 12x − 16 = (x + 2)²(x − 4).
