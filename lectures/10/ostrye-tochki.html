Статья 10.7

Исследование функции с корнями: острые точки

Функции с корнями нечётной степени и дробными степенями ведут себя иначе, чем многочлены и дроби: у них есть особые точки, где производная бесконечна, а сама функция определена (экстремум в такой точке называют острым). В статье — что нужно знать при работе с такими функциями (область определения, знак кубического корня, критические точки с бесконечной производной), полный разбор примера 10 лекции (∛(x²/(x + 2)): острый минимум, две точки перегиба, вертикальная асимптота с разными знаками бесконечности) и дополнительный пример ln x/x, где область определения — полупрямая.

Особенности функций с корнями

  • Область определения. Корень нечётной степени (∛u) определён при любых u и имеет знак u. Корень чётной степени (√u) требует u ≥ 0. Для ∛(x²) пишут x2/3 = (∛x)²: так формула верна и при x < 0 (запись «степень 2/3» в калькуляторе при x < 0 может дать ошибку).
  • Производная. (xp/3)′ = (p/3)x(p−3)/3: при p = 1, 2 в знаменателе появляется кубический корень из x, и в x = 0 конечной производной нет, хотя f(0) определена. Такая точка критическая (статья 10.1); если экстремум в ней есть, он острый (статья 10.2).
  • Знаки. Корень нечётной степени имеет знак подкоренного выражения, а корень любой степени из положительного числа положителен. Поэтому (x + 2)4/3 = ∛((x + 2)⁴) > 0 при x ≠ −2 и ∛(x⁴) > 0 при x ≠ 0 (под корнем чётная степень). Это упрощает таблицу знаков: нужные множители можно отбросить.
  • Сложная дробь под корнем. Удобно дифференцировать по правилу (u1/3)′ = u′/(3u2/3) и приводить к общему знаменателю; вторую производную можно искать по правилу произведения.

Пример 10 лекции: ∛(x²/(x + 2))

Пример 10: полное исследование ∛(x²/(x + 2))из лекции, стр. 14–15
Исследовать функцию f(x) = ∛(x²/(x + 2)) и построить график.

  1. 1) Область определения. Кубический корень существует для любого значения под корнем, дробь — при x ≠ −2. D(f) = (−∞; −2) ∪ (−2; +∞), x = −2 — разрыв. 2) Чётность. D(f) несимметрична (2 ∈ D, −2 ∉ D): ни чётная, ни нечётная.

  2. 3) Монотонность. Пусть g = x²/(x + 2). Тогда g′ = (2x(x + 2) − x²)/(x + 2)² = x(x + 4)/(x + 2)², и f′ = g′/(3g2/3) = [x(x + 4)/(x + 2)²]·(x + 2)2/3/(3x4/3). Приводя степени (x/x4/3 = x−1/3, (x + 2)2/3/(x + 2)² = (x + 2)−4/3), получаем

    f′(x) = (x + 4)/(3·∛x·∛((x + 2)⁴))

    Критические точки: x = −4 (f′ = 0, стационарная) и x = 0 (в знаменателе ∛x = 0, конечной f′ нет, а f(0) = 0 определена). x = −2 ∉ D(f) — «дырка». Корень ∛((x + 2)⁴) > 0 при x ≠ −2, знак f′ задаёт дробь (x + 4)/∛x.

    Возрастает на (−∞; −4] и [0; +∞), убывает на [−4; −2) и (−2; 0]. В x = −4 гладкий максимум f(−4) = ∛(16/(−2)) = −2. В x = 0 острый минимум f(0) = 0: слева f′ → −∞, справа f′ → +∞, касательная вертикальна, график — «клюв» вниз.

  3. 4) Выпуклость. Запишем f′ = (1/3)(x + 4)·g₁, g₁ = x−1/3(x + 2)−4/3. По правилу произведения f″ = (1/3)g₁[1 − (x + 4)(1/(3x) + 4/(3(x + 2)))] = (1/3)g₁·(−2)(x² + 8x + 4)/(3x(x + 2)). Итог:

    f″(x) = −2(x² + 8x + 4) / (9·∛(x⁴)·∛((x + 2)⁷))

    Трёхчлен x² + 8x + 4 = (x + 4 − 2√3)(x + 4 + 2√3) (корни x = −4 ± 2√3). Кандидаты: x₁ = −4 − 2√3 ≈ −7,46, x₂ = −4 + 2√3 ≈ −0,54 и x = 0, где f″ не существует. Знаменатель имеет знак x + 2, числитель −2(x² + 8x + 4) положителен между x₁ и x₂.

    Выпукла вниз на (−∞; x₁) и (−2; x₂), вверх на (x₁; −2), (x₂; 0) и (0; +∞). Перегибы: x₁ и x₂ (там f′ конечна), f(x₂) ≈ 0,58, f(x₁) ≈ −2,17. В x = 0 перегиба нет: острие, знак f″ не меняется.

  4. 5) Асимптоты. x → −2 − 0: x² → 4, а x + 2 → 0 со знаком −, поэтому x²/(x + 2) → −∞ и f → −∞; x → −2 + 0: f → +∞. Прямая x = −2 — вертикальная асимптота (с разными знаками бесконечности). На бесконечности f(x) ~ ∛x: k = lim f(x)/x = 0, но b = lim f(x) = ±∞, поэтому ни наклонных, ни горизонтальных асимптот нет.

  5. 6) Точки. f(x) = 0 только при x = 0; знак f совпадает со знаком x + 2. 7) График — ниже.

максимум f(−4) = −2, острый минимум f(0) = 0, перегибы x = −4 ± 2√3, асимптота x = −2.

Замечание

В лекции на стр. 15 указано f(−4 − 2√3) ≈ −2,1. Точнее f(−4 − 2√3) ≈ −2,17: в лекции цифры после десятых отброшены (округление до десятых даёт −2,2). Значение f(−4 + 2√3) ≈ 0,6 округлено верно (≈ 0,58).

Ещё пример: ln x / x (дополнительно)

Исследуем f(x) = ln x / x. (1) D(f) = (0; +∞), граница x = 0 в область не входит. (2) Область несимметрична: ни чётная, ни нечётная. (3) f′ = (1 − ln x)/x²; нуль x = e; знаки: + на (0; e), − на (e; +∞). Максимум f(e) = 1/e ≈ 0,37. (4) f″ = (2 ln x − 3)/x³; нуль x = e3/2 ≈ 4,48; знаки − и +: перегиб в (e3/2; 3/(2e3/2)), ординату ≈ 0,33. (5) x → 0 + 0: ln x → −∞, 1/x → +∞, f → −∞: вертикальная асимптота x = 0 (односторонняя, справа). x → +∞: ln x/x → 0, y = 0 — горизонтальная асимптота (только на +∞: на −∞ функции нет). (6) f(x) = 0 при x = 1: график пересекает Ox в (1; 0).

Частые ошибки

Так нельзя

Не считать x = 0 критической, потому что «f′ там не существует».

Так правильно

Критическая точка — это и точка без конечной f′, если f в ней определена. У ∛(x²/(x + 2)) это острый минимум.

Так нельзя

Считать, что функция с f′ = ±∞ в точке не монотонна: f(x) = ∛x, f′(0) = +∞, «значит, там экстремум».

Так правильно

Бесконечная производная одного знака по обе стороны монотонность не портит: ∛x строго возрастает. Экстремум — только при смене знака f′.

Так нельзя

Склеить (x₂; 0) и (0; +∞) в один промежуток выпуклости вверх (x₂; +∞): «знак f″ там везде −».

Так правильно

Нельзя: в нуле острый минимум, и определение 4.7.1 нарушено. Для точек a = −0,1 и b = 0,1 середина хорды ≈ 0,17 выше точки графика f(0) = 0, а для выпуклости вверх должна быть не выше.

Так нельзя

Искать асимптоты y = kx + b у функции, которая на бесконечности растёт как ∛x.

Так правильно

k = lim f/x = 0, но b = lim f = ±∞: асимптот нет. Нужны оба конечных предела.

Так нельзя

Использовать x^(2/3) для отрицательных x в калькуляторе или формуле.

Так правильно

Пиши (∛x)² или ∛(x²): так функция определена на всей оси.

Кратко для повторения

Кратко для повторения

  • Особая точка: функция определена, конечной f′ нет (f′ → ±∞ или угол). Она критическая; экстремум в ней называют острым; знак f′ слева и справа решает дело.
  • f непрерывна в x₀ и f′ бесконечна одного знака по обе стороны ⟹ монотонность сохраняется (∛x); с разными знаками ⟹ экстремум (∛(x²) в нуле — минимум; такую точку графика называют точкой возврата).
  • Корень нечётной степени имеет знак подкоренного выражения; корень любой степени из положительного числа положителен; множители вида (x − a)4/3 на знак не влияют.
  • Пример 10: максимум f(−4) = −2, острый минимум f(0) = 0, перегибы x = −4 ± 2√3, вертикальная асимптота x = −2, наклонных нет (f ~ ∛x).
  • У функции на полупрямой (ln x/x) вертикальная асимптота — на границе области, горизонтальная — только на +∞.

Задания для самопроверки

Решено: 0 из 6

Выберите вариант, заполните пропуски или введите число (допустимы дроби вида 1/3 и десятичные 0,25), затем «Проверить».

1
Сколько точек экстремума у функции g(x) = ∛(x³ − 3x²)?

Показать решение

g′ = (3x² − 6x)/(3(x³ − 3x²)2/3) = (x − 2)/(∛x·∛((x − 3)²)). Критические точки: 2 (g′ = 0), 0 и 3 (там g′ бесконечна, g определена). Корень ∛((x − 3)²) > 0 при x ≠ 3, знак даёт (x − 2)/∛x: на (−∞; 0), (0; 2), (2; 3), (3; +∞): + − + +. Смена знака в 0 (острый максимум) и 2 (гладкий минимум). В x = 3 знак + с обеих сторон: экстремума нет. Ответ: 2.

2
Исследуем f(x) = ∛x в точке x = 0. В каком шаге допущена первая ошибка?
Варианты ответа

Показать решение

Критическая точка — лишь кандидат. Экстремум требует смены знака f′, а здесь f′ > 0 по обе стороны от нуля, f′(0) = +∞ одного знака. ∛x строго возрастает на всей оси: экстремума нет.

3
Какие утверждения верны для функции h(x) = x·ln x? Отметьте все верные.
Варианты ответа; можно выбрать несколько

Показать решение

h′ = ln x + 1: нуль x = 1/e, знак − → +: минимум. h″ = 1/x > 0 на (0; +∞): выпукла вниз. limx→0+ x ln x = 0, k = lim ln x = +∞ — асимптот нет.

4
Заполните пропуски.
Если функция непрерывна в x₀, а её производная слева стремится к −∞ и справа к +∞, то в x₀ с касательной.

Показать решение

Знак f′ меняется с − на +: минимум. Конечной производной нет, значит, он острый (лекция, стр. 5). Производная бесконечна, поэтому касательная вертикальна (пример ∛(x²) в нуле).

5
Найдите значение функции f(x) = ∛(x²) − x/3 в точке её локального максимума. Запишите ответ обыкновенной дробью.

Показать решение

f′ = (2/3)x−1/3 − 1/3 = (2 − ∛x)/(3∛x). Критические точки x = 0 (острая) и x = 8 (∛x = 2). Знаки f′: − + − на (−∞; 0), (0; 8), (8; +∞). Максимум в x = 8: f(8) = 4 − 8/3 = 4/3. (В нуле острый минимум f(0) = 0.)
