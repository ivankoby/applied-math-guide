Полное исследование функции — это сборка предыдущих статей в один план: область определения, симметрия, монотонность и экстремумы, выпуклость и перегибы, асимптоты, точки пересечения с осями, график. План лекции состоит из семи пунктов (стр. 13). В статье: что писать в каждом пункте и зачем он нужен, сквозной пример 9 лекции с графиком (в нём две опечатки, они исправлены), ещё один пример с нечётной функцией и типовые ошибки. Главная привычка: после каждого пункта сверять результат с предыдущими (монотонность с экстремумом, асимптоты с поведением на краях).

Дополнительно к лекции (опорный конспект): в общей схеме исследования (пп. 5.1–5.10) ещё называют область значений E(f) и непрерывность в области определения; порядок пунктов там другой (асимптоты раньше производных). Промежутки знакопостоянства в этой схеме не названы, они есть в экзаменационной программе курса. Эти пункты не обязательны, но помогают при проверке: если по знакам f график должен лежать выше оси, а в таблице получился спуск под ось, где-то ошибка.

Как выполнять пункты

  • Пункт 2. Функция чётна, если D(f) симметрична относительно нуля и f(−x) = f(x) (график симметричен относительно оси Oy); нечётна, если f(−x) = −f(x) (симметрия относительно начала координат). Лекция пишет «не является ни чётной, ни нечётной» без обоснования; обоснование — один контрпример: D(f) несимметрична (есть −1 ∈ D, но 1 ∉ D) или f(−1) ≠ ±f(1). Периодичность проверяют для тригонометрических функций.
  • Пункт 3. Работают по алгоритму статьи 10.1: f′ на множители, критические точки и «дырки» на ось, знаки, промежутки; затем экстремумы (статья 10.2). Стационарная точка без смены знака (x² в числителе f′) экстремума не даёт.
  • Пункт 4. Алгоритм статьи 10.4: кандидаты в перегибы, знаки f″, ординаты перегибов.
  • Пункт 5. Вертикальные — в точках разрыва по односторонним пределам; наклонные — отдельно на ±∞. Полезно сразу узнать, с какой стороны график подходит к асимптоте (знак остатка).
  • Пункт 6. Пересечение с Oy: f(0) (если 0 ∈ D); с Ox: решить f(x) = 0. Берут и пару контрольных точек, если график неясен.
  • Пункт 7. Сначала асимптоты пунктиром и ключевые точки (экстремумы, перегибы, пересечения) с направлением касательной: горизонтальная в стационарных точках, вертикальная там, где f′ = ±∞, а в угловых точках две односторонние касательные. Потом соединяют: где f′ > 0 — возрастает, где f′ < 0 — убывает; где f″ > 0 — выпукла вниз (∪), где f″ < 0 — выпукла вверх (∩).

Пример 9 лекции: x³/(x − 1)²

Пример 9: полное исследование x³/(x − 1)²из лекции, стр. 13–14
Исследовать функцию f(x) = x³/(x − 1)² и построить график.

  1. 1) Область определения. x ≠ 1: D(f) = (−∞; 1) ∪ (1; +∞), x = 1 — точка разрыва. 2) Чётность. −1 ∈ D(f), 1 ∉ D(f): область несимметрична, функция ни чётная, ни нечётная.

  2. 3) Монотонность и экстремумы. f = x³(x − 1)−2, f′ = 3x²(x − 1)−2 − 2x³(x − 1)−3 = x²(3(x − 1) − 2x)/(x − 1)³, то есть

    f′(x) = x²(x − 3)/(x − 1)³

    Стационарные точки x = 0 и x = 3; x = 1 не входит в D(f). Множитель x² знак не меняет, знак f′ задаёт (x − 3)/(x − 1)³.

    Функция возрастает на (−∞; 1) (точку 0 склеиваем: f в ней непрерывна, а знак f′ не меняется) и на [3; +∞), убывает на (1; 3]. В x = 3 минимум: f(3) = 27/4. В x = 0 экстремума нет.

  3. 4) Выпуклость. f′ = (x³ − 3x²)/(x − 1)³, поэтому f″ = [(3x² − 6x)(x − 1) − 3(x³ − 3x²)]/(x − 1)⁴ = 6x/(x − 1)⁴. Знаменатель положителен, знак задаёт x.

    Выпукла вверх на (−∞; 0), вниз на (0; 1) и (1; +∞). В x = 0 знак f″ меняется, f′(0) = 0 существует: точка перегиба (0; 0) с горизонтальной касательной.

  4. 5) Асимптоты. x → 1: числитель → 1, знаменатель (x − 1)² → 0, оставаясь положительным, поэтому lim f = +∞ с обеих сторон: вертикальная асимптота x = 1. Наклонная: выделим целую часть, x³ = (x − 1)²(x + 2) + 3x − 2, значит f(x) = x + 2 + (3x − 2)/(x − 1)². Остаток → 0 при x → ±∞, поэтому y = x + 2 — асимптота на обеих сторонах (проверка: k = 1, b = lim (f − x) = 2). Остаток положителен при x > 2/3: справа график над асимптотой, слева (x → −∞) под ней.

  5. 6) Точки. f(x) = 0 только при x = 0: график проходит через начало координат (оно же перегиб). Область значений (дополнительно): на (−∞; 1) функция непрерывна и возрастает от −∞ до +∞, поэтому E(f) = ℝ. 7) График — ниже.

минимум f(3) = 27/4; перегиб (0; 0); асимптоты x = 1 и y = x + 2.

Замечание

В лекции на стр. 13 написано f(3) = 27/8; верно 27/4 (3³/2² = 27/4). На стр. 14 остаток записан как (3x + 2)/(x − 1)²; верно (3x − 2)/(x − 1)² (проверка: (x − 1)²(x + 2) = x³ − 3x + 2). На асимптоту y = x + 2 это не влияет, но влияет на положение графика относительно неё.

Ещё один пример: нечётная функция (дополнительно)

Исследуем f(x) = x/(x² + 1). (1) D = ℝ, разрывов нет. (2) f(−x) = −f(x): функция нечётна, график симметричен относительно начала координат; достаточно изучить x ≥ 0. (3) f′ = (1 − x²)/(x² + 1)²; знаки на (−∞; −1), (−1; 1), (1; +∞): − + −. Минимум f(−1) = −1/2, максимум f(1) = 1/2. (4) f″ = 2x(x² − 3)/(x² + 1)³; знаки на (−∞; −√3), (−√3; 0), (0; √3), (√3; +∞): − + − +; три перегиба: x = 0, x = ±√3 (f(√3) = √3/4 ≈ 0,43). (5) Вертикальных асимптот нет, k = 0, b = lim f = 0: y = 0 на обеих сторонах. (6) Ось Ox график пересекает только в нуле. Итог по промежуткам: возрастает на [−1; 1], убывает на (−∞; −1] и [1; +∞); выпукла вверх на (−∞; −√3) и (0; √3), вниз на (−√3; 0) и (√3; +∞). Область значений (дополнительно): наибольшее значение 1/2, наименьшее −1/2, на бесконечности f → 0, а непрерывная функция принимает все промежуточные значения, поэтому E(f) = [−1/2; 1/2].

Частые ошибки

Так нельзя

Исследовать функцию, не найдя область определения: x³/(x − 1)² «возрастает на (−∞; 3]».

Так правильно

Точка x = 1 выбрасывается: f возрастает на (−∞; 1), убывает на (1; 3].

Так нельзя

Считать стационарную точку экстремумом: f′(0) = 0 у x³/(x − 1)², значит, там экстремум.

Так правильно

Знак f′ в нуле не меняется (множитель x²), экстремума нет; это перегиб с горизонтальной касательной.

Так нельзя

Ошибиться в симметрии: «x/(x² + 1) чётна, потому что x²».

Так правильно

Проверяй f(−x): здесь f(−x) = −f(x), функция нечётна (симметрия относительно начала координат).

Так нельзя

Строить график, не сверив пункты: убывание между двумя точками, а график между ними поднимается.

Так правильно

После таблицы проверь согласованность: знаки f′, значения в точках, асимптоты и поведение на краях области должны сходиться.

Кратко для повторения

Кратко для повторения

  • План лекции: D(f) и разрывы → чётность и периодичность → f′ (монотонность, экстремумы) → f″ (выпуклость, перегибы) → асимптоты → точки пересечения → график.
  • Чётность требует симметричной D(f); «ни чётная, ни нечётная» подтверждают контрпримером.
  • В знаковых таблицах «дырки» режут ось, стационарные точки без смены знака промежутки не разрывают.
  • Пример 9: минимум 27/4 в x = 3, перегиб (0; 0), асимптоты x = 1 и y = x + 2; в лекции опечатки 27/8 и 3x + 2.
  • Строят: асимптоты пунктиром → ключевые точки с касательными → кривая по знакам f′ и f″.

f(−x) = −f(x) — нечётна. f′ = (4 − x²)/(x² + 4)², знаки − + −: минимум в −2, максимум в 2 (f(2) = 1/4), на (−∞; −2] убывает. k = 0, b = lim f = 0: y = 0. Вертикальных асимптот нет.

2
Найдите значение функции f(x) = x²/(x − 1) в точке её локального минимума.

Показать решение

f′ = x(x − 2)/(x − 1)²; знаки на (−∞; 0), (0; 1), (1; 2), (2; +∞): + − − +. В x = 0 максимум f(0) = 0, в x = 2 минимум f(2) = 4/1 = 4.

3
Исследуем f(x) = x/(x² + 1) на симметрию. В каком шаге допущена первая ошибка?
Варианты ответа

Показать решение

Из f(−x) = −f(x) следует нечётность, а не чётность. График нечётной функции симметричен относительно начала координат (чётной — относительно оси Oy).

4
Сколько точек перегиба у графика функции f(x) = x/(x² + 3)?

Показать решение

f′ = (3 − x²)/(x² + 3)², f″ = 2x(x² − 9)/(x² + 3)³. Нули 0, ±3 простые, знаки − + − +: смена знака в каждом. Три перегиба: (0; 0) и (±3; ±1/4).

5
Заполните пропуски для f(x) = x²/(x − 1), где f = x + 1 + 1/(x − 1).
При x → +∞ график лежит асимптоты y = x + 1, а при x → −∞ график лежит этой асимптоты.

Показать решение

Остаток 1/(x − 1) положителен при x > 1 (график над асимптотой на +∞) и отрицателен при x < 1 (график под асимптотой на −∞). Проверка: f(10) − 11 = 100/9 − 11 > 0, f(−10) − (−9) = −100/11 + 9 < 0.

6
Выполните полное исследование f(x) = x/(x² − 1): область определения, чётность, монотонность, выпуклость и перегибы, асимптоты. Затем сверьте с решением.

Показать решение

1) D = ℝ \ {−1, 1}. 2) Нечётна. 3) f′ = −(x² + 1)/(x² − 1)² < 0: убывает на каждом из (−∞; −1), (−1; 1), (1; +∞), экстремумов нет. 4) f″ = 2x(x² + 3)/(x² − 1)³; знаки на (−∞; −1), (−1; 0), (0; 1), (1; +∞): − + − +; перегиб один: (0; 0) (точки ±1 не в D). 5) Вертикальные x = ±1 (пределы бесконечны), горизонтальная y = 0 на обеих сторонах (k = 0, b = lim f = 0). 6) Пересечение с осями — только (0; 0).
