1

Возрастание и экстремумы

Производная подсказывает, куда идёт график: вверх или вниз. Это как горка.

  1. Найди критические точки: f′ = 0 или f′ не существует
  2. Раздели область определения на промежутки этими точками
  3. Смотри знак f′ на каждом промежутке
  4. Знак + — функция растёт, знак − — убывает
f′(x) ≥ 0 на (a; b) ⇔ f возрастает на (a; b)
Читается: если производная не отрицательная, функция растёт. Для убывания нужен знак f′ ≤ 0.
  • ⛰️Максимум: слева f′ > 0, справа f′ < 0. Вершина горки.
  • 🕳️Минимум: слева f′ < 0, справа f′ > 0. Дно ямки.
  • 📌Ферма: в гладкой точке экстремума f′ = 0. Обратное неверно: у x³ в нуле f′ = 0, но экстремума нет.
💡 Как в жизниКатишься с горки: сначала вверх, потом вниз. Место разворота — это вершина.
🎓 Слова для взрослых
экстремум — точка максимума или минимума функциикритическая точка — точка, где f′ = 0 или производной нетстационарная точка — точка, где f′ = 0
Как называется точка, где f′ = 0?
✅ Стационарная точка.
2

Выпуклость и перегибы

Вторая производная показывает, как график гнётся: как улыбка или как шапка.

😊 f″ > 0

  • выпукла вниз
  • как улыбка
  • график не ниже касательной

🎩 f″ < 0

  • выпукла вверх
  • как шапка
  • график не выше касательной
f′(x₀) = 0 и f″(x₀) > 0 ⇒ x₀ — минимум; f″(x₀) < 0 ⇒ x₀ — максимум
Признак экстремума через вторую производную. Сначала находим точку, где f′ = 0.
  • 🔀Перегиб: точка, где f″ меняет знак. Гнутость переворачивается.
  • 🔍Перегибы ищи там, где f″ = 0 или f″ не существует.
  • 🧭Если f′ = f″ = … = f⁽ⁿ⁻¹⁾ = 0, а f⁽ⁿ⁾ ≠ 0: при чётном n экстремум, при нечётном — нет.
💡 Как в жизниМиска с супом вогнутая, как улыбка. Крышка выпуклая, как шапка.
🎓 Слова для взрослых
выпуклость вниз — график лежит не ниже своей касательнойточка перегиба — точка, где гнутость меняется на противоположную
Какой знак у второй производной у «улыбки»?
✅ Плюс: f″ > 0.
3

Асимптоты

Асимптота — прямая, к которой график подходит всё ближе.

  1. Область определения, разрывы, чётность
  2. Монотонность и экстремумы по f′
  3. Выпуклость и перегибы по f″
  4. Асимптоты: вертикальные и наклонные
  5. Точки пересечения с осями
  6. Строим график
k = lim(x→∞) f(x)/x, b = lim(x→∞) (f(x) − k·x), y = k·x + b
Наклонная асимптота y = kx + b. Если k = 0, она горизонтальная: b = lim f(x).
  • 📏Вертикальная асимптота x = x₀, если lim f(x) = ∞ при x → x₀.
  • 📐Пример: (x² + x)/(x − 2) = x + 3 + 6/(x − 2). Асимптоты: y = x + 3 и x = 2.
  • 🧪Пример: x³/(x − 1)²: вертикальная x = 1, наклонная y = x + 2.
💡 Как в жизниКак дорога, которая всё ближе подходит к прямой линии у горизонта.
🎓 Слова для взрослых
асимптота — прямая, к которой график подходит очень близконаклонная асимптота — прямая y = kx + b
Какая асимптота получается при k = 0?
✅ Горизонтальная.
4

Наибольшее и наименьшее значение

Задача «самое большое» — например, самый большой прямоугольник. Ищем критические точки и концы отрезка.

  1. Найди критические точки внутри отрезка
  2. Вычисли f в этих точках
  3. Вычисли f на концах отрезка
  4. Самое большое значение — наибольшее, самое маленькое — наименьшее
max[a; b] f = max{ f(xкрит), f(a), f(b) }
Работает на замкнутом отрезке, где функция непрерывна. Берём все кандидаты и сравниваем.
  • 🔺Пример: в треугольник с основанием a и высотой h вписан прямоугольник. Площадь S(y) = (a/h)·(h − y)·y.
  • 🏆S′ = 0 при y = h/2. Тогда основание x = a/2, а S = ah/4.
  • ⚠️Локальный максимум не всегда наибольший на отрезке: проверь концы.
💡 Как в жизниКак найти самую высокую горку на карте: проверь вершины и края карты.
🎓 Слова для взрослых
наибольшее значение — самое большое значение функции на отрезкелокальный экстремум — максимум или минимум в маленькой окрестности точки
Где ищем наибольшее значение функции на отрезке?
✅ В критических точках и на концах отрезка.
