Статья 7.2

Односторонняя непрерывность и свойства в точке

Непрерывность в точке можно проверять «по частям»: отдельно слева и отдельно справа. Это нужно для кусочных функций, у которых слева и справа от точки работают разные формулы, и для задач вида «при каком a функция непрерывна». Затем две теоремы в точке: если непрерывная функция положительна в точке, то она положительна и в некоторой окрестности этой точки; а суммы, произведения и частные непрерывных функций снова непрерывны.

Односторонняя непрерывность

Непрерывность слева и справа

Пусть функция f определена на левой (правой) половине некоторой окрестности точки x₀ и в самой точке x₀. Функцию f называют непрерывной слева в точке x₀, если limx→x₀− f(x) = f(x₀), и непрерывной справа, если limx→x₀+ f(x) = f(x₀).

Односторонние пределы часто записывают f(x₀ − 0) и f(x₀ + 0). Связь между обычным и односторонними пределами (лекция 6) даёт критерий:

f непрерывна в x₀ ⇔ f(x₀ − 0) = f(x₀) = f(x₀ + 0)
Функция непрерывна в точке тогда и только тогда, когда она непрерывна и слева, и справа.

Обрати внимание: в равенстве три числа, и значение в точке f(x₀) стоит в нём наравне с двумя пределами. Если слева и справа предел один и тот же, но f(x₀) другое (или его нет), непрерывности нет.

Пример: целая часть числа

Целая часть [x]из лекции, стр. 3 (рис. 3.1)
Исследуйте непрерывность y = [x] слева и справа.

  1. Возьми целую точку x₀ = n. Значение функции: [n] = n.

  2. Справа: при x чуть больше n имеем [x] = n, поэтому f(n + 0) = n = f(n) — непрерывна справа.

  3. Слева: при x чуть меньше n имеем [x] = n − 1, поэтому f(n − 0) = n − 1 ≠ n = f(n) — слева непрерывности нет.

  4. Любая нецелая точка лежит внутри ступеньки, где функция постоянна, а постоянная непрерывна (статья 7.1).

В каждой целой точке [x] непрерывна справа (но не слева, значит, не непрерывна), во всех остальных точках непрерывна.

Кусочная функция: подбор параметра

Дополнительно к лекции (практика № 10). Кусочная функция задана разными формулами на разных промежутках. Внутри каждого промежутка формула элементарная, а элементарные функции непрерывны (статья 7.8). Значит, подозрительны только точки стыка, где формула меняется, и точки внутри промежутков, где сама формула не определена (например, 1/(x − 1) на промежутке, содержащем 1; см. статью 7.4). Алгоритм:

  • найди точки стыка (границы промежутков);
  • в каждой точке стыка x₀ вычисли f(x₀ − 0) по формуле слева, f(x₀ + 0) по формуле справа и f(x₀) по той формуле, которой принадлежит сама точка;
  • приравняй три числа: f(x₀ − 0) = f(x₀) = f(x₀ + 0); если в формулах есть параметры, получится уравнение или система для них.
Пример. Один параметрдополнительно к лекции (практика № 10)
При каком a функция непрерывна на всей оси?
f(x) =
a x + 2, x < 3
x² − 1, x ≥ 3

  1. Формулы ax + 2 и x² − 1 непрерывны на своих промежутках, поэтому возможный разрыв только в точке стыка x₀ = 3.

  2. Слева: f(3 − 0) = limx→3− (ax + 2) = 3a + 2. Справа и в самой точке (формула x² − 1 действует при x ≥ 3): f(3 + 0) = f(3) = 3² − 1 = 8.

  3. Приравниваем: 3a + 2 = 8, откуда a = 2.

  4. Проверка: при a = 2 слева 2·3 + 2 = 8, справа 9 − 1 = 8. Совпало.

a = 2.

Пример. Два параметрадополнительно к лекции (практика № 10)
При каких a и b функция непрерывна на всей оси?
f(x) =
2, x ≤ 1
a x + b, 1 < x < 3
8, x ≥ 3

  1. Точки стыка: x = 1 и x = 3. В каждой из них слева и справа значения должны совпасть.

  2. В точке x = 1: слева 2, справа a·1 + b. Условие: a + b = 2.

  3. В точке x = 3: слева 3a + b, справа 8. Условие: 3a + b = 8.

  4. Вычитаем первое уравнение из второго: 2a = 6, a = 3. Тогда b = 2 − 3 = −1. Проверка второго уравнения: 3·3 + (−1) = 8.

  5. График при a = 3, b = −1 — непрерывная ломаная:

a = 3, b = −1.

Запомни

Параметр не исправит бесконечный предел. Например, у f(x) = ax при x < 0 и f(x) = 1/x при x > 0 справа от нуля предел равен +∞ при любом a, поэтому непрерывности не добиться. Подбор имеет смысл, когда односторонние пределы конечны.

Теорема о сохранении знака

Теорема 1 (о сохранении знака)

Пусть функция f непрерывна в точке x₀ и f(x₀) > 0. Тогда существуют положительное число α и окрестность точки x₀, в которой для всех точек выполнено f(x) > α.

Простыми словами: непрерывная функция, положительная в точке, остаётся положительной (и даже больше некоторого α > 0) на целой окрестности этой точки. Почему это так: возьми любое ε₀ с 0 < ε₀ < f(x₀), например ε₀ = f(x₀)/2. Из непрерывности для него найдётся δ₀, при котором |f(x) − f(x₀)| < ε₀, а значит, f(x) > f(x₀) − ε₀ =: α > 0 (стр. 4). Буква α здесь — положительное число, не путай её с б.м.ф. α из формулы (3.1).

  • Замечание 1. При f(x₀) < 0 верно аналогичное: найдётся окрестность, где f(x) < −α < 0 (знак сохраняется и в этом случае).
  • Замечание 2. Есть «односторонний вариант»: если f непрерывна справа в x₀ и f(x₀) > 0, то f(x) > α на некотором полуинтервале [x₀, b); аналогично слева на (a, x₀].

Почему условия нужны

Условий два, и оба нужны. (1) Непрерывность в точке: f(0) = 1, f(x) = −1 при x ≠ 0 положительна в нуле, но отрицательна во всех соседних точках. (2) Строгая положительность: f(x) = x непрерывна в нуле, f(0) = 0, и ни в какой окрестности нуля знак не сохраняется. Вывод теоремы тоже локальный: он говорит только о малой окрестности точки.

Арифметика непрерывных функций

Теорема 2 (о непрерывности суммы, произведения и частного)

Если функции f и g непрерывны в точке x₀, то непрерывны в x₀ и функции c·f (c — постоянная), f ± g, f·g, а также f/g, если g(x₀) ≠ 0.

Доказательство сразу следует из арифметических свойств предела: lim (f + g) = lim f + lim g = f(x₀) + g(x₀), и так далее. Индукцией утверждение переносится на любое конечное число слагаемых и множителей. Для f/g при g(x₀) ≠ 0 частное определено и около x₀: по теореме 1, применённой к |g|, в окрестности точки g ≠ 0.

Примеры 3–5из лекции, стр. 4
Что можно сказать о непрерывности степенной функции, многочлена и рациональной дроби?

  1. Пример 3. y = xn — произведение n непрерывных функций y = x (статья 7.1, пример 2). По теореме 2 она непрерывна на всей оси.

  2. Пример 4. Многочлен Pn(x) = anxn + an−1xn−1 + … + a1x + a0 — сумма непрерывных функций akxk (постоянная на степень), значит, непрерывен на всей оси.

  3. Пример 5. Рациональная дробь Pn(x)/Qm(x) — частное двух многочленов: непрерывна в каждой точке, где Qm(x) ≠ 0, то есть в каждой точке своей области определения.

  4. Для числа: R(x) = (x² + 1)/(x² − 5x + 6). Знаменатель (x − 2)(x − 3) равен нулю при x = 2 и x = 3, там функция не определена. Во всех остальных точках R непрерывна как частное многочленов, а x = 2 и x = 3 — точки разрыва (какого рода, разберёт статья 7.3).

Многочлен непрерывен на ℝ; рациональная дробь непрерывна всюду, где знаменатель не обращается в нуль.

Осторожно

Теорема 2 даёт достаточные условия. Обратное неверно: например, [x] и x − [x] (дробная часть) разрывны в каждой целой точке, а их сумма x непрерывна. Верно другое: если f и f + g непрерывны в точке, то и g = (f + g) − f непрерывна.

Частые ошибки

Так нельзя

Приравнять левый и правый пределы и забыть про значение в самой точке.

Так правильно

Нужны три числа: f(x₀ − 0) = f(x₀) = f(x₀ + 0). У функции 1 при x ≠ 2, 0 при x = 2 пределы слева и справа равны, а непрерывности нет.

Так нельзя

В кусочной функции подставлять x₀ не в ту формулу.

Так правильно

Слева от точки работает формула для x < x₀, справа — для x > x₀, а значение f(x₀) берут по той формуле, где написано «=» (≤ или ≥).

Так нельзя

«f и g непрерывны, значит, f/g непрерывна везде».

Так правильно

Частное непрерывно только там, где g(x₀) ≠ 0. Дробь 1/x — частное непрерывных функций, но в нуле она не определена.

Так нельзя

«Сумма f + g непрерывна, значит, обе функции непрерывны».

Так правильно

Так не следует ([x] и x − [x]). Верно только: если непрерывна f + g и одно из слагаемых, то непрерывно и другое.

Кратко для повторения

Кратко для повторения

  • Непрерывна слева: limx→x₀− f(x) = f(x₀); справа: limx→x₀+ f(x) = f(x₀). Непрерывна в точке ⇔ непрерывна и слева, и справа.
  • [x] в каждой целой точке непрерывна справа, но не слева; в остальных точках непрерывна.
  • Кусочная функция: проверяй только точки стыка; приравнивай f(x₀ − 0), f(x₀), f(x₀ + 0) и решай уравнение или систему для параметров.
  • Сохранение знака: f непрерывна в x₀, f(x₀) > 0 ⇒ f(x) > α > 0 на окрестности x₀ (аналогично при f(x₀) < 0).
  • Сумма, разность, произведение, частное (при g(x₀) ≠ 0) непрерывных функций непрерывны; многочлены непрерывны всюду, рациональные дроби — в каждой точке области определения.

Проверь себя

Задания для самопроверки

Решено: 0 из 6

Ответ — число: целое, десятичное (0,25) или дробь (1/4). Минус — обычный дефис. Подсказки появляются после неверного ответа, решение можно открыть в любой момент.

1
При каком значении a функция непрерывна в точке x = 4?
f(x) =
x² − 2x, x ≤ 4
a x − 4, x > 4

Показать решение

Слева (и в самой точке, x ≤ 4): f(4) = 16 − 8 = 8. Справа: limx→4+ (ax − 4) = 4a − 4. Условие непрерывности: 4a − 4 = 8, откуда a = 3.

2
В каких точках функция y = [x] (целая часть) непрерывна? Отметьте все верные точки.
Варианты ответа; можно выбрать несколько

Показать решение

В нецелых точках функция локально постоянна, поэтому непрерывна (0,5 и 3,99). В целых точках (2, −3) она непрерывна справа, но не слева, то есть разрывна.

3
Функция f непрерывна в точке x₀ = 2, и f(2) = 6. Какое утверждение обязательно верно?
Варианты ответа

Показать решение

По теореме о сохранении знака при f(2) = 6 > 0 найдётся окрестность, где f(x) > α для некоторого 0 < α < 6; можно взять α = 3 (ε₀ = 3). Про сравнение с самим значением 6 ничего гарантировать нельзя.

4
Какие утверждения о функциях f и g верны? Отметьте все верные.
Варианты ответа; можно выбрать несколько

Показать решение

Первое — теорема 2. Второе: g = (f + g) − f — разность непрерывных функций. Третье и четвёртое неверны, контрпримеры в подсказках.

5
Подбираем a, при котором f непрерывна в точке x = 2. В каком шаге допущена первая ошибка?
f(x) =
x² + 1, x < 2
a, x = 2
3x − 1, x > 2
Варианты ответа

Показать решение

Для непрерывности нужно ещё, чтобы совпало значение в самой точке: f(2 − 0) = f(2) = f(2 + 0), то есть a = 5. При любом другом a получается разрыв (устранимый).

6
Найдите b, при котором функция непрерывна на всей оси (параметр a тоже подбирается).
f(x) =
−3, x ≤ 1
a x + b, 1 < x < 4
9, x ≥ 4

Показать решение

В точке x = 1: a·1 + b = −3. В точке x = 4: 4a + b = 9. Вычитая первое из второго: 3a = 12, a = 4, затем b = −3 − 4 = −7. Проверка: 4·4 − 7 = 9.
