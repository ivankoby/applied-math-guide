Последний шаг лекции отвечает на вопрос «а какие функции вообще непрерывны?». Оказывается, все, которые мы привыкли писать формулами (многочлены, дроби, степени, показательные, логарифмы, тригонометрические и их композиции), непрерывны во всех точках, где определены. Для этого нужны две вещи: теорема о непрерывности обратной функции (так получаются логарифм, корни и обратные тригонометрические) и определение класса элементарных функций. Практический итог: пределы элементарных функций в «хороших» точках считаются подстановкой.

Обратная функция

Обратная функция

Пусть функция f: X → Y такова, что для любого y ∈ Y существует единственный элемент x ∈ X, для которого y = f(x). Тогда на множестве Y определена функция, которая каждому y ставит в соответствие этот x. Её называют обратной к f и обозначают f⁻¹: x = f⁻¹(y) (или в привычных обозначениях y = f⁻¹(x)).

f[f⁻¹(y)] = y при всех y ∈ Y,
f⁻¹[f(x)] = x при всех x ∈ X.
Функция и обратная «отменяют» друг друга.

Геометрия. Если точка (x, f(x)) лежит на графике f, то точка (f(x), x) лежит на графике f⁻¹. Поэтому графики симметричны относительно биссектрисы первого и третьего координатных углов, то есть прямой y = x.

Как найти обратную (дополнительно к лекции). Реши уравнение y = f(x) относительно x, а затем обозначь аргумент снова буквой x. Пример: y = 2x + 1 даёт x = (y − 1)/2, обратная функция y = (x − 1)/2. Проверка: f(f⁻¹(5)) = f(2) = 5.

Запомни

Обратной функции может и не быть. Для y = x² на всей оси значение 4 получается дважды (x = 2 и x = −2), единственности нет. Помогает сужение области: на [0; +∞) функция x² обратима, и обратная к ней — √x.

Теорема об обратной функции

Теорема 1 (о существовании и непрерывности обратной функции)

Если функция f непрерывна и строго возрастает (строго убывает) на конечном или бесконечном промежутке ⟨a, b⟩, то обратная функция f⁻¹ существует, строго возрастает (строго убывает) и непрерывна на промежутке f(⟨a, b⟩).

Строго возрастает: x₁ < x₂ ⇒ f(x₁) < f(x₂). Идея доказательства из лекции (для возрастающей f, стр. 12–13):

  • Образ — промежуток. Это следствие теоремы Больцано–Коши (статья 7.7): f непрерывна на промежутке.
  • Обратная существует. Если бы f(x′) = f(x″) при x′ ≠ x″, это противоречило бы строгому возрастанию. Значит, каждое y из образа получается из единственного x.
  • Обратная возрастает. Пусть y₁ < y₂, xi = f⁻¹(yi). Если бы x₁ ≥ x₂, то из возрастания f вышло бы y₁ ≥ y₂. Противоречие.
  • Обратная непрерывна. Возьмём y₀ = f(x₀) и ε > 0 (достаточно малое, чтобы x₀ − ε оставалось в промежутке). Положим y₁ = f(x₀ − ε), тогда y₁ < y₀. Для всех y ∈ (y₁; y₀) из монотонности f⁻¹ получаем x₀ − ε < f⁻¹(y) < x₀, то есть |f⁻¹(y) − x₀| < ε. Это и есть левосторонний предел f⁻¹(y₀) (правосторонний — аналогично). Если x₀ — левый конец промежутка, левого предела нет: берут x₀ + ε и правосторонний предел, ведь для граничной точки образа нужен лишь тот односторонний предел, который имеет смысл (стр. 13).

Условия

Здесь важны обе стороны: непрерывность f нужна, чтобы образ был промежутком (иначе f⁻¹ определена на множестве с «дырками»), а строгая монотонность — чтобы обратная существовала (для непрерывной на промежутке f обратимость равносильна строгой монотонности). Теорема даёт достаточные условия (стр. 12): без непрерывности обратимая функция может быть немонотонной, например f(x) = x при 0 ≤ x < 1 и f(x) = 3 − x при 1 ≤ x ≤ 2.

Корень n-й степени как обратная функция

Пример 1из лекции, стр. 14
Объясните, почему существует непрерывный корень n-й степени.

  1. Пусть n чётно. Функция y = xⁿ на промежутке [0; +∞) строго возрастает и непрерывна, её образ равен [0; +∞).

  2. По теореме 1 на [0; +∞) существует обратная функция — корень n-й степени y = ⁿ√x; она строго возрастает и непрерывна на [0; +∞).

  3. Для нечётного n функция xⁿ строго возрастает на всей оси, её образ — вся ось, поэтому корень ⁿ√x определён и непрерывен на (−∞; +∞).

  4. Числа: 2⁴ = 16, поэтому ⁴√16 = 2; (−2)³ = −8, поэтому ³√(−8) = −2.

Корень чётной степени непрерывен на [0; +∞), нечётной — на всей оси.

Основные элементарные функции

Основные элементарные функции

Основными элементарными называются 12 функций: y = c (постоянная), y = ax (a > 0, a ≠ 1), y = loga x (a > 0, a ≠ 1), y = xα (α ≠ 0), y = sin x, y = cos x, y = tg x, y = ctg x, y = arcsin x, y = arccos x, y = arctg x, y = arcctg x.

Лекция считает известными их области определения, множества значений и промежутки монотонности (из школьного курса). Напомним области определения:

Теорема 2

Любая из основных элементарных функций непрерывна в каждой точке своей области определения (на концах области — односторонне, например arcsin x в точках ±1).

В практике № 10 к списку добавлены sec x = 1/cos x и cosec x = 1/sin x: это частные, они непрерывны там, где определены (статья 7.2).

Замечание

На стр. 14 в цепочке неравенств 1 = a⁰ < ax ≤ a1/k (лекция пишет её для членов последовательности) сказано «в силу строгого возрастания показательной функции при a > 0». Строгое возрастание есть только при a > 1; именно этот случай рассматривается (в начале доказательства сказано «при a > 1»). Случай 0 < a < 1 разобран ниже через 1/a.

Элементарные функции

Элементарная функция

Элементарной называют функцию, которую можно получить при помощи конечного числа арифметических операций и конечного числа операций композиции над основными элементарными функциями. Все такие функции составляют класс элементарных функций.

Пример 2из лекции, стр. 16
Покажите, что y = x³ + √(ln(1 + tg x)) — элементарная функция.

  1. Разложим на куски: f₁(x) = x³, f₂(u) = √u, f₃(v) = ln v, f₄(x) = 1 (постоянная), f₅(x) = tg x.

  2. Собираем изнутри: v = f₄(x) + f₅(x) = 1 + tg x; затем u = f₃(v) = ln(1 + tg x); затем f₂(u) = √(ln(1 + tg x)); наконец прибавляем f₁(x) = x³.

  3. Итог: y = f₁(x) + f₂[f₃[f₄(x) + f₅(x)]]. Все куски — основные элементарные, операции — сложение и композиция.

  4. Область определения (дополнительно): нужно, чтобы существовал tg x (x ≠ π/2 + πk), аргумент логарифма положителен (1 + tg x > 0) и под корнем неотрицательно ln(1 + tg x) ≥ 0, то есть 1 + tg x ≥ 1, tg x ≥ 0. Получаем x ∈ [πk; π/2 + πk), k ∈ ℤ.

Функция элементарная; определена на объединении промежутков [πk; π/2 + πk).

Теорема 3 (о непрерывности элементарных функций)

Всякая элементарная функция непрерывна в каждой точке, в окрестности которой она определена.

Почему: основные элементарные функции непрерывны (теорема 2), а арифметические операции (статья 7.2) и композиция (статья 7.5) сохраняют непрерывность. Для функции из примера 2: она непрерывна на каждом интервале (πk; π/2 + πk). В точке x = πk функция определена (y(πk) = (πk)³), но слева от неё tg x < 0 и значение под корнем отрицательно, то есть окрестность точки не лежит в области определения; там непрерывность только справа.

Осторожно

«Элементарная» не означает «непрерывна на всей оси». 1/x, tg x, ln x — элементарные функции, но у них есть точки, где они не определены. Теорема 3 говорит только о точках, около которых функция определена. А функции [x] и sign x (с sign 0 = 0) в класс элементарных не входят, и теорема 3 на них не распространяется. Кусочно заданная функция внутри каждого промежутка совпадает с элементарной, поэтому там непрерывна; на стыках проверка нужна отдельно (статья 7.2).

Предел подстановкой

Следствие теоремы 3 (и определения непрерывности): если функция f элементарна и определена около точки x₀ (в том числе в самой точке), то limx→x₀ f(x) = f(x₀). Предел находится простой подстановкой x₀ в формулу.

Пределы подстановкойдополнительно к лекции
Найдите limx→2 (x² + 1)/(x³ − 3) и limx→3 (√(x + 1) + 2x)/(x − 1).

  1. Первый. Дробь — элементарная функция, в точке 2 знаменатель 2³ − 3 = 5 ≠ 0, функция определена около 2. Подставляем: (2² + 1)/(2³ − 3) = 5/5 = 1.

  2. Второй. Числитель √(x + 1) + 2x и знаменатель x − 1 непрерывны в точке 3, знаменатель в ней равен 2 ≠ 0. Подставляем: (√4 + 2³)/(3 − 1) = (2 + 8)/2 = 5.

Первый предел равен 1, второй равен 5.

Запомни

Если подстановка даёт 0/0 или бессмысленное выражение (ln 0, 1/0), то x₀ не лежит в области определения, и теорема 3 не применима: это точка разрыва или неопределённость. Тогда сначала преобразуй выражение (разложи на множители, сократи), как в статье 7.4, и подставляй в упрощённое.

Частые ошибки

Так нельзя

Считать, что f⁻¹(x) — это 1/f(x).

Так правильно

f⁻¹ — обратная функция, а не обратное число. Для f(x) = 2x + 1 получаем f⁻¹(x) = (x − 1)/2, а 1/f(x) = 1/(2x + 1).

Так нельзя

Искать обратную к непрерывной функции, не являющейся строго монотонной на промежутке (например, x² на [−1; 1]).

Так правильно

Нужна строгая монотонность. Сузь область до промежутка, где она есть: x² на [0; 1].

Так нельзя

Применять теорему 3 в точке, где функция не определена (например, к 1/x в нуле).

Так правильно

Теорема говорит о точках, около которых функция определена. В нуле у 1/x разрыв второго рода.

Так нельзя

Считать любую формулу «элементарной» и потому непрерывной всюду.

Так правильно

Элементарные функции непрерывны только там, где определены (около точки). tg x разрывна в точках π/2 + πk, не входящих в область определения.

Так нельзя

Подставлять x₀ в предел, не проверив, что функция определена в x₀ и около неё.

Так правильно

Сначала область определения. Если подстановка даёт 0/0, нужна другая техника (статья 7.4).

Кратко для повторения

Кратко для повторения

  • Обратная функция f⁻¹ существует, если каждое y из Y получается из единственного x; f[f⁻¹(y)] = y, f⁻¹[f(x)] = x; графики симметричны относительно y = x.
  • Теорема 1: f непрерывна и строго монотонна на промежутке ⇒ f⁻¹ существует, строго монотонна того же вида и непрерывна на f(⟨a, b⟩). Пример: ⁿ√x непрерывен на [0; +∞) (нечётное n — на всей оси).
  • 12 основных элементарных функций: c, ax, loga x, xα, sin, cos, tg, ctg, arcsin, arccos, arctg, arcctg. Каждая непрерывна в каждой точке своей области определения (теорема 2).
  • Элементарная функция — конечное число арифметических операций и композиций над основными. Теорема 3: она непрерывна в каждой точке, в окрестности которой определена.
  • Предел элементарной функции в такой точке находится подстановкой. Если подстановка даёт 0/0, точка не из области определения: сначала упрости.

Задания для самопроверки

Решено: 0 из 6

1
Для каких функций на указанном промежутке обратная функция существует и непрерывна по теореме 1? Отметьте все верные.
Варианты ответа; можно выбрать несколько

Показать решение

Нужны непрерывность и строгая монотонность на промежутке. x³ строго возрастает на всей оси, 1/x строго убывает на (0; +∞) (образ тоже (0; +∞)). x² на [−1; 1] и sin x на [0; π] монотонными не являются.

2
Функция f(x) = x³ + 1 строго возрастает и непрерывна на всей оси. Найдите f⁻¹(28).

Показать решение

f⁻¹(28) — число x, для которого f(x) = 28: x³ + 1 = 28, x³ = 27, x = 3. Проверка: f(3) = 27 + 1 = 28.

3
Подставьте пропущенное про графики функции и обратной.
Графики f и f⁻¹ симметричны относительно . Если точка (2; 5) лежит на графике f, то на графике f⁻¹ лежит точка .

Показать решение

Точка (x, f(x)) переходит в (f(x), x), то есть координаты меняются местами. Это симметрия относительно прямой y = x; точка (2; 5) переходит в (5; 2).

4
Ищем обратную к функции y = x², заданной на всей оси. В каком шаге допущена первая ошибка?
Варианты ответа

Показать решение

Из шага 1 видно, что каждому y > 0 отвечают два значения x: единственности нет, обратной функции у x² на всей оси не существует. Чтобы она появилась, область сужают: на [0; +∞) обратная — √x.

5
Где непрерывна функция y = √(ln x)?
Варианты ответа

Показать решение

Область определения: ln x ≥ 0, то есть x ≥ 1. Функция — композиция ln x и √u: в каждой точке (1; +∞) она непрерывна по теореме о композиции, а в точке 1 — справа, по её одностороннему варианту (статья 7.5): ln x непрерывна, ln x ≥ 0 при x ≥ 1, а √u непрерывен справа в нуле. Слева от 1 функция не определена.

6
Найдите limx→2 (√(x + 7) + 3x)/(x + 1).

Показать решение

Функция элементарная, в точке 2 знаменатель равен 3 ≠ 0, значит, предел равен значению: (√9 + 3²)/(2 + 1) = (3 + 9)/3 = 4.
