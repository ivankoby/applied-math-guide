Теоремы о нуле и о промежуточных значениях

График непрерывной функции нельзя нарисовать без «перехода» через каждое промежуточное значение: если в начале отрезка функция отрицательна, а в конце положительна, то где-то она обязана обратиться в нуль. Это теорема о нуле. Из неё выводится теорема Больцано–Коши: непрерывная функция принимает все промежуточные значения. На них держится доказательство того, что уравнение имеет корень, и ещё один факт: образ промежутка — снова промежуток.

Теорема о нуле

Теорема 2 (о прохождении непрерывной функции через нуль)

Пусть функция f непрерывна на отрезке [a, b], причём на концах отрезка она принимает значения противоположных знаков, то есть f(a)·f(b) < 0. Тогда внутри отрезка найдётся точка ξ такая, что f(ξ) = 0.

Геометрически: график непрерывной функции, концы которого лежат по разные стороны от оси абсцисс, обязательно её пересекает. Условие f(a)·f(b) < 0 — это записанные одной строкой слова «значения противоположных знаков и оба не равны нулю».

Условия

Условия теоремы нельзя отбрасывать. Без непрерывности: f(x) = −1 при x < 0 и f(x) = 1 при x ≥ 0 на [−1; 1] принимает на концах значения разных знаков, а нуля не принимает. Без разных знаков: f(x) = x² − 1 на [−2; 2] имеет f(−2) = f(2) = 3, но два корня ±1, а f(x) = x² + 1 корней не имеет совсем. Поэтому теорема даёт только достаточное условие: при одинаковых знаках на концах о корнях по ней ничего не скажешь.

Метод половинного деления

Лекция доказывает теорему методом половинного деления (стр. 9–10). Это одновременно и способ найти корень приближённо.

  • Пусть для определённости f(a) < 0, f(b) > 0. Разделим отрезок пополам точкой c = (a + b)/2. Если f(c) = 0, корень найден (ξ = c).
  • Иначе из двух половин возьмём ту, на концах которой значения f имеют противоположные знаки; обозначим её [a₁, b₁]. Для неё f(a₁) < 0, f(b₁) > 0.
  • Повторяем. Либо на каком-то шаге попадём в нуль, либо получим бесконечную цепочку вложенных отрезков [an, bn] длины (b − a)/2ⁿ → 0, для которых f(an) < 0, f(bn) > 0.
  • По теореме о вложенных отрезках (лекция 6, Кантор: у системы вложенных отрезков, длины которых стремятся к нулю, есть ровно одна общая точка) у них есть общая точка ξ = lim an = lim bn. По непрерывности f(ξ) = lim f(an) ≤ 0 и f(ξ) = lim f(bn) ≥ 0, откуда f(ξ) = 0. Корень не совпадает с концами a, b, потому что f(a)·f(b) < 0 (значения в них не нулевые).

Теорема Больцано–Коши о промежуточных значениях

Теорема 3 (Больцано–Коши)

Пусть функция f непрерывна на отрезке [a, b] и f(a) = A, f(b) = B. Тогда для любого числа C, заключённого между A и B, найдётся такая внутренняя точка ξ отрезка [a, b], что f(ξ) = C.

Доказательство сводит всё к теореме о нуле. Пусть для определённости A < C < B (случай A > B аналогичен). Введём функцию φ(x) = f(x) − C. Она непрерывна на [a, b] как разность непрерывных функций, φ(a) = A − C < 0, φ(b) = B − C > 0. По теореме 2 найдётся ξ ∈ (a, b), при которой φ(ξ) = 0, то есть f(ξ) = C.

«Между A и B» понимается строго (C ≠ A, C ≠ B): тогда точка ξ действительно внутренняя. При C = A или C = B годятся сами концы a или b.

Замечание

Название «Больцано–Коши» носят в разных пособиях разные теоремы. В лекции так названа теорема о промежуточных значениях (теорема 3), а теорема о нуле — это теорема 2. В практике № 10 наоборот: теорема о нуле названа теоремой Больцано–Коши, а теорема 3 — «теоремой о промежуточных значениях». Смотри на формулировку, а не на имя.

Обратное неверно (дополнительно к лекции): свойство «принимать все промежуточные значения» ещё не означает непрерывности. Функция f(x) = sin(1/x) при x ≠ 0, f(0) = 0 на [0; 1] принимает все значения из [−1; 1], но в нуле разрывна (статья 7.3).

Следствие: образ промежутка

Следствие

Образом непрерывной на промежутке функции является промежуток.

Доказательство из лекции (стр. 11). Образ — это множество значений f(⟨a, b⟩). Числовое множество является промежутком тогда и только тогда, когда вместе с любыми двумя точками оно содержит весь соединяющий их отрезок. Выберем два значения y₁ = f(x₁) и y₂ = f(x₂). Функция непрерывна на отрезке [x₁, x₂] (он лежит внутри промежутка), поэтому по теореме Больцано–Коши она принимает все значения между y₁ и y₂: отрезок [y₁, y₂] целиком лежит в образе.

Если соединить это следствие с теоремой Вейерштрасса (статья 7.6), получаем: непрерывная на отрезке [a, b] функция с наименьшим значением m и наибольшим M принимает ровно все значения из [m; M], то есть f([a, b]) = [m; M]. Пример: f(x) = x² на [−1; 2]: m = 0 (при x = 0), M = 4 (при x = 2), образ — отрезок [0; 4].

Как доказывать существование корня

Дополнительно к лекции. Типичная задача: доказать, что уравнение f(x) = 0 имеет корень (на заданном отрезке или вообще). Рецепт:

  • перенеси всё в одну часть: f(x) = 0 (для f(x) = C возьми φ = f − C, как в доказательстве теоремы 3);
  • проверь, что f непрерывна на всём отрезке [a, b] (элементарная функция, определённая в каждой точке отрезка);
  • найди a и b с f(a)·f(b) < 0 (подбор: считай значения в целых точках, пока знак не поменяется);
  • сделай вывод по теореме 2: внутри (a; b) есть корень.
Локализация корней кубического уравнениядополнительно к лекции
Покажите, что уравнение x³ − 3x + 1 = 0 имеет три действительных корня, и укажите содержащие их отрезки.

  1. f(x) = x³ − 3x + 1 непрерывна на всей оси. Составим таблицу значений:

    x−2−1012
    f(x)−131−13

  2. Знак меняется на отрезках [−2; −1] (−1 и 3), [0; 1] (1 и −1) и [1; 2] (−1 и 3). По теореме 2 на каждом из них есть корень.

  3. Корней у кубического уравнения не больше трёх (факт алгебры), поэтому найденные три корня — все, по одному на каждом отрезке.

Три корня: в (−2; −1), (0; 1) и (1; 2).

Уравнение cos x = xдополнительно к лекции
Докажите, что уравнение cos x = x имеет корень на интервале (0; 1).

  1. Положим φ(x) = cos x − x. Это непрерывная функция (разность непрерывных, статья 7.2).

  2. φ(0) = cos 0 − 0 = 1 > 0; φ(1) = cos 1 − 1 ≈ −0,46 < 0 (аргумент в радианах). Значения на концах разных знаков.

  3. По теореме 2 найдётся ξ ∈ (0; 1), для которой φ(ξ) = 0, то есть cos ξ = ξ.

Корень существует. (Сколько их — теорема не говорит.)

Неподвижная точкадополнительно к лекции
Пусть f непрерывна на [0; 1] и все её значения лежат в [0; 1]. Докажите, что найдётся ξ ∈ [0; 1] с f(ξ) = ξ.

  1. Положим φ(x) = f(x) − x, она непрерывна на [0; 1].

  2. Так как 0 ≤ f(x) ≤ 1, имеем φ(0) = f(0) ≥ 0 и φ(1) = f(1) − 1 ≤ 0.

  3. Если φ(0) = 0 или φ(1) = 0, корень — конец отрезка (ξ = 0 или ξ = 1). Иначе φ(0) > 0 > φ(1), и по теореме 2 корень φ лежит внутри (0; 1).

Такая точка ξ есть: график f пересекает диагональ y = x.

Осторожно

Ловушка: f(x) = 1/x на [−1; 1] имеет f(−1) = −1 < 0, f(1) = 1 > 0, а корней нет. Причина в том, что функция в нуле (внутри отрезка) не определена, то есть не непрерывна на отрезке. Перед применением теоремы всегда проверяй непрерывность на всём отрезке.

Частые ошибки

Так нельзя

Применять теорему о нуле, не проверив непрерывность на всём отрезке: «f(−1) < 0, f(1) > 0, значит, 1/x обращается в нуль».

Так правильно

Теорема требует непрерывности на отрезке. 1/x разрывна в нуле, корня нет.

Так нельзя

«На концах знаки одинаковы, значит, корней нет».

Так правильно

Это не следует. Корней может не быть (x² + 1), а может быть несколько (x² − 1 на [−2; 2]). Теорема даёт лишь достаточное условие.

Так нельзя

Считать, что теорема о нуле даёт ровно один корень.

Так правильно

Она гарантирует хотя бы один. Единственность нужно доказывать отдельно (например, монотонностью).

Так нельзя

Применять теорему Больцано–Коши для значения C вне отрезка между A и B.

Так правильно

Гарантия только для C между f(a) и f(b). Для других значений решение может быть, а может не быть.

Так нельзя

Путать теоремы: говорить «по Больцано–Коши есть корень», не уточняя, какая именно теорема.

Так правильно

Называй формулировку: «по теореме о нуле (f(a)·f(b) < 0)» или «по теореме о промежуточных значениях». Названия в учебниках расходятся.

Кратко для повторения

Кратко для повторения

  • Теорема о нуле: f непрерывна на [a, b] и f(a)·f(b) < 0 ⇒ внутри есть ξ с f(ξ) = 0.
  • Метод половинного деления: берём половину с противоположными знаками на концах; после n шагов отрезок длины (b − a)/2ⁿ содержит корень.
  • Больцано–Коши: f непрерывна на [a, b], f(a) = A, f(b) = B, C между A и B ⇒ есть внутренняя ξ с f(ξ) = C (вывод: φ = f − C и теорема о нуле).
  • Образ непрерывной функции на промежутке — промежуток; на отрезке — отрезок [m; M].
  • Чтобы доказать корень: непрерывность на отрезке плюс разные знаки на концах. Без непрерывности (1/x на [−1; 1]) теорема неверна.

1
На каком из отрезков теорема о нуле гарантирует корень уравнения x³ + 2x − 5 = 0?
Варианты ответа

Показать решение

f(x) = x³ + 2x − 5 непрерывна. f(0) = −5, f(1) = −2, f(2) = 7, f(3) = 28, f(−1) = −8. Знак меняется только между 1 и 2: f(1)·f(2) = −14 < 0.

2
Уравнение x³ − 5 = 0 решают методом половинного деления на [1; 2]. Каков левый конец отрезка после трёх шагов?

Показать решение

f(1) = −4, f(2) = 3. Шаг 1: c = 1,5, f = −1,625 < 0 → [1,5; 2]. Шаг 2: c = 1,75, f ≈ 0,359 > 0 → [1,5; 1,75]. Шаг 3: c = 1,625, f ≈ −0,709 < 0 → [1,625; 1,75]. Левый конец 1,625.

3
Рассуждают о функции f(x) = 1/x на отрезке [−1; 1]. В каком шаге допущена первая ошибка?
Варианты ответа

Показать решение

Теорема о нуле требует непрерывности на всём отрезке. Функция 1/x в точке x = 0 ∈ [−1; 1] не определена (разрыв второго рода), поэтому теорема неприменима. Корней у 1/x нет совсем.

Функция f непрерывна на отрезке [1; 4], её наименьшее значение равно −2, наибольшее 5. Сколько целых значений принимает f?

По теореме Вейерштрасса m = −2 и M = 5 достигаются, а по теореме Больцано–Коши (следствие) f принимает все значения между ними: образ — отрезок [−2; 5]. Целые значения: −2, −1, 0, 1, 2, 3, 4, 5, всего 8.
