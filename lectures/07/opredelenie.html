Статья 7.1

Непрерывность в точке: определения

Непрерывность — это математическая запись слов «без скачков»: малое изменение аргумента даёт малое изменение значения функции. С неё начинается всё остальное в лекции: точки разрыва, теоремы на отрезке, непрерывность элементарных функций. В статье — определение в пяти равносильных формах, три условия, которые нужно проверить, и приём «докажи по определению».

Идея непрерывности

Многие зависимости в технике и экономике меняются «плавно»: координаты ракеты при росте времени с момента запуска, затраты ресурсов при постепенном увеличении объёма продукции. Как записать «плавно» формулой? Возьми точку x₀ из области определения функции f и её значение f(x₀). Начнём понемногу сдвигать аргумент от x₀ в любую сторону. Если функция «плавная», её значения тоже сдвигаются понемногу и остаются близкими к f(x₀). Иначе говоря, в малой окрестности точки x₀ непрерывную функцию можно приближённо заменить постоянной y = f(x₀).

Непрерывность через бесконечно малую функцию (формула 3.1)

Функция f, определённая на некоторой окрестности точки x₀, называется непрерывной в точке x₀, если найдётся такая бесконечно малая функция (б.м.ф.) α в окрестности x₀, что f(x) = f(x₀) + α(x) при всех x из некоторой проколотой окрестности точки x₀.

Б.м.ф. при x → x₀ — это функция, предел которой в точке x₀ равен нулю (теория пределов — лекция 6). Окрестность здесь проколотая, то есть без самой точки x₀: функция α может быть не определена в x₀, и лекция на это прямо указывает. Смысл формулы: разность f(x) − f(x₀) становится сколь угодно малой, когда x близко к x₀.

Запомни

Образ «график можно нарисовать, не отрывая карандаша» годится как первое впечатление и только на промежутке. Например, tg x непрерывна в каждой точке своей области определения, но её график состоит из отдельных ветвей, и нарисовать его одним росчерком нельзя.

Определение через предел

Чаще всего непрерывность определяют через предел. Это равносильное определение (формула 3.2):

limx→x₀ f(x) = f(x₀)
Функция непрерывна в точке, если её предел в этой точке равен её значению.

Равенство содержит три требования. Все три нужно проверять, и нарушение любого делает функцию разрывной в точке:

  • функция определена в точке x₀ (иначе справа в равенстве нечего писать); определённость и около x₀ лекция требует в определениях (3.1) и ε–δ, а практика № 10 включает её в это первое условие;
  • существует конечный предел limx→x₀ f(x) (иначе нечего писать слева);
  • эти два числа совпадают.

Запомни

Слово «конечный» важно (лекция, стр. 2, условие 2). Предел +∞ или −∞ числом не является, и равенство lim = f(x₀) в таком случае не выполняется. Предел и значение в точке — это две разные проверки: предел описывает поведение функции около x₀, а значение — то, что происходит в x₀.

Пример 1из лекции, стр. 2
Пусть f(x) = c — постоянная. Докажите, что f непрерывна в каждой точке.

  1. Возьми любую точку x₀. Функция определена в ней и около неё, f(x₀) = c.

  2. Предел постоянной равен ей самой: limx→x₀ c = c.

  3. Предел и значение совпадают: limx→x₀ f(x) = c = f(x₀). Все три условия выполнены.

Постоянная функция непрерывна в каждой точке числовой оси.

Пример 2из лекции, стр. 2
Пусть f(x) = x. Докажите, что f непрерывна в каждой точке.

  1. Возьми любую точку x₀. Функция определена на всей оси, f(x₀) = x₀.

  2. При x → x₀ значения x стремятся к x₀: limx→x₀ x = x₀.

  3. Предел равен значению: limx→x₀ f(x) = x₀ = f(x₀).

Функция f(x) = x непрерывна в каждой точке числовой оси.

Ещё три формы определения

Лекция даёт определение непрерывности сразу в нескольких равносильных формах. Разные формы удобны для разных задач, поэтому знать нужно все.

Замечание

В заголовке п. 1° (стр. 1) сказано «четыре эквивалентных определения», но в тексте их пять: (3.1) через б.м.ф., (3.2) через предел, ε–δ и по последовательностям (стр. 2), а на стр. 7 добавлено пятое, через приращение функции (3.3).

Форма ε–δ

Функция f, определённая в окрестности точки x₀, непрерывна в x₀, если для любого ε > 0 существует δ > 0 такое, что для всех x с |x − x₀| < δ выполнено |f(x) − f(x₀)| < ε.

Словами: как бы строго ты ни задал допустимую погрешность ε в значении функции, найдётся такая окрестность x₀ (радиуса δ), в которой значения отличаются от f(x₀) меньше чем на ε. (В лекции x берётся из проколотой окрестности; в самой точке x₀ неравенство выполнено тривиально, так как |f(x₀) − f(x₀)| = 0.)

Для ε = 0,5 подходит δ = 0,4. Можно взять и чуть больше: границы полосы достигаются при x = √2 ≈ 1,414 и x = √6 ≈ 2,449, поэтому годится любое δ до √6 − 2 ≈ 0,449. Чем меньше ε, тем меньше может понадобиться δ.

Пример 3. Подобрать δ по заданному εдополнительно к лекции
Для f(x) = 3x + 2 в точке x₀ = 1 найдите δ, при котором |f(x) − f(1)| < ε, если ε = 0,06.

  1. Значение в точке: f(1) = 5.

  2. Оценим отклонение: |f(x) − f(1)| = |3x + 2 − 5| = 3|x − 1|.

  3. Условие 3|x − 1| < ε равносильно |x − 1| < ε/3. Значит, подходит δ = ε/3; при ε = 0,06 получаем δ = 0,02.

  4. Проверка: на краю окрестности x = 1,02 имеем f = 5,06, то есть отклонение ровно 0,06; внутри окрестности оно строго меньше.

δ = ε/3 = 0,02. Для линейной функции kx + b (при k ≠ 0) годится δ = ε/|k|.

Форма по последовательностям (Гейне)

Функция f непрерывна в x₀, если для любой последовательности xn, у которой xn → x₀ и xn ≠ x₀, выполнено f(xn) → f(x₀).

Эта форма особенно удобна, чтобы опровергнуть непрерывность: достаточно предъявить одну «плохую» последовательность. Пример (дополнительно к лекции): f(x) = sin(1/x) при x ≠ 0, f(0) = 0. Возьми xn = 1/(π/2 + 2πn). Тогда xn → 0, но f(xn) = sin(π/2 + 2πn) = 1, а не f(0) = 0. Значит, в нуле функция не непрерывна.

Форма через приращения (формула 3.3, стр. 6–7)

Пусть Δx = x − x₀ — приращение аргумента, Δy = f(x₀ + Δx) − f(x₀) — приращение функции. Функция f непрерывна в точке x₀, если limΔx→0 Δy = 0, то есть приращение функции — б.м.ф. при Δx → 0.

Как лекция это получает: подставим x = x₀ + Δx в формулу (3.1), тогда Δy = α(x₀ + Δx), а композиция двух б.м.ф. — снова б.м.ф. (лемма о композиции, разобрана в статье 7.5). Обратное тоже верно. На языке приращений непрерывность звучит совсем просто: малому приращению аргумента отвечает малое приращение функции.

Как доказать непрерывность по определению

Два стандартных способа:

  • Через предел. (1) Найди f(x₀); (2) вычисли limx→x₀ f(x) по теоремам о пределах суммы, произведения и частного; (3) сравни.
  • Через приращения. (1) Запиши Δy = f(x₀ + Δx) − f(x₀) и раскрой скобки; (2) вынеси Δx за скобки; (3) покажи, что Δy → 0 при Δx → 0.
Пример 4. Доказательство по определению, двумя способамидополнительно к лекции (практика № 10)
Докажите, что функция f(x) = 2x² − 5x + 1 непрерывна в произвольной точке x₀ числовой оси.

  1. Способ 1 (через предел). По теоремам о пределе суммы и произведения: limx→x₀ (2x² − 5x + 1) = 2·(lim x)² − 5·lim x + 1 = 2x₀² − 5x₀ + 1.

  2. Значение в точке: f(x₀) = 2x₀² − 5x₀ + 1. Предел равен значению, функция непрерывна в x₀.

  3. Способ 2 (через приращения). Запишем приращение функции:

    Δy = 2(x₀ + Δx)² − 5(x₀ + Δx) + 1 − (2x₀² − 5x₀ + 1) = 4x₀Δx + 2(Δx)² − 5Δx = (4x₀ − 5)Δx + 2(Δx)²

  4. При Δx → 0 оба слагаемых стремятся к нулю: lim Δy = (4x₀ − 5)·0 + 2·0 = 0. Это и есть непрерывность в точке x₀.

  5. Проверка числами: при x₀ = 3, Δx = 0,1 имеем f(3) = 4, f(3,1) = 4,72, Δy = 0,72; по формуле (4·3 − 5)·0,1 + 2·0,01 = 0,7 + 0,02 = 0,72.

Функция непрерывна в любой точке x₀ ∈ ℝ.

Пример 5. Непрерывность модуля по ε–δдополнительно к лекции
Докажите, что f(x) = |x| непрерывна в любой точке x₀.

  1. Неравенство треугольника даёт ||x| − |x₀|| ≤ |x − x₀|.

  2. Пусть задано ε > 0. Возьмём δ = ε. Если |x − x₀| < δ, то |f(x) − f(x₀)| = ||x| − |x₀|| ≤ |x − x₀| < ε.

Для любого ε подходит δ = ε, значит, |x| непрерывна в каждой точке.

Частые ошибки

Так нельзя

«Предел в точке существует, значит, функция непрерывна».

Так правильно

Нужно ещё, чтобы функция была определена в точке и её значение равнялось этому пределу. Например, (x² − 9)/(x − 3) в точке 3 имеет предел 6, но не определена.

Так нельзя

«Функция определена в точке, значит, непрерывна».

Так правильно

Значение в точке ещё ничего не говорит о поведении вокруг. [x] определена в каждой целой точке, но предела там нет.

Так нельзя

Считать, что предел +∞ — это «существующий» предел, и поэтому условие 2 выполнено.

Так правильно

В определении непрерывности нужен конечный предел. Бесконечный предел — это нарушение, и разрыв будет второго рода (статья 7.3).

Так нельзя

Для ε–δ брать δ в виде ε для любой функции.

Так правильно

δ зависит от функции и точки: для f(x) = 3x + 2 подходит δ = ε/3 (и любое меньшее), для |x| подходит δ = ε.

Кратко для повторения

Кратко для повторения

  • Функция f непрерывна в x₀, если limx→x₀ f(x) = f(x₀): f определена в x₀ (и около), конечный предел существует, предел равен значению.
  • Равносильные формы: f(x) = f(x₀) + α(x) (α — б.м.ф.); ε–δ; по последовательностям (Гейне); lim Δy = 0 при Δx → 0.
  • Постоянная функция и f(x) = x непрерывны в каждой точке.
  • Доказательство по определению: через предел (сравнить lim и f(x₀)) или через приращения (Δy = (…)·Δx + …, затем Δx → 0).
  • Опровергать непрерывность удобно последовательностью xn → x₀, для которой f(xn) не стремится к f(x₀).

Проверь себя

Задания для самопроверки

Решено: 0 из 6

Ответ — число: целое, десятичное (0,25) или дробь (1/4). Минус — обычный дефис. Подсказки появляются после неверного ответа, решение можно открыть в любой момент.

1
У функции f(x) = (x² − 9)/(x − 3) исследуем непрерывность в точке x₀ = 3. Какое из трёх условий определения нарушено?
Варианты ответа

Показать решение

При x ≠ 3 имеем (x² − 9)/(x − 3) = (x − 3)(x + 3)/(x − 3) = x + 3, поэтому предел при x → 3 равен 6. Но в самой точке x = 3 знаменатель обращается в нуль, значение f(3) не определено. Нарушено первое условие.

2
Какие из условий равносильны непрерывности функции f в точке x₀? Отметьте все верные.
Варианты ответа; можно выбрать несколько

Показать решение

Три первых условия — это определение через предел, через приращения и по Гейне. Последние два — лишь части определения: нужны оба и ещё совпадение значений.

3
Функция f(x) = 3x² + x. Подставьте пропущенное, чтобы доказать непрерывность через приращения.
Δy = f(x₀ + Δx) − f(x₀) = . При Δx → 0 получаем Δy → , значит, функция в точке x₀.

Показать решение

3(x₀ + Δx)² + (x₀ + Δx) − 3x₀² − x₀ = 6x₀Δx + 3(Δx)² + Δx = (6x₀ + 1)Δx + 3(Δx)². При Δx → 0 это стремится к 0, то есть lim Δy = 0, и функция непрерывна в каждой точке.

4
Для функции f(x) = 4x − 1 в точке x₀ = 2 найдите наибольшее δ, при котором из |x − 2| < δ следует |f(x) − f(2)| < 0,2.

Показать решение

|f(x) − f(2)| = |4x − 1 − 7| = 4|x − 2|. Условие 4|x − 2| < 0,2 равносильно |x − 2| < 0,05. Наибольшее δ равно 0,05.

5
Проверяем непрерывность функции f(x) = sin x / x в точке x₀ = 0. В каком шаге допущена первая ошибка?
Варианты ответа

Показать решение

Существование предела — только второе условие. Функция sin x / x в точке 0 не определена, поэтому непрерывной там она не является. Разрыв устраним: если положить f(0) = 1, получится непрерывная функция.

6
Известно, что f(0) = 0, а для последовательности xn = 1/n (она стремится к 0) значения f(xn) = 1 при всех n. Что отсюда следует?
Варианты ответа

Показать решение

xn = 1/n → 0, xn ≠ 0, но f(xn) = 1 → 1 ≠ 0 = f(0). Условие Гейне нарушено, значит, f в точке 0 не непрерывна.
