Практика № 10 строится на задачах нескольких типов: найти точки разрыва и их род, найти скачок, доопределить функцию по непрерывности, подобрать параметр, выбрать функции с разрывом первого рода. Все они решаются по одному плану и одним набором предельных приёмов. Статья — рабочая тетрадь: план, справочник типовых пределов, разобранные примеры и раздел про показатели вида 1/(x² − a²) и x/(9 − x²). Теория разрывов — в статье 7.3, подбор параметра — в статье 7.2.

План исследования

  • Область определения. Выпиши, где функция не определена: знаменатель равен нулю, аргумент логарифма не положителен, tg x при x = π/2 + πk и т. д. Это первые подозрительные точки.
  • Точки стыка у кусочной функции — вторые подозрительные точки.
  • Остальные точки. На промежутках, где функция задана одной элементарной формулой, она непрерывна (статья 7.8). Так и напиши: «на (…) непрерывна как элементарная».
  • В каждой подозрительной точке найди f(x₀ − 0), f(x₀ + 0) и, если есть, f(x₀). У дроби сначала разложи и сократи.
  • Классифицируй (статья 7.3) и запиши ответ: «в точке x = … разрыв … рода (устранимый / скачок … / бесконечный)», для устранимого — значение доопределения.

Запомни

Образец ответа: «функция непрерывна всюду, кроме x = −2 (второй род) и x = 2 (устранимый разрыв, f(2) = −1/4)».

Рациональная дробь: сократить и посмотреть на знаменатель

Пример 1. Дробь с общим множителемдополнительно к лекции (практика № 10)
Найдите точки разрыва функции f(x) = (x² − 5x + 6)/(x² − 4), определите их род; для устранимого разрыва укажите значение доопределения.

  1. Знаменатель (x − 2)(x + 2) равен нулю при x = 2 и x = −2. В остальных точках f непрерывна как рациональная дробь (статья 7.2).

  2. Разложим числитель: x² − 5x + 6 = (x − 2)(x − 3). При x ≠ ±2 получаем f(x) = (x − 2)(x − 3)/((x − 2)(x + 2)) = (x − 3)/(x + 2).

  3. Точка x = 2. Пределы слева и справа одинаковы: limx→2 (x − 3)/(x + 2) = (2 − 3)/(2 + 2) = −1/4. Они конечны и равны, а f(2) не определена: устранимый разрыв. Доопределим f(2) = −1/4.

  4. Точка x = −2. Числитель x − 3 → −5, знаменатель x + 2 → 0. При x → −2− знаменатель отрицателен: (−5)/(0−) = +∞; при x → −2+ он положителен: (−5)/(0+) = −∞. Пределы бесконечны: разрыв второго рода.

  5. График (после сокращения — гипербола, в точке 2 «дырка»):

x = 2: устранимый разрыв (f(2) = −1/4 делает функцию непрерывной); x = −2: разрыв второго рода.

Кусочная функция: проверяем точки стыка

Пример 2. Три формулы, два стыкадополнительно к лекции (практика № 10)
Исследуйте на непрерывность функцию и определите характер разрывов.
f(x) =
x² + 1, x ≤ 0
x + 1, 0 < x ≤ 2
6 − x, x > 2

  1. Каждая из формул x² + 1, x + 1, 6 − x непрерывна на всей оси, поэтому разрыв возможен только в точках стыка x = 0 и x = 2.

  2. Точка x = 0. Слева (формула x² + 1): f(0 − 0) = 1; значение f(0) = 0² + 1 = 1; справа (формула x + 1): f(0 + 0) = 1. Все три числа равны: функция непрерывна.

  3. Точка x = 2. Слева: f(2 − 0) = 2 + 1 = 3; значение f(2) = 3; справа (формула 6 − x): f(2 + 0) = 6 − 2 = 4. Пределы конечны, но различны: скачок 4 − 3 = 1; так как f(2) = f(2 − 0), слева функция непрерывна.

x = 0 — точка непрерывности; x = 2 — разрыв первого рода (скачок 1), непрерывность слева.

Пример 3. Формулы разных типовдополнительно к лекции (практика № 10)
Исследуйте на непрерывность функцию, заданную элементарными формулами разных типов.
f(x) =
2x, x ≤ 0
cos x, 0 < x ≤ π
1/(x − π), x > π

  1. Формулы 2x, cos x непрерывны на всей оси, а 1/(x − π) непрерывна при x > π (там знаменатель не нуль). Подозрительны только стыки x = 0 и x = π.

  2. Точка x = 0. Слева f(0 − 0) = 2⁰ = 1, значение f(0) = 2⁰ = 1 (формула с «≤»), справа f(0 + 0) = cos 0 = 1. Все три числа равны: функция непрерывна.

  3. Точка x = π. Слева f(π − 0) = cos π = −1, значение f(π) = cos π = −1: непрерывна слева. Справа x − π → 0+, поэтому f(π + 0) = lim 1/(x − π) = +∞.

  4. Правый предел бесконечен: разрыв второго рода, хотя слева функция непрерывна.

x = 0 — непрерывна; x = π — разрыв второго рода (непрерывность слева).

Показательная функция с 1/x в показателе

Пример 4. Скачокдополнительно к лекции (практика № 10)
Определите характер разрыва функции f(x) = 1/(1 + 21/x) в точке x = 0.

  1. В нуле функция не определена (1/x в показателе), поэтому x = 0 — точка разрыва.

  2. Слева: x → 0−, 1/x → −∞, 21/x → 0, поэтому f(0 − 0) = 1/(1 + 0) = 1.

  3. Справа: x → 0+, 1/x → +∞, 21/x → +∞, поэтому f(0 + 0) = 1/(1 + ∞) = 0.

  4. Оба предела конечны, но различны: разрыв первого рода, скачок f(0 + 0) − f(0 − 0) = 0 − 1 = −1.

Разрыв первого рода (неустранимый), скачок −1.

Пример 5. Показательная функция в числителедополнительно к лекции (практика № 10)
Найдите точки разрыва f(x) = 31/(x − 2)/(x + 1) и определите их род.

  1. Не определена при x = 2 (в показателе) и x = −1 (в знаменателе). Других подозрительных точек нет.

  2. Точка x = 2. Слева: 1/(x − 2) → −∞, 31/(x − 2) → 0, знаменатель x + 1 → 3, поэтому f(2 − 0) = 0. Справа: 31/(x − 2) → +∞, поэтому f(2 + 0) = +∞. Правый предел бесконечен: разрыв второго рода.

  3. Точка x = −1. Числитель стремится к положительному числу 3−1/3, знаменатель x + 1 → 0. Слева знаменатель отрицателен: f(−1 − 0) = −∞; справа положителен: f(−1 + 0) = +∞. Разрыв второго рода.

Обе точки, x = 2 и x = −1, — разрывы второго рода.

Замечание

В разборе практики № 10 для 101/(x − 3)/(x + 1) оба односторонних предела в точке x = 3 названы бесконечными. Слева на самом деле 0 (10−∞ = 0), справа +∞; вывод «разрыв второго рода» верен, но пределы нужно записать так.

Показатель посложнее: знаки по интервалам

В практике показатель чаще такой: 1/(x² − x − 2), 1/(4 − x²), x/(9 − x²), 1/(x²(x² − 1)), а знаменатель дроби может обращаться в нуль в той же точке. Идея прежняя: куда идёт показатель φ(x) и чему равно aφ; новое — найти знак φ по обе стороны от каждого корня. Алгоритм (для a > 1):

  • Разложи знаменатель показателя (трёхчлен ax² + bx + c = a(x − x₁)(x − x₂) — через дискриминант, 4 − x² — по разности квадратов). Его корни и корни знаменателя дроби — подозрительные точки.
  • Знак φ по интервалам: отметь корни числителя и знаменателя φ, на каждом интервале определи знак каждого множителя и перемножь.
  • Кратность корня. Множитель (x − c)k меняет знак в c при нечётном k и не меняет при чётном; у корня чётной кратности знак φ по обе стороны задают остальные множители (x²(x − 2) около нуля отрицателен, x²(2 − x) положителен).
  • Результат у корня c (числитель φ в c не нуль, φ → ±∞): сторона φ → +∞ даёт +∞, сторона φ → −∞ даёт 0; затем учти знак множителя дроби. При a < 1 стороны меняются.
  • Корни совпали (корень показателя — и корень знаменателя дроби): 0 на бесконечность, выигрывает показательная функция. Сторона φ → +∞ даёт ±∞ (знак по знаменателю), сторона φ → −∞ — 0 (пример 8).

  2. Точка x = −2. Слева φ → −∞, 2φ → 0; справа φ → +∞, 2φ → +∞. Знаменатель дроби x − 1 → −3 отрицателен: f(−2 − 0) = 0, f(−2 + 0) = −∞.

  3. Точка x = 2. Слева φ → −∞, справа φ → +∞, x − 1 → 1: f(2 − 0) = 0, f(2 + 0) = +∞. Точка x = 1: показатель конечен (φ(1) = −1/3), 2−1/3 > 0, а x − 1 → 0, поэтому f(1 − 0) = −∞, f(1 + 0) = +∞.

Три точки, x = −2, x = 2 и x = 1, — разрывы второго рода.

Пример 7. Корень чётной кратностидополнительно к лекции (практика № 10)
Найдите точки разрыва f(x) = 51/(x²(x − 2)) и определите их род.

  1. Показатель не определён при x = 0 (корень кратности 2) и x = 2. При x ≠ 0 множитель x² > 0, поэтому знак x²(x − 2) совпадает со знаком x − 2: < 0 при x < 2, > 0 при x > 2.

  2. Точка x = 0. Знак не меняется: знаменатель показателя < 0 и слева, и справа, φ → −∞ с обеих сторон, 5φ → 0. Итак, f(0 − 0) = f(0 + 0) = 0, а f(0) не определена: устранимый разрыв.

  3. Точка x = 2 (кратность 1). Слева φ → −∞, f(2 − 0) = 0; справа φ → +∞, f(2 + 0) = +∞: второй род.

x = 0 — устранимый разрыв (f(0) = 0 делает функцию непрерывной); x = 2 — второго рода.

Пример 8. Корень показателя совпал с корнем знаменателядополнительно к лекции (практика № 10)
Найдите точки разрыва f(x) = 31/(x² − 4x + 3)/(x − 1) и определите их род.

  1. x² − 4x + 3 = (x − 1)(x − 3) (D = 4, корни 3 и 1). Корень x = 1 показателя совпал с корнем знаменателя дроби; x = 3 обычный.

  2. Точка x = 3. Слева (x − 1)(x − 3) < 0, справа > 0; x − 1 → 2. Поэтому f(3 − 0) = 0, f(3 + 0) = +∞: второй род.

  3. Точка x = 1. Пусть t = x − 1: x − 3 → −2, знаменатель показателя ≈ −2t, φ ≈ −1/(2t). Слева (t < 0): φ → +∞, 3φ → +∞, 1/t → −∞: f(1 − 0) = −∞.

  4. Справа (t > 0): φ → −∞, 3φ → 0, а 1/t → +∞: нуль на бесконечность. При s = 1/(2t) → +∞ функция ведёт себя как 2s/3s (с точностью до постоянного множителя) и стремится к нулю, ведь показательная функция растёт быстрее степенной: f(1 + 0) = 0. Числами: f(1,05) ≈ 2,6·10−4, f(1,01) ≈ 1,1·10−22.

x = 1: f(1 − 0) = −∞, f(1 + 0) = 0; x = 3: f(3 − 0) = 0, f(3 + 0) = +∞. Обе точки — второго рода.

Модуль и арктангенс: скачки

Пример 9. Модуль в дробидополнительно к лекции (практика № 10)
Определите характер разрыва функции f(x) = x + |x − 3|/(x − 3) в точке x = 3.

  1. Раскроем модуль. При x > 3: |x − 3| = x − 3, дробь равна 1, f(x) = x + 1. При x < 3: |x − 3| = −(x − 3), дробь равна −1, f(x) = x − 1.

  2. В точке 3 функция не определена. Односторонние пределы: f(3 − 0) = 3 − 1 = 2, f(3 + 0) = 3 + 1 = 4.

  3. Пределы конечны и различны: разрыв первого рода, скачок 4 − 2 = 2.

Разрыв первого рода (неустранимый), скачок 2.

Пример 10. Арктангенсдополнительно к лекции (практика № 10)
Определите характер разрыва функции f(x) = arctg(1/(x + 1)) в точке x = −1 и найдите скачок.

  1. В точке −1 функция не определена. При x → −1− имеем x + 1 → 0−, 1/(x + 1) → −∞, arctg → −π/2: f(−1 − 0) = −π/2.

  2. При x → −1+ имеем 1/(x + 1) → +∞, arctg → π/2: f(−1 + 0) = π/2.

  3. Пределы конечны и различны. Скачок π/2 − (−π/2) = π.

Разрыв первого рода, скачок π.

Пример 11. Три точки подозрениядополнительно к лекции (практика № 10)
Найдите все точки разрыва f(x) = (x + 2)/ln|x| и определите их характер.

  1. Подозрительны: x = 0 (под логарифмом нуль) и x = ±1, где знаменатель ln|x| = 0. Всего три точки.

  2. Точка x = 0. При x → 0 имеем ln|x| → −∞, поэтому 1/ln|x| → 0, а x + 2 → 2. Оба односторонних предела равны 2·0 = 0: устранимый разрыв (f(0) можно положить равным 0).

  3. Точка x = 1. Числитель → 3. Знаменатель: слева ln x < 0, справа ln x > 0, и стремится к нулю. Значит, f(1 − 0) = −∞, f(1 + 0) = +∞: разрыв второго рода.

  4. Точка x = −1. Числитель → 1. При x → −1− имеем |x| > 1, ln|x| → 0+, f → +∞; при x → −1+ имеем |x| < 1, ln|x| → 0−, f → −∞. Разрыв второго рода.

Три точки разрыва: x = 0 — устранимый, x = 1 и x = −1 — второго рода.

Каким числом доопределить функцию по непрерывности

В задачах практики спрашивают: «каким числом можно доопределить функцию в точке x₀, чтобы она стала непрерывной». Ответ существует тогда и только тогда, когда у функции в x₀ устранимый разрыв, то есть когда существует конечный предел A; тогда f(x₀) = A. Если оба односторонних предела конечны, но различны (скачок), или хотя бы один бесконечен или не существует (колебания, как у sin(1/x)), то сделать функцию непрерывной одним значением нельзя.

Пример 12. Три вопроса «каким числом доопределить»дополнительно к лекции (практика № 10)
Можно ли доопределить в точке x = 0 функции (а) sin 5x/(2x), (б) x·cos(1/x), (в) arcctg(2/x), чтобы они стали непрерывными? Если можно, каким числом?

  1. (а) Первый замечательный предел: sin 5x/(2x) = (5/2)·(sin 5x/(5x)) → 5/2. Конечный предел есть, доопределяем f(0) = 5/2.

  2. (б) |x·cos(1/x)| ≤ |x| → 0: произведение б.м.ф. на ограниченную функцию стремится к нулю. Доопределяем f(0) = 0.

  3. (в) Слева: 2/x → −∞, arcctg(−∞) = π, то есть f(0 − 0) = π. Справа: 2/x → +∞, arcctg(+∞) = 0, то есть f(0 + 0) = 0. Пределы различны (скачок −π), общего предела нет: доопределить нельзя.

(а) да, 5/2; (б) да, 0; (в) нельзя: разрыв первого рода, скачок.

Частые ошибки

Так нельзя

После сокращения дроби считать, что точка сокращённого множителя стала непрерывной.

Так правильно

Равенство (x − 2)(x − 3)/((x − 2)(x + 2)) = (x − 3)/(x + 2) верно только при x ≠ 2; в самой точке 2 исходная функция не определена: устранимый разрыв, а не непрерывность.

Так нельзя

Писать «f(x₀ − 0) = f(x₀ + 0) = ∞, значит, предел существует, это первый род».

Так правильно

∞ — не число: разрыв с бесконечным пределом второго рода.

Так нельзя

Для aφ считать, что слева и справа одно и то же, или определять знак показателя по одному множителю (x² «всегда +∞»).

Так правильно

Знак φ задаёт весь знаменатель, а сторон две: корень нечётной кратности даёт разные бесконечности (при a > 1 пределы 0 и +∞), чётной — одну. Проверяй каждую сторону отдельно.

Так нельзя

Для кусочной функции искать разрыв внутри промежутка, где формула одна.

Так правильно

Внутри промежутка элементарная формула непрерывна. Разрыв может быть только на стыках и там, где формула не определена.

Так нельзя

Забыть про значение функции f(x₀) при проверке точки стыка.

Так правильно

Для непрерывности нужны три числа: f(x₀ − 0), f(x₀), f(x₀ + 0). Если f(x₀) отличается от общего предела, разрыв устранимый.

Кратко для повторения

Кратко для повторения

  • План: область определения и точки стыка → в каждой подозрительной точке f(x₀ − 0), f(x₀), f(x₀ + 0) → род и тип → ответ.
  • Дробь: разложи и сократи; если знаменатель в точке остался нулевым, а числитель нет, пределы бесконечны (второй род); знак смотри слева и справа.
  • a1/(x − c) при a > 1: слева 0, справа +∞; arctg(1/(x − c)): слева −π/2, справа π/2; |x − c|/(x − c): −1 и 1.
  • Показатель посложнее: знак по интервалам; у корня чётной кратности знак не меняется; если корень показателя и знаменателя дроби совпали, показательная функция сильнее степени.
  • Доопределить по непрерывности можно только при устранимом разрыве: f(x₀) = A, где A — общий конечный предел.
  • Скачок f(x₀ + 0) − f(x₀ − 0) считается как правый минус левый; у устранимого разрыва он равен нулю.
