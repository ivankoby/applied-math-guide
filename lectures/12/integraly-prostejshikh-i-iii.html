Статья 12.5

Интегралы простейших дробей I–III типов

После разложения (статьи 12.3–12.4) от рациональной функции остаются слагаемые четырёх типов, и интегрируют их по отдельности. Типы I и II берутся одной строкой, настоящая работа — в типе III, дроби (Mx + N)/(x² + px + q) с неприводимым трёхчленом. Лекция (стр. 4–5) решает её заменой t = x + p/2, и в ответе появляются логарифм и арктангенс: формула (24.3). Разберём её вывод по шагам, чтобы пересчитывать формулу, а не заучивать, и добавим то, чего нет в лекции: дроби с ax + b и со старшим коэффициентом, не равным 1. Тип IV (степень n ≥ 2 у квадратного трёхчлена) — в статье 12.6.

Что предполагается

На стр. 4 лекция договаривается: интеграл вычисляют на промежутке, в каждой точке которого подынтегральная функция определена. Для 1/(x − a) это промежуток слева или справа от a, но не оба сразу. Из лекции 11 (таблица интегралов, п. 22.2) нужны формулы: ∫xⁿ dx = xn+1/(n + 1) + C при n ≠ −1 (формула 1), ∫dx/x = ln|x| + C (формула 2), ∫dt/(t² + a²) = (1/a)·arctg(t/a) + C при a > 0 (формула 12) и линейность интеграла (22.6).

Нужно и правило сдвига: если F′ = f, то (F(kx + b))′ = k·f(kx + b), поэтому ∫f(kx + b) dx = (1/k)·F(kx + b) + C при k ≠ 0 (подведение под знак дифференциала, лекция 11).

Типы I и II: A/(x − a)n

∫ A/(x − a) dx = A·ln|x − a| + C (24.1)
∫ A/(x − a)n dx = −A/((n − 1)(x − a)n−1) + C, n ≥ 2 (24.2)
Тип I даёт логарифм, тип II — степень с отрицательным показателем; в (24.2) показатель в знаменателе на единицу меньше.

Вывод: в (24.1) формула 2 и сдвиг x → x − a (при x < a тоже верно: (ln|x − a|)′ = 1/(x − a)). В (24.2) пишем A(x − a)−n, и формула 1 даёт A·(x − a)−n+1/(−n + 1). Модуль под логарифмом нужен, чтобы формула работала и слева от a.

Дополнительно к лекции (опорный конспект, стр. 35): для знаменателя ax + b по правилу сдвига выходит множитель 1/a: ∫A/(ax + b) dx = (A/a)·ln|ax + b| + C, ∫A/(ax + b)n dx = −A/(a(n − 1)(ax + b)n−1) + C. Особенно легко ошибиться при a < 0: ∫dx/(3 − x) = −ln|3 − x| + C, так как (3 − x)′ = −1.

Тип III: (Mx + N)/(x² + px + q)

Здесь p²/4 − q < 0: у трёхчлена нет действительных корней. Вывод (24.3) в пять шагов (лекция, стр. 5):

  • 1. Выдели полный квадрат: x² + px + q = (x + p/2)² + (q − p²/4). Обозначь t = x + p/2 (тогда dx = dt) и a² = q − p²/4. Число a² > 0 — это ровно условие p²/4 − q < 0.
  • 2. Перепиши числитель через t: x = t − p/2, Mx + N = M(t − p/2) + N = Mt + (N − Mp/2).
  • 3. Раздели на два интеграла: ∫(Mx + N)/(x² + px + q) dx = M∫t dt/(t² + a²) + (N − Mp/2)∫dt/(t² + a²).
  • 4. Возьми каждый: ∫t dt/(t² + a²) = (1/2)·ln(t² + a²) (в числителе половина производной знаменателя), ∫dt/(t² + a²) = (1/a)·arctg(t/a) (формула 12).
  • 5. Вернись к x: t² + a² = x² + px + q, t/a = (2x + p)/(2a).
∫(Mx + N)/(x² + px + q) dx = (M/2)·ln(x² + px + q) + (2N − Mp)/(2a)·arctg((2x + p)/(2a)) + C, a² = q − p²/4 (24.3)
Логарифм без модуля: x² + px + q > 0 при любом x, ведь D < 0. Коэффициент при арктангенсе: (N − Mp/2)/a = (2N − Mp)/(2a).

Осторожно с буквой a

Буква a в (24.3) — не корень из типов I–II: здесь a² = q − p²/4, а 2a = √(4q − p²). Из-за этой путаницы часто теряют 1/a в арктангенсе. Ниже, в разделе про старший коэффициент, a — коэффициент при x²; это другое число. Формулу ∫dt/(t² + a²) = (1/a)·arctg(t/a) проверь подстановкой t = a·u: dt = a du, t² + a² = a²(u² + 1), откуда (1/a)·∫du/(u² + 1).

Два частных случая. При M = 0 остаётся один арктангенс: ∫N dx/(x² + px + q) = (N/a)·arctg((2x + p)/(2a)) + C. При N = Mp/2 (числитель кратен производной знаменателя 2x + p) остаётся один логарифм: (M/2)·ln(x² + px + q).

Удобный вариант (опорный конспект, стр. 36). Не вводя t, выдели в числителе производную знаменателя: Mx + N = (M/2)(2x + p) + (N − Mp/2). Первое слагаемое даёт (M/2)·ln(x² + px + q), ведь (2x + p)dx = d(x² + px + q); второе — арктангенс после выделения полного квадрата в знаменателе. Ответ тот же.

Что будет без условия D < 0. При p²/4 − q > 0 число q − p²/4 отрицательно, a² < 0 и арктангенса нет: трёхчлен раскладывается на (x − x₁)(x − x₂), и дробь надо разбивать на типы I (логарифмы). Сравни ∫dx/(x² + 1) = arctg x, но ∫dx/(x² − 1) = (1/2)·ln|(x − 1)/(x + 1)| (формула 13 лекции 11). При p²/4 − q = 0 трёхчлен равен (x + p/2)², и дробь разбивается на типы I и II.

Если старший коэффициент не 1

Дополнительно к лекции (опорный конспект, стр. 36). Простейшие дроби с ax² + bx + c, a ≠ 1, встречаются в задачах. Вынеси a за скобки: ax² + bx + c = a(x² + (b/a)x + c/a), постоянный множитель 1/a вынеси из интеграла и применяй (24.3) с p = b/a, q = c/a. Или выдели производную знаменателя: Mx + N = (M/(2a))(2ax + b) + (N − bM/(2a)), тогда ∫(2ax + b)dx/(ax² + bx + c) = ln|ax² + bx + c|, а в оставшемся интеграле выдели полный квадрат. Модуль нужен, если a < 0. Здесь a — старший коэффициент; число a из (24.3) для p = b/a, q = c/a равно √(4ac − b²)/(2|a|).

Разобранные примеры

Пример 1: числитель не пропорционален производной знаменателядополнительно (типовая задача)
Вычислить ∫(2x + 3)/(x² + 2x + 5) dx.

  1. p = 2, q = 5, p²/4 − q = 1 − 5 = −4 < 0: тип III. Полный квадрат: x² + 2x + 5 = (x + 1)² + 4, t = x + 1, a² = 4, a = 2.

  2. Числитель: 2x + 3 = 2(t − 1) + 3 = 2t + 1. Интеграл: ∫(2t + 1)/(t² + 4) dt = ∫2t dt/(t² + 4) + ∫dt/(t² + 4) = ln(t² + 4) + (1/2)·arctg(t/2).

  3. Возвращаемся к x: t² + 4 = x² + 2x + 5, t/2 = (x + 1)/2. По (24.3): M/2 = 1, (2N − Mp)/(2a) = (6 − 4)/4 = 1/2 — совпало.

∫(2x + 3)/(x² + 2x + 5) dx = ln(x² + 2x + 5) + (1/2)·arctg((x + 1)/2) + C

Пример 2: число a иррациональнодополнительно (по знаменателю из опорного конспекта, стр. 41)
Вычислить ∫(x − 1)/(x² + x + 1) dx.

  1. p = q = 1, p²/4 − q = 1/4 − 1 = −3/4 < 0. a² = q − p²/4 = 3/4, a = √3/2, 2a = √3. M = 1, N = −1.

  2. По (24.3): M/2 = 1/2; (2N − Mp)/(2a) = (−2 − 1)/√3 = −3/√3 = −√3; (2x + p)/(2a) = (2x + 1)/√3. Ответ можно и так проверить заменой: t = x + 1/2, x − 1 = t − 3/2, ∫t dt/(t² + 3/4) = (1/2)·ln(t² + 3/4), −(3/2)·(1/a)·arctg(t/a) = −(3/2)(2/√3)·arctg(…) = −√3·arctg(…).

∫(x − 1)/(x² + x + 1) dx = (1/2)·ln(x² + x + 1) − √3·arctg((2x + 1)/√3) + C

Пример 3: старший коэффициент 3дополнительно к лекции (опорный конспект, стр. 36)
Вычислить ∫(7x − 2)/(3x² − 5x + 4) dx.

  1. D = 25 − 48 = −23 < 0, трёхчлен неприводим. Производная знаменателя 6x − 5. Числитель: 7x − 2 = (7/6)(6x − 5) + 23/6 (проверка: (7/6)·6x = 7x, −35/6 + 23/6 = −2).

  2. Первое слагаемое: (7/6)·∫(6x − 5)/(3x² − 5x + 4) dx = (7/6)·ln(3x² − 5x + 4).

  3. Второе: (23/6)·∫dx/(3x² − 5x + 4). Вынесем 3: 3x² − 5x + 4 = 3((x − 5/6)² + 23/36), поэтому ∫dx/(3x² − 5x + 4) = (1/3)·(6/√23)·arctg(6(x − 5/6)/√23) = (2/√23)·arctg((6x − 5)/√23). Умножаем на 23/6: (23/6)(2/√23) = √23/3.

∫(7x − 2)/(3x² − 5x + 4) dx = (7/6)·ln(3x² − 5x + 4) + (√23/3)·arctg((6x − 5)/√23) + C

Пример 4: типы I и II со знаменателем ax + bдополнительно
Вычислить ∫(5/(2x − 3) + 4/(3 − x)²) dx.

  1. Первое слагаемое — тип I с a = 2: ∫5/(2x − 3) dx = (5/2)·ln|2x − 3|.

  2. Второе: (3 − x)² = (x − 3)², тип II, n = 2: ∫4/(x − 3)² dx = −4/(x − 3) = 4/(3 − x). Проверка: (4/(3 − x))′ = 4/(3 − x)².

∫(5/(2x − 3) + 4/(3 − x)²) dx = (5/2)·ln|2x − 3| + 4/(3 − x) + C на любом из промежутков, где знаменатели не нули.

Частые ошибки

Так нельзя

∫dx/(x² + 4) = ln(x² + 4).

Так правильно

Логарифм даёт часть числителя, пропорциональная производной знаменателя 2x (M ≠ 0). Здесь числитель — число, M = 0, и ∫dx/(x² + 4) = (1/2)·arctg(x/2) + C.

Так нельзя

∫dx/(x² + 4) = arctg(x/2) — потерян множитель 1/a.

Так правильно

∫dt/(t² + a²) = (1/a)·arctg(t/a). При a = 2 перед арктангенсом стоит 1/2. Проверка: ((1/2)·arctg(x/2))′ = (1/2)·(1/2)/(1 + x²/4) = 1/(x² + 4).

Так нельзя

В (24.3) взять в арктангенс просто N: N/a·arctg(…).

Так правильно

Числитель Mx + N при замене t = x + p/2 превращается в Mt + (N − Mp/2): коэффициент при арктангенсе (N − Mp/2)/a = (2N − Mp)/(2a). Для (2x + 3)/(x² + 2x + 5) это 1/2, а не 3/2.

Так нельзя

∫A/(x − a)n dx = A·ln|x − a| при n ≥ 2.

Так правильно

Логарифм только при n = 1. При n ≥ 2 — степенная формула (24.2): ∫dx/(x − a)² = −1/(x − a).

Так нельзя

∫dx/(2x − 3) = ln|2x − 3|, ∫dx/(3 − x) = ln|3 − x|.

Так правильно

Нужен множитель 1/k из правила сдвига: ∫dx/(2x − 3) = (1/2)·ln|2x − 3|, ∫dx/(3 − x) = −ln|3 − x|.

Так нельзя

Для 1/(x² − 4) брать арктангенс.

Так правильно

Арктангенс только при D < 0. У x² − 4 корни ±2, дробь раскладывается на типы I: 1/(x² − 4) = (1/4)(1/(x − 2) − 1/(x + 2)).

Кратко для повторения

Кратко для повторения

  • Тип I: ∫A/(x − a) dx = A·ln|x − a| + C (24.1). Тип II, n ≥ 2: ∫A/(x − a)n dx = −A/((n − 1)(x − a)n−1) + C (24.2). Для ax + b добавляется множитель 1/a.
  • Тип III, p²/4 − q < 0: t = x + p/2, a² = q − p²/4, Mx + N = Mt + (N − Mp/2); ∫ = (M/2)·ln(x² + px + q) + (2N − Mp)/(2a)·arctg((2x + p)/(2a)) + C (24.3).
  • ∫dt/(t² + a²) = (1/a)·arctg(t/a) + C; логарифм от трёхчлена не требует модуля.
  • Если старший коэффициент a ≠ 1, выдели производную знаменателя 2ax + b или вынеси a за скобки.
  • Арктангенс бывает только при D < 0; при D ≥ 0 дробь раскладывается на типы I и II.

Задания для самопроверки

Решено: 0 из 6

1
Найдите ∫(4x + 6)/(x² + 2x + 10) dx (константу C не пишем).
Варианты ответа

Показать решение

p = 2, q = 10, p²/4 − q = −9 < 0, a² = 9, a = 3, t = x + 1. 4x + 6 = 4(t − 1) + 6 = 4t + 2. ∫4t dt/(t² + 9) = 2·ln(t² + 9), ∫2 dt/(t² + 9) = (2/3)·arctg(t/3). Ответ: 2·ln(x² + 2x + 10) + (2/3)·arctg((x + 1)/3).

2
Найдите ∫(3/(2x − 1) + 2/(x + 1)²) dx на промежутке x > 1/2 (константу не пишем).
Варианты ответа

Показать решение

∫3/(2x − 1) dx = (3/2)·ln|2x − 1|; ∫2/(x + 1)² dx = −2/(x + 1). Проверка: (−2/(x + 1))′ = 2/(x + 1)² и ((3/2)·ln|2x − 1|)′ = (3/2)·2/(2x − 1) = 3/(2x − 1).

3
В ∫(3x + 4)/(x² + 4x + 13) dx = (3/2)·ln(x² + 4x + 13) + k·arctg((x + 2)/3) + C найдите коэффициент k.

Показать решение

a² = 13 − 4 = 9, a = 3. M = 3, N = 4, p = 4. k = (2N − Mp)/(2a) = (8 − 12)/6 = −2/3. Проверка через t = x + 2: 3x + 4 = 3t − 2, ∫(−2) dt/(t² + 9) = −(2/3)·arctg(t/3).

Варианты ответа
