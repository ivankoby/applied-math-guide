Рациональная дробь: правильная и неправильная, целая часть

Интегрировать многочлен умеет каждый: это сумма степеней. Интегрировать «многочлен на многочлен» напрямую нельзя, дробь сначала нужно привести к удобному виду. Первый шаг всегда один и тот же: выяснить, правильная дробь или нет, и, если нет, выделить целую часть делением. Так же, как 7/2 = 3 + 1/2: неправильная дробь равна целой части плюс правильная. В статье: определения, формула (23.24) лекции, деление уголком по шагам (с проверкой), пример из лекции со стр. 6 и три дополнительных примера, график, который показывает смысл целой части. Дальше всё внимание достаётся правильной дроби: её раскладывают на простейшие (статьи 12.2–12.4) и интегрируют (статьи 12.5–12.7).

Рациональная дробь

Многочлен и его степень

Многочлен — сумма a₀xⁿ + a₁xⁿ⁻¹ + … + aₙ; наибольшая степень x, при которой коэффициент не равен нулю, называется его степенью deg P. Постоянный многочлен c ≠ 0 имеет степень 0. Нулевому многочлену степень не приписывают: считай, что она меньше любой другой.

Рациональная дробь

Рациональной дробью называют частное двух многочленов P(x)/Q(x), где Q не нулевой многочлен. Дробь определена при тех x, для которых Q(x) ≠ 0. В лекции (стр. 1) коэффициенты многочленов действительные: на этом условии держатся теорема о разложении на простейшие дроби (статья 12.3) и формулы интегралов.

Многочлен — частный случай рациональной дроби (Q = 1). В этой лекции учимся находить ∫P(x)/Q(x) dx: по теореме 1 §24.2 (статья 12.7) на промежутке, где знаменатель не обращается в нуль, ответ всегда выражается через элементарные функции. На практике нужно суметь разложить знаменатель на множители (статья 12.2).

Правильная и неправильная

Правильная дробь (лекция, стр. 1)

Рациональная дробь P(x)/Q(x) называется правильной, если степень P меньше степени Q: deg P < deg Q. Если deg P ≥ deg Q, дробь неправильная.

Сравнивай только степени; сами коэффициенты и корни знаменателя ни на что не влияют.
Дробьdeg Pdeg QВид
x/(x² + 1)12правильная
5/(x² + 4)02правильная: число — многочлен нулевой степени
(x² + 1)/(x² − 1)22неправильная: степени равны
x³/(x − 1)31неправильная
(x + 5)/310неправильная: знаменатель — число

Для чисел ты уже так делал: 7/2 неправильная дробь, 7 = 3·2 + 1, поэтому 7/2 = 3 + 1/2: целая часть 3 и правильная дробь 1/2. С многочленами — то же самое, только «целая часть» тоже многочлен.

Формула (23.24): целая часть и остаток

Если дробь неправильная, то, как сказано в лекции (стр. 1), числитель делят на знаменатель по правилу деления многочленов, и дробь представляется в виде

P(x)/Q(x) = R(x) + P₁(x)/Q₁(x) (23.24)
R(x) — многочлен («целая часть»), P₁(x)/Q₁(x) — правильная дробь. Целая часть не число, а многочлен: только при deg P = deg Q она постоянна.

Откуда берётся (23.24). Для любых многочленов P и Q ≠ 0 существуют единственные многочлены R (частное) и P₁ (остаток) такие, что

P(x) = R(x)·Q(x) + P₁(x), deg P₁ < deg Q (или P₁ = 0)
Это деление с остатком, как у целых чисел: 7 = 3·2 + 1, остаток 1 меньше делителя 2.

Разделив обе части на Q(x), получаем P/Q = R + P₁/Q. В лекции знаменатель правой части обозначен общей буквой Q₁, но при делении уголком знаменатель не меняется: Q₁ = Q, изменяется только числитель (вместо P стоит остаток P₁). Так и получится в примере со стр. 6: знаменатель x(x² + 1)² остался прежним.

  • Степень частного: deg R = deg P − deg Q (если deg P ≥ deg Q). Многочлен степени 7, делённый на многочлен степени 3, даёт частное степени 4.
  • Степень остатка меньше степени делителя: после деления на Q степени 3 остаток имеет степень не выше 2.
  • Если дробь правильная, делить нечего: R = 0, целой части нет.

Q₁ и Q

Если после деления числитель остатка и знаменатель имеют общий множитель, дробь P₁/Q можно сократить, и тогда в (23.24) знаменатель Q₁ — это знаменатель уже сокращённой дроби. Сокращать полезно, но не обязательно: разложение на простейшие дроби от этого не ломается, лишние слагаемые просто получат нулевые коэффициенты.

Деление уголком по шагам

Деление многочленов устроено как деление столбиком чисел. Алгоритм:

  • 0. Раскрой знаменатель, если он записан произведением: x(x² + 1)² = x⁵ + 2x³ + x. Деление идёт на многочлен в стандартном виде.
  • 1. Запиши оба многочлена по убыванию степеней. Пропущенные степени допиши с нулевым коэффициентом: x⁶ + 2x⁴ + 2x² − 1 — это x⁶ + 0x⁵ + 2x⁴ + 0x³ + 2x² + 0x − 1.
  • 2. Разделить старший член остатка на старший член делителя. Получится следующий член частного (в первый раз остаток — это сам числитель).
  • 3. Умножь этот член на весь делитель и вычти из остатка, меняя знак у каждого члена. Старший член при этом сокращается.
  • 4. Повторяй шаги 2–3, пока степень остатка не станет меньше степени делителя. Что получилось в частном — целая часть R, что осталось — числитель P₁.
  • 5. Проверь: R·Q + P₁ должно дать P.

Если старший коэффициент делителя не 1, в частном появятся дроби: коэффициент члена частного — это (старший коэффициент остатка) / (старший коэффициент делителя). Для делителя 2x + 4 и остатка с членом x² получится x²/2x = x/2.

Разобранные примеры

Пример 1: деление из лекции (§24.2, пример 2)из лекции, стр. 6
Выделить целую часть дроби (x⁶ + 2x⁴ + 2x² − 1)/(x(x² + 1)²).

  1. Раскрываем знаменатель: x(x² + 1)² = x(x⁴ + 2x² + 1) = x⁵ + 2x³ + x. Степень числителя 6, знаменателя 5: дробь неправильная, deg R = 6 − 5 = 1.

  2. Пропущенные степени допишем нулями: числитель x⁶ + 0x⁵ + 2x⁴ + 0x³ + 2x² + 0x − 1, делитель x⁵ + 0x⁴ + 2x³ + 0x² + x + 0. Делим: единственный шаг.

  3. ШагОстаток до шагаСтарший член : старший член делителяВычитаем (член частного × делитель)Остаток после шага
    1x⁶ + 2x⁴ + 2x² − 1x⁶ : x⁵ = xx⁶ + 2x⁴ + x²x² − 1

  4. После первого шага остаток x² − 1 имеет степень 2 < 5, деление закончено. Проверка: x·(x⁵ + 2x³ + x) + (x² − 1) = x⁶ + 2x⁴ + x² + x² − 1 = x⁶ + 2x⁴ + 2x² − 1 ✓.

(x⁶ + 2x⁴ + 2x² − 1)/(x(x² + 1)²) = x + (x² − 1)/(x(x² + 1)²): целая часть R = x, правильная дробь (x² − 1)/(x(x² + 1)²). Она раскладывается в статье 12.4.

Пример 2: несколько шаговдополнительно к лекции (опорный конспект, стр. 39)
Выделить целую часть дроби (x⁵ + 4x)/(x² + 2x + 3).

  1. deg P = 5, deg Q = 2, значит, deg R = 3. В числителе пропущены x⁴, x³, x² и свободный член: x⁵ + 0x⁴ + 0x³ + 0x² + 4x + 0.

  2. ШагОстаток до шагаСтарший член : старший член делителяВычитаем (член частного × делитель)Остаток после шага
    1x⁵ + 4xx⁵ : x² = x³x⁵ + 2x⁴ + 3x³−2x⁴ − 3x³ + 4x
    2−2x⁴ − 3x³ + 4x−2x⁴ : x² = −2x²−2x⁴ − 4x³ − 6x²x³ + 6x² + 4x
    3x³ + 6x² + 4xx³ : x² = xx³ + 2x² + 3x4x² + x
    44x² + x4x² : x² = 44x² + 8x + 12−7x − 12

  3. Четыре шага; после четвёртого остаток −7x − 12 имеет степень 1 < 2. Частное — сумма членов, записанных в третьем столбце: x³ − 2x² + x + 4.

  4. Проверка: (x² + 2x + 3)(x³ − 2x² + x + 4) = x⁵ + 11x + 12, а x⁵ + 11x + 12 − 7x − 12 = x⁵ + 4x ✓.

(x⁵ + 4x)/(x² + 2x + 3) = x³ − 2x² + x + 4 + (−7x − 12)/(x² + 2x + 3).

Пример 3: у делителя старший коэффициент не 1дополнительно
Выделить целую часть дроби (x² + 3x + 1)/(2x + 4).

  1. Старший член числителя x², делителя 2x: x²/2x = x/2. Умножаем: (x/2)(2x + 4) = x² + 2x. Вычитаем: x² + 3x + 1 − (x² + 2x) = x + 1.

  2. Теперь x/2x = 1/2. Умножаем: (1/2)(2x + 4) = x + 2. Вычитаем: x + 1 − (x + 2) = −1. Остаток −1 — число, его степень 0 < 1.

  3. Проверка: (x/2 + 1/2)(2x + 4) − 1 = x² + 2x + x + 2 − 1 = x² + 3x + 1 ✓.

(x² + 3x + 1)/(2x + 4) = x/2 + 1/2 − 1/(2x + 4). Дробь −1/(2x + 4) правильная.

Пример 4: степени равныдополнительно
Выделить целую часть дроби (3x² + x − 2)/(x² + 1).

  1. deg P = deg Q = 2: дробь неправильная, deg R = 0, то есть целая часть — число. 3x²/x² = 3; 3(x² + 1) = 3x² + 3; остаток 3x² + x − 2 − 3x² − 3 = x − 5.

  2. Степень остатка 1 < 2, готово. Проверка: 3(x² + 1) + x − 5 = 3x² + x − 2 ✓.

(3x² + x − 2)/(x² + 1) = 3 + (x − 5)/(x² + 1).

Что дальше

Зачем всё это для интеграла. ∫P/Q dx = ∫R dx + ∫P₁/Q dx: первый интеграл — многочлен, считается почленно по формуле степени. Например, (x² + 1)/(x − 1) = x + 1 + 2/(x − 1), и ∫(x² + 1)/(x − 1) dx = x²/2 + x + 2 ln|x − 1| + C. Всё сложное остаётся в правильной дроби.

Целая часть на графике

Целая часть — не просто приём вычисления. Остаток P₁/Q — правильная дробь, и при x → ∞ она стремится к нулю: числитель растёт медленнее знаменателя. Значит, вдали от начала координат график неправильной дроби почти совпадает с графиком многочлена R. На рисунке y = (x² + 1)/(x − 1) = x + 1 + 2/(x − 1): синяя кривая прижимается к прямой y = x + 1 (целая часть), а в точке x = 1, где знаменатель обращается в нуль, у неё вертикальная асимптота.

Частые ошибки

Так нельзя

«Степени числителя и знаменателя равны, значит, дробь правильная».

Так правильно

Правильная дробь требует deg P < deg Q строго. При равных степенях целая часть есть: это число, как в примере 4 (3 + (x − 5)/(x² + 1)).

Так нельзя

Не дописать нулевые коэффициенты: в x⁴ − 3x² + 5 сразу делить, как будто есть x³ и x.

Так правильно

Пропущенные степени пиши с нулями (x⁴ + 0x³ − 3x² + 0x + 5), иначе члены окажутся не под своими степенями и остаток получится неверным.

Так нельзя

Поменять знак не у всех членов вычитаемого: в примере 1 x⁶ + 2x⁴ + 2x² − 1 − (x⁶ + 2x⁴ + x²) посчитать как 3x² − 1 (у x² знак остался плюсом).

Так правильно

Знак меняют у каждого члена: x⁶ + 2x⁴ + 2x² − 1 − x⁶ − 2x⁴ − x² = x² − 1. Проверяй результат умножением: R·Q + P₁ = P.

Так нельзя

Разделить дробь «почленно» по знаменателю: 1/(x² + 1) = 1/x² + 1.

Так правильно

Почленно можно делить на одночлен: (x³ + 2x)/x² = x + 2/x. Сумму в знаменателе разбивать нельзя: проверь при x = 1: слева 1/2, справа 2.

Так нельзя

Называть целой частью число: «(x⁵ + 4x)/(x² + 2x + 3) — целая часть 3, остаток 4».

Так правильно

Целая часть — многочлен R(x) (в примере 2 x³ − 2x² + x + 4). Число она только при deg P = deg Q.

Кратко для повторения

Кратко для повторения

  • Рациональная дробь P(x)/Q(x): многочлены с действительными коэффициентами, Q ≠ 0. Правильная, если deg P < deg Q; иначе неправильная (в том числе при равных степенях).
  • Неправильную дробь представляют в виде P/Q = R + P₁/Q (формула 23.24): R — частное, P₁ — остаток от деления P на Q, deg P₁ < deg Q; знаменатель при делении не меняется (Q₁ = Q).
  • deg R = deg P − deg Q. Если дробь правильная, целой части нет.
  • Деление уголком: раскрыть знаменатель, записать по убыванию степеней с нулями на месте пропущенных, делить старшие члены, вычитать каждый член, повторять до deg остатка < deg делителя. Проверка: R·Q + P₁ = P.
  • Целая часть интегрируется почленно; остаётся правильная дробь, которую раскладывают на простейшие.

Проверь себя

Задания для самопроверки

Решено: 0 из 6

Выберите вариант, заполните пропуски или введите число (допустимы целые и дроби вида −1/3), затем «Проверить».

1
Какая из дробей правильная?
Варианты ответа

Показать решение

Правильная дробь: deg P < deg Q. Здесь это только x³/(x⁴ − 1): 3 < 4. В остальных степени 2 и 2, 4 и 3, 1 и 0.

2
Многочлен седьмой степени делят на многочлен третьей степени. Какова степень частного (целой части)?

Показать решение

deg R = deg P − deg Q = 7 − 3 = 4. (Остаток при этом имеет степень не выше 2.)

3
Разделите 2x⁴ − 5x² + x + 6 на x² − x + 2 с остатком. Найдите коэффициент при x в остатке.

Показать решение

Дописываем 0x³: 2x⁴ + 0x³ − 5x² + x + 6. Шаг 1: 2x²·(x² − x + 2) = 2x⁴ − 2x³ + 4x²; остаток 2x³ − 9x² + x + 6. Шаг 2: 2x·(x² − x + 2) = 2x³ − 2x² + 4x; остаток −7x² − 3x + 6. Шаг 3: −7·(x² − x + 2) = −7x² + 7x − 14; остаток −10x + 20. Частное 2x² + 2x − 7, остаток −10x + 20. Проверка: (2x² + 2x − 7)(x² − x + 2) = 2x⁴ − 5x² + 11x − 14, и + (−10x + 20) даёт 2x⁴ − 5x² + x + 6 ✓.

4
Разделите 4x³ − 2x² + 3x + 7 на 2x − 1 и заполните пропуски.
(4x³ − 2x² + 3x + 7)/(2x − 1) = + + /(2x − 1)

Показать решение

4x³/2x = 2x²; 2x²(2x − 1) = 4x³ − 2x²; остаток 3x + 7. 3x/2x = 3/2; (3/2)(2x − 1) = 3x − 3/2; остаток 7 − (−3/2) = 7 + 3/2 = 17/2. Частное 2x² + 3/2, остаток 17/2. Проверка: (2x² + 3/2)(2x − 1) = 4x³ − 2x² + 3x − 3/2; прибавляем 17/2 и получаем 4x³ − 2x² + 3x + 7 ✓.

5
Делим x³ + 2x − 3 на x² − x + 1. В каком шаге допущена первая ошибка?
Варианты ответа

Показать решение

В шаге 3 при вычитании −(−x) = +x: x + x = 2x, и −3 − 1 = −4. Правильный остаток: x² + x − 3 − x² + x − 1 = 2x − 4. Частное x + 1, остаток 2x − 4; проверка: (x + 1)(x² − x + 1) = x³ + 1, x³ + 1 + 2x − 4 = x³ + 2x − 3 ✓.

6
Выделите целую часть: (x³ + 2)/(x² − 1) = ?
Варианты ответа

Показать решение

x³ + 2 = x·(x² − 1) + (x + 2), deg(x + 2) = 1 < 2. Поэтому (x³ + 2)/(x² − 1) = x + (x + 2)/(x² − 1).
