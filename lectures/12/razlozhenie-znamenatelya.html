Разложение знаменателя на множители

Чтобы разложить правильную дробь на простейшие, нужно знать, из каких множителей состоит знаменатель: в теореме лекции он записан как (x − a₁)α₁ … (x² + p₁x + q₁)β₁ … (формула 23.29). Сама лекция эту разбивку не выводит: на стр. 7 она лишь оговаривает, что метод применим, когда знаменатель удалось разложить на множители. Получать это разложение придётся тебе, и ошибка здесь портит всё дальнейшее. В статье: что утверждает теорема о разложении многочлена, как искать корни (теорема Безу, схема Горнера, рациональные корни), как действовать пошагово и как понять, что остановиться пора.

Что утверждает теорема

Корень и кратность

Число a — корень многочлена Q, если Q(a) = 0. Корень имеет кратность k, если Q(x) = (x − a)k·Q₁(x) и Q₁(a) ≠ 0. Корень кратности 1 называют простым.

Разложение многочлена с действительными коэффициентами

Всякий многочлен Q степени n ≥ 1 с действительными коэффициентами и старшим коэффициентом 1 представляется в виде Q(x) = (x − a₁)α₁ … (x − ar)αr·(x² + p₁x + q₁)β₁ … (x² + psx + qs)βs, где ai — попарно различные действительные корни кратности αi, а x² + pjx + qj — попарно различные трёхчлены без действительных корней, то есть pj²/4 − qj < 0, и βj — кратность каждого из двух комплексных корней трёхчлена. При этом α₁ + … + αr + 2(β₁ + … + βs) = n.

Это формула (23.29) лекции (стр. 2). На стр. 3 и 7 лекция ссылается на формулу (23.10), то есть на разложение многочлена на множители такого же вида из предыдущих пунктов курса; в этих семи страницах оно не доказывается. Если старший коэффициент Q не 1, число выносят за скобки: оно только делит числитель дроби и ничего не меняет в разложении. Для знаменателя 2x³ + … пишут 2·(x − …)….

Откуда это следует (дополнительно к лекции; опорный конспект, разд. 2.13, стр. 38–39). По основной теореме алгебры любой многочлен степени n имеет n корней, действительных или комплексных (с учётом кратности). Если a + bi — корень многочлена с действительными коэффициентами, то и a − bi — корень (сопряжённые корни идут парами), причём кратности у них одинаковы: если Q(x) = (x − z)βg(x), g(z) ≠ 0, то после замены всех коэффициентов на сопряжённые (у Q они действительные и не меняются) получаем Q(x) = (x − w)βh(x), h(w) ≠ 0, где w — число, сопряжённое с z. Произведение (x − (a + bi))(x − (a − bi)) = x² − 2ax + a² + b² — трёхчлен с действительными коэффициентами и D = (2a)² − 4(a² + b²) = −4b² < 0. Так линейные множители и неприводимые квадратные трёхчлены и получаются.

Три записи одного условия

Условие p²/4 − q < 0 равносильно D = p² − 4q < 0 и равносильно тому, что q − p²/4 > 0. Эта величина a² = q − p²/4 понадобится в статье 12.5: на ней держится арктангенс в интегралах.

Теорема Безу и схема Горнера

Теорема Безу (опорный конспект, разд. 2.13)

Остаток от деления многочлена Q(x) на x − a равен Q(a). Следствие: a — корень Q ⇔ Q делится на x − a без остатка.

Доказательство из конспекта в одну строку: Q(x) = (x − a)·Q₁(x) + r, где r — число (степень остатка меньше 1); подставим x = a и получим Q(a) = r.

Быстро делить на x − a и заодно считать Q(a) позволяет схема Горнера. Выпиши коэффициенты Q по убыванию степеней (пропущенные — нулями). Первое число спусти без изменений. Каждое следующее равно «коэффициент + a × предыдущее число нижней строки». Последнее число нижней строки — остаток Q(a), остальные — коэффициенты частного.

Схема Горнера для x⁴ + x³ − x − 1 и a = 1: 1; 1 + 1·1 = 2; 0 + 1·2 = 2; −1 + 1·2 = 1; −1 + 1·1 = 0. Остаток 0: x = 1 — корень; частное x³ + 2x² + 2x + 1.

Алгоритм разложения

  • 1. Вынеси общий множитель: число, степень x. 3x⁴ − 12x² = 3x²(x² − 4).
  • 2. Квадратный трёхчлен x² + px + q: найди D = p² − 4q. При D > 0 получишь (x − x₁)(x − x₂), при D = 0 — (x − x₀)², при D < 0 трёхчлен оставь как есть.
  • 3. Формулы сокращённого умножения: a² − b² = (a − b)(a + b), x³ − a³ = (x − a)(x² + ax + a²), x³ + a³ = (x + a)(x² − ax + a²). Сумма квадратов x² + a² при a ≠ 0 на вещественные множители не раскладывается.
  • 4. Группировка: x⁴ + x³ − x − 1 = x³(x + 1) − (x + 1) = (x + 1)(x³ − 1).
  • 5. Рациональные корни. Если у Q целые коэффициенты и несократимая дробь m/k (k > 0) — корень, то m делит свободный член, а k делит старший коэффициент. Выпиши кандидатов (со знаками ±), проверь их схемой Горнера. Найденный корень «снимай» и проверяй снова на том же частном: так находят кратность.
  • 6. Остановись, когда остались только линейные множители и трёхчлены с D < 0. Проверь, что степень совпадает: α₁ + … + 2(β₁ + …) = n; при сомнениях перемножь множители. Поиск m/k находит только рациональные корни: если их нет, а оставшийся множитель имеет степень не меньше 3, это ещё не конец: корень может быть иррациональным (x³ − 2 = (x − 21/3)(x² + 21/3x + 22/3); у многочлена нечётной степени действительный корень есть всегда). В задачах курса знаменатели подобраны так, что рациональных корней и формул хватает.

Почему кандидаты именно такие (дополнительно). Пусть c₀xⁿ + c₁xⁿ⁻¹ + … + cₙ = 0 при x = m/k, дробь несократима (k > 0); здесь n — степень многочлена, k — знаменатель корня. Умножим на kⁿ: c₀mⁿ + c₁mⁿ⁻¹k + … + cₙkⁿ = 0. Все слагаемые, кроме последнего, делятся на m, значит, на m делится и cₙkⁿ; так как m и k взаимно просты, на m делится cₙ. Так же (все слагаемые, кроме первого, делятся на k) на k делится c₀. Для многочлена с дробными коэффициентами сначала умножь его на общий знаменатель.

Осторожно

Многочлен степени 4 без действительных корней всё равно раскладывается: x⁴ + 4 = (x² + 2)² − (2x)² = (x² − 2x + 2)(x² + 2x + 2). Неприводимыми над действительными числами бывают только многочлены первой и второй степени (следствие теоремы выше), поэтому «нет корней» ещё не значит «не раскладывается» для степеней 4 и выше.

Пример 2: группировка и схема Горнерадополнительно к лекции (знаменатель из опорного конспекта, стр. 41)
Разложить на множители Q(x) = x⁴ + x³ − x − 1.

  2. Схема Горнера. Старший коэффициент 1, свободный член −1: кандидаты ±1. Пробуем 1, затем −1 на частном.

  5. Проверка: n = 2 + 1 + 2 = 5 ✓.

x⁵ + x³ − 2x² − 12x − 8 = (x + 1)²(x − 2)(x² + 4).

Пример 4: старший коэффициент не 1дополнительно
Разложить на множители Q(x) = 2x³ − 3x² − 11x + 6.

  1. Кандидаты m/k: m делит 6 (±1, ±2, ±3, ±6), k делит 2 (1 или 2). Среди дробей есть ±1/2, ±3/2. Проверяем 1/2 схемой Горнера: 2; −3 + 2/2 = −2; −11 + (−2)/2 = −12; 6 + (−12)/2 = 0. Остаток 0, значит, 1/2 — корень.

  2. Частное 2x² − 2x − 12 = 2(x² − x − 6). У трёхчлена D = 1 + 24 = 25, корни (1 ± 5)/2, то есть 3 и −2, и x² − x − 6 = (x − 3)(x + 2).

  3. Собираем: Q = (x − 1/2)·2(x − 3)(x + 2) = (2x − 1)(x − 3)(x + 2). Проверка при x = 0: (−1)(−3)(2) = 6 ✓.

2x³ − 3x² − 11x + 6 = (2x − 1)(x − 3)(x + 2) = 2(x − 1/2)(x − 3)(x + 2).

Корни на графике

Действительные корни многочлена — это общие точки графика с осью x (при чётной кратности график касается оси, а не пересекает её). Квадратный множитель с D < 0 ось не пересекает, потому что он нигде не обращается в нуль: x² + x + 1 = (x + 1/2)² + 3/4 ≥ 3/4. У x⁴ + x³ − x − 1 на рисунке ровно две общие точки с осью — −1 и 1, — хотя степень 4: два «недостающих» корня комплексные и скрыты в множителе x² + x + 1.

Частые ошибки

Так нельзя

x² + 4 = (x − 2)(x + 2).

Так правильно

(x − 2)(x + 2) = x² − 4. Сумма квадратов x² + 4 не раскладывается: D = −16 < 0, это готовый квадратный множитель.

Так нельзя

Корень −1 записывать множителем (x − 1), корень 2 множителем (x + 2).

Так правильно

Корень a даёт множитель (x − a): корень −1 — (x + 1), корень 2 — (x − 2). Проверь: при x = a множитель обращается в нуль.

Так нельзя

Нашёл корень −1 и пошёл дальше, не проверив его ещё раз.

Так правильно

Корень может быть кратным. После снятия корня проверь его на частном: в примере 3 −1 встречается дважды.

Так нельзя

Пробовать только положительные делители свободного члена.

Так правильно

Кандидаты берут со знаками ±: в примере 3 корень −1 положительным делителем не найти.

Так нельзя

Раскладывать трёхчлен x² + x + 1 дальше «на (x + …)(x + …)».

Так правильно

При D < 0 вещественных множителей нет. Раскладывать его можно только на комплексные: в этой лекции так не делают, потому что коэффициенты должны оставаться действительными.

Так нельзя

Применять правило кандидатов m/k к многочлену с дробными коэффициентами.

Так правильно

Правило доказано для целых коэффициентов. Дробные коэффициенты сначала убери умножением на общий знаменатель.

Кратко для повторения

Кратко для повторения

  • Многочлен с действительными коэффициентами и старшим коэффициентом 1: (x − a₁)α₁…(x − ar)αr·(x² + p₁x + q₁)β₁… с pj²/4 − qj < 0 (формула 23.29), Σα + 2Σβ = n.
  • Корень a даёт множитель (x − a); кратность находят повторной проверкой корня на частном.
  • Теорема Безу: остаток от деления Q на x − a равен Q(a). Схема Горнера делит на x − a и заодно считает Q(a).
  • Для целых коэффициентов рациональный корень m/k (несократимая дробь): m делит свободный член, k делит старший коэффициент.
  • Алгоритм: вынеси общий множитель, формулы сокращённого умножения и группировка, поиск корней по Горнеру, D для оставшегося трёхчлена. Сумма квадратов и трёхчлен с D < 0 — готовые неприводимые множители.
  • Неприводимы над действительными числами только многочлены степени 1 и 2: x⁴ + 4 = (x² − 2x + 2)(x² + 2x + 2).

Проверь себя

Задания для самопроверки

Решено: 0 из 6

Выберите вариант, заполните пропуски или введите число (допустимы целые и дроби вида −1/3), затем «Проверить».

1
Какой из трёхчленов нельзя разложить на множители с действительными коэффициентами?
Варианты ответа

Показать решение

Критерий: D = p² − 4q < 0. Для x² − 6x + 10: D = 36 − 40 = −4 < 0, действительных корней нет, трёхчлен неприводим. У остальных D = 0, 25, 1.

2
Найдите степень многочлена x²(x + 1)³(x² + 4)², не раскрывая скобки.

Показать решение

Степени складываются: x² даёт 2, (x + 1)³ даёт 3, (x² + 4)² даёт 2·2 = 4. Всего 2 + 3 + 4 = 9 (так и в формуле Σα + 2Σβ = n).

3
Найдите остаток от деления x⁴ − 3x³ + x − 5 на x − 2.

Показать решение

По теореме Безу остаток равен Q(2) = 2⁴ − 3·2³ + 2 − 5 = 16 − 24 + 2 − 5 = −11. Схема Горнера: 1; −3 + 2 = −1; 0 − 2 = −2; 1 − 4 = −3; −5 − 6 = −11.

4
Дан многочлен Q(x) = (x − 2)(x + 1)²(x² + 9). Заполните пропуски.
Вещественные корни: . Кратность корня −1 равна . Трёхчлен x² + 9 на вещественные множители .

Показать решение

(x − 2) даёт корень 2; (x + 1)² = (x − (−1))² — корень −1 кратности 2. У x² + 9 дискриминант D = −36 < 0, корней нет; (x − 3)(x + 3) = x² − 9, а не x² + 9.

5
Сколько неприводимых квадратных множителей в разложении x⁶ − 1 на множители с действительными коэффициентами?

Показать решение

x⁶ − 1 = (x³ − 1)(x³ + 1) = (x − 1)(x² + x + 1)(x + 1)(x² − x + 1). Оба трёхчлена имеют D = −3 < 0. Проверка степени: 1 + 1 + 2 + 2 = 6. Квадратных множителей два.

6
Раскладываем x³ − 7x + 6. В каком шаге допущена первая ошибка?
Варианты ответа

Показать решение

Корень 2 даёт множитель (x − 2), корень −3 — множитель (x + 3): x² + x − 6 = (x − 2)(x + 3). Итог (x − 1)(x − 2)(x + 3); проверка при x = 0: (−1)(−2)(3) = 6 ✓.
