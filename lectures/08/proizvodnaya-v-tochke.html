Производная в точке: определение и вычисление по определению

Производная — главное понятие этой лекции: на ней держатся касательная, скорость, дифференциал и почти всё, что вы будете делать дальше (исследование функций, интегралы). Определяют её через предел: сначала смотрят, на сколько изменилась функция при небольшом сдвиге аргумента, а потом сдвиг «гасят». Считать по определению приходится редко, но без него непонятны ни таблица производных, ни слова «дифференцируема» и «непрерывна». В статье определение, алгоритм вычисления и все примеры лекции со всеми шагами.

Приращение аргумента и приращение функции

Пусть функция y = f(x) определена в некоторой окрестности точки x₀. Перейдём от значения x₀ к другому значению x. Разность x − x₀ называется приращением аргумента и обозначается Δx, так что x = x₀ + Δx. Соответствующее приращение функции в точке x₀:

Δy = f(x₀ + Δx) − f(x₀)
Приращение — это «на сколько изменилось», а не «чему стало равно». Приращение функции Δy может быть положительным, отрицательным или нулём; приращение аргумента Δx — положительным или отрицательным, но не нулём: лекция (стр. 1) оговаривает «в общем случае Δx ≠ 0», при Δx = 0 отношение Δy/Δx составить нельзя.

Отношение Δy/Δx — средняя скорость изменения функции на промежутке от x₀ до x₀ + Δx. На графике это угловой коэффициент секущей, проведённой через точки (x₀; f(x₀)) и (x₀ + Δx; f(x₀ + Δx)). Если приближать вторую точку к первой, секущая поворачивается и в пределе ложится на касательную.

Непрерывность через приращения (лекция, стр. 1–2): функция непрерывна в точке x₀, если бесконечно малому приращению аргумента Δx → 0 отвечает бесконечно малое приращение функции Δy → 0. Это то же определение из лекции 7, только записанное через Δx и Δy. Для производной требуется больше: ещё и отношение Δy/Δx должно иметь конечный предел.

Определение производной

Производная функции в точке

Производной функции y = f(x) в точке x = x₀ называется конечный предел отношения приращения функции Δy к приращению аргумента Δx при стремлении последнего к нулю (Δx → 0). Если такой предел существует и конечен, функция называется дифференцируемой в точке x₀.

f′(x₀) = limΔx→0 Δy/Δx = limΔx→0 (f(x₀ + Δx) − f(x₀)) / Δx
Это формула лекции (стр. 2). Если вместо x₀ писать произвольное x, получится производная как функция.

Что в этом определении легко упустить:

  • «Конечный». Если отношение Δy/Δx уходит в +∞ или −∞, предел не конечен, и по определению лекции функция в этой точке не дифференцируема. Например, для y = ∛x в точке x = 0 имеем Δy/Δx = ∛(Δx)/Δx = 1/∛(Δx²) → +∞ (подробнее в статье 8.2).
  • Производная в точке — число. Оно зависит от выбранной точки x₀ и не зависит от Δx: Δx в пределе исчезает. Если брать разные точки, получатся разные числа; так появляется функция f′(x).
  • Область определения. Точка x₀ + Δx обязана лежать в области определения функции; если это не так, Δx нужно уменьшить (лекция, стр. 2).
  • Предел двусторонний. Δx стремится к нулю и справа, и слева; если пределы с двух сторон разные, производной нет (статья 8.2).

Обозначения производной в точке x: y′, y′x, f′(x), dy/dx, df/dx; в конкретной точке x₀: y′(x₀), y′|x=x₀, f′(x₀), df(x₀)/dx. Штрих ввёл Лагранж, дробное обозначение — Лейбниц. Пока читай dy/dx как единый символ «производная y по x»; почему его можно считать дробью, объяснено в статье 8.8. Нахождение производной называется дифференцированием (лекция, стр. 3): «продифференцировать функцию» значит найти её производную.

Запомни

Производная — это предел отношения, а не само отношение. Для конкретного малого Δx величина Δy/Δx — лишь угловой коэффициент секущей, приближение к производной.

Числовой пример. Для f(x) = x² в точке x₀ = 3 имеем Δy = 6Δx + (Δx)², значит, Δy/Δx = 6 + Δx при любом Δx ≠ 0. Посмотрим, как это отношение ведёт себя справа и слева от нуля:

Отношение приращений для f(x) = x² в точке x₀ = 3: и справа, и слева значения приближаются к 6, поэтому f′(3) = 6.

Как вычислить производную по определению: алгоритм

  • Шаг 1. Задай аргументу x₀ произвольное приращение Δx (учти, что x₀ + Δx должна лежать в области определения).
  • Шаг 2. Найди приращение функции Δy = f(x₀ + Δx) − f(x₀); раскрой скобки и приведи подобные.
  • Шаг 3. Составь отношение Δy/Δx и сократи на Δx: при Δx → 0 подставлять Δx = 0 нельзя, получится 0/0, а сокращать можно, ведь Δx ≠ 0.
  • Шаг 4. Найди предел при Δx → 0. Если он существует и конечен, он и есть f′(x₀).

Почему шаг 3 так важен: у отношения Δy/Δx и числитель, и знаменатель стремятся к нулю, то есть перед нами неопределённость 0/0 (лекция 6). Обычно её раскрывают именно сокращением на Δx, а когда сокращать нечего (синус, косинус), используют замечательные пределы.

Примеры лекции

Пример 1.1: (C)′ = 0из лекции, стр. 3–4
Найти производную постоянной функции y = C.

  1. Значение функции не меняется: f(x) = C и f(x + Δx) = C для любых x и Δx. Поэтому Δy = C − C = 0.

  2. Отношение Δy/Δx = 0/Δx = 0 при любом Δx ≠ 0, а предел нулей равен нулю: y′ = 0.

(C)′ = 0.

Пример 1.2: x′ = 1из лекции, стр. 4
Найти производную функции y = x.

  1. f(x) = x, f(x + Δx) = x + Δx, поэтому Δy = x + Δx − x = Δx.

  2. Δy/Δx = Δx/Δx = 1, предел единиц равен 1.

x′ = 1.

Пример 1.3: (xⁿ)′ = n·xⁿ⁻¹ при натуральном nиз лекции, стр. 4–5
Найти производную функции y = xⁿ, где n — натуральное число.

  1. Приращение: Δy = (x + Δx)ⁿ − xⁿ. По формуле бинома Ньютона (x + Δx)ⁿ = xⁿ + n·xn−1Δx + [n(n − 1)/(1·2)]·xn−2(Δx)² + … + (Δx)ⁿ. Слагаемое xⁿ сокращается с вычитаемым, и остаётся Δy = n·xn−1Δx + [n(n − 1)/2]·xn−2(Δx)² + … + (Δx)ⁿ.

  2. Делим на Δx: Δy/Δx = n·xn−1 + [n(n − 1)/2]·xn−2Δx + … + (Δx)n−1. Все слагаемые, кроме первого, содержат Δx в положительной степени.

  3. При Δx → 0 они стремятся к нулю, остаётся первое слагаемое: (xⁿ)′ = n·xn−1. Проверка на малом случае n = 4: Δy = 4x³Δx + 6x²(Δx)² + 4x(Δx)³ + (Δx)⁴ (коэффициенты 1, 4, 6, 4, 1), после деления и предела получаем 4x³.

(xⁿ)′ = n·xn−1.

Замечание

В лекции формула доказана только для натурального n (стр. 4–5): доказательство опирается на бином. Для других показателей она тоже верна, и таблица (статья 8.3) ею пользуется, но обосновывается иначе: для целого n < 0 — правилом частного (статья 8.4) при x ≠ 0; для любого вещественного α, например 1/3, — через xα = eα·ln x при x > 0 (статья 8.5; лекция, часть 2, стр. 6). Два частных случая ниже (примеры 1.6 и 1.7) выведены прямо из определения. Пока можно пользоваться формулой смело, как это делает лекция в примерах 2.1 и 2.2.

Пример 1.4: (cos x)′ = −sin xиз лекции, стр. 5–6
Найти производную функции y = cos x.

  1. Приращение Δy = cos(x + Δx) − cos x. Применяем формулу разности косинусов cos α − cos β = −2 sin((α + β)/2)·sin((α − β)/2): Δy = −2 sin(x + Δx/2)·sin(Δx/2).

  2. Составляем отношение и записываем 2/Δx как 1/(Δx/2): Δy/Δx = −sin(x + Δx/2)·sin(Δx/2) / (Δx/2). При Δx → 0 имеем неопределённость 0/0 во втором множителе.

  3. Раскрываем её первым замечательным пределом: при t = Δx/2 → 0 получаем sin t / t → 1. Первый множитель sin(x + Δx/2) → sin x, потому что синус непрерывен.

  4. Итог: (cos x)′ = −sin x · 1 = −sin x.

(cos x)′ = −sin x.

Пример 1.5: значение производной в точке по определениюиз лекции, стр. 6
Вычислить значение производной функции y = x² + 3x − 1 в точке x = 2, используя определение.

  1. Задаём приращение Δx и находим Δy = f(2 + Δx) − f(2). Значение f(2) = 4 + 6 − 1 = 9. Тогда Δy = (2 + Δx)² + 3(2 + Δx) − 1 − 9 = 4 + 4Δx + (Δx)² + 6 + 3Δx − 1 − 9 = (Δx)² + 7Δx.

  2. Отношение Δy/Δx = ((Δx)² + 7Δx)/Δx = Δx + 7 (сократили на Δx).

  3. Предел: limΔx→0 (Δx + 7) = 7.

  4. Проверка другим способом. По таблице и правилам (статьи 8.3 и 8.4) (x² + 3x − 1)′ = 2x + 3, при x = 2 получаем 7. Результаты совпали.

y′(2) = 7.

Ещё два вывода по определению (дополнительно)

Пример 1.6: y = 1/xдополнительно к лекции
Найти по определению производную функции y = 1/x в точке x ≠ 0.

  1. Δy = 1/(x + Δx) − 1/x = (x − (x + Δx)) / (x(x + Δx)) = −Δx / (x(x + Δx)). Здесь x + Δx ≠ 0: Δx берём настолько малым, чтобы точка не попала в нуль.

  2. Δy/Δx = −1 / (x(x + Δx)). Сократили на Δx, теперь можно переходить к пределу.

  3. При Δx → 0 знаменатель стремится к x·x = x², поэтому предел равен −1/x².

(1/x)′ = −1/x², x ≠ 0.

Пример 1.7: y = √xдополнительно к лекции
Найти по определению производную функции y = √x при x > 0.

  1. Δy = √(x + Δx) − √x. Разность корней умножаем и делим на сопряжённое выражение √(x + Δx) + √x: Δy = ((x + Δx) − x) / (√(x + Δx) + √x) = Δx / (√(x + Δx) + √x).

  2. Δy/Δx = 1 / (√(x + Δx) + √x). Сократили на Δx.

  3. При Δx → 0 корень √(x + Δx) → √x (корень непрерывен), поэтому знаменатель стремится к 2√x.

(√x)′ = 1/(2√x), x > 0.

Оба результата вы увидите в таблице производных (статья 8.3) как частные случаи формулы (xα)′ = α·xα−1: 1/x = x−1 и √x = x1/2.

Частые ошибки

Так нельзя

Подставить Δx = 0 в отношение Δy/Δx и получить 0/0: «производной нет».

Так правильно

0/0 — неопределённость, а не ответ. Сначала упрости отношение и сократи на Δx (оно не равно нулю при Δx → 0), потом переходи к пределу.

Так нельзя

«Производная в точке — это функция f′(x)».

Так правильно

Производная в точке x₀ — число f′(x₀). Функция f′(x) получается, когда x₀ пробегает значения; f′(x₀) — её значение.

Так нельзя

«f′(x₀) = Δy/Δx при малом Δx».

Так правильно

Производная — предел отношения. Для одного малого Δx отношение даёт угловой коэффициент секущей, то есть лишь приближённое значение.

Так нельзя

Считать, что предел отношения, равный +∞, — это «бесконечная производная», и функция дифференцируема.

Так правильно

По определению лекции производная — конечный предел. Если предел бесконечен, функция в этой точке не дифференцируема (вертикальная касательная, статья 8.2).

Так нельзя

В примере (x + Δx)² − x² = Δx².

Так правильно

(x + Δx)² = x² + 2xΔx + (Δx)². Квадрат суммы — это не сумма квадратов; потерянное слагаемое 2xΔx и даёт производную 2x.

Кратко для повторения

Кратко для повторения

  • Δx = x − x₀ — приращение аргумента, Δy = f(x₀ + Δx) − f(x₀) — приращение функции в точке x₀; Δy/Δx — угловой коэффициент секущей (средняя скорость изменения).
  • Производная в точке — конечный предел limΔx→0 Δy/Δx. Это число; если предел существует и конечен, функция дифференцируема в точке.
  • Обозначения: y′, y′x, f′(x), dy/dx, df/dx; в точке x₀: y′(x₀), f′(x₀), y′|x=x₀. Нахождение производной — дифференцирование.
  • Алгоритм: задай Δx → найди Δy → составь Δy/Δx и сократи на Δx → найди предел при Δx → 0.
  • Из лекции: (C)′ = 0, x′ = 1, (xⁿ)′ = n·xn−1 (для натурального n), (cos x)′ = −sin x, y′(2) = 7 для y = x² + 3x − 1. Дополнительно: (1/x)′ = −1/x², (√x)′ = 1/(2√x).
