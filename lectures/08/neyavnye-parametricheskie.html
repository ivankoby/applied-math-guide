До сих пор функция была задана явно, формулой y = f(x). Но кривая может быть задана уравнением, связывающим x и y, например x² + y² = 1, или двумя формулами через параметр, как траектория точки. Решать такое уравнение относительно y часто невозможно или невыгодно, а производная при этом находится. В статье три приёма: дифференцирование неявной функции, параметрической и логарифмическая производная для показательно-степенных функций, в каждом алгоритм и примеры. Основа — правила дифференцирования сложной и обратной функций (статьи 8.5 и 8.6).

Неявная функция

Пусть задано уравнение F(x, y) = 0, которое для каждого x из окрестности U(x₀) имеет решение y = f(x), то есть F(x, f(x)) = 0 для всех x ∈ U(x₀) (лекция, часть 2, стр. 7). Говорят, что функция f неявно задана уравнением F(x, y) = 0. Предполагают, что f дифференцируема на U(x₀) и что левая часть тождества F(x, f(x)) ≡ 0 — дифференцируемая функция. Тогда тождество можно продифференцировать по x почленно; «иногда оказывается (это зависит от вида F), что продифференцированное тождество можно разрешить относительно f′» — так находят производную неявной функции.

Ключевой момент: в тождестве y — функция от x, поэтому y дифференцируется как сложная функция (статья 8.5), и каждое слагаемое с y даёт множитель y′:

Алгоритм из практики № 12:

  • Шаг 1. Продифференцируй обе части уравнения по x, считая y = y(x) и помня x′ = 1.
  • Шаг 2. Собери слагаемые с y′ в одной части уравнения, остальные перенеси в другую; вынеси y′ за скобку.
  • Шаг 3. Раздели на коэффициент при y′ (он должен быть отличен от нуля) и получи y′ = …. Ответ обычно содержит и x, и y.
Пример из лекции: окружностьиз лекции, часть 2, стр. 7–8
Пусть F(x, y) = x² + y² − 1 и y = f(x) — одно из решений уравнения x² + y² − 1 = 0 при x ∈ (−1; 1). Найти f′(x).

  1. Тогда x² + (f(x))² − 1 ≡ 0 на (−1; 1). Предполагая, что f дифференцируема, дифференцируем тождество по x: 2x + 2f(x)·f′(x) = 0.

  2. Разрешаем относительно f′: f′(x) = −x/f(x), то есть y′ = −x/y.

  3. Условие y ≠ 0: в точках (±1; 0) касательная к окружности вертикальна, и производной нет. Результат верен для обеих половин окружности: для верхней y = √(1 − x²) получаем y′ = −x/√(1 − x²), для нижней y = −√(1 − x²) — y′ = x/√(1 − x²), и обе записи совпадают с −x/y.

y′ = −x/y, y ≠ 0.

Геометрически формула y′ = −x/y говорит, что касательная к окружности в точке (x; y) перпендикулярна радиусу: угловой коэффициент радиуса y/x, коэффициент касательной −x/y, их произведение −1.

Пример 1: декартов листдополнительно к лекции (тип 7.1–7.2 практики № 12)
Найти y′ для неявной функции x³ + y³ = 6xy, вычислить её в точке (3; 3) и записать уравнение касательной в этой точке.

  1. Шаг 1. Дифференцируем по x: 3x² + 3y²·y′ = 6y + 6x·y′ (справа произведение xy, его производная y + x·y′).

  2. Шаг 2. Слагаемые с y′ — влево, остальные — вправо: 3y²·y′ − 6x·y′ = 6y − 3x²; выносим y′: y′(3y² − 6x) = 6y − 3x².

  3. Шаг 3. y′ = (6y − 3x²)/(3y² − 6x) = (2y − x²)/(y² − 2x).

  4. В точке (3; 3) (она лежит на кривой: 27 + 27 = 54 = 6·9): y′ = (6 − 9)/(9 − 6) = −3/3 = −1. Касательная y − 3 = −1·(x − 3), то есть y = −x + 6.

y′ = (2y − x²)/(y² − 2x); в точке (3; 3) производная равна −1, касательная y = −x + 6. В начале координат числитель и знаменатель равны нулю (0/0): там кривая самопересекается, формула не применима.

Пример 2: показательная функция в неявном уравнениидополнительно к лекции
Найти y′ для exy + y = x и вычислить y′ в точке (0; −1).

  1. Дифференцируем: exy·(xy)′ + y′ = 1. Так как (xy)′ = y + x·y′, получаем exy(y + x·y′) + y′ = 1.

  2. Раскрываем скобки и собираем y′: x·exy·y′ + y′ = 1 − y·exy, откуда y′(1 + x·exy) = 1 − y·exy и y′ = (1 − y·exy)/(1 + x·exy).

  3. Точка (0; −1) лежит на кривой: e⁰ + (−1) = 0 = x. y′ = (1 − (−1)·1)/(1 + 0) = 2.

y′ = (1 − y·exy)/(1 + x·exy), в точке (0; −1) равна 2.

Логарифмическая производная

Показательно-степенная функция y = u(x)v(x) (и основание, и показатель зависят от x) не входит в таблицу: это ни степень, ни показательная. Её дифференцируют логарифмированием (практика № 12, разд. 8). Тот же приём полезен для произведений и частных с многими множителями и корнями.

Алгоритм логарифмического дифференцирования

Пусть u(x) > 0 и u, v имеют производные. (1) Прологарифмируй: ln y = v·ln u. (2) Продифференцируй обе части по x, помня (ln y)′ = y′/y. (3) Вырази y′ = y·(…). (4) Подставь y = uv.

(uv)′ = uv·( v′·ln u + v·u′/u )
Формула — сумма двух «обычных» производных: если зафиксировать v, это степень v·uv−1·u′; если зафиксировать u, это показательная uv·ln u·v′. Условие u > 0 нужно для ln u.

Условие

Если функция принимает и отрицательные значения (например, y = (x − 1)(x + 2)/(x − 3) при 1 < x < 3, где y < 0), логарифмируют модуль: ln|y|. Производная та же, (ln|y|)′ = y′/y, поэтому y′ = y·(1/(x − 1) + 1/(x + 2) − 1/(x − 3)); формула годится при y ≠ 0 (в нуле y сумма в скобках не определена).

Пример 3: показательно-степенная функциядополнительно к лекции (тип 8.1 практики № 12)
Найти производную функции y = xsin x, x > 0.

  1. (1) ln y = sin x·ln x.

  2. (2) Дифференцируем: y′/y = cos x·ln x + sin x·(1/x) (справа произведение).

  3. (3)–(4) y′ = y(cos x·ln x + sin x/x) = xsin x(cos x·ln x + sin x/x).

  4. Проверка по формуле: u = x, v = sin x: v′ln u + v·u′/u = cos x·ln x + sin x·1/x — то же.

y′ = xsin x(cos x·ln x + (sin x)/x).

Пример 4: произведение и частноедополнительно к лекции (по образцу примера 5.4 методических указаний)
Найти производную функции y = (x + 1)²·√(x − 2)/(x + 3)³ при x > 2.

  1. Логарифмируем и раскладываем: ln y = 2 ln(x + 1) + (1/2) ln(x − 2) − 3 ln(x + 3). Прямое дифференцирование дроби потребовало бы правил произведения и частного, а здесь получается сумма.

  2. y′/y = 2/(x + 1) + 1/(2(x − 2)) − 3/(x + 3).

  3. y′ = (x + 1)²√(x − 2)/(x + 3)³ · [2/(x + 1) + 1/(2(x − 2)) − 3/(x + 3)]. Ответ оставляют в таком виде: он компактный и удобный для проверки.

y′ = y·[2/(x + 1) + 1/(2(x − 2)) − 3/(x + 3)], где y = (x + 1)²√(x − 2)/(x + 3)³.

Пример 5: гиперболический показатель, арк-функция в основаниидополнительно к лекции (тип 12.x практики № 12; числа свои)
Найти производную функции y = (arcsin 2x)sh 3x при 0 < x < 1/2.

  1. u = arcsin 2x > 0, v = sh 3x: ln y = sh 3x·ln(arcsin 2x).

  2. Дифференцируем произведение. (sh 3x)′ = 3 ch 3x (строка sh, w = 3x); (ln arcsin 2x)′ = 2/(√(1 − 4x²)·arcsin 2x) (строка arcsin, w = 2x, w′ = 2). Поэтому y′/y = 3 ch 3x·ln(arcsin 2x) + sh 3x·2/(√(1 − 4x²)·arcsin 2x).

y′ = (arcsin 2x)sh 3x·[3 ch 3x·ln(arcsin 2x) + 2 sh 3x/(√(1 − 4x²)·arcsin 2x)].

Пример 6: cth с вложенным аргументом, корень в показателедополнительно к лекции (тип 12.x практики № 12; числа свои)
Найти производную функции y = (cth 2x²)√(x+1) при x > −1, x ≠ 0.

  1. При x ≠ 0 имеем cth 2x² > 1, логарифмировать можно: ln y = √(x + 1)·ln(cth 2x²).

  2. Для основания w = 2x², w′ = 4x: (ln cth 2x²)′ = −4x/(sh 2x²·ch 2x²); для показателя (√(x + 1))′ = 1/(2√(x + 1)). y′/y = ln(cth 2x²)/(2√(x + 1)) − 4x√(x + 1)/(sh 2x²·ch 2x²).

y′ = (cth 2x²)√(x+1)·[ln(cth 2x²)/(2√(x + 1)) − 4x√(x + 1)/(sh 2x²·ch 2x²)].

Параметрически заданная функция

Функция y(x) задана параметрически, если обе переменные выражены через параметр t (практика № 12, разд. 9):

x = φ(t),
y = ψ(t).

Лекция (часть 2, стр. 7): пусть φ непрерывна и строго монотонна в окрестности t₀ и существуют φ′(t₀), ψ′(t₀) (условие φ′(t₀) ≠ 0 в лекции не названо, см. замечание ниже). Тогда существует обратная функция t = φ⁻¹(x) (статья 8.6), и y = ψ(φ⁻¹(x)) — сложная функция (статья 8.5). По формулам для сложной функции и для производной обратной (φ⁻¹)′ = 1/φ′:

dy/dx (x₀) = ψ′(t₀)·1/φ′(t₀) = ψ′(t₀)/φ′(t₀), то есть y′x = y′t/x′t
Производная получается как функция параметра t; иногда пишут y′x = ẏ/ẋ. Знаменатель φ′(t₀) ≠ 0: на него делят (в формуле для обратной функции нужно φ′ ≠ 0).

Замечание

В практике № 12 (стр. 5) условие записано как φ(t) ≠ 0: это опечатка, нужно φ′(t) ≠ 0, то есть x′t ≠ 0 (так в опорном конспекте, 2.5.4, и в методических указаниях). В лекции оно явно не названо, лишь подразумевается знаменателем φ′(t₀), хотя без него теорема неверна: для x = t³ функция φ непрерывна и строго монотонна, но φ′(0) = 0, а обратная t = ∛x в нуле не дифференцируема (при y = t получаем y = ∛x с вертикальной касательной в нуле). Если x′t(t₀) = 0, а y′t(t₀) ≠ 0, касательная вертикальна.

Алгоритм: (1) найди x′t и y′t; (2) составь y′x = y′t/x′t и упрости; (3) если нужно значение в точке — найди t₀ по условию (по данной точке из x₀ = φ(t₀) либо по заданному t₀) и подставь.

Пример 7: эллипсдополнительно к лекции (по образцу примера 5.2 методических указаний; тип 2.x практики № 12)
Найти y′x для функции x = 2 cos t, y = 3 sin t и вычислить её при t = π/4.

  1. (1) x′t = −2 sin t, y′t = 3 cos t.

  2. (2) y′x = y′t/x′t = 3 cos t/(−2 sin t) = −(3/2)·ctg t (при sin t ≠ 0).

  3. (3) При t = π/4: ctg(π/4) = 1, y′x = −3/2.

y′x = −(3/2)·ctg t; при t = π/4 равна −3/2.

Пример 8: циклоида и касательнаядополнительно к лекции (тип 2.x практики № 12; числа свои)
Для циклоиды x = 2(t − sin t), y = 2(1 − cos t) найти y′x и уравнение касательной при t = 2π/3.

  1. x′t = 2(1 − cos t), y′t = 2 sin t, поэтому y′x = sin t/(1 − cos t) (множитель 2 сокращается). Используя sin t = 2 sin(t/2)cos(t/2) и 1 − cos t = 2 sin²(t/2), получаем y′x = ctg(t/2) при t ≠ 2πk (там x′t = 0: точки возврата циклоиды).

  2. При t = 2π/3: y′x = ctg(π/3) = 1/√3. Точка касания x = 2(2π/3 − sin(2π/3)) = 4π/3 − √3, y = 2(1 − cos(2π/3)) = 2(1 + 1/2) = 3.

  3. Касательная: y − 3 = (1/√3)(x − 4π/3 + √3), то есть y = x/√3 + 4 − 4π/(3√3) ≈ 0,577x + 1,582.

y′x = ctg(t/2); касательная y = x/√3 + 4 − 4π/(3√3) в точке (4π/3 − √3; 3).

Частые ошибки

Так нельзя

В неявной функции (y²)′ = 2y — забыли множитель y′.

Так правильно

y — функция от x, поэтому (y²)′ = 2y·y′. Множитель y′ нужен у каждого слагаемого с y.

Так нельзя

(xy)′ = y′ или (xy)′ = x·y′.

Так правильно

xy — произведение двух функций от x: (xy)′ = y + x·y′.

Так нельзя

В uv дифференцировать только степень v·uv−1·u′ (или только показательную часть).

Так правильно

Нужна сумма обеих частей: (uv)′ = uv(v′ln u + v·u′/u). Проверка: при v = const второе слагаемое даёт степенную формулу, при u = const — показательную.

Так нельзя

y′x = x′t/y′t — формула перевёрнута.

Так правильно

y′x = y′t/x′t — числитель y по t, знаменатель x по t. Ориентир: dy/dx = (dy/dt)/(dx/dt).

Так нельзя

Разрешать уравнение F(x, y) = 0 относительно y перед дифференцированием, «чтобы было по-честному».

Так правильно

Это не нужно и часто невозможно. Дифференцируем уравнение как есть, а ответ выражаем через x и y. Значение производной в точке берут по координатам точки на кривой.

Кратко для повторения

Кратко для повторения

  • Неявная функция: F(x, f(x)) ≡ 0; дифференцируем тождество по x (y = y(x), у каждого слагаемого с y появляется y′), собираем y′, делим на его коэффициент (он не должен быть нулём).
  • Пример лекции: x² + y² = 1 даёт y′ = −x/y при y ≠ 0. Для произведений: (xy)′ = y + x·y′.
  • Логарифмическая производная: ln y = v·ln u, y′ = y(v′ln u + v·u′/u) при u > 0; для произведений и частных логарифмирование превращает их в суммы. Типы 12.x — тот же метод с таблицей v′ и (ln u)′ (sh → cth, ch → th, arcsin, √, log₂, …).
  • Параметрическая функция x = φ(t), y = ψ(t): y′x = ψ′(t)/φ′(t) при φ′(t) ≠ 0 (φ непрерывна и строго монотонна; без φ′ ≠ 0 теорема неверна: x = t³). Результат — функция параметра; для значения в точке найди t₀.
  • Касательная в неявном или параметрическом случае: точка (x₀; y₀), угловой коэффициент y′ из формулы, дальше y − y₀ = y′(x − x₀) (статья 8.7).

Задания для самопроверки

Решено: 0 из 7

Ответ — число: целое, десятичное (0,25) или дробь (1/4). Минус — обычный дефис. Подсказки появляются после неверного ответа, решение можно открыть в любой момент.

1
Точка (2; 1) лежит на кривой x² + xy + y² = 7. Найдите угловой коэффициент касательной к кривой в этой точке (производную неявной функции).

Показать решение

Дифференцируем по x: 2x + (y + x·y′) + 2y·y′ = 0. Собираем y′: y′(x + 2y) = −(2x + y), y′ = −(2x + y)/(x + 2y). В точке (2; 1): −(4 + 1)/(2 + 2) = −5/4 = −1,25.

Варианты ответа

Показать решение

Дифференцируем по x: 2y·y′ = 3x² + 1. Отсюда y′ = (3x² + 1)/(2y) (при y ≠ 0).

Показать решение

Формула y′x = y′t/x′t: y′x = 3 cos t/(−2 sin t) = −(3/2)·ctg t. При t = π/4: −3/2. В шаге 2 числитель и знаменатель поменяли местами.

6
Для кривой x = t² − 2t, y = t³ − 3t найдите значение t, при котором касательная горизонтальна.

Показать решение

Касательная горизонтальна, когда y′x = y′t/x′t = 0: y′t = 3t² − 3 = 0 при t = ±1 и одновременно x′t = 2t − 2 ≠ 0. При t = 1 знаменатель равен нулю, при t = −1 равен −4. Ответ t = −1.

7

Показать решение

x′t = 1/t = 1/9, y′t = 1/(2√t) = 1/6 при t = 9. y′x = (1/6)/(1/9) = 9/6 = 1,5. Общая формула: y′x = √t/2.
