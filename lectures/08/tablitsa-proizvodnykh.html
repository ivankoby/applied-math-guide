Произведение, частное и сложные функции — в статьях 8.4 и 8.5.

Два правила, без которых таблицей не воспользоваться

Пусть функции u = u(x) и v = v(x) дифференцируемы в точке x₀ (так начинается раздел о правилах в лекции, стр. 7). Тогда в этой точке:

  • Правило 1. Постоянный множитель выносится за знак производной: (C·u)′ = C·u′.
  • Правило 2. Производная суммы (разности) равна сумме (разности) производных: (u ± v)′ = u′ ± v′; это верно для любого конечного числа слагаемых.

Этого хватает, чтобы дифференцировать многочлены и любые суммы функций из таблицы «по частям». Правила 3 и 4 (произведение и частное) — в статье 8.4.

Как выучить таблицу

  • Минусы. В таблице 2.1 знак «минус» стоит у производных функций с приставкой «ко-»: cos, ctg, arccos, arcctg. У остальных функций таблицы знак «плюс».
  • Парные формулы. Производные arcsin и arccos отличаются только знаком, так же arctg и arcctg. Причина: arcsin x + arccos x = π/2 — константа, а у константы производная нуль. Значит, (arccos x)′ = −(arcsin x)′. Аналогично arctg x + arcctg x = π/2.
  • Логарифм основания a. Показательная ax умножается на ln a, логарифм loga x — делится: loga x = ln x / ln a, поэтому (loga x)′ = (1/x)/ln a. При a = e имеем ln e = 1, и формулы 4 и 6 превращаются в 5 и 7.
  • Тангенс и котангенс. В знаменателе у tg стоит cos²x, у ctg — sin²x: функция и «ко-» в знаменателе меняются местами (причина — формула частного, статья 8.4).

Откуда берутся формулы (вывод нескольких строк)

Лекция выводит по определению строки 1–3 (для натурального n) и формулу 9 для cos x (статья 8.1). Ещё три вывода — дополнительно к лекции (опорный конспект). Во всех трёх используются замечательные пределы из лекции 6: limt→0 sin t / t = 1, limt→0 (at − 1)/t = ln a (при a = e это 1), limt→0 ln(1 + t)/t = 1.

Вывод: (sin x)′ = cos xдополнительно к лекции
Вывести формулу 8.

  1. Δy = sin(x + Δx) − sin x = 2 sin(Δx/2)·cos(x + Δx/2) (формула разности синусов).

  2. Δy/Δx = cos(x + Δx/2) · sin(Δx/2)/(Δx/2). При Δx → 0: первый множитель стремится к cos x (косинус непрерывен), второй — к 1.

(sin x)′ = cos x.

Вывод: (aˣ)′ = aˣ·ln aдополнительно к лекции
Вывести формулы 4 и 5.

  1. Δy = ax + Δx − ax = ax(aΔx − 1). Множитель ax от Δx не зависит.

  2. Δy/Δx = ax·(aΔx − 1)/Δx → ax·ln a, потому что (at − 1)/t → ln a. При a = e получаем (ex)′ = ex: единственная функция, которая равна своей производной (с точностью до множителя).

(ax)′ = ax·ln a, (ex)′ = ex.

Вывод: (ln x)′ = 1/xдополнительно к лекции
Вывести формулу 7 при x > 0 (и для ln|x| при x ≠ 0).

  1. Δy = ln(x + Δx) − ln x = ln((x + Δx)/x) = ln(1 + Δx/x). Обозначим t = Δx/x, тогда Δx = x·t и t → 0 вместе с Δx.

  2. Δy/Δx = ln(1 + t)/(x·t) = (1/x)·ln(1 + t)/t → (1/x)·1.

  3. Логарифм модуля. При x < 0 берут ln|x|. При малом Δx числа x + Δx и x одного знака, поэтому ln|x + Δx| − ln|x| = ln(1 + Δx/x): то же выражение, тот же предел. Итак, (ln|x|)′ = 1/x при x ≠ 0 и (loga|x|)′ = 1/(x·ln a) (пригодится в статьях 8.5 и 8.9).

(ln x)′ = 1/x при x > 0; (ln|x|)′ = 1/x при x ≠ 0.

Оставшиеся строки выводятся уже не по определению, а через правила: tg и ctg — частное sin/cos и cos/sin (статья 8.4), loga — делением на ln a, арксинусы и арктангенсы — через производную обратной функции (статья 8.6), степень с любым показателем — через xα = eα·ln x (статья 8.5).

Приём: корень и дробь превращаем в степень

В таблице есть только степень xα. Поэтому перед дифференцированием корни и дроби переписывают как степени (лекция, стр. 9–10, свойства степени из приложения 3):

ⁿ√(aᵐ) = am/n, 1/aⁿ = a−n, 1/ⁿ√(aᵐ) = a−m/n
Пример: √x = x1/2, ∛x = x1/3, 1/x³ = x−3, 1/∛(x²) = x−2/3. Формулы с корнем — для a > 0, формула 1/aⁿ = a−n — при a ≠ 0.
Готовые производные корней и дробей: показатель уменьшается на 1 (1/2 − 1 = −1/2, −1 − 1 = −2). Последний столбец — где формула верна (у ∛x и 1/∛(x²) при x < 0 берётся действительный корень).

Алгоритм: (1) выпиши константы и переменную по отдельности, (2) преврати корни и дроби в степени xα, (3) продифференцируй почленно: (C·xα)′ = C·α·xα−1, (4) при желании верни ответ к корням и дробям.

Пример 2.1из лекции, стр. 9
Найти производную функции y = 15x² − 4∛x + 3.

  1. Применим правило суммы (разности): y′ = (15x²)′ − (4∛x)′ + (3)′.

  2. Преобразуем корень по свойству степени: ∛x = x1/3 (здесь m = 1, n = 3). Выносим константы за знак производной: y′ = 15·(x²)′ − 4·(x1/3)′ + 0.

  3. По формуле 3: y′ = 15·2x2−1 − 4·(1/3)·x1/3−1 = 30x − (4/3)·x−2/3 = 30x − 4/(3∛(x²)).

y′ = 30x − 4/(3∛(x²)) при x ≠ 0 (в нуле у ∛x производной нет, статья 8.2).

Пример 2.2из лекции, стр. 9–10
Найти производную функции y = 2/(15x³).

  1. Свойство степени 1/aⁿ = a−n: y = (2/15)·x−3.

  2. Выносим константу 2/15 и применяем формулу 3: y′ = (2/15)·(−3)·x−3−1 = −(2/5)·x−4 = −2/(5x⁴).

y′ = −2/(5x⁴) при x ≠ 0.

Пример 3: сумма разных функцийдополнительно к лекции
Найти производную функции y = 5x⁴ − 3/x² + 2√x − 7 при x > 0.

  1. Перепишем: y = 5x⁴ − 3x−2 + 2x1/2 − 7.

  2. Дифференцируем по слагаемым: (5x⁴)′ = 20x³; (−3x−2)′ = −3·(−2)x−3 = 6x−3; (2x1/2)′ = 2·(1/2)x−1/2 = x−1/2; (−7)′ = 0.

  3. Складываем и возвращаемся к корням и дробям: y′ = 20x³ + 6/x³ + 1/√x.

y′ = 20x³ + 6/x³ + 1/√x, x > 0.

Пример 4: показательная, логарифм, косинусдополнительно к лекции
Найти производную функции y = 7·2x − 4 ln x + 3 cos x.

  1. Выносим константы и берём из таблицы строки 4, 7 и 9: y′ = 7·(2x)′ − 4·(ln x)′ + 3·(cos x)′.

  2. (2x)′ = 2x·ln 2, (ln x)′ = 1/x, (cos x)′ = −sin x, поэтому y′ = 7·2x·ln 2 − 4/x − 3 sin x.

y′ = 7·2x·ln 2 − 4/x − 3 sin x, x > 0.

Значение производной в точке и точки, где производная равна нулю

Две стандартные задачи после того, как производная найдена (практика № 11): (1) вычислить f′(x₀) — найти производную как функцию и подставить число; (2) найти x, при которых f′(x) = 0 — приравнять производную к нулю и решить уравнение.

Пример 5: значение производной в точкахдополнительно к лекции (тип задачи практики № 11)
Найти значения производной функции f(x) = x² − 3√x (при x > 0) в точках x = 4 и x = 0,01.

  1. Сначала производная: f′(x) = 2x − 3·(1/2)x−1/2 = 2x − 3/(2√x).

  2. При x = 4: √4 = 2, f′(4) = 8 − 3/(2·2) = 8 − 0,75 = 7,25.

  3. При x = 0,01: √0,01 = 0,1, f′(0,01) = 0,02 − 3/(2·0,1) = 0,02 − 15 = −14,98.

f′(4) = 7,25, f′(0,01) = −14,98.

Пример 6: где производная равна нулюдополнительно к лекции (тип задачи практики № 11)
Для функции f(x) = 2x³ − 9x² + 12x − 4 найти f′(0), f′(3) и все x, при которых f′(x) = 0.

  1. f′(x) = 6x² − 18x + 12. Значения: f′(0) = 12, f′(3) = 6·9 − 18·3 + 12 = 54 − 54 + 12 = 12.

  2. Приравниваем к нулю и делим на 6: x² − 3x + 2 = 0, то есть (x − 1)(x − 2) = 0. Корни x = 1 и x = 2: в этих точках касательная к графику горизонтальна (статья 8.7).

f′(0) = f′(3) = 12; f′(x) = 0 при x = 1 и x = 2.

Ещё три типа из практики № 11

В практике № 11 встречаются функции, которых нет в примерах лекции (дополнительно). Общая идея: подготовить функцию так, чтобы осталась сумма табличных слагаемых.

Пример 7: основание меньше 1дополнительно к лекции (тип практики № 11)
Найти производную функции y = 4·(1/3)x.

  1. Формула (ax)′ = ax·ln a верна при любом a > 0, a ≠ 1, и при a < 1 тоже. Здесь a = 1/3, ln(1/3) = −ln 3 < 0, поэтому y′ = 4·(1/3)x·ln(1/3) = −4·ln 3·(1/3)x.

y′ = −4·ln 3·(1/3)x. Минус не ошибка: функция с основанием меньше 1 убывает.

Пример 8: корень со степенью и произведение в знаменателедополнительно к лекции (тип практики № 11)
Найти производную функции y = 6∛(x⁵) − 3/(x²√x) при x > 0.

  1. ∛(x⁵) = x5/3 (в формуле ⁿ√(aᵐ) = am/n здесь m = 5, n = 3). В знаменателе показатели при умножении складываются: x²·√x = x5/2, поэтому 3/(x²√x) = 3x−5/2.

  2. y = 6x5/3 − 3x−5/2, y′ = 6·(5/3)x2/3 − 3·(−5/2)x−7/2 = 10x2/3 + (15/2)x−7/2.

y′ = 10∛(x²) + 15/(2x³√x).

Замечание

В пособии практики № 11 (стр. 12, задание 1а) для y = 4x³ + 3∛(x⁵) − 5/x³ в решении получено 12x² + 5x2/3 + 15x−4, а в ответе напечатано 5∛(x²) − 15/x⁴ + 12x²: знак перед 15/x⁴ потерян. Верно +15/x⁴, ведь (−5x−3)′ = −5·(−3)x−4 = +15x−4 (проверено разностью).

Пример 9: деление на одночлен — почленнодополнительно к лекции (тип практики № 11)
Найти производную функции y = (3x⁴ − 2x² + 5)/x².

  1. Знаменатель — одночлен, правило частного не нужно: делим на x² каждое слагаемое числителя, y = 3x² − 2 + 5x−2. Сумму в знаменателе так разбивать нельзя: 1/(x + 2) ≠ 1/x + 1/2.

  2. y′ = 6x − 10x−3.

y′ = 6x − 10/x³, x ≠ 0.

Частые ошибки

Так нельзя

(ax)′ = x·ax−1 — применили формулу степени к показательной функции.

Так правильно

В ax переменная в показателе. Формула (ax)′ = ax·ln a; формула (xα)′ = α·xα−1 относится к x в основании.

Так нельзя

(23)′ = 3·2², (e²)′ = 2e или (√π)′ = 1/(2√π) — константы дифференцируют как степени.

Так правильно

2³ = 8, e² и √π — числа, у чисел производная нуль: (2³)′ = (e²)′ = (√π)′ = 0. Формула степени — только когда x — переменная.

Так нельзя

(√x)′ = 1/√x и (1/x)′ = ln x.

Так правильно

(√x)′ = (1/2)x−1/2 = 1/(2√x) — не забудь показатель 1/2 как множитель. (1/x)′ = (x−1)′ = −x−2 = −1/x²; логарифм здесь ни при чём.

Так нельзя

(x−3)′ = −3x−3 — показатель не уменьшили.

Так правильно

Показатель на 1 уменьшается: (x−3)′ = −3·x−3−1 = −3x−4.

Так нельзя

(tg x)′ = 1/cos x, (arccos x)′ = 1/√(1 − x²).

Так правильно

(tg x)′ = 1/cos²x (квадрат!), (arccos x)′ = −1/√(1 − x²) (функция с «ко-» — знак минус).

Кратко для повторения

Кратко для повторения

  • Правила для начала: (C·u)′ = C·u′, (u ± v)′ = u′ ± v′ (при дифференцируемых u и v).
  • Таблица: C′ = 0, x′ = 1, (xα)′ = α·xα−1, (ax)′ = ax·ln a, (ex)′ = ex, (loga x)′ = 1/(x·ln a), (ln x)′ = 1/x, (sin x)′ = cos x, (cos x)′ = −sin x, (tg x)′ = 1/cos²x, (ctg x)′ = −1/sin²x, (arcsin x)′ = 1/√(1 − x²), (arccos x)′ = −1/√(1 − x²), (arctg x)′ = 1/(1 + x²), (arcctg x)′ = −1/(1 + x²).
  • Минус стоит у функций с «ко-»: cos, ctg, arccos, arcctg.
  • Корень и дробь переписывай как степень: √x = x1/2, 1/xn = x−n; показатель потом уменьшается на 1. Деление на одночлен — почленно; (ax)′ = ax·ln a и при a < 1 (тогда ln a < 0). (ln|x|)′ = 1/x при x ≠ 0.
  • Для значения в точке: производная как функция, затем подстановка; для нулей производной — уравнение f′(x) = 0.

Проверь себя

Задания для самопроверки

Решено: 0 из 6

Ответ — число: целое, десятичное (0,25) или дробь (1/4). Минус — обычный дефис. Подсказки появляются после неверного ответа, решение можно открыть в любой момент.

1
Найдите производную функции y = (1/4)x.
Варианты ответа

Показать решение

Строка 4 таблицы при a = 1/4: (1/4)x·ln(1/4) = −2 ln 2·(1/4)x. Производная отрицательна: функция убывает.

2
Найдите производную функции y = 6/x⁴ − 3√x.
Варианты ответа

Показать решение

y = 6x−4 − 3x1/2. Тогда y′ = 6·(−4)x−5 − 3·(1/2)x−1/2 = −24/x⁵ − 3/(2√x).

3
Найдите значение производной функции f(x) = ln x + 4√x в точке x = 4.

Показать решение

f′(x) = 1/x + 4·1/(2√x) = 1/x + 2/√x. При x = 4 получаем 1/4 + 2/2 = 0,25 + 1 = 1,25.

4
Заполните пропуски в формулах таблицы.
(arcsin x)′ = 1/√(); (arcctg x)′ = 1/(1 + x²); (ctg x)′ = −1/

Показать решение

(arcsin x)′ = 1/√(1 − x²) (определена при |x| < 1); у функций с «ко-» — минус: (arcctg x)′ = −1/(1 + x²); (ctg x)′ = −1/sin²x.

5
Находим производную функции y = 4/∛x. В каком шаге допущена первая ошибка?
Варианты ответа

Показать решение

1/∛x = x−1/3 (дробь даёт знак минус в показателе). Правильно: y = 4x−1/3, y′ = 4·(−1/3)·x−4/3 = −4/(3x∛x).

6
При каком положительном x производная функции f(x) = x³ − 12x + 5 равна нулю?

Показать решение

f′(x) = 3x² − 12. Уравнение 3x² − 12 = 0 даёт x² = 4, то есть x = −2 или x = 2. Положительная точка x = 2.
