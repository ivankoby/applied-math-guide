Пример 1дополнительно (по образцу практики, стр. 5)
Доказать, что 𝒜x = (x₂ + 2x₃, 3x₁ − x₃, x₁ + x₂ − x₃) линейно, и найти матрицу.

  1. Аддитивность. Для x = (x₁, x₂, x₃), y = (y₁, y₂, y₃) подставляем сумму и собираем слагаемые:

    𝒜(x + y) = ((x₂ + y₂) + 2(x₃ + y₃), 3(x₁ + y₁) − (x₃ + y₃), (x₁ + y₁) + (x₂ + y₂) − (x₃ + y₃)) = 𝒜x + 𝒜y

  2. Однородность. 𝒜(αx) = (αx₂ + 2αx₃, 3αx₁ − αx₃, αx₁ + αx₂ − αx₃) = α·𝒜x.

  3. Матрица. Столбцы — образы e₁, e₂, e₃: 𝒜e₁ = (0, 3, 1), 𝒜e₂ = (1, 0, 1), 𝒜e₃ = (2, −1, −1). Они же — коэффициенты формулы по строкам.

Быстрый признак нелинейности: линейный оператор переводит o в o. Для 𝒜x = (x₁ + 1, x₂, x₃) образ нуля (1, 0, 0) ≠ o, значит, оператор нелинеен.

Разные размерности (пример практики, стр. 4): Π: ℝ³ → ℝ², Π(x₁, x₂, x₃) = (x₁, x₂). Образы базиса Πe₁ = (1, 0), Πe₂ = (0, 1), Πe₃ = (0, 0) — столбцы матрицы размера m × n = 2 × 3:

Π =100010, Π·(x₁, x₂, x₃)T = (x₁, x₂)T

Соглашение

В условии не сказано, вдоль чего проектируют. Принимаем ортогональное проектирование и отражение: в обозначениях статьи 5.7 это ΠL₁ и ZL₁ вдоль L₂ = L₁⊥. Плоскость записывай как ax + by + cz = 0 (всё в левую часть: y = √3x ⇒ √3x − y = 0); тогда L₂ — прямая Lin(n), n = (a, b, c) — нормаль.

Частые ошибки

Так нельзя

Для проектирования на плоскость взять n nT/(n, n).

Так правильно

Это проектирование на ось Lin(n). На плоскость: E − n nT/(n, n); контроль P n = o, P² = P.

Так нельзя

Для отражения взять E − n nT/(n, n).

Так правильно

Это проекция. Отражение Z = E − 2n nT/(n, n); контроль Z n = −n, Z² = E, det Z = −1.

Так нельзя

Для поворота вокруг Oy поставить −s над диагональю, как у Rx и Rz: ((c, 0, −s), (0, 1, 0), (s, 0, c)).

Так правильно

Это поворот в обратную сторону. У Ry знаки sin φ обратные: ((c, 0, s), (0, 1, 0), (−s, 0, c)). Контроль: при φ = 90° вектор k переходит в i.

Так нельзя

В задании 12 считать CAC⁻¹ или составлять C из координат векторов e′j по строкам.

Так правильно

B = C⁻¹AC, а координаты e′j — столбцы C. Контроль: det B = det A, tr B = tr A.

Так нельзя

Считать ядром проектирования на плоскость саму плоскость.

Так правильно

Плоскость — образ (Π v = v на ней). Ядро — перпендикулярная прямая Lin(n).

Кратко для повторения

Кратко для повторения

  • В практике направление проектирования не указано; принимаем проектирование и отражение ортогональными (как в её примере Π: ℝ³ → ℝ², стр. 4). Плоскость ax + by + cz = 0 имеет нормаль n = (a, b, c). P = E − n nT/(n, n), Z = E − 2n nT/(n, n), на ось d: d dT/(d, d).
  • Проекция на плоскость: Ker = Lin(n), Im — плоскость, ранг 2. Отражение: Ker = {o}, Im = ℝ³, det = −1. Поворот: Ker = {o}, det = 1.
  • Поворот в положительном направлении — против часовой стрелки с конца оси (правая тройка i, j, k); Rx, Rz с −s в верхнем правом углу блока, у Ry знаки s наоборот.
  • Задание 12: B = C⁻¹AC, C из столбцов e′j; одна C⁻¹ на все варианты; проверки det, tr, столбцы B.
  • Практика обозначает матрицу перехода C (как статья 3.7), в статье 5.8 она S; Aei = Σ ajifj, а не aij.
