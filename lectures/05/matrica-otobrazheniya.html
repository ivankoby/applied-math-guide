Матрица линейного отображения

Линейное отображение — абстрактный объект, а матрица — конкретная таблица чисел, с которой можно считать. Если зафиксировать базисы, то каждому линейному отображению отвечает ровно одна матрица, и наоборот. Образ вектора превращается в произведение матрицы на столбец, композиция отображений — в произведение матриц, обратное отображение — в обратную матрицу. Это главный мост от лекции 5 к матричной алгебре лекций 1 и 2.

Определение матрицы отображения

Пусть 𝒜: V → W — линейное отображение n-мерного пространства V в m-мерное пространство W. Зафиксируем базис (e) = (e₁, …, en) в V и базис (f) = (f₁, …, fm) в W. Образ 𝒜(ei) каждого базисного вектора — вектор из W, поэтому его можно разложить по базису (f):

𝒜(ei) = a1if₁ + a2if₂ + … + amifm, i = 1, …, n
Это n разложений, по одному для каждого вектора базиса V. Базис (f) стоит в разложении, поэтому первая цифра индекса — номер вектора из (f).
Матрица линейного отображения

Матрицей линейного отображения 𝒜 в базисах (e) и (f) называется матрица размеров m × n, столбцами которой служат координатные столбцы векторов 𝒜(e₁), …, 𝒜(en) относительно базиса (f). Её обозначают также A(e),(f), чтобы подчеркнуть зависимость от выбранных базисов.

Запомни

Размер матрицы — «в обратном порядке»: отображение идёт из V (размерность n) в W (размерность m), а матрица имеет размер m × n. Чтобы не ошибиться, помни: столбец — один базисный вектор из V, а его длина — размерность W.

Запомни

Матрица зависит от выбора базисов. Одно и то же отображение в разных базисах записывается разными матрицами; пример — в конце статьи, а связь между ними для операторов — в статье 5.8.

Как построить матрицу: алгоритм из лекции

  • Зафиксируй базисы (e) = (e₁, …, en) в V и (f) = (f₁, …, fm) в W (если базисы не заданы, возьми стандартные).
  • Найди образ первого базисного вектора 𝒜(e₁) и разложи его по базису (f). Полученные координаты запиши в первый столбец матрицы.
  • То же со вторым вектором: координаты 𝒜(e₂) по базису (f) — во второй столбец. И так далее.
  • В последний столбец запиши координаты 𝒜(en).

Если базис (f) стандартный, то разлагать нечего: координаты вектора совпадают с его компонентами. Если же (f) нестандартный, для каждого образа придётся решить маленькую систему (пример 3 ниже).

Формула w = Av: образ вектора через матрицу

Матрица нужна, чтобы по координатам вектора v находить координаты образа w = 𝒜(v). Пусть v = v₁e₁ + … + vnen и w = w₁f₁ + … + wmfm; столбцы координат — v = (v₁ … vn)T и w = (w₁ … wm)T. По линейности и определению матрицы:

w = 𝒜(v) = v₁𝒜(e₁) + … + vn𝒜(en) = Σi vi Σj ajifj
Координаты вектора по базису единственны, поэтому коэффициент при fj слева (wj) равен коэффициенту справа: wj = aj1v₁ + … + ajnvn — это ровно строка матрицы на столбец.
w = A·v, то есть wj = Σi=1n ajivi, j = 1, …, m
(формула 9.2 лекции). Оба столбца, v и w, — координатные, относительно выбранных базисов.

Соответствие

Для каждого линейного отображения n-мерного V в m-мерное W (при фиксированных базисах) определена единственная матрица A. И наоборот, любая числовая матрица размера m × n является матрицей некоторого линейного отображения: по свойству 6 (статья 5.3) возьми образы базисных векторов, равные её столбцам. Так что отображения и матрицы соответствуют друг другу взаимно однозначно.

Матрицы отображений из статьи 5.2 (пример лекции)

Пример 1из лекции, стр. 7–9
Найти матрицы линейных отображений из статьи 5.2: нулевого O: V → W; координатного æ: V → ℝn; проекции pre₁: E → ℝ; дифференцирования 𝒟: Pn(ℝ) → Pn−1(ℝ).

  1. Нулевое отображение. Образ любого базисного вектора равен oW, а его координаты в любом базисе равны нулю. Поэтому матрица нулевого отображения нулевая относительно любых базисов V и W.

  2. Координатное отображение æ. В V взят базис e₁, …, en, в ℝn — стандартный базис. Координаты вектора x = (x₁ … xn)T в стандартном базисе совпадают с самим столбцом x, потому что x = x₁e₁ + … + xnen. Образ æ(e₁) — координатный столбец вектора e₁, то есть (1 0 … 0)T, совпадающий с первым базисным вектором ℝn; æ(e₂) = e₂ и так далее. Эти столбцы составляют единичную матрицу E порядка n.

  3. Проекция. Берём в евклидовом E ортонормированный базис e₁, …, en, а в одномерном ℝ — базис из единицы. Для единичного e₁ имеем pre₁(v) = (e₁, v). Тогда pre₁(e₁) = (e₁, e₁) = 1, а pre₁(ei) = (e₁, ei) = 0 при i ≠ 1. Матрица — строка 1 × n, в общем случае (1 0 … 0). Для n = 3:

    pre₁ =100

  4. Дифференцирование. Стандартные базисы: 1, x, …, xn в Pn и 1, x, …, xn−1 в Pn−1. Образы базисных векторов (производные): 𝒟(1) = 0, 𝒟(x) = 1, 𝒟(x²) = 2x, …, 𝒟(xn) = n·xn−1. Координаты по столбцам дают матрицу размера n × (n + 1): в первом столбце нули, а вектор xk (это (k + 1)-й вектор базиса 1, x, …, xn) даёт столбец номер k + 1, у которого в k-й строке стоит число k. Для n = 3 (дополнительно) получаем три строки и четыре столбца: P3 четырёхмерно, P2 трёхмерно.

    D =010000200003

Нулевая матрица; E; строка (1 0 … 0); матрица D размера n × (n + 1) с числами 1, 2, …, n над главной диагональю.

Свойства матриц отображений

При фиксированных базисах линейных пространств:

  • (1) матрица суммы линейных отображений 𝒜 + ℬ равна сумме их матриц: A + B;
  • (2) матрица произведения отображения на число λ равна произведению матрицы на то же число: λA;
  • (3) матрица обратного отображения 𝒜⁻¹ равна обратной матрице A⁻¹ (при dim V = dim W; в области 𝒜⁻¹, то есть в W, берут тот же базис (f), а в образе — (e));
  • (4) матрица композиции 𝒞 = ℬ∘𝒜 равна произведению матриц: C = BA (матрица того, что действует первым, стоит справа).

Доказательство свойства (4) (из лекции). Пусть в V, W, U выбраны базисы (e), (f), (g), а 𝒜: V → W, ℬ: W → U и 𝒞 = ℬ∘𝒜 имеют матрицы A, B, C. Для координатных столбцов v, w = 𝒜(v), u = ℬ(w) = 𝒞(v) по формуле w = Av имеем w = Av, u = Bw, u = Cv. Тогда Cv = u = Bw = BAv для столбца v любого вектора. Равенство Cv = BAv верно для всех столбцов v; взяв в качестве v столбцы единичной матрицы, получаем, что у C и BA совпадают все столбцы: C = BA.

Запомни

Порядок C = BA, а не AB, как у записи композиции ℬ∘𝒜 и у функций f(g(x)): ближе к вектору стоит то, что действует первым. Размеры тоже подсказывают: у 𝒜: ℝ² → ℝ³ матрица 3 × 2, у ℬ: ℝ³ → ℝ² — 2 × 3; произведение BA имеет размер 2 × 2 (отображение ℝ² → ℝ²), а AB — 3 × 3 и описывает композицию в другую сторону.

Осторожно

Матрица тождественного отображения ℰ: V → V равна E, если в области и в образе взят один и тот же базис. Если взять разные базисы, получится не E, а матрица перехода от базиса образа к базису области (статья 5.8).

Примеры в разных базисах

Пример 2дополнительно (продолжение примера 2 статьи 5.3)
В стандартных базисах найти матрицы отображений 𝒜(x, y) = (x + 2y, 3x − y), ℬ(x, y) = (x, x + y), а затем матрицы 𝒜 + ℬ, 3𝒜, ℬ∘𝒜.

  1. Столбцы матрицы — образы базисных векторов e₁ = (1, 0), e₂ = (0, 1) (в стандартном базисе координаты совпадают с компонентами). 𝒜(e₁) = (1, 3), 𝒜(e₂) = (2, −1), ℬ(e₁) = (1, 1), ℬ(e₂) = (0, 1):

    A =123−1, B =1011

  2. Сумма и число. По свойствам (1) и (2):

    A + B =2240, 3A =369−3

    Сравни с формулами из статьи 5.3: (𝒜 + ℬ)(x, y) = (2x + 2y, 4x) и (3𝒜)(x, y) = (3x + 6y, 9x − 3y): коэффициенты — это строки найденных матриц.

  3. Композиция. По свойству (4) матрица ℬ∘𝒜 равна BA (не AB):

    BA =1011·123−1=1241

    Формула из статьи 5.3 была (ℬ∘𝒜)(x, y) = (x + 2y, 4x + y): те же коэффициенты. А произведение в другом порядке даёт другую матрицу:

    AB =322−1≠ BA

    Это матрица композиции 𝒜∘ℬ: сначала ℬ, потом 𝒜.

A + B, 3A, BA — матрицы выше.

Пример 3: нестандартные базисыдополнительно
Отображение 𝒜: ℝ² → ℝ², 𝒜(x, y) = (x + y, 2x − y). В области возьмём базис e₁ = (1, 1), e₂ = (1, −1), в образе — базис f₁ = (1, 1), f₂ = (1, 0). Найти матрицу A(e),(f) и проверить формулу w = Av на векторе v = (3, 1).

  1. Образы базисных векторов (в стандартных координатах): 𝒜(e₁) = 𝒜(1, 1) = (2, 1), 𝒜(e₂) = 𝒜(1, −1) = (0, 3).

  2. Первый столбец. Раскладываем 𝒜(e₁) = (2, 1) по базису (f): (2, 1) = a·(1, 1) + b·(1, 0). Покоординатно: a + b = 2 и a = 1. Отсюда a = 1, b = 1. Столбец (1, 1)T. Проверка: 1·(1, 1) + 1·(1, 0) = (2, 1).

  3. Второй столбец. Раскладываем 𝒜(e₂) = (0, 3): (0, 3) = a·(1, 1) + b·(1, 0), то есть a + b = 0, a = 3. Отсюда a = 3, b = −3. Столбец (3, −3)T. Проверка: 3·(1, 1) − 3·(1, 0) = (0, 3).

    A(e),(f) =131−3

  4. Проверка формулы w = Av. Координаты v = (3, 1) в базисе (e) из системы a + b = 3, a − b = 1: a = 2, b = 1 (как в примере 1 статьи 5.3). Тогда координаты образа в базисе (f):

    w =131−3·21=5−1

    Это координаты, а не сам вектор. Сам образ: w = 5·f₁ − 1·f₂ = 5·(1, 1) − (1, 0) = (4, 5). Прямо по формуле 𝒜(3, 1) = (3 + 1, 6 − 1) = (4, 5). Всё сошлось.

A(e),(f) — матрица выше; одно и то же отображение имеет в стандартных базисах матрицу ((1, 1), (2, −1)), а в этих — ((1, 3), (1, −3)).

Частые ошибки

Так нельзя

Записывать координаты образа 𝒜(ei) в строки матрицы.

Так правильно

Координаты образа i-го базисного вектора записывают в i-й столбец.

Так нельзя

Для 𝒜: ℝ³ → ℝ² писать матрицу 3 × 2.

Так правильно

Размер m × n, где n = dim V = 3 — число столбцов, а m = dim W = 2 — число строк: матрица 2 × 3.

Так нельзя

Матрица композиции ℬ∘𝒜 равна AB.

Так правильно

C = BA: сначала действует 𝒜, его матрица стоит справа, ближе к вектору. AB описывает другую композицию (𝒜∘ℬ) и может иметь другой размер или не существовать.

Так нельзя

Разлагать образ 𝒜(ei) по базису V, а не W.

Так правильно

Образ лежит в W, поэтому разложение идёт по базису (f) пространства W. Базис (e) нужен только для того, чтобы знать, какие векторы отображаем.

Так нельзя

В нестандартном базисе (f) брать компоненты образа за столбец матрицы.

Так правильно

Столбец матрицы — координаты образа в базисе (f): для нестандартного (f) их находят из системы a₁f₁ + … + amfm = 𝒜(ei).

Так нельзя

Считать, что у линейного отображения «одна матрица».

Так правильно

Матрица зависит от базисов: у одного отображения в разных базисах разные матрицы. Единственна матрица при фиксированных базисах.

Кратко для повторения

Кратко для повторения

  • dim V = n, dim W = m, базисы (e) и (f): матрица A имеет размер m × n; i-й столбец — координаты 𝒜(ei) в базисе (f): 𝒜(ei) = Σj ajifj.
  • Алгоритм: взять 𝒜(e₁), …, 𝒜(en), разложить каждый по (f), записать координаты в столбцы.
  • w = A·v (формула 9.2): wj = Σ ajivi, все столбцы — координатные. Отображения и матрицы (при фиксированных базисах) соответствуют друг другу взаимно однозначно.
  • Матрицы: нулевого отображения — нулевая; координатного æ — E; проекции на e₁ — строка (1 0 … 0); дифференцирования Pn → Pn−1 — n × (n + 1) с числами 1, …, n над диагональю.
  • A𝒜+ℬ = A + B, Aλ𝒜 = λA, A𝒜⁻¹ = A⁻¹, Aℬ∘𝒜 = BA (при фиксированных базисах).
