Линейное преобразование (оператор) — это линейное отображение пространства в себя: 𝒜: V → V. Растяжение, поворот, симметрия, проекция на плоскость, дифференцирование многочленов — всё это операторы. Раз начало и конец совпадают, матрицу оператора принято строить в одном базисе (для прообразов и образов): она квадратная, и появляются новые вопросы (обратим ли оператор, как меняется матрица при смене базиса, статья 5.8). В статье — определение и восемь примеров лекции с матрицами, ядрами, образами и сводной таблицей: по ним удобно тренироваться.

Определение оператора и его матрицы

Линейное преобразование (оператор)

Линейным преобразованием (линейным оператором) линейного пространства V называется линейное отображение 𝒜: V → V пространства V в себя.

Оператор — частный случай линейного отображения, поэтому к нему применимо всё из статей 5.1–5.6: инъективность, сюръективность, биективность, обратимость, ядро, образ, дефект, ранг, теорема 9.1.

Матрица оператора

Матрицей линейного преобразования 𝒜: V → V в базисе e₁, …, en пространства V называется квадратная матрица A, составленная из координатных столбцов образов 𝒜(e₁), …, 𝒜(en), найденных относительно того же базиса e₁, …, en.

Алгоритм тот же, что в статье 5.4, но базис в V берётся один раз: для 𝒜(ei) находим координаты в базисе (e) и записываем в i-й столбец. Матрица квадратная, порядка n = dim V.

Запомни

Матрица биективного оператора обратима, то есть невырождена. Поэтому биективное (обратимое) преобразование называют также невырожденным. У оператора пространство прообразов и пространство образов — одно и то же, dim V = dim W = n, поэтому по статье 5.6 для оператора в конечномерном пространстве инъективность, сюръективность, биективность и условие det A ≠ 0 равносильны.

Простейшие операторы: нулевой, тождественный, симметрия, гомотетия

Примеры 1–4из лекции, часть 2, стр. 1
Исследовать операторы n-мерного пространства V: нулевой O; тождественный ℰ; центральную симметрию Zo, Zo(v) = −v; гомотетию Hλ, Hλ(v) = λ·v.

  1. 1. Нулевой O: V → V ставит каждому вектору нулевой o. Не инъективен, не сюръективен, не биективен, не обратим. Матрица (в любом базисе) нулевая, Ker O = V, Im O = {o}, дефект d = n, ранг r = 0.

  2. 2. Тождественный ℰ(v) = v инъективен, сюръективен, биективен, обратим. Матрица в любом базисе — единичная E порядка n (образ ei — сам ei). Ker ℰ = {o}, Im ℰ = V, d = 0, r = n.

  3. 3. Центральная симметрия Zo(v) = −v (относительно нулевого вектора) линейна, биективна, обратима. Матрица −E (в любом базисе), Ker Zo = {o}, Im Zo = V, d = 0, r = n.

  4. 4. Гомотетия Hλ(v) = λ·v (коэффициент λ) — каждый вектор переходит в коллинеарный ему. Линейна. Матрица λE в любом базисе. При λ ≠ 0 она инъективна, сюръективна, биективна, обратима: Ker Hλ = {o}, Im Hλ = V, d = 0, r = n. Частные случаи: H₀ = O (пример 1), H₁ = ℰ (пример 2), H−1 = Zo (пример 3).

Матрицы: 0, E, −E, λE; обратимы все, кроме нулевого оператора (он же H0).

Запомни

Слова «гомотетия растягивает в λ раз» верны только при λ > 1. При 0 < λ < 1 вектор сжимается, при λ < 0 ещё и меняет направление на противоположное, при λ = 0 получается нулевой оператор.

Поворот плоскости

Пример 5: поворот плоскостииз лекции, часть 2, стр. 1–2
В линейном пространстве V₂ радиус-векторов плоскости рассмотрим поворот Rφ: V₂ → V₂ вокруг точки O на угол φ в положительном направлении (против часовой стрелки). Найти матрицу в стандартном ортонормированном базисе i, j, ядро, образ.

  1. Преобразование линейное, инъективное, сюръективное, биективное, обратимое (поворот можно «отыграть» назад). Матрица строится по алгоритму: находим образы базисных векторов i′ = Rφ(i), j′ = Rφ(j) и раскладываем по i, j (рисунок ниже).

  2. Из прямоугольных треугольников на рисунке:

    i′ = cos φ·i + sin φ·j, j′ = −sin φ·i + cos φ·j

  3. Координаты записываем по столбцам:

    Rφ =cos φ−sin φsin φcos φ

  4. Ядро Ker Rφ = {o}, образ Im Rφ = V₂, дефект d = 0, ранг r = 2. Частные случаи: при φ = 2πk, k ∈ ℤ, R2πk = ℰ; при φ = π + 2πk получается центральная симметрия Rπ+2πk = Zo.

Rφ — матрица выше; Ker = {o}, Im = V₂, d = 0, r = 2.

Проверим на числах (дополнительно). При φ = 90° имеем cos φ = 0, sin φ = 1, и матрица равна ((0, −1), (1, 0)): образ i = (1, 0) — вектор (0, 1), то есть j. Вектор (2, 3) переходит в (0·2 − 1·3, 1·2 + 0·3) = (−3, 2). Композиции двух таких поворотов отвечает произведение матриц (статья 5.4):

0−110·0−110=−100−1= −E

Поворот на 90° дважды — поворот на 180°, и действительно получили −E, матрицу симметрии Zo = Rπ из примера 3.

Дифференцирование как оператор

Пример 6а: дифференцирование на многочленахиз лекции, часть 2, стр. 2
Оператор дифференцирования 𝒟: Pn(ℝ) → Pn(ℝ), 𝒟(p(x)) = p′(x), переводит многочлен степени не выше n в его производную, рассматриваемую как многочлен степени не выше n. Найти матрицу в стандартном базисе, ядро, образ.

  1. Оператор линейный, не инъективный, не сюръективный, не биективный, необратимый. Это тот же 𝒟, что в статье 5.4, но теперь пространство образов совпадает с Pn, поэтому в матрице появилась ещё одна строка из нулей (производная многочлена степени n имеет степень не выше n − 1).

  2. Матрица порядка n + 1 в базисе 1, x, …, xn: в первом столбце нули, а столбец xk имеет число k на k-м месте, считая с первой строки. Для n = 3 (дополнительно):

    D =0100002000030000

  3. Ядро Ker 𝒟 = P₀(ℝ) — константы (включая нулевой многочлен), образ Im 𝒟 = Pn−1(ℝ), дефект d = 1, ранг r = n, причём dim Pn(ℝ) = n + 1 (проверка теоремы 9.1: 1 + n = n + 1). Для n = 3: rg D = 3 (три ненулевые строки ступенчатого вида), ядро — вектор (1, 0, 0, 0)T, то есть многочлен 1; определитель det D = 0.

D порядка n + 1; Ker = P₀, Im = Pn−1, d = 1, r = n; необратим.

Пример 6б: дифференцирование на тригонометрических многочленахиз лекции, часть 2, стр. 2–3
Пусть Tω(ℝ) = Lin(sin ωt, cos ωt) — пространство тригонометрических многочленов частоты ω ≠ 0, то есть функций f(t) = a sin ωt + b cos ωt с вещественными a, b. Рассмотрим 𝒟: Tω(ℝ) → Tω(ℝ), 𝒟(f) = f′. Найти матрицу в стандартном базисе e₁(t) = sin ωt, e₂(t) = cos ωt, ядро, образ.

  1. Пространство двумерное: функции sin ωt и cos ωt линейно независимы (тождество a sin ωt + b cos ωt ≡ 0 возможно только при a = b = 0). Производная f′(t) = −bω sin ωt + aω cos ωt — функция того же вида, поэтому 𝒟 действительно отображает Tω(ℝ) в себя. Оператор линейный, инъективный, сюръективный, биективный, обратимый.

  2. Матрица. 𝒟(e₁) = ω cos ωt = 0·sin ωt + ω·cos ωt, 𝒟(e₂) = −ω sin ωt = −ω·sin ωt + 0·cos ωt. Координаты записываем по столбцам:

    D =0−ωω0

  3. Ядро — нулевая функция o(t) = 0·sin ωt + 0·cos ωt (нулевое подпространство), образ Im 𝒟 = Tω(ℝ), d = 0, r = 2. Определитель ω² ≠ 0, поэтому матрица обратима (при ω ≠ 0).

  4. Аналогичные свойства имеет оператор 𝒟: Tω(ℂ) → Tω(ℂ) на комплексных коэффициентах a, b ∈ ℂ: это двумерное комплексное линейное пространство.

  5. Числовая проверка (дополнительно). Пусть ω = 2 и f = 3 sin 2t − cos 2t, координаты (3, −1)T. Тогда D·(3, −1)T = (0·3 − 2·(−1), 2·3 + 0·(−1))T = (2, 6)T, то есть f′ = 2 sin 2t + 6 cos 2t. Прямым дифференцированием: (3 sin 2t − cos 2t)′ = 6 cos 2t + 2 sin 2t. Совпало. Обратный оператор имеет матрицу D⁻¹ = ((0, 1/2), (−1/2, 0)), он «интегрирует без константы».

D = ((0, −ω), (ω, 0)), Ker = {o}, Im = Tω, d = 0, r = 2; обратим.

Запомни

Одно и то же дифференцирование необратимо на многочленах Pn (теряем константу) и обратимо на Tω: в Tω нет констант, поэтому по производной функцию можно восстановить.

Проекция и отражение

Прямая сумма подпространств

Говорят, что пространство разлагается в прямую сумму подпространств, V = L₁ ⊕ L₂, если каждый вектор v ∈ V единственным образом представляется в виде v = v₁ + v₂, где v₁ ∈ L₁, v₂ ∈ L₂. Равносильно: L₁ ∩ L₂ = {o} и L₁ + L₂ = V (каждый вектор раскладывается, и только одним способом).

Проекция и отражение

Пусть V = L₁ ⊕ L₂. Оператором проектирования на L₁ параллельно L₂ называется ΠL₁: V → V, ΠL₁(v₁ + v₂) = v₁: каждому вектору ставится в соответствие его составляющая из L₁. Оператором отражения в L₁ параллельно L₂ (преобразованием симметрии) называется ZL₁: V → V, ZL₁(v₁ + v₂) = v₁ − v₂: составляющая из L₂ меняет знак.

Запомни

Условие V = L₁ ⊕ L₂ обязательно, и одного L₁ недостаточно: проекция на L₁ зависит от того, вдоль какого L₂ проектируем. Без единственности разложения v = v₁ + v₂ оператор не определён.

Примеры 7 и 8: проекция и отражениеиз лекции, часть 2, стр. 3–4
Пусть V = L₁ ⊕ L₂. Исследовать операторы ΠL₁ и ZL₁: линейность, обратимость, ядро, образ, дефект, ранг, частные случаи.

  1. Проекция ΠL₁. Оператор линейный (складывая векторы, складываем их составляющие). При L₁ ≠ V он не инъективен, не сюръективен, не биективен, необратим. Ядро: Π(v) = o ⇔ v₁ = o ⇔ v = v₂ ∈ L₂, значит Ker ΠL₁ = L₂. Образ: любой v₁ ∈ L₁ есть Π(v₁ + o), значит Im ΠL₁ = L₁. Дефект d = dim L₂, ранг r = dim L₁ (в сумме dim V, теорема 9.1).

  2. Частные случаи проекции. При L₁ = V (тогда L₂ = {o}) получаем ΠV = ℰ; при L₂ = V (то есть L₁ — нулевое подпространство {o}) проекция на L₁ — нулевой оператор O.

  3. Отражение ZL₁. Линейно, инъективно, сюръективно, биективно, обратимо. Ker ZL₁ = {o}, Im ZL₁ = V, d = 0, r = dim V. При L₁ = V получается ZV = ℰ.

Ker Π = L₂, Im Π = L₁, d = dim L₂, r = dim L₁; Z обратимо, d = 0, r = dim V.

Свойства матриц операторов и приём исследования

Замечания 9.2 (часть 2). Для матриц операторов справедливы свойства из статьи 5.4. При фиксированном базисе: матрица суммы операторов равна сумме матриц; матрица произведения оператора на число равна произведению матрицы на то же число; матрица композиции операторов равна произведению матриц; матрица обратного оператора обратна к матрице обратимого оператора.

Как исследовать оператор по его матрице A (порядка n).

  • Найди det A. Если det A ≠ 0, оператор обратим: ядро нулевое, образ — всё V, d = 0, r = n.
  • Если det A = 0, найди ранг r = rg A (статья 1.7) и дефект d = n − r. Ядро — решения Ax = o, образ — оболочка столбцов A (статья 5.5).
  • Если нужны сами векторы (а не координатные столбцы), разверни координаты по базису.

Частые ошибки

Так нельзя

Проекция «на L₁» определена одним подпространством.

Так правильно

Нужны два подпространства с V = L₁ ⊕ L₂: проекция на L₁ параллельно L₂. Для L₁ — ось абсцисс, L₂ = Lin((1, 1)) получаем Π(3, 2) = (1, 0), для L₂′ = Lin((0, 1)) — (3, 0).

Так нельзя

Записать матрицу поворота как ((cos φ, sin φ), (−sin φ, cos φ)).

Так правильно

Первый столбец — образ i: (cos φ, sin φ), второй — образ j: (−sin φ, cos φ). Матрица ((cos φ, −sin φ), (sin φ, cos φ)); другой вариант — поворот в противоположную сторону (на −φ).

Так нельзя

«Гомотетия всегда растягивает векторы в λ раз».

Так правильно

Только при λ > 1. При |λ| < 1 — сжатие, при λ < 0 — ещё и смена направления, λ = 0 даёт нулевой оператор, λ = 1 — тождественный.

Так нельзя

Считать дифференцирование на Pn обратимым («производную можно вернуть интегралом»).

Так правильно

Константа теряется: 𝒟(x + 1) = 𝒟(x). Ядро P₀ ненулевое, d = 1, оператор не обратим. А вот на Tω (ω ≠ 0) оператор обратим.

Так нельзя

Для оператора брать разные базисы в «области» и «образе» и всё равно называть результат матрицей оператора.

Так правильно

Матрицей оператора называют матрицу в одном базисе: она квадратная порядка n, столбцы — координаты образов в том же базисе. При разных базисах получится матрица отображения (например, S⁻¹ для тождественного оператора), и формула (9.4) к ней неприменима.

Кратко для повторения

Кратко для повторения

  • Линейный оператор — линейное отображение 𝒜: V → V; матрица в базисе e — квадратная порядка n: i-й столбец — координаты 𝒜(ei) в том же базисе. Обратим ⇔ биективен ⇔ det A ≠ 0.
  • Нулевой: матрица 0, d = n, r = 0. Тождественный ℰ: E. Центральная симметрия Zo = −E. Гомотетия Hλ = λE (при λ ≠ 0 обратима; H₀ = O, H₁ = ℰ, H−1 = Zo).
  • Поворот Rφ: ((cos φ, −sin φ), (sin φ, cos φ)), d = 0, r = 2; R2πk = ℰ, Rπ+2πk = Zo.
  • 𝒟 на Pn: порядок n + 1, Ker = P₀, Im = Pn−1, d = 1, r = n, необратим. 𝒟 на Tω: ((0, −ω), (ω, 0)), d = 0, r = 2, обратим.
  • При V = L₁ ⊕ L₂: ΠL₁(v₁ + v₂) = v₁ (Ker = L₂, Im = L₁, d = dim L₂, r = dim L₁); ZL₁(v₁ + v₂) = v₁ − v₂ (обратим, d = 0).
