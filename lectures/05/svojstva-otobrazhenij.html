Линейное отображение «ведёт себя хорошо» по отношению к линейной зависимости, размерностям, композициям и обращению. Шесть свойств из лекции отвечают на вопросы вроде: может ли линейное отображение «склеить» независимые векторы? можно ли линейно отобразить ℝ² на ℝ³? обязана ли композиция линейных отображений быть линейной? Самое практичное — свойство 6: линейное отображение полностью определяется образами базисных векторов. Оно лежит в основе матрицы отображения (статья 5.4).

Во всей статье 𝒜: V → W — линейное отображение. Пользоваться будем замечаниями из статьи 5.2: 𝒜(oV) = oW и 𝒜(λ₁v₁ + … + λkvk) = λ₁𝒜(v₁) + … + λk𝒜(vk).

Свойство 1: образы зависимых векторов зависимы

1Зависимость сохраняется

Если векторы v₁, …, vk линейно зависимы, то их образы 𝒜(v₁), …, 𝒜(vk) тоже линейно зависимы.

Пример для 𝒜(x, y, z) = (x + y, y − z): векторы v₁ = (1, 0, 1), v₂ = (0, 1, 1), v₃ = (1, 1, 2) зависимы, потому что v₁ + v₂ − v₃ = o. Образы (1, −1), (1, 0), (2, −1) связаны тем же соотношением: 𝒜(v₁) + 𝒜(v₂) − 𝒜(v₃) = (0, 0).

Это свойство обычно применяют «от противного»: если образы независимы, то и сами векторы независимы.

Доказательство. Зависимость означает, что есть нетривиальная (не все коэффициенты нули) комбинация λ₁v₁ + … + λkvk = oV. Применим 𝒜 к обеим частям. Слева по линейности получим λ₁𝒜(v₁) + … + λk𝒜(vk), справа 𝒜(oV) = oW. Итак, λ₁𝒜(v₁) + … + λk𝒜(vk) = oW с теми же коэффициентами, не все из которых нули: образы зависимы.

Запомни

Обратное неверно: образы независимых векторов могут оказаться зависимыми. Для линейного отображения 𝒜(x, y) = x + y (из ℝ² в ℝ) независимые векторы (1, 0) и (0, 1) имеют образы 1 и 1, а эти два числа линейно зависимы. Отображение может «склеить» независимые векторы.

Свойство 2: независимые образы имеют независимые прообразы

2Прообразы независимых

Пусть 𝒜: V → W сюръективно, а векторы w₁, …, wk из W линейно независимы. Тогда в V найдутся линейно независимые векторы v₁, …, vk с 𝒜(vi) = wi.

Для 𝒜(x, y, z) = (x + y, y − z) (оно сюръективно: система x + y = a, y − z = b разрешима при любых a, b, например y = 0, x = a, z = −b) возьмём независимые w₁ = (1, 0), w₂ = (0, 1). Прообразы находим из уравнений 𝒜(v) = w. Для w₁: x + y = 1, y − z = 0; берём y = z = 0, x = 1, получаем v₁ = (1, 0, 0). Для w₂: x + y = 0, y − z = 1; берём z = 0, y = 1, x = −1, получаем v₂ = (−1, 1, 0). Проверка: 𝒜(v₁) = (1, 0), 𝒜(v₂) = (−1 + 1, 1 − 0) = (0, 1). Векторы v₁, v₂ не пропорциональны, значит, независимы.

Сюръективность нужна: иначе у некоторых wi вообще может не быть прообраза.

Доказательство. Из-за сюръективности у каждого wi есть прообраз vi. Если бы векторы v₁, …, vk оказались зависимыми, то по свойству 1 зависимыми были бы и их образы w₁, …, wk, а они по условию независимы. Значит, найденные прообразы независимы.

Свойство 3: для сюръекции dim W ≤ dim V

3Сюръекция не увеличивает размерность

Если 𝒜: V → W линейно и сюръективно, а пространство V конечномерно, то dim W ≤ dim V.

Сюръективных линейных отображений ℝ² → ℝ³ не существует: 3 > 2. А вот ℝ³ → ℝ² существуют, например (x, y, z) ↦ (x, y). Оператор дифференцирования 𝒟: Pn(ℝ) → Pn−1(ℝ) сюръективен, и действительно dim Pn−1 = n ≤ n + 1 = dim Pn.

Следствие: если 𝒜 биективно, то dim V = dim W (свойство 5 даёт сюръективное 𝒜⁻¹: W → V, откуда dim V ≤ dim W).

Доказательство. Пусть в W есть линейно независимая система из k векторов. По свойству 2 в V найдётся линейно независимая система из k векторов. Но в V не бывает независимых систем из более чем dim V векторов. Значит, в W нет независимых систем длиннее dim V, то есть dim W ≤ dim V.

Свойства 4 и 5: композиция и обратное отображение

4Композиция линейных линейна

Если 𝒜: U → V и ℬ: V → W линейны, то композиция 𝒞 = ℬ∘𝒜: U → W тоже линейна.

Например, 𝒜(x, y) = (x + 2y, 3x − y) и ℬ(x, y) = (x, x + y): композиция ℬ(𝒜(x, y)) = (x + 2y, 4x + y), каждая координата — снова линейная однородная функция x и y.

Доказательство аддитивности. 𝒞(u₁ + u₂) = ℬ(𝒜(u₁ + u₂)) = ℬ(𝒜(u₁) + 𝒜(u₂)) = ℬ(𝒜(u₁)) + ℬ(𝒜(u₂)) = 𝒞(u₁) + 𝒞(u₂): сначала линейность 𝒜, потом линейность ℬ. Однородность проверяется так же: 𝒞(λu) = ℬ(𝒜(λu)) = ℬ(λ𝒜(u)) = λℬ(𝒜(u)) = λ𝒞(u).

5Обратное линейного линейно

Если линейное отображение 𝒜: V → W обратимо (то есть биективно), то обратное отображение 𝒜⁻¹: W → V тоже линейно.

Для 𝒜(x, y) = (x + y, x − y) обратное — 𝒜⁻¹(a, b) = ((a + b)/2, (a − b)/2). Это снова линейное отображение: обе координаты — линейные однородные функции a и b.

Доказательство аддитивности. Обозначим v = 𝒜⁻¹(w₁) + 𝒜⁻¹(w₂). По линейности 𝒜: 𝒜(v) = 𝒜(𝒜⁻¹(w₁)) + 𝒜(𝒜⁻¹(w₂)) = w₁ + w₂. Применим 𝒜⁻¹: v = 𝒜⁻¹(w₁ + w₂), то есть 𝒜⁻¹(w₁ + w₂) = 𝒜⁻¹(w₁) + 𝒜⁻¹(w₂). Для однородности возьмём v = λ𝒜⁻¹(w): тогда 𝒜(v) = λ𝒜(𝒜⁻¹(w)) = λw, откуда 𝒜⁻¹(λw) = v = λ𝒜⁻¹(w).

Свойство 6: линейное отображение задаётся образами базиса

Свойство 6

Пусть e₁, …, en — базис конечномерного пространства V, а f₁, …, fn — произвольная система из n векторов пространства W. Тогда существует единственное линейное отображение 𝒜: V → W, для которого 𝒜(ei) = fi при i = 1, …, n.

Формула этого отображения: если v = v₁e₁ + … + vnen, то 𝒜(v) = v₁f₁ + … + vnfn. Смысл свойства двоякий: образы базисных векторов можно выбирать как угодно (отображение всегда найдётся), и после выбора отображение единственно.

Доказательство. Существование. Зададим 𝒜(v) = Σ vifi. Тогда 𝒜(ei) = fi (у ei одна ненулевая координата, равная 1), а линейность следует из того, что координаты суммы равны суммам координат, а координаты λv равны λvi: 𝒜(u + v) = Σ(ui + vi)fi = 𝒜(u) + 𝒜(v), 𝒜(λv) = Σ λvifi = λ𝒜(v). Единственность. Если линейное ℬ тоже удовлетворяет ℬ(ei) = fi, то ℬ(v) = ℬ(Σ viei) = Σ viℬ(ei) = Σ vifi = 𝒜(v) для любого v, то есть ℬ = 𝒜.

Замечание

В лекции (стр. 6) сказано, что единственность доказывается «от противного», но далее приведено прямое рассуждение ℬ(v) = … = 𝒜(v). Оно корректно; метод «от противного» тут не нужен.

Как найти образ вектора по образам базиса

  • Разложи вектор по базису: найди координаты v₁, …, vn из системы v = v₁e₁ + … + vnen.
  • Составь ту же комбинацию образов: 𝒜(v) = v₁𝒜(e₁) + … + vn𝒜(en).
  • Если нужна формула для любого вектора, повтори то же для произвольного (x, y) (или (x, y, z)).
Пример 1дополнительно
Линейное отображение 𝒜: ℝ² → ℝ² задано образами базиса e₁ = (1, 1), e₂ = (1, −1): 𝒜(e₁) = (2, 1), 𝒜(e₂) = (0, 3). Найти 𝒜(3, 1) и общую формулу 𝒜(x, y).

  1. Сначала проверим, что e₁, e₂ — базис: определитель из их координат −2 ≠ 0, поэтому они независимы, а их два, как и размерность плоскости. По свойству 6 такое отображение существует и единственно.

  2. Разложение. Ищем a и b из (3, 1) = a·(1, 1) + b·(1, −1). Покоординатно: a + b = 3, a − b = 1. Складывая, получаем 2a = 4, значит a = 2, тогда b = 1. Проверка: 2·(1, 1) + 1·(1, −1) = (3, 1).

  3. Образ. 𝒜(3, 1) = 2·𝒜(e₁) + 1·𝒜(e₂) = 2·(2, 1) + (0, 3) = (4, 2) + (0, 3) = (4, 5).

  4. Общая формула. Для (x, y) = a·e₁ + b·e₂ имеем a + b = x, a − b = y, откуда a = (x + y)/2, b = (x − y)/2. Тогда 𝒜(x, y) = (x + y)/2·(2, 1) + (x − y)/2·(0, 3) = (x + y, (x + y)/2 + 3(x − y)/2) = (x + y, 2x − y). Проверка по условию: 𝒜(1, 1) = (2, 1), 𝒜(1, −1) = (0, 3), 𝒜(3, 1) = (4, 5).

𝒜(3, 1) = (4, 5), 𝒜(x, y) = (x + y, 2x − y).

Осторожно

Образы нужно сопоставлять базисным векторам. Образы линейно зависимых векторов задавать произвольно нельзя. Например, линейного отображения ℝ² → ℝ² с 𝒜(1, 0) = (1, 0), 𝒜(0, 1) = (0, 1) и 𝒜(1, 1) = (5, 5) не существует: по аддитивности 𝒜(1, 1) = 𝒜(1, 0) + 𝒜(0, 1) = (1, 1).

Частный случай: если базисы в V и W стандартные, то образы 𝒜(e₁), …, 𝒜(en) — просто столбцы чисел, и из них составляется матрица отображения. Об этом — следующая статья.

Сумма отображений и умножение на число

Сумма и произведение на число

Суммой отображений 𝒜: V → W и ℬ: V → W называется отображение (𝒜 + ℬ): V → W, определяемое равенством (𝒜 + ℬ)(v) = 𝒜(v) + ℬ(v) для всех v ∈ V. Произведением отображения 𝒜: V → W на число λ называется отображение (λ·𝒜): V → W, (λ·𝒜)(v) = λ·𝒜(v).

Складывать можно только отображения между одними и теми же пространствами V → W. Сумма линейных отображений и произведение линейного отображения на число снова линейны (в лекции «нетрудно доказать»). Например, для суммы: (𝒜 + ℬ)(v₁ + v₂) = 𝒜(v₁ + v₂) + ℬ(v₁ + v₂) = 𝒜(v₁) + 𝒜(v₂) + ℬ(v₁) + ℬ(v₂) = (𝒜 + ℬ)(v₁) + (𝒜 + ℬ)(v₂); однородность и случай λ·𝒜 — аналогично.

Пример 2дополнительно
Для 𝒜(x, y) = (x + 2y, 3x − y) и ℬ(x, y) = (x, x + y) найти формулы для 𝒜 + ℬ, 3𝒜 и композиции ℬ∘𝒜, а также значения этих отображений в точке (1, 2).

  1. Сумма. Складываем образы покоординатно: (𝒜 + ℬ)(x, y) = (x + 2y + x, 3x − y + x + y) = (2x + 2y, 4x). В точке (1, 2): 𝒜(1, 2) = (5, 1), ℬ(1, 2) = (1, 3), сумма (6, 4). По формуле: (2 + 4, 4) = (6, 4).

  2. Число. (3𝒜)(x, y) = (3x + 6y, 9x − 3y), в точке (1, 2) это (15, 3) = 3·(5, 1).

  3. Композиция. (ℬ∘𝒜)(x, y) = ℬ(𝒜(x, y)) = ℬ(x + 2y, 3x − y) = (x + 2y, (x + 2y) + (3x − y)) = (x + 2y, 4x + y). В точке (1, 2): ℬ(5, 1) = (5, 6); по формуле (1 + 4, 4 + 2) = (5, 6).

(𝒜 + ℬ)(x, y) = (2x + 2y, 4x), (3𝒜)(x, y) = (3x + 6y, 9x − 3y), (ℬ∘𝒜)(x, y) = (x + 2y, 4x + y).

Запомни

Сумма 𝒜 + ℬ («применили оба и сложили результаты») и композиция ℬ∘𝒜 («применили сначала 𝒜, потом ℬ») — разные действия, и ответы разные: в точке (1, 2) получились (6, 4) и (5, 6). Им отвечают разные операции над матрицами: сумма и произведение (статья 5.4).

Частые ошибки

Так нельзя

«Линейное отображение переводит независимые векторы в независимые».

Так правильно

Верно лишь обратное (свойство 1): образы зависимых зависимы. Отображение x + y: ℝ² → ℝ переводит независимые (1, 0) и (0, 1) в зависимые 1 и 1.

Так нельзя

Применять свойство 2 к любому линейному отображению.

Так правильно

Нужна сюръективность: у несюръективного отображения часть векторов wi может вообще не иметь прообраза.

Так нельзя

«Линейное отображение ℝ² → ℝ³ может быть сюръективным: надо только подобрать формулы».

Так правильно

Свойство 3: сюръекция не увеличивает размерность. Раз 3 > 2, сюръективного линейного отображения ℝ² → ℝ³ нет, как формулы ни подбирай.

Так нельзя

Задавать образы произвольных (в частности, зависимых) векторов независимо друг от друга.

Так правильно

Свободно выбираются образы базисных векторов. Образы остальных векторов определяются по линейности.

Так нельзя

Искать 𝒜(v) по базису e₁, e₂, подставляя в комбинацию координаты вектора в стандартном базисе.

Так правильно

Сначала найди координаты v именно в базисе e₁, e₂ (решив небольшую систему), и только потом составь комбинацию образов.

Так нельзя

Путать сумму и композицию: (𝒜 + ℬ)(v) = ℬ(𝒜(v)).

Так правильно

(𝒜 + ℬ)(v) = 𝒜(v) + ℬ(v) — применяем оба отображения к v и складываем. Композиция (ℬ∘𝒜)(v) = ℬ(𝒜(v)) — применяем одно за другим.

Кратко для повторения

Кратко для повторения

  • Свойство 1: образы линейно зависимых векторов линейно зависимы (те же коэффициенты). Обратное неверно.
  • Свойство 2: если 𝒜 сюръективно, то у независимой системы в W есть независимая система прообразов.
  • Свойство 3: если 𝒜 линейно и сюръективно, а V конечномерно, то dim W ≤ dim V; у биекции dim V = dim W.
  • Свойства 4 и 5: композиция линейных отображений линейна; обратное к обратимому линейному отображению линейно.
  • Свойство 6: образы базисных векторов можно задать любыми; линейное отображение с такими образами существует и единственно; 𝒜(v) = v₁f₁ + … + vnfn.
  • (𝒜 + ℬ)(v) = 𝒜(v) + ℬ(v) и (λ𝒜)(v) = λ𝒜(v) — линейны, если линейны 𝒜 и ℬ (оба между одними пространствами).

Проверь себя

Задания для самопроверки

Решено: 0 из 6

Ответ — число: целое, десятичное (0,25) или дробь (1/4). Минус — обычный дефис. Подсказки появляются после неверного ответа, решение можно открыть в любой момент.

1
Какие утверждения о линейном отображении 𝒜: V → W верны? Отметьте все верные.
Варианты ответа; можно выбрать несколько

Показать решение

Верны свойства 1, 5 и 4. Второе утверждение опровергает x + y: ℝ² → ℝ на векторах (1, 0), (0, 1). В последнем 5 > 3 противоречит свойству 3.

2
Линейное отображение 𝒜: ℝ² → ℝ² задано образами базиса e₁ = (1, 1), e₂ = (1, −1): 𝒜(e₁) = (2, 1), 𝒜(e₂) = (0, 3). Найдите вторую координату вектора 𝒜(5, 1).

Показать решение

Раскладываем: a + b = 5, a − b = 1, отсюда a = 3, b = 2. Тогда 𝒜(5, 1) = 3·(2, 1) + 2·(0, 3) = (6, 3) + (0, 6) = (6, 9). Вторая координата равна 9. Проверка по формуле 𝒜(x, y) = (x + y, 2x − y): (6, 10 − 1) = (6, 9).

3
Для каких пар пространств существует сюръективное линейное отображение V → W? Отметьте все верные.
Варианты ответа; можно выбрать несколько

Показать решение

Для ℝ4 → ℝ² подойдёт (x₁, x₂, x₃, x₄) ↦ (x₁, x₂), для ℝ³ → ℝ³ — тождественное отображение. В двух других случаях dim W > dim V, это невозможно (свойство 3).

4
Дополните утверждения о линейных отображениях:
Образы линейно зависимых векторов . Образы линейно независимых векторов . Отображение, обратное к линейному обратимому, .

Показать решение

Свойство 1: зависимость сохраняется. Обратное неверно: независимые векторы могут перейти в зависимые (например, в нуль). Свойство 5: обратное к линейному обратимому отображению линейно.

5
Ищем линейное отображение 𝒜: ℝ² → ℝ² с 𝒜(1, 0) = (1, 0), 𝒜(0, 1) = (0, 1), 𝒜(1, 1) = (5, 5). В каком шаге допущена первая ошибка?
Варианты ответа

Показать решение

Противоречие возникло из-за образа зависимого от (1, 0) и (0, 1) вектора (1, 1). А векторы (1, 0), (0, 1) — базис, и по свойству 6 их образы можно задать любыми. Нельзя было ещё и произвольно задавать образ (1, 1).

6
Отображения 𝒜(x, y) = (x + 2y, 3x − y) и ℬ(x, y) = (x, x + y) линейны. Найдите вторую координату значения композиции (ℬ∘𝒜)(1, 2).

Показать решение

𝒜(1, 2) = (1 + 4, 3 − 2) = (5, 1). Затем ℬ(5, 1) = (5, 5 + 1) = (5, 6). Вторая координата равна 6.
