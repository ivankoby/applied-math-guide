Непрерывность в точке

Непрерывная функция — та, у которой нет скачков. График можно нарисовать, не отрывая карандаш.

три шага непрерывности
lim x → x₀ f(x) = f(x₀)
Предел в точке равен значению в точке. Так пишут «без дырок».
  • 📍Функция в точке x₀ определена.
  • 👣Слева и справа подходим к одному числу — пределу.
  • ✅Это число равно f(x₀).
💡 Как в жизниКак мультик без пропущенных кадров: каждый кадр плавно продолжает предыдущий.

2

Точки разрыва

Разрыв — место, где график «рвётся». Таких мест бывает два вида.

🪜 Первого рода

  • Оба предела существуют
  • Скачок или дырка
  • Пример: целая часть [x]

🕳️ Второго рода

  • Хотя бы один предел не существует
  • Пример: 1/x в точке 0
два вида разрыва
x₀ — разрыв 1-го рода ⇔ существуют оба односторонних предела
Если оба предела есть — первого рода. Иначе — второго рода.
  • 🪜Первого рода: оба односторонних предела существуют.
  • 🕳️Второго рода: хотя бы один предел не существует.
  • 🧩Если оба предела равны, разрыв устранимый — дырку можно заклеить.
💡 Как в жизниКак ступенька на дорожке: шагнул — и сразу выше.
🎓 Слова для взрослых
точка разрыва — место, где функция не непрерывнаустранимый разрыв — пределы слева и справа совпадают

3

Свойства непрерывных функций

Если функция на отрезке без дыр, у неё есть важные свойства.

  1. Раздели отрезок пополам.
  2. Оставь половину, где знак меняется.
  3. Повторяй деление снова и снова.
  4. Так найдёшь точку, где функция равна нулю.
метод половинного деления
f(a) · f(b) < 0 ⇒ f(ξ) = 0 для некоторого ξ ∈ (a, b)
Знаки на концах разные — внутри точно есть ноль.
  • 🏔️Вейерштрасс: есть наибольшее и наименьшее значение.
  • 🧗Больцано–Коши: встречаются все значения между A и B.
  • 🎯Если на концах знаки разные, внутри есть ноль.
💡 Как в жизниТы шёл от подножия к вершине без прыжков. Значит, побывал на каждой высоте между ними.
🎓 Слова для взрослых
отрезок [a, b] — все числа от a до b, включая концыметод половинного деления — делишь отрезок пополам и оставляешь половину со сменой знака
Что говорит теорема о нуле?
✅ Если на концах знаки разные, внутри есть ноль.

Элементарные функции

Элементарные функции — синус, логарифм, степень — без дыр там, где определены.

🌊
sin x, cos x
📐

🚀
aˣ
🪞

все они непрерывны там, где определены
lim x → 0 sin x = 0
Синус подходит к нулю, когда x подходит к нулю. По этому доказывают непрерывность синуса.
  • ➕Сумма, произведение и частное тоже непрерывны (на ноль не делим).
  • 🔗Функция внутри функции тоже непрерывна.
  • 🪞Обратная к строго возрастающей непрерывной тоже непрерывна.
💡 Как в жизниКак дорога из ровных плиток: без дыр и ступенек, по ней едешь везде, где она есть.
🎓 Слова для взрослых
элементарная функция — построена из основных функций сложением, умножением и вложениемсложная функция — одна функция подставлена внутрь другой
Непрерывен ли синус?
✅ Да, везде, где он определён.
