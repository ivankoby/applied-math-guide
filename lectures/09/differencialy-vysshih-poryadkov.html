Статья 9.2

Дифференциалы высших порядков; вторая производная неявной и параметрической функций

Дифференциал df = f′(x)dx — главная линейная часть приращения функции. У него есть «высшие» аналоги: второй дифференциал d²f, третий d³f и так далее. Лекция утверждает формулу dⁿf = f(n)(x)(dx)ⁿ (индукцию оставляет читателю) и тут же предупреждает: при n ≥ 2 она верна только для независимой переменной x. Если же x сама зависит от другой переменной t, у второго дифференциала появляется добавка. Эта добавка нужна на практике: из неё получается формула второй производной параметрически заданной функции. В конце статьи — вторая производная неявной функции (типовые задания 13 на стр. 14–15 второго файла лекции).

Первый дифференциал как функция x

Пусть функция f имеет производную f′ на окрестности U(x₀). Её дифференциал df(x) = f′(x)dx, x ∈ U(x₀), является функцией аргумента x. Попутно он линейно зависит от dx, но в этой статье dx — фиксированное число (приращение независимой переменной), а меняется только x. Это значит: df — снова функция от x, и её можно дифференцировать.

Напоминание

Дифференциал df — главная линейная часть приращения Δf при Δx = dx (лекция 8). Для независимой переменной x дифференциал dx совпадает с приращением Δx; для первого дифференциала форма df = f′(x)dx сохраняется и тогда, когда x зависит от другой переменной (инвариантность формы первого дифференциала, лекция 8).

Второй и n-й дифференциалы

Если f′ дифференцируема в точке x₀ (то есть существует f″(x₀)), можно взять дифференциал от df(x). Чтобы не путать его с уже построенным df, лекция обозначает его символом δ, а дифференциал независимого переменного — символом δx. Затем δx приравнивают к dx.

Второй дифференциал

Вторым дифференциалом функции f в точке x₀ называется d²f(x₀) := δ(df)(x₀)|δx = dx = δ(f′(x)dx)(x₀)|δx = dx = (f′(x)dx)′(x₀)·δx|δx = dx = f″(x₀)(dx)².

Цепочка равенств содержит и определение (первое равенство), и выражение через f″(x₀). Смысл простой: dx — константа, поэтому d(f′(x)dx) = f″(x)dx·dx = f″(x)(dx)².

n-й дифференциал

n-м дифференциалом функции f в точке x₀ называется dⁿf(x₀) := δ(dⁿ⁻¹f)(x₀)|δx = dx.

dⁿf(x₀) = f(n)(x₀)·(dx)ⁿ (1)
Формула (1) получается индукцией: если dⁿ⁻¹f = f(n−1)(x)(dx)ⁿ⁻¹ и dx — константа, то dⁿf = δ(f(n−1)(x)(dx)ⁿ⁻¹) = f(n)(x)·dx·(dx)ⁿ⁻¹ = f(n)(x)(dx)ⁿ. Она верна, если существует f(n)(x₀), и если x — независимая переменная.

Формула (1) объясняет обозначение f(n) = dⁿf/dxⁿ, но только для независимой x. Нельзя путать степени: (dx)ⁿ — это n-я степень числа dx, а dⁿx — дифференциал n-го порядка от x. Второй дифференциал d²f — не квадрат (df)² первого. И (dx)² — не d(x²) = 2x·dx. Для y = x²: d²y = 2(dx)², (dy)² = 4x²(dx)², d(x²) = 2x·dx: три разных выражения. Для независимой переменной d²x = 0: dx — константа, её дифференциал равен нулю.

Пример 1: d²y для независимой xдополнительно
Найти dy и d²y для y = ln(1 + x²), где x независима.

  1. Первая производная: y′ = 2x/(1 + x²). Значит, dy = 2x/(1 + x²)·dx.

  2. Вторая производная: y″ = (2(1 + x²) − 2x·2x)/(1 + x²)² = (2 − 2x²)/(1 + x²)².

  3. По формуле (1): d²y = y″·(dx)² = (2 − 2x²)/(1 + x²)²·(dx)². Например, при x = 2 получаем d²y = (2 − 8)/25·(dx)² = −(6/25)(dx)².

dy = 2x/(1 + x²)·dx, d²y = (2 − 2x²)/(1 + x²)²·(dx)².

Второй дифференциал не инвариантен: что меняется, если x зависит от t

Пусть y = f(x) дважды дифференцируема в точке x₀, а её аргумент x = x(t) — дважды дифференцируемая функция независимой переменной t. Найдём d²f как второй дифференциал сложной функции от t. Для независимой t справедлива формула (1): d²f = (f(x(t)))″tt·(dt)². Дифференцируем дважды по правилу сложной функции:

d²f(x) = (f(x(t)))″tt(dt)² = (f′(x)·x′t)′t(dt)² = (f″(x)·x′t² + f′(x)·x″tt)(dt)²
В скобках первое слагаемое — производная f′(x) по t (цепное правило, множитель x′t), умноженная на x′t; второе — f′(x) на производную x′t.

Теперь используем dx = x′tdt и d²x = x″tt(dt)²:

d²f(x) = f″(x)(dx)² + f′(x)·d²x
Для независимой x вторая добавка исчезает (d²x = 0) и получается (1).

Сравнивая с (1) при n = 2, видим, что второй дифференциал не обладает свойством инвариантности формы: форма d²f = f″(dx)² справедлива только когда x независима (или линейно зависит от t: x = kt + b, тогда x″ = 0 и d²x = 0). У первого дифференциала форма f′(x)dx сохраняется и при зависимой x, а у d²f — нет.

Пример 2: x = t², y = sin xдополнительно
Найти d²y для y = sin x, где x = t², двумя способами и сравнить с «наивной» формулой.

  1. Способ 1 (прямо по t). y = sin(t²), y′t = 2t·cos t², y″tt = 2cos t² − 4t²·sin t². Тогда d²y = (2cos t² − 4t²·sin t²)(dt)².

  2. Способ 2 (по формуле). f″(x) = −sin x, f′(x) = cos x, dx = 2t·dt, d²x = 2(dt)²:

    d²y = −sin t²·(2t·dt)² + cos t²·2(dt)² = (−4t²·sin t² + 2cos t²)(dt)²

    Совпало.

  3. Наивная формула d²y = f″(x)(dx)² = −sin t²·4t²(dt)² теряет слагаемое 2cos t²·(dt)²: форма второго дифференциала не сохраняется.

d²y = (2cos t² − 4t²·sin t²)(dt)².

Когда наивная формула работает. При линейной подстановке x = kt + b: d²x = 0, и d²f = f″(dx)². Например, y = x³, x = 2t + 1: d²y = 6x·(dx)² = 6(2t + 1)·4(dt)² = 24(2t + 1)(dt)²; прямо: y = (2t + 1)³, y″tt = 24(2t + 1). Совпало.

Вторая производная параметрически заданной функции

(Формула второй производной параметрической функции — дополнительно к лекции, она есть в дополнительных материалах курса; здесь она выводится из формулы для d²f.) Функция задана параметрически: x = x(t), y = y(t). Если x(t) и y(t) дважды дифференцируемы и x′t ≠ 0, то первая производная y′x = y′t/x′t (лекция 8). Для второй возьмём формулу d²y = y″xx(dx)² + y′x·d²x и выразим всё через t: d²y = y″tt(dt)², dx = x′tdt, d²x = x″tt(dt)². Сократив на (dt)²:

y″tt = y″xx·x′t² + y′x·x″tt, y′x = y′t/x′t

Отсюда y″xx = (y″tt − y′xx″tt)/x′t², и после подстановки y′x получаем рабочую формулу:

y″xx = (y″tt·x′t − y′t·x″tt) / (x′t)³, x′t ≠ 0
Условия: x(t), y(t) дважды дифференцируемы по t, x′t ≠ 0 (тогда y как функция от x определена около точки).

Второй способ (проще запоминается). Дифференцируем первую производную по t как функцию от t, затем делим на x′t:

y″xx = (y′x)′t / x′t
Это то же самое: (y′t/x′t)′t = (y″ttx′t − y′tx″tt)/x′t², а деление на x′t даёт куб в знаменателе.

Осторожно

В заданиях 13 лекции стоит запись d²y/dx²: это обозначение второй производной y″xx, а не отношение d²y к (dx)². При зависимой x отношение d²y/(dx)² равно y″xx + y′x·d²x/(dx)², то есть не совпадает с y″xx.

Пример 3: циклоидадополнительно
Найти y′x и y″xx для x = t − sin t, y = 1 − cos t, t ≠ 2πk.

  1. Производные по параметру: x′t = 1 − cos t, x″tt = sin t, y′t = sin t, y″tt = cos t. Условие x′t ≠ 0 означает t ≠ 2πk.

  2. Первая производная: y′x = sin t/(1 − cos t) = ctg(t/2).

  3. По формуле: числитель y″ttx′t − y′tx″tt = cos t(1 − cos t) − sin²t = cos t − cos²t − sin²t = cos t − 1, знаменатель (1 − cos t)³:

    y″xx = (cos t − 1)/(1 − cos t)³ = −1/(1 − cos t)²

  4. Проверка вторым способом: (y′x)′t = (cos t(1 − cos t) − sin²t)/(1 − cos t)² = (cos t − 1)/(1 − cos t)² = −1/(1 − cos t); делим на x′t = 1 − cos t: −1/(1 − cos t)². Совпало.

y′x = ctg(t/2), y″xx = −1/(1 − cos t)² < 0: арка циклоиды выпукла вверх.

Пример 4: эллипсдополнительно
Найти y″xx для x = 2cos t, y = 3 sin t, t ≠ πk.

  1. x′t = −2 sin t, x″tt = −2cos t, y′t = 3cos t, y″tt = −3 sin t. Условие x′t ≠ 0 — это t ≠ πk.

  2. Числитель: y″ttx′t − y′tx″tt = (−3 sin t)(−2 sin t) − (3cos t)(−2cos t) = 6 sin²t + 6cos²t = 6. Знаменатель: (−2 sin t)³ = −8 sin³t.

  3. y″xx = 6/(−8 sin³t) = −3/(4 sin³t). Знак совпадает со знаком −sin t: на верхней половине эллипса (sin t > 0) y″ < 0, и график выпуклый вверх.

y″xx = −3/(4 sin³t).

Вторая производная неявной функции

Уравнение F(x, y) = 0 задаёт y = y(x) неявно (лекция 8). Первую производную находят, дифференцируя тождество F(x, y(x)) = 0 по x, считая y функцией от x, и выражая y′. Для второй производной алгоритм такой:

  • Найди y′: продифференцируй уравнение по x (производная y — это y′, например (y²)′ = 2y·y′) и выбери y′; нужно, чтобы коэффициент при y′ не был нулём.
  • Продифференцируй ещё раз выражение для y′ по x: y″ содержит x, y и y′. Как и раньше, y — функция от x, поэтому каждая встреча y даёт множитель y′.
  • Подставь y′ из первого шага, получи y″ как функцию от x и y. Это основная форма ответа. Если y′ — громоздкая дробь, допустимо оставить в ответе y′, но тогда рядом пиши, чему она равна (пример 8): обе записи верны.
  • Упрости с помощью исходного уравнения (например, замени x² + y² на правую часть) — ответ часто становится короче.

Ответ в задачах на y″ не обязан быть функцией одного x: чаще всего он выражается через x и y вместе (при условии, что в этих точках знаменатели не равны нулю). Единое правило: ответ через x и y — основной; запись через y′ допустима, только если формула для y′ выписана рядом.

Пример 5: параболаиз лекции, стр. 15 (задание 13.15)
Найти y′ и y″ для y² = 8x.

  1. Дифференцируем по x: 2y·y′ = 8, откуда y′ = 4/y (при y ≠ 0).

  2. Дифференцируем y′ = 4y−1 ещё раз: y″ = −4y−2·y′ = −4/y²·(4/y) = −16/y³.

  3. Проверка: на ветви y = √(8x) имеем y′ = 4/√(8x), y″ = 4·(−1/2)(8x)−3/2·8 = −16/(8x)3/2 = −16/y³.

y′ = 4/y, y″ = −16/y³.

Пример 6: эллипсиз лекции, стр. 15 (задание 13.16)
Найти y′ и y″ для x²/5 + y²/7 = 1.

  1. Дифференцируем: 2x/5 + 2y·y′/7 = 0, откуда y′ = −7x/(5y) (при y ≠ 0).

  2. Дифференцируем частное y′ = −(7/5)·x/y: y″ = −(7/5)·(y − x·y′)/y² = −(7/5)·(y + 7x²/(5y))/y² = −(7/5)·(5y² + 7x²)/(5y³).

  3. Теперь используем уравнение: умножим x²/5 + y²/7 = 1 на 35, получим 7x² + 5y² = 35. Тогда y″ = −(7/5)·35/(5y³) = −49/(5y³).

y′ = −7x/(5y), y″ = −49/(5y³).

Пример 7: упрощение перед вторым шагомиз лекции, стр. 15 (задание 13.17)
Найти y′ и y″ для x + arctg y = y.

  1. Дифференцируем по x: 1 + y′/(1 + y²) = y′, откуда 1 = y′·(1 − 1/(1 + y²)) = y′·y²/(1 + y²), и y′ = (1 + y²)/y² = 1 + y−2 (при y ≠ 0).

  2. Теперь вторая производная проще: y″ = (1 + y−2)′ = −2y−3·y′ = −2/y³·(1 + y²)/y² = −2(1 + y²)/y⁵. Приём: перед вторым дифференцированием упрости y′ (здесь разделили почленно), и производная частного не потребуется.

y′ = (1 + y²)/y², y″ = −2(1 + y²)/y⁵.

Пример 8: ответ остаётся через x, y и y′дополнительно (дополнительные материалы курса)
Найти y′ и y″ для y³ − 5xy + x² = 0.

  1. Дифференцируем уравнение по x: 3y²·y′ − 5y − 5x·y′ + 2x = 0. Выразим y′: y′·(3y² − 5x) = 5y − 2x, y′ = (5y − 2x)/(3y² − 5x) (при 3y² ≠ 5x).

  2. Дифференцируем равенство 3y²·y′ − 5y − 5x·y′ + 2x = 0 ещё раз (так проще, чем дифференцировать дробь): 6y·(y′)² + 3y²·y″ − 5y′ − 5y′ − 5x·y″ + 2 = 0.

  3. Соберём y″: y″·(3y² − 5x) = −6y·(y′)² + 10y′ − 2, откуда y″ = (−6y·(y′)² + 10y′ − 2)/(3y² − 5x). Здесь y′ можно заменить дробью из первого шага, но выражение разрастается, поэтому ответ часто оставляют с y′ — при условии, что формула для y′ записана рядом.

  4. Для сравнения подстановка y′ = (5y − 2x)/(3y² − 5x): общий знаменатель даёт y″ = (−6y(5y − 2x)² + 10(5y − 2x)(3y² − 5x) − 2(3y² − 5x)²)/(3y² − 5x)³. Обе записи верны.

y″ = (−6y(y′)² + 10y′ − 2)/(3y² − 5x), где y′ = (5y − 2x)/(3y² − 5x); развёрнуто — в последнем шаге.

Выбор способа

Два способа найти y″: (1) дифференцировать готовое выражение y′ = φ(x, y): y″ = φ′x + φ′y·y′; (2) дифференцировать ещё раз исходное равенство F′ = 0 и выразить y″ из линейного уравнения. Первый удобен, когда y′ короткое (примеры 5–7); второй — когда y′ громоздкая дробь (пример 8).

Частые ошибки

Так нельзя

d²f = f″(x)(dx)² при любой зависимости x.

Так правильно

Только для независимой x (или линейной подстановки). В общем случае d²f = f″(dx)² + f′·d²x, потому что d²x = x″(dt)² ≠ 0.

Так нельзя

(dx)² путают с d(x²) = 2x·dx или d²f с (df)².

Так правильно

(dx)² — квадрат числа dx; d²f — второй дифференциал (дифференциал от df).

Так нельзя

y″xx = y″tt/x″tt для параметрической функции.

Так правильно

Верно y″xx = (y″ttx′t − y′tx″tt)/(x′t)³. Деление вторых производных по t — не вторая производная по x.

Так нельзя

y″xx = (y′x)′t — забыли поделить на x′t.

Так правильно

Производная по x равна производной по t, делённой на x′t: y″xx = (y′x)′t/x′t.

Так нельзя

Для неявной функции дифференцировать y′ = φ(x, y), забыв, что y зависит от x.

Так правильно

Каждое y в выражении даёт множитель y′: (y²)′ = 2y·y′, (x/y)′ = (y − x·y′)/y².

Так нельзя

Оставить в ответе для y″ производную y′, не написав, чему она равна, или не упростить ответ с помощью исходного уравнения.

Так правильно

Выпиши y′ рядом или подставь её; если возможно, упрости по уравнению: для эллипса x²/5 + y²/7 = 1 ответ −49/(5y³) намного проще, чем выражение через x, y и y′.

Кратко для повторения

Кратко для повторения

  • df(x) = f′(x)dx — функция от x при фиксированном dx. d²f(x₀) = f″(x₀)(dx)², dⁿf(x₀) = f(n)(x₀)(dx)ⁿ — если существует f(n)(x₀) и x независима.
  • Для x = x(t): d²f = f″(x)(dx)² + f′(x)·d²x, d²x = x″(dt)². Второй дифференциал не инвариантен; первый дифференциал инвариантен.
  • Параметрическая функция: y′x = y′t/x′t, y″xx = (y′x)′t/x′t = (y″ttx′t − y′tx″tt)/(x′t)³, при x′t ≠ 0.
  • Неявная функция: дифференцируем F(x, y) = 0 по x (y — функция от x), находим y′ = φ(x, y), затем y″ = φ′x + φ′yy′; упрощаем по уравнению. Ответ — через x и y; запись через y′ допустима, если формула для y′ выписана рядом.
  • d²y/dx² в заданиях — обозначение y″xx, а не отношение вторых дифференциалов.

1
Пусть y = f(x), где x = x(t) — дважды дифференцируемая функция другой переменной t. Какая формула верна для второго дифференциала d²y?
Варианты ответа

Показать решение

Из d²y = (f(x(t)))″tt(dt)² = (f″x′² + f′x″)(dt)² и dx = x′dt, d²x = x″(dt)² получаем d²y = f″(x)(dx)² + f′(x)d²x. Для независимой x вторая добавка равна нулю.

2
y = x³, x — независимая переменная. Найдите значение d²y при x = 3 и dx = 0,1.

Показать решение

y″ = 6x, y″(3) = 18. d²y = y″(dx)² = 18·0,1² = 18·0,01 = 0,18.

3
Функция задана параметрически: x = t², y = t³ + t. Найдите y″xx при t = 2. Ответ запишите обыкновенной дробью.

Показать решение

x′t = 2t = 4, x″tt = 2, y′t = 3t² + 1 = 13, y″tt = 6t = 12. По формуле: (y″ttx′t − y′tx″tt)/(x′t)³ = (12·4 − 13·2)/64 = 22/64 = 11/32. Второй способ: y′x = (3t² + 1)/(2t) = 1,5t + 0,5/t, (y′x)′t = 1,5 − 0,5/t² = 11/8 при t = 2, деление на x′t = 4 даёт 11/32.

4
Окружность задана неявно уравнением x² + y² = 4. Чему равна y″ (в точках, где y ≠ 0)?
Варианты ответа

Показать решение

2x + 2y·y′ = 0, y′ = −x/y. Далее y″ = −(y − x·y′)/y² = −(y + x²/y)/y² = −(y² + x²)/y³ = −4/y³, так как x² + y² = 4. Проверка на ветви y = √(4 − x²): y′ = −x/√(4 − x²), y″ = −4/(4 − x²)3/2 = −4/y³.

5
Параметрическая функция x = t³, y = t² (t > 0). Ищем y″xx. В каком шаге допущена первая ошибка?
Варианты ответа

Показать решение

Производная по t — ещё не производная по x: нужно поделить на x′t = 3t². Верно y″xx = (−2/(3t²))/(3t²) = −2/(9t⁴). Проверка по формуле: x″tt = 6t, y″tt = 2, (2·3t² − 2t·6t)/(27t⁶) = −6t²/(27t⁶) = −2/(9t⁴).
