Правило Лопиталя раскрывает неопределённости 0/0 и ∞/∞: вместо предела отношения функций берут предел отношения их производных. Правилу слишком часто верят вслепую, а оно работает только при выполнении условий: нужный вид неопределённости, дифференцируемость, g′ ≠ 0 и — самое забываемое — существование предела отношения производных. В статье: три теоремы лекции со всеми условиями, доказательство через теорему Коши, контрпримеры, алгоритм, примеры лекции (ln x/x^ε, xⁿ/aˣ, (2x + sin x)/x) и дополнительные.

Идея правила

Пусть при нахождении предела отношения f(x)/g(x) при x → x₀ числитель и знаменатель стремятся к нулю или оба стремятся к бесконечности. Говорят, что имеется неопределённость вида 0/0 или ∞/∞. Нахождение этого предела (если он существует) называют раскрытием неопределённости. Пока непонятно, чему равен предел: дробь 0/0 может быть любым числом (x/x → 1, x²/x → 0, x/x² → ∞).

Один из способов — выделение главных частей числителя и знаменателя (формула Тейлора, статья 9.5). Другой — правило Лопиталя: вычисление предела отношения функций заменяется вычислением предела отношения их производных.

Почему это правдоподобно: вблизи точки a, где f(a) = g(a) = 0, функции ведут себя как касательные: f(x) ≈ f′(a)(x − a), g(x) ≈ g′(a)(x − a), и отношение f/g ≈ f′(a)/g′(a). Строгое обоснование — теорема Коши (статья 9.3).

Теорема 1: неопределённость 0/0 при x → a + 0

Теорема 1 (правило Лопиталя для 0/0)

Пусть функции f, g: 1° дифференцируемы на интервале (a, b), b − a < ∞; 2° limx→a+0 f(x) = limx→a+0 g(x) = 0; 3° g′ ≠ 0 на (a, b); 4° существует limx→a+0 f′(x)/g′(x) ∈ ℝ̄. Тогда существует limx→a+0 f(x)/g(x) = limx→a+0 f′(x)/g′(x).

Здесь ℝ̄ = ℝ ∪ {−∞, +∞} — расширенная числовая прямая: предел отношения производных может быть конечным числом, +∞ или −∞. Запись x → a + 0 значит «справа от a»; остальные варианты — ниже.

Четыре условия — это четыре вопроса, которые нужно задать до дифференцирования: (1) функции дифференцируемы около точки? (2) числитель и знаменатель действительно стремятся к нулю? (3) g′ не обращается в нуль рядом с точкой? (4) предел отношения производных существует?

Доказательство (идея лекции)

Доопределим f(a) = g(a) = 0. По условию 2° функции станут непрерывными на [a, b). Для x ∈ (a, b) применим теорему Коши на отрезке [a, x] (её условия выполнены: непрерывность на [a, x], дифференцируемость на (a, x), g′ ≠ 0):

f(x)/g(x) = (f(x) − f(a))/(g(x) − g(a)) = f′(ξ)/g′(ξ), a < ξ < x < b
Значение f(a) = g(a) = 0 нужно только для того, чтобы можно было применить Коши; на предел при x ≠ a оно не влияет.

Пусть lim f′/g′ = A ∈ ℝ̄, ε > 0. Найдётся δ > 0 такое, что f′(ξ)/g′(ξ) лежит в ε-окрестности A при всех a < ξ < a + δ. Если a < x < a + δ, то и ξ ∈ (a, x) ⊂ (a, a + δ), значит, f(x)/g(x) = f′(ξ)/g′(ξ) попадает в эту же окрестность. Это и означает lim f/g = A. Каждое условие работает: 1° и 2° дают непрерывность на [a, x], 3° нужно в теореме Коши, 4° задаёт A.

Теоремы 2 и 3: бесконечная точка и неопределённость ∞/∞

Теорема 2 (x → +∞, вариант 0/0)

Пусть функции f, g: 1° дифференцируемы при x > c > 0; 2° limx→+∞ f(x) = limx→+∞ g(x) = 0; 3° g′ ≠ 0 на (c, +∞); 4° существует limx→+∞ f′(x)/g′(x) ∈ ℝ̄. Тогда существует limx→+∞ f(x)/g(x) = limx→+∞ f′(x)/g′(x).

Замечание: в лекции условие пропущено

В формулировке теоремы 2 на стр. 10 лекции (по картинке) стоят только три условия: дифференцируемость при x > c > 0, g′ ≠ 0 на (c, +∞) и существование lim f′/g′; равенства lim f = lim g = 0 там нет. В рамке выше оно добавлено как условие 2°. Оно нужно: в доказательстве теорема 1 применяется к функциям f(1/t), g(1/t) при t → 0 + 0, а для неё необходимы нулевые пределы. Без него утверждение лекции ложно: f(x) = 1, g(x) = 1 + 1/x. Здесь g′ = −1/x² ≠ 0, lim f′/g′ = 0/(−1/x²) = 0, а lim f/g = 1.

Доказательство теоремы 2 (идея). Замена x = 1/t переводит x → +∞ в t → 0 + 0. По цепному правилу d/dt f(1/t) = f′(1/t)·(−1/t²), множители −1/t² в отношении производных сокращаются: limt→0+0 (d/dt f(1/t))/(d/dt g(1/t)) = lim f′(1/t)/g′(1/t) = A. По теореме 1 lim f(1/t)/g(1/t) = A, то есть limx→+∞ f/g = A. Лекция оговаривает: здесь дважды использован предельный переход в сложной функции в ситуации, не разобранной в § 4.2, и его обоснование оставлено читателю; в статье оно тоже не проводится.

Теорема 3 (неопределённость ∞/∞)

Пусть функции f, g: 1° дифференцируемы на интервале (a, b), b − a < ∞; 2° limx→a+0 f(x) = ±∞, limx→a+0 g(x) = ±∞; 3° g′ ≠ 0 на (a, b); 4° существует limx→a+0 f′(x)/g′(x) ∈ ℝ̄. Тогда существует limx→a+0 f(x)/g(x) = limx→a+0 f′(x)/g′(x).

Идея доказательства теоремы 3. Доопределить в точке a теперь нельзя (функции уходят в бесконечность), поэтому теорему Коши применяют не на [a, x], а на [x, xε], где xε близко к a и f′/g′ около A на (a, xε): (f(x) − f(xε))/(g(x) − g(xε)) = f′(ξ)/g′(ξ). Вынеся f(x)/g(x), получаем f(x)/g(x) = [(1 − g(xε)/g(x))/(1 − f(xε)/f(x))]·f′(ξ)/g′(ξ). При x → a + 0 f(x), g(x) → ∞, а f(xε), g(xε) фиксированы, поэтому первый множитель близок к 1, второй близок к A. Лекция выписывает оценку явно (стр. 11–12); в ней есть неточность, см. замечание ниже.

Замечание об оценке в лекции

Лекция утверждает, что первый множитель лежит в (1 − 4ε, 1 + 2ε). Нижняя граница верна (с запасом), а верхняя нет: при |g(xε)/g(x)| < ε и |f(xε)/f(x)| < ε множитель может быть сколь угодно близок к (1 + ε)/(1 − ε) = 1 + 2ε/(1 − ε) > 1 + 2ε. При ε = 0,2 это 1,5, а не 1,4. Верный интервал при ε < 1/4: (1 − 2ε, 1 + 3ε). На вывод теоремы это не влияет (границы стремятся к 1 при ε → 0), но явную формулу η(A, ε) со стр. 12 без пересчёта не используй. Ещё на стр. 11 напечатано «f′ ≠ 0 на (a, xε)»: по смыслу нужно g′ ≠ 0.

Замечание лекции. Теоремы 1–3 верны и при x → a + 0, x → a − 0, x → a, x → +∞, x → −∞ с соответствующими изменениями формулировок: для x → a условия берут в проколотой окрестности точки a, для x → −∞ — на (−∞, c).

Что проверять в каждом случае. Предел lim f′/g′ может быть конечным или бесконечным.

Достаточные, не необходимые

Теоремы 1–3 дают достаточные условия раскрытия неопределённости, но не необходимые (лекция, стр. 12). Если предел f/g существует, а предела f′/g′ нет, правило просто ничего не говорит: см. пример 3.

Зачем нужны условия: четыре контрпримера

  • Нет неопределённости (условие 2° нарушено). limx→0 (x² + 1)/(x + 1): числитель и знаменатель стремятся к 1, подстановка даёт 1. Если применить правило вслепую, получим lim 2x/1 = 0. Ответ 0 неверен.
  • Нет предела отношения производных (условие 4° нарушено). limx→+∞ (2x + sin x)/x = 2 (пример 3 лекции), но f′/g′ = 2 + cos x предела не имеет. Другой пример, 0/0 при x → 0: x²·sin(1/x)/x = x·sin(1/x) → 0, а f′/g′ = 2x·sin(1/x) − cos(1/x) предела не имеет.
  • Для x → +∞ в варианте 0/0 не проверено f, g → 0. Контрпример f = 1, g = 1 + 1/x выше: отношение производных стремится к 0, а настоящий предел равен 1.
  • g′ обращается в нуль (условие 3° нарушено). Для теоремы Коши условие нужно (статья 9.3), и без него правило ломается. При x → +∞ возьмём f(x) = x + sin x·cos x и g(x) = f(x)·esin x: обе функции стремятся к +∞, f′ = 2cos²x, g′ = esin x·cos x·(2cos x + f) и обращается в нуль в точках π/2 + πk, то есть в любой окрестности +∞. Там, где g′ ≠ 0, f′/g′ = 2cos x/(esin x(2cos x + f)) → 0, а f/g = e−sin x предела не имеет (при x = 2πk + π/2 равно e−1, при x = 2πk − π/2 равно e).

Дополнительно

Правилом Лопиталя нельзя доказывать первый замечательный предел lim sin x/x = 1: формула (sin x)′ = cos x сама выводится из этого предела, получится порочный круг. Для нахождения других пределов (например, lim sin 3x/x) ссылаться на правило можно.

Алгоритм: как решать

  • Подставь предельное значение в f и g отдельно. Убедись, что неопределённость именно 0/0 или ∞/∞. Если нет, правило не применяют: предел находят подстановкой или другим способом.
  • Проверь условия: f, g дифференцируемы около точки; g′ ≠ 0 рядом с ней.
  • Продифференцируй числитель и знаменатель ОТДЕЛЬНО (f′ и g′), а не как частное: (f/g)′ здесь не нужна.
  • Найди lim f′/g′. Если он существует (конечный или ±∞), это и есть ответ. Если снова 0/0 или ∞/∞, применяй правило ещё раз, каждый раз проверяя условия заново.
  • Если предела f′/g′ нет — правило молчит. Сократи общие множители, замени функции эквивалентными или используй разложение Тейлора.
  • Перед дифференцированием упрощай: сокращай общие множители и выноси постоянные, чтобы производные не разрастались.

Как читать цепочку равенств. В записи lim f/g = lim f′/g′ = … первое равенство написано при условии, что предел справа существует, и становится оправданным только после того, как этот предел найден (так объясняет лекция на примере 1). Поэтому ниже между пределами пишем «=» и ссылаемся на правило.

Разобранные примеры

Пример 1: ln x / x^εиз лекции, стр. 12 (пример 1)
Найти limx→+∞ ln x / x^ε при ε > 0.

  1. Числитель и знаменатель стремятся к +∞ (степень с ε > 0 растёт), неопределённость ∞/∞. f = ln x, g = x^ε дифференцируемы при x > 0, g′ = εxε−1 ≠ 0.

  2. Применяем теорему 3 (в варианте x → +∞):

    limx→+∞ ln x/x^ε = limx→+∞ (1/x)/(εxε−1) = limx→+∞ 1/(εx^ε) = 0

  3. Последний предел равен 0, так как εx^ε → +∞ при ε > 0. Предел отношения производных существует, поэтому первое равенство оправдано (так и сказано в лекции).

  4. Смысл: логарифм растёт медленнее любой положительной степени x. Например, ln x/√x → 0, хотя при x = e² отношение достигает максимума 2/e ≈ 0,74 (рисунок ниже): стремление к нулю может быть очень медленным.

0.

Пример 2: xⁿ / aˣиз лекции, стр. 12 (пример 2)
Найти limx→+∞ xⁿ/aˣ, n ∈ ℕ, a > 1.

  1. Числитель и знаменатель стремятся к +∞: неопределённость ∞/∞. g = aˣ, g′ = aˣ·ln a ≠ 0 (так как a > 1, ln a > 0).

  2. Применяем правило, пока числитель не станет константой, каждый раз получая ∞/∞:

    lim xⁿ/aˣ = lim nxⁿ⁻¹/(aˣ ln a) = lim n(n − 1)xⁿ⁻²/(aˣ ln²a) = … = lim n!/(aˣ lnⁿ a) = 0

  3. Последняя дробь: числитель n! постоянен, знаменатель aˣ lnⁿ a → +∞. Правило применено n раз.

  4. Смысл (иерархия роста при x → +∞): ln x ≪ xᵋ ≪ aˣ (ε > 0, a > 1): показательная функция растёт быстрее любой степени, степень — быстрее логарифма. Например, x¹⁰⁰/1,01ˣ → 0, хотя при небольших x дробь огромна.

0.

Пример 3: предел существует, правило не работаетиз лекции, стр. 13 (пример 3)
Найти limx→+∞ (2x + sin x)/x и объяснить, почему правило Лопиталя тут не даёт ответа.

  1. Числитель 2x + sin x ≥ 2x − 1 → +∞ и знаменатель x → +∞: неопределённость ∞/∞. Условия 1°–3° выполнены.

  2. Отношение производных (2 + cos x)/1 = 2 + cos x колеблется между 1 и 3 и предела не имеет. Условие 4° нарушено: правило ничего не утверждает.

  3. Но сам предел существует, его находим алгебраически: (2x + sin x)/x = 2 + sin x/x. Так как |sin x/x| ≤ 1/x → 0, предел равен 2.

2. Правило Лопиталя ответа не даёт: lim (2 + cos x) не существует (условие 4° нарушено).

Пример 4: дробь с многочленамидополнительно (дополнительные материалы курса)
Найти limx→1 (x³ − 2x² − x + 2)/(x³ − 7x + 6).

  1. Подставим x = 1: числитель 1 − 2 − 1 + 2 = 0, знаменатель 1 − 7 + 6 = 0. Это 0/0. g′ = 3x² − 7 ≠ 0 около x = 1 (там g′ ≈ −4).

  2. Правило Лопиталя: lim (3x² − 4x − 1)/(3x² − 7) = (3 − 4 − 1)/(3 − 7) = (−2)/(−4) = 1/2.

  3. Проверка без правила: числитель (x − 1)(x − 2)(x + 1), знаменатель (x − 1)(x − 2)(x + 3); после сокращения (x + 1)/(x + 3) → 2/4 = 1/2. Совпало.

1/2.

Пример 5: несколько примененийдополнительно (дополнительные материалы курса)
Найти limx→0 (eˣ − e−x − 2x)/(x − sin x).

  1. Подстановка: 0/0. Производные: числитель eˣ + e−x − 2, знаменатель 1 − cos x; снова 0/0 (1 + 1 − 2 = 0, 1 − 1 = 0). На каждом шаге производная знаменателя (1 − cos x, затем sin x, затем cos x) не обращается в нуль при малых x ≠ 0.

  2. Второй раз: числитель eˣ − e−x, знаменатель sin x; опять 0/0.

  3. Третий раз: числитель eˣ + e−x → 2, знаменатель cos x → 1. Предел 2/1 = 2. Все три применения оправданы тем, что последний предел существует (цепочка читается справа налево).

  4. Тот же ответ дают разложения Тейлора (статья 9.5, пример 3): метод Тейлора здесь короче.

Пример 6: 0/0 на бесконечностидополнительно
Найти limx→+∞ (π/2 − arctg x)/(1/x).

  1. Числитель π/2 − arctg x → 0 и знаменатель 1/x → 0: 0/0 при x → +∞. Условие f, g → 0 проверено явно (теорема 2). g′ = −1/x² ≠ 0.

  2. f′ = −1/(1 + x²), g′ = −1/x², отношение x²/(1 + x²) → 1.

Найти limx→0+0 sin x/x².

Частые ошибки

Так нельзя

«Правило Лопиталя можно применять, когда получается 0/0 или ∞/∞» (и только это).

Так правильно

Этого мало: нужны ещё дифференцируемость, g′ ≠ 0 рядом с точкой и существование lim f′/g′. Если предел f′/g′ не существует, правило ничего не говорит.

Так нельзя

Применять правило, когда неопределённости нет: limx→0 (x² + 1)/(x + 1) = lim 2x/1 = 0.

Так правильно

Подстановка даёт 1/1 = 1. Правило при f → 1, g → 1 не работает: условие 2° нарушено.

Так нельзя

Дифференцировать дробь как частное: (f/g)′ = (f′g − fg′)/g².

Так правильно

В правиле Лопиталя берут отдельно f′ и g′ и делят: f′/g′.

Так нельзя

Если lim f′/g′ не существует, то и lim f/g не существует.

Так правильно

Из отсутствия lim f′/g′ ничего не следует: (2x + sin x)/x → 2, хотя 2 + cos x предела не имеет.

Так нельзя

Применять правило на бесконечности в варианте 0/0, не проверив f, g → 0 (теорема 2).

Так правильно

Для x → +∞ в виде 0/0 условие lim f = lim g = 0 обязательно: контрпример f = 1, g = 1 + 1/x.

Так нельзя

Применять правило много раз подряд, не проверяя условия на каждом шаге.

Так правильно

После каждого дифференцирования убедись, что снова 0/0 или ∞/∞. Если дробь перестала быть неопределённостью, дальше правило нельзя применять: считай подстановкой.

Кратко для повторения

Кратко для повторения

  • Неопределённости 0/0 и ∞/∞: числитель и знаменатель оба стремятся к 0 (или оба к ∞). Раскрытие — нахождение предела.
  • Теорема 1 (0/0, x → a + 0): f, g дифференцируемы на (a, b), b − a < ∞; lim f = lim g = 0; g′ ≠ 0 на (a, b); существует lim f′/g′ ∈ ℝ̄ ⟹ lim f/g = lim f′/g′. Доказательство: Коши на [a, x].
  • Теорема 2 (x → +∞): дифференцируемость при x > c, g′ ≠ 0, существует lim f′/g′ и lim f = lim g = 0 (в тексте лекции пропущено, нужно для варианта 0/0).
  • Теорема 3 (∞/∞): то же, но f, g → ±∞; Коши применяют на [x, xε].
  • Теоремы верны для x → a ± 0, a, ±∞. Условия достаточные, не необходимые: пример (2x + sin x)/x → 2 при отсутствии lim (2 + cos x).
  • Алгоритм: подставить, проверить вид и условия, дифференцировать f и g отдельно, найти lim f′/g′; при 0/0 или ∞/∞ повторить. Рост на +∞: ln x ≪ xᵋ ≪ aˣ.
