Неопределённости других видов и выбор метода

Правило Лопиталя работает только с дробями 0/0 и ∞/∞. Но неопределённостей больше: на стр. 13 лекция называет ещё пять — 0·∞, ∞ − ∞, 0⁰, ∞⁰, 1^∞ — и объясняет идею: первые две приводят преобразованием к дроби, выражения для последних трёх логарифмируют. В статье: рецепт для каждого вида, разобранные примеры (в том числе упражнение лекции lim x^x), сравнение трёх инструментов (правило Лопиталя, формула Тейлора, алгебра) и типичные ошибки.

Какие бывают неопределённости

Запись 0·∞ — не число, а тип предела: произведение f·g, где f → 0, а g → ∞. Пока не известно, кто «победит», результат может быть любым:

  • 0·∞: при x → +∞ произведения x·(1/x) → 1, x²·(1/x) → +∞, x·(1/x²) → 0;
  • ∞ − ∞: (x + 1) − x → 1, 2x − x → +∞, x − 2x → −∞ при x → +∞;
  • 1^∞: (1 + 1/x)x → e, (1 + 1/x)x² → +∞, (1 + 1/x²)x → 1 при x → +∞.

Лекция называет пять видов: 0·∞, +∞ − (+∞), (+0)⁰, (+∞)⁰, 1^∞. Для степеней uv основание должно быть положительным (в (+0)⁰ оно стремится к нулю справа), иначе логарифм и сама степень не определены.

Не путай

Не всякая запись с бесконечностью — неопределённость. Определены: (+∞) + (+∞) = +∞, (+∞)·(+∞) = +∞, (+0)+∞ = 0, (+∞)+∞ = +∞, (+0)−∞ = +∞, 1/(+0) = +∞. Правило Лопиталя и преобразования нужны только для настоящих неопределённостей.

0·∞ и ∞ − ∞: свести к дроби

0·∞. Пусть f → 0, g → ∞. Тогда f·g = f/(1/g) — дробь вида 0/0, либо f·g = g/(1/f) — дробь вида ∞/∞. К получившейся дроби применяют правило Лопиталя. Какой вариант выбрать? Тот, где производные проще. Эмпирическое правило: логарифм ставят в числитель, а степень или показательную функцию — в знаменатель в виде 1/… (так x·ln x = ln x/(1/x), и производная логарифма проста).

∞ − ∞. Разность f − g преобразуют так, чтобы получить дробь: приводят к общему знаменателю (1/x − 1/sin x = (sin x − x)/(x·sin x)), домножают на сопряжённое для корней (√A − √B = (A − B)/(√A + √B)), выносят общий множитель (f − g = f·(1 − g/f)). Дальше раскрывают неопределённость 0/0 или ∞/∞.

0⁰, ∞⁰ и 1^∞: логарифм

Пусть y = u(x)v(x), u > 0 около точки. Лекция советует такие выражения прологарифмировать. Схема:

  • ln y = v·ln u — произведение, чаще всего вида 0·∞;
  • приведи v·ln u к дроби и найди L = lim ln y (конечный или ±∞);
  • вернись к y: lim y = eL (непрерывность eˣ); при L = +∞ получается +∞, при L = −∞ получается 0.
lim uv = eL, где L = lim v·ln u
Шаг «вернуться к y» нельзя забывать: найденный предел L — это предел логарифма, а не самой функции.

Короткий путь для 1^∞ (дополнительно). Если u → 1, v → ∞, то ln u ≈ u − 1 (ln u/(u − 1) → 1), поэтому L = lim v·(u − 1), если этот предел существует. Тогда lim uv = elim v(u − 1). Например, (1 + 1/x)x: v(u − 1) = x·(1/x) = 1, предел e¹ = e.

Разобранные примеры

Пример 1: 0⁰ и предел x^xиз лекции, стр. 13 (упражнение 1)
Найти limx→0+0 xx.

  1. Основание x → +0, показатель x → 0: неопределённость (+0)⁰. y = xx, ln y = x·ln x — это 0·(−∞).

  2. Приводим к дроби с логарифмом в числителе: ln y = ln x/(1/x). Числитель → −∞, знаменатель → +∞: вид ∞/∞; g = 1/x дифференцируема на (0, b), g′ = −1/x² ≠ 0.

  3. По правилу Лопиталя lim ln x/(1/x) = lim (1/x)/(−1/x²) = lim (−x) = 0. Итак, L = 0.

  4. Возвращаемся к y: lim xx = e0 = 1.

1.

Пример 2: 0·∞дополнительно
Найти limx→π/2−0 (π/2 − x)·tg x.

  1. π/2 − x → 0, tg x → +∞: вид 0·∞. Запишем tg x = 1/ctg x: (π/2 − x)/ctg x — дробь 0/0 (ctg x → 0 при x → π/2). Производная знаменателя −1/sin²x ≠ 0.

  2. lim (π/2 − x)/ctg x = lim (−1)/(−1/sin²x) = lim sin²x = 1.

1.

Пример 3: ∞ − ∞дополнительно
Найти limx→0 (1/x − 1/sin x).

  1. Оба слагаемых стремятся к +∞ при x → 0 + 0 (и к −∞ при x → 0 − 0): ∞ − ∞. Общий знаменатель: 1/x − 1/sin x = (sin x − x)/(x·sin x) — дробь 0/0.

  2. Правило Лопиталя: (cos x − 1)/(sin x + x·cos x) — снова 0/0. Ещё раз: (−sin x)/(2cos x − x·sin x) → 0/2 = 0.

  3. Проверка по Тейлору (статья 9.5): sin x − x = −x³/6 + o(x³), знаменатель x·sin x = x² + o(x²); отношение ~ −x/6 → 0.

0.

Пример 4: ∞ − ∞ с корнемдополнительно
Найти limx→+∞ (√(x² + x) − x).

  1. +∞ − (+∞). Домножим на сопряжённое: √(x² + x) − x = (x² + x − x²)/(√(x² + x) + x) = x/(√(x² + x) + x).

  2. Разделим числитель и знаменатель на x (x > 0): 1/(√(1 + 1/x) + 1) → 1/(1 + 1) = 1/2.

  3. Правило Лопиталя здесь не нужно; алгебра короче. (Ответ не 0: вычитание «бесконечностей» не даёт нуль.)

1/2.

Пример 5: 1^∞дополнительно (по образцу дополнительных материалов курса)
Найти limx→0 (cos x)1/x².

  1. Основание cos x → 1, показатель 1/x² → +∞: 1^∞. Основание положительно при малых x. y = (cos x)1/x², ln y = ln cos x/x² — дробь 0/0.

  2. Правило Лопиталя: (−tg x)/(2x) — снова 0/0; ещё раз: (−1/cos²x)/2 → −1/2. Итак, L = −1/2.

  3. lim y = e−1/2 = 1/√e.

  4. Короткий путь: v(u − 1) = (cos x − 1)/x² → −1/2 (первый замечательный предел, 1 − cos x ~ x²/2), тот же L.

e−1/2.

Пример 6: второй замечательный предел и ∞⁰дополнительно
Найти limx→+∞ (1 + 1/x)x и limx→+∞ x1/x.

  1. Первый. 1^∞. ln y = x·ln(1 + 1/x) = ln(1 + 1/x)/(1/x) — дробь 0/0. Производные: (1/(1 + 1/x))·(−1/x²) и −1/x², отношение 1/(1 + 1/x) → 1. Значит, L = 1, lim y = e. Это вычисление, а не доказательство второго замечательного предела: формула (ln x)′ = 1/x сама выводится из него (как и с sin x/x в статье 9.6).

  2. Второй. (+∞)⁰. ln y = (1/x)·ln x = ln x/x — дробь ∞/∞, (1/x)/1 → 0 (пример 1 статьи 9.6 при ε = 1). L = 0, lim x1/x = e⁰ = 1.

e и 1.

Пример 7: три способа для одного пределадополнительно
Найти limx→0 (tg x − sin x)/x³ тремя способами.

  1. Алгебра и замечательные пределы. tg x − sin x = tg x·(1 − cos x), поэтому (tg x − sin x)/x³ = (tg x/x)·((1 − cos x)/x²) → 1·(1/2) = 1/2. Самый короткий путь.

  2. Формула Тейлора. tg x = sin x/cos x = (x − x³/6)/(1 − x²/2) + … = x + x³/3 + o(x³), sin x = x − x³/6 + o(x⁴). Разность = x³/3 + x³/6 + o(x³) = x³/2 + o(x³), предел 1/2.

  3. Правило Лопиталя. Нужны три применения. (1/cos²x − cos x)/(3x²) — снова 0/0; (2·sin x/cos³x + sin x)/(6x) — снова 0/0; (2/cos²x + 6·sin²x/cos⁴x + cos x)/6 → (2 + 0 + 1)/6 = 1/2. Ответ тот же, но производные заметно громоздче.

1/2 всеми способами; короче всего первый.

Частые ошибки

Так нельзя

«0·∞ = 0», «∞ − ∞ = 0», «1^∞ = 1» — считать по арифметике.

Так правильно

Это неопределённости. x·(1/x) → 1, (x² − x) → +∞ при x → +∞ (∞ − ∞), (1 + 1/x)x → e (1^∞). Результат зависит от функций.

Так нельзя

Применять правило Лопиталя прямо к 0·∞ или к 1^∞ (там нет дроби).

Так правильно

Сначала сведи выражение к дроби 0/0 или ∞/∞; степень сначала прологарифмируй.

Так нельзя

Найти L = lim ln y и написать «lim y = L».

Так правильно

L — предел логарифма: lim y = eL. Для xx: L = 0, ответ e⁰ = 1, не 0.

Так нельзя

Логарифмировать, не проверив, что основание положительно.

Так правильно

Для uv нужно u > 0 около точки (иначе ln u не определён); на лекции этот случай не рассматривается.

Так нельзя

Для 0·∞ выбирать дробь наугад: x·ln x = x/(1/ln x).

Так правильно

Запись законна (дробь 0/0), но невыгодна: (x)′/(1/ln x)′ = −x·ln²x, снова 0·∞. Логарифм ставят в числитель: ln x/(1/x), и (1/x)/(−1/x²) = −x.

Так нельзя

Выбирать правило Лопиталя всегда, даже когда есть сокращение или замечательный предел.

Так правильно

Сначала упрости: сократи общий множитель, воспользуйся эквивалентностями или разложением Тейлора. Правило — один из инструментов, а не единственный.

Кратко для повторения

Кратко для повторения

  • Пять других видов: 0·∞, +∞ − (+∞), (+0)⁰, (+∞)⁰, 1^∞ (лекция, стр. 13). Это типы пределов, а не числа; результат зависит от функций. Определены: ∞ + ∞, ∞·∞, (+0)+∞, (+∞)+∞.
  • 0·∞: f·g = f/(1/g) или g/(1/f); ∞ − ∞: общий знаменатель, сопряжённое или вынесение множителя. Затем Лопиталь.
  • uv (u > 0): ln y = v·ln u, найти L = lim ln y, ответ lim y = eL. Для 1^∞ ещё elim v(u − 1).
  • Упражнение лекции: limx→0+0 xx = 1.
  • Выбирай самый короткий метод: сокращение, замечательные пределы, Тейлор или Лопиталь.

3

Варианты ответа

Показать решение

1^∞. ln y = (2/x)·ln(1 + 3x), 0/0: lim ln(1 + 3x)/(x/2) = lim (3/(1 + 3x))/(1/2) = 6. Ответ e⁶. Короткий путь: v(u − 1) = (2/x)·3x = 6.

4
Найдите limx→+∞ (√(x² + 4x) − x).

Показать решение

√(x² + 4x) − x = 4x/(√(x² + 4x) + x) = 4/(√(1 + 4/x) + 1) → 4/(1 + 1) = 2.
