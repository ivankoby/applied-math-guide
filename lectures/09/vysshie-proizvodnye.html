Производная — тоже функция, поэтому её можно дифференцировать ещё раз. Так получаются производные второго, третьего и вообще n-го порядка. Вторая производная нужна для выпуклости и исследования экстремумов (лекция 10), n-я — для формулы Тейлора (статья 9.4). В этой статье: определение со всеми условиями, таблица n-х производных основных функций, формула Лейбница для n-й производной произведения и схема решения типовых заданий «найти производную указанного порядка» (задания 12 на стр. 14 второго файла лекции).

Определение и обозначения

Производная порядка n

Пусть функция f определена на окрестности U(x₀) и имеет там производную f′(x). Если f′ имеет производную в точке x₀, то её называют второй производной f″(x₀) = (f′)′(x₀). Вообще, производная порядка n определяется равенством f(n)(x₀) = (f(n−1)(x))′|x = x₀, n ≥ 1. Удобно считать f(0)(x) := f(x).

Из определения видно, что если существует f(n)(x₀), то производная f(n−1) должна быть определена в некоторой окрестности точки x₀: иначе в точке x₀ нечего дифференцировать. Значит, существование f(n)(x₀) требует, чтобы f′, f″, …, f(n−1) существовали не только в самой точке, но и вокруг неё.

Обозначения. Производную порядка n пишут f(n)(x₀) или dⁿf(x₀)/dxⁿ; для первых порядков — штрихами: f′, f″, f‴. Для функции y пишут y(n). В заданиях на стр. 14 лекции порядок указан римской цифрой: yIII — третья, yIV — четвёртая, yV — пятая производная.

Простейший пример — многочлен: каждое дифференцирование понижает степень на единицу. Для y = x⁴:

y′ = 4x³, y″ = 12x², y‴ = 24x, y(4) = 24, y(5) = 0.

Пример: f′ есть всюду, а f″(0) нет

Возьмём f(x) = x·|x|. При x ≥ 0 это x², при x < 0 это −x². В точке 0 производная существует: f′(0) = limx→0 x|x|/x = lim |x| = 0, и вообще f′(x) = 2|x| при всех x. Но график f′(x) = 2|x| имеет в нуле угол: справа наклон +2, слева −2. Значит, f″(0) не существует, хотя f″(x) = 2·sgn x существует при каждом x ≠ 0. Вывод: из существования f′ вокруг x₀ существование f″(x₀) не следует; нужно ещё, чтобы функция f′, определённая вокруг x₀, была дифференцируема в самой точке x₀.

Линейный аргумент

Если внутри линейная функция, то при каждом дифференцировании из цепного правила выходит множитель k: для постоянных k, b имеем (f(kx + b))(n) = kⁿ·f(n)(kx + b). Например, (e−3x)(n) = (−3)ⁿ·e−3x, (sin 2x)(n) = 2ⁿ·sin(2x + nπ/2). Не забывай возвести k в степень n, а не умножить на n.

Теорема о свойствах и формула Лейбница

Теорема 1 (свойства производных высших порядков)

Пусть существуют f(n)(x₀) и g(n)(x₀). Тогда в точке x₀ существуют: 1° (f ± g)(n) = f(n) ± g(n); 2° (формула Лейбница) (fg)(n) = f(n)g + Cn1f(n−1)g′ + … + fg(n) = Σk=0n Cnkf(n−k)g(k), где Cnk = n!/(k!(n − k)!).

Следствие. Если существует f(n)(x₀), то для постоянной c существует (cf)(n)(x₀) = c·f(n)(x₀) (постоянный множитель выносится). В лекции на стр. 1 постоянный множитель в следствии набран буквой, которую легко принять за x; он, конечно, постоянный. Это частный случай формулы Лейбница при g ≡ c: g(k) = 0 при k ≥ 1, остаётся одно слагаемое f(n)·c.

Условие «существуют f(n)(x₀) и g(n)(x₀)» относится к обеим функциям: для f или для g по отдельности формула не гарантируется.

Как читать формулу. Порядки производных f убывают от n до 0, порядки производных g растут от 0 до n, а их сумма в каждом слагаемом равна n. Коэффициенты Cnk — это биномиальные коэффициенты, строки треугольника Паскаля. Формула устроена как бином Ньютона (a + b)ⁿ = Σ Cnk an−kbk, только степени заменены порядками производных.

Для первых порядков формула Лейбница выглядит так (коэффициенты — строки таблицы):

n = 1: (fg)′ = f′g + fg′
n = 2: (fg)″ = f″g + 2f′g′ + fg″
n = 3: (fg)‴ = f‴g + 3f″g′ + 3f′g″ + fg‴
n = 4: (fg)(4) = f(4)g + 4f‴g′ + 6f″g″ + 4f′g‴ + fg(4)
Случай n = 1 — обычное правило производной произведения. Нигде нет слагаемого f(n)g(n): производная произведения — не произведение производных.

Почему именно так. При n-кратном дифференцировании произведения каждое из n дифференцирований «достаётся» либо f, либо g. Слагаемое с g(k) получается, если g досталось ровно k дифференцирований из n; выбрать, каких именно, можно Cnk способами.

Доказательство формулы Лейбница (индукция)

База: n = 1 — правило производной произведения (fg)′ = f′g + fg′. Шаг: пусть формула верна для порядка n, и существуют f(n+1)(x₀), g(n+1)(x₀); тогда все производные до порядка n существуют около x₀, и формула для порядка n верна в окрестности. Дифференцируем её почленно:

(fg)(n+1) = ((fg)(n))′ = Σk=0n Cnk(f(n−k+1)g(k) + f(n−k)g(k+1))
Каждое слагаемое — производная произведения f(n−k)·g(k).

Разобьём на две суммы и во второй сдвинем индекс: j = k + 1, j = 1, …, n + 1. Соберём слагаемые с одинаковыми порядками производных:

= Cn0f(n+1)g + Σk=1n(Cnk + Cnk−1)f(n+1−k)g(k) + Cnnfg(n+1)

Осталось показать, что Cnk + Cnk−1 = Cn+1k:

n!/(k!(n − k)!) + n!/((k − 1)!(n − k + 1)!) = n!·((n − k + 1) + k)/(k!(n − k + 1)!) = (n + 1)!/(k!(n + 1 − k)!) = Cn+1k
Общий знаменатель k!(n − k + 1)!: первую дробь домножили на n − k + 1, вторую на k. Крайние коэффициенты Cn0 = Cnn = 1 = Cn+10 = Cn+1n+1.

Формула для порядка n + 1 получена. Пункт 1° теоремы (сумма и разность) очевиден: производная суммы равна сумме производных, и так n раз.

Как применять формулу Лейбница

Прямое дифференцирование n раз быстро становится громоздким уже при n = 4. Формула Лейбница выгодна, когда у одного из множителей производные «кончаются» (многочлен) или имеют простую общую формулу (из таблицы).

  • Выбери множитель-многочлен степени m в роль g. Тогда g(k) = 0 при k > m, и в сумме остаются только слагаемые с k = 0, …, m, то есть не больше m + 1 членов, какой бы большой ни была производная n ≥ m.
  • Выпиши производные g до порядка m и производные другого множителя f порядков n, n − 1, …, n − m (по таблице или повторным дифференцированием).
  • Выпиши коэффициенты Cnk (строка треугольника Паскаля).
  • Собери сумму, вынеси общий множитель (например, ex или степень (x − 3)) и приведи подобные.
  • Дробь u/v записывай как произведение u·v−1 и применяй ту же формулу (производные степени берутся по таблице).
  • Сумма функций — дифференцируй почленно (пункт 1°); постоянный множитель выноси за знак производной (следствие).
  • Проверка: подставь удобное значение x или сравни с прямым дифференцированием при малом n.

Что встречается в типовых заданиях 12 (стр. 14 лекции): многочлен, умноженный на ln, ekx, sin, cos ((x² + 3)ln(x − 3), (5x − 8)·2−x, x·cos x²); частные ln x/xᵏ и ln(ax + b)/(ax + b); произведение двух функций с «бесконечными» цепочками (ex/2·sin 2x, e1−2x·sin(2 + 3x)). Есть и множители, которых нет в таблице: ln²x (задания 12.10, 12.15, 12.22), arctg x (12.23), log₂x (12.18), 1/√(x − 1) (12.17). Метод тот же: для ln²x и arctg x производные нужных порядков находят прямым дифференцированием, а log₂x = ln x/ln 2 и 1/√(x − 1) = (x − 1)−1/2 сводятся к таблице. Пример 6 ниже разбирает задание с arctg x.

Разобранные примеры

Пример 1: последовательное дифференцированиедополнительно
Найти y‴ и y(4) для y = x²·ln x.

  1. Дифференцируем по правилу произведения и сразу упрощаем:

    y′ = 2x·ln x + x²·(1/x) = 2x·ln x + x

  2. Второй раз: y″ = (2x·ln x)′ + 1 = 2·ln x + 2x·(1/x) + 1 = 2·ln x + 3.

  3. Далее y‴ = 2/x и y(4) = (2x−1)′ = −2/x². На третьем шаге пропал логарифм: от степени x² к третьей производной остался только дробный остаток.

y‴ = 2/x, y(4) = −2/x².

Пример 2: общая формула для n-й производнойдополнительно
Найти y(n) для y = ln(3 − 2x) и z(5) для z = sin 2x.

  1. Для ln u с линейным u = 3 − 2x возьмём (ln x)(n) = (−1)n−1(n − 1)!/xⁿ и учтём множитель k = −2 из цепного правила: (ln(kx + b))(n) = kⁿ·(−1)n−1(n − 1)!/(kx + b)ⁿ.

  2. При k = −2 множитель (−2)ⁿ·(−1)n−1 = (−1)2n−1·2ⁿ = −2ⁿ. Итог:

    y(n) = −2ⁿ·(n − 1)!/(3 − 2x)ⁿ

    Проверка при n = 1: y′ = −2/(3 − 2x), как и должно быть. При n = 4: y(4) = −16·6/(3 − 2x)⁴ = −96/(3 − 2x)⁴.

  3. Для z = sin 2x: z(n) = 2ⁿ·sin(2x + nπ/2). При n = 5: 32·sin(2x + 5π/2) = 32·sin(2x + π/2) = 32·cos 2x (период синуса 2π, поэтому 5π/2 можно заменить на π/2).

y(n) = −2ⁿ(n − 1)!/(3 − 2x)ⁿ; z(5) = 32·cos 2x.

Пример 3: многочлен на логарифмиз лекции, стр. 14 (задание 12.1)
Найти y(4) для y = (x² + 3)·ln(x − 3).

  1. Выбор ролей. Многочлен g = x² + 3 степени 2: g′ = 2x, g″ = 2, g‴ = 0. Значит, в формуле Лейбница при n = 4 остаются слагаемые с k = 0, 1, 2. Пусть f = ln(x − 3).

  2. Производные f. По таблице (коэффициент при x в x − 3 равен 1) f(m) = (−1)m−1(m − 1)!/(x − 3)m: f″ = −1/(x − 3)², f‴ = 2/(x − 3)³, f(4) = −6/(x − 3)⁴.

  3. Формула (строка 1, 4, 6, 4, 1): y(4) = f(4)g + 4f‴g′ + 6f″g″, слагаемые с g‴, g(4) нулевые.

    y(4) = −6(x² + 3)/(x − 3)⁴ + 4·2/(x − 3)³·2x + 6·(−1/(x − 3)²)·2 = −6(x² + 3)/(x − 3)⁴ + 16x/(x − 3)³ − 12/(x − 3)²

  4. Общий знаменатель (x − 3)⁴: числитель −6(x² + 3) + 16x(x − 3) − 12(x − 3)² = −6x² − 18 + 16x² − 48x − 12x² + 72x − 108 = −2x² + 24x − 126 = −2(x² − 12x + 63).

  5. Проверка при x = 5: сумма трёх слагаемых −6·28/16 + 80/8 − 12/4 = −10,5 + 10 − 3 = −3,5; формула −2·(25 − 60 + 63)/16 = −2·28/16 = −3,5. Совпало.

y(4) = −2(x² − 12x + 63)/(x − 3)⁴.

Пример 4: произведение двух «бесконечных» цепочекиз лекции, стр. 14 (задание 12.7)
Найти y(4) для y = ex/2·sin 2x.

  1. Оба множителя дифференцируются бесконечно долго, поэтому в формуле Лейбница будут все пять слагаемых (строка 1, 4, 6, 4, 1). Пусть f = ex/2, g = sin 2x. По таблице с линейным аргументом f(j) = (1/2)jex/2, g(k) = 2k·sin(2x + kπ/2):

  2. g = sin 2x, g′ = 2cos 2x, g″ = −4 sin 2x, g‴ = −8cos 2x, g(4) = 16 sin 2x; множители при ex/2 у f(4), f‴, f″, f′, f: 1/16, 1/8, 1/4, 1/2, 1.

  3. Слагаемые (общий множитель ex/2), k = 0, …, 4:

    • k = 0: 1·(1/16)·sin 2x = (1/16) sin 2x
    • k = 1: 4·(1/8)·2cos 2x = cos 2x
    • k = 2: 6·(1/4)·(−4 sin 2x) = −6 sin 2x
    • k = 3: 4·(1/2)·(−8cos 2x) = −16 cos 2x
    • k = 4: 1·1·16 sin 2x = 16 sin 2x

  4. Сложим: при sin 2x стоит 1/16 − 6 + 16 = 161/16, при cos 2x стоит 1 − 16 = −15.

y(4) = ex/2·((161/16)·sin 2x − 15·cos 2x).

Пример 5: частное как произведениедополнительно (по типу заданий 12.4, 12.21, 12.24)
Найти y‴ для y = ln x / x².

  1. Запишем y = ln x·x−2 и возьмём f = ln x, g = x−2 (степень по таблице: (xm)(k) = m(m − 1)…(m − k + 1)xm−k). Многочленом g не является, поэтому берём все четыре слагаемых (1, 3, 3, 1).

  2. f′ = 1/x, f″ = −1/x², f‴ = 2/x³; g′ = −2x−3, g″ = 6x−4, g‴ = −24x−5.

  3. y‴ = f‴g + 3f″g′ + 3f′g″ + fg‴ = 2x−3·x−2 + 3·(−x−2)·(−2x−3) + 3·x−1·6x−4 + ln x·(−24x−5). Первые три слагаемых: 2x−5 + 6x−5 + 18x−5 = 26x−5.

y‴ = (26 − 24·ln x)/x⁵.

Пример 6: множитель, которого нет в таблицеиз лекции, стр. 14 (задание 12.23)
Найти y‴ для y = (1 + x²)·arctg x.

  1. Многочлен g = 1 + x²: g′ = 2x, g″ = 2, g‴ = 0. Для f = arctg x в таблице производных нет, дифференцируем прямо: f′ = 1/(1 + x²), f″ = −2x/(1 + x²)², f‴ = (6x² − 2)/(1 + x²)³.

  2. Формула Лейбница (1, 3, 3, 1), слагаемые с g‴ нулевые: y‴ = f‴g + 3f″g′ + 3f′g″. Подставляем и приводим к знаменателю (1 + x²)² (первое слагаемое сокращается на 1 + x²):

    y‴ = (6x² − 2)/(1 + x²)² − 12x²/(1 + x²)² + 6/(1 + x²) = (6x² − 2 − 12x² + 6 + 6x²)/(1 + x²)² = 4/(1 + x²)²

  3. Проверка прямым дифференцированием: y′ = 2x·arctg x + 1, y″ = 2·arctg x + 2x/(1 + x²), y‴ = 2/(1 + x²) + (2 − 2x²)/(1 + x²)² = 4/(1 + x²)². Совпало.

y‴ = 4/(1 + x²)².

Частые ошибки

Так нельзя

(fg)(n) = f(n)·g(n): «производная произведения — произведение производных».

Так правильно

Верна формула Лейбница Σ Cnkf(n−k)g(k). Уже при n = 1: (fg)′ = f′g + fg′.

Так нельзя

В формуле Лейбница забыть биномиальные коэффициенты или взять коэффициенты 1, 2, 2, 1 при n = 3.

Так правильно

Коэффициенты — строка треугольника Паскаля для n: при n = 3 это 1, 3, 3, 1; при n = 4 — 1, 4, 6, 4, 1.

Так нельзя

(sin 2x)(n) = 2n·sin(2x + nπ/2) или sin(2x + nπ/2) без множителя.

Так правильно

Каждое дифференцирование даёт множитель 2, значит, 2ⁿ: (sin 2x)(n) = 2ⁿ·sin(2x + nπ/2).

Так нельзя

(ln x)(n) = (n − 1)!/xⁿ (потеряли знак).

Так правильно

(ln x)(n) = (−1)n−1(n − 1)!/xⁿ: знак чередуется, (ln x)″ = −1/x².

Так нельзя

(f(g(x)))″ = f″(g(x))·g″(x).

Так правильно

Нужно цепное правило дважды: (f(g))″ = f″(g)·(g′)² + f′(g)·g″. Простая формула с множителем kⁿ верна только для линейного g(x) = kx + b, где g″ = 0.

Так нельзя

Дифференцировать частное по формуле Лейбница, не перейдя к произведению.

Так правильно

Сначала u/v = u·v−1, потом формула Лейбница; производные v−1 берут по таблице степеней.

Кратко для повторения

Кратко для повторения

  • f(n)(x₀) = (f(n−1))′(x₀), f(0) = f; если f(n)(x₀) существует, то f(n−1) определена на окрестности x₀ (а значит, f′, …, f(n−1) существуют около x₀).
  • Обозначения: f(n), y(n), dⁿf/dxⁿ; в заданиях лекции порядок римской цифрой (yIV).
  • Теорема 1 (при условии, что существуют f(n)(x₀) и g(n)(x₀)): (f ± g)(n) = f(n) ± g(n); (cf)(n) = c·f(n); (fg)(n) = Σk=0n Cnkf(n−k)g(k), Cnk = n!/(k!(n − k)!).
  • Лейбниц выгоден, когда один множитель — многочлен степени m (остаётся не больше m + 1 слагаемых) или когда n-е производные множителей известны по таблице.
  • Дробь u/v — это u·v−1. Для линейного аргумента (f(kx + b))(n) = kⁿf(n)(kx + b).
  • Таблица: (sin x)(n) = sin(x + nπ/2), (ln x)(n) = (−1)n−1(n − 1)!/xⁿ, (1/x)(n) = (−1)ⁿn!/xn+1, (aˣ)(n) = aˣ(ln a)ⁿ.
