Касательная — это первое приближение функции многочленом: степени один, с общим значением и общей производной в точке. Формула Тейлора идёт дальше: она приближает функцию вблизи точки многочленом любой степени n, коэффициенты которого — производные функции в этой точке, и точно описывает ошибку («остаточный член»). Это главный инструмент для пределов (статьи 9.5, 9.7) и приближённых вычислений. В статье: определение, лемма, две теоремы об остатке (Пеано и Лагранжа) со всеми условиями, смысл записей o(…) и θ, примеры построения многочлена и оценки погрешности.

Формула Тейлора и её части

В этом параграфе лекции n ∈ ℕ (некоторые утверждения сохраняются и для n = 0). Пусть существует f(n)(x₀). Тогда на некоторой окрестности U(x₀) можно написать равенство

f(x) = Σk=0n f(k)(x₀)/k!·(x − x₀)k + rn(f, x) = Pn(f, x) + rn(f, x) (1)
Это формула Тейлора функции f в точке x₀. Условие «существует f(n)(x₀)» включает существование f′, …, f(n−1) около x₀ (статья 9.1).
  • f(k)(x₀)/k!·(x − x₀)k называется k-м членом формулы Тейлора;
  • Pn(f, x) — многочлен Тейлора (сумма членов с k = 0, …, n);
  • rn(f, x) — остаточный член формулы Тейлора (после n-го члена). Часто пишут просто Pn(x), rn(x).

Равенство (1) по сути определяет остаток: rn(f, x) := f(x) − Pn(f, x). Содержательные утверждения — теоремы о том, насколько мал остаток (форма Пеано и форма Лагранжа ниже). При x₀ = 0 формулу Тейлора называют формулой Маклорена (статья 9.5).

Откуда берутся коэффициенты f(k)(x₀)/k!. Многочлен Pn подбирают так, чтобы его значение и все производные до порядка n в точке x₀ совпадали с f. Дифференцируя слагаемое ck(x − x₀)k ровно k раз, получаем ck·k!, а остальные слагаемые при x = x₀ дают нуль. Значит, Pn(k)(x₀) = ck·k!, и из Pn(k)(x₀) = f(k)(x₀) следует ck = f(k)(x₀)/k!.

Алгоритм построения Pn: (1) найди f(x₀), f′(x₀), …, f(n)(x₀); (2) каждое f(k)(x₀) раздели на k!; (3) умножь на (x − x₀)k (степени разности, а не x!) и сложи. Помни 0! = 1, f(0) = f.

Что приближает каждый член

P₀(x) = f(x₀) — постоянная: «рядом с точкой функция примерно равна своему значению». P₁(x) = f(x₀) + f′(x₀)(x − x₀) — касательная. P₂ добавляет член f″(x₀)/2·(x − x₀)² и превращается в параболу, которая учитывает изгиб графика. Вблизи x₀ каждый следующий член уточняет приближение: остаток убывает быстрее, чем (x − x₀)ⁿ (теорема 1 ниже). Вдали от x₀ это не гарантировано: для eˣ ошибки P₁, P₂, P₃ в точке x = −2 равны 1,14; 0,86; 0,47 (убывают), а в точке x = −4 равны 3,02; 4,98; 5,68 (растут). Теоремы этой статьи — о поведении при x → x₀.

Лемма: остаток производной

Лемма

Пусть существуют f(n)(x₀) и f′ в проколотой окрестности Ů(x₀). Тогда в Ů(x₀) справедливо (rn(f, x))′ = rn−1(f′, x).

Доказательство из лекции. Дифференцируем rn(f, x) = f(x) − Σk=0n f(k)(x₀)/k!·(x − x₀)k. Слагаемое k = 0 (постоянная) пропадает, а члены с k ≥ 1 дают f(k)(x₀)/(k − 1)!·(x − x₀)k−1:

(rn(f, x))′ = f′(x) − Σk=1n f(k)(x₀)/(k − 1)!·(x − x₀)k−1 = rn−1(f′, x)
Сдвиг индекса j = k − 1 и равенство (f′)(j) = f(j+1) показывают, что сумма — многочлен Тейлора Pn−1(f′, x).

Смысл леммы: производная остатка порядка n функции f — это остаток порядка n − 1 её производной f′. Поэтому доказательства ведут индукцией по n, переходя от f к f′.

Теорема 1: остаток в форме Пеано

Теорема 1 (формула Тейлора с остаточным членом в форме Пеано)

Пусть n ∈ ℕ и существует f(n)(x₀). Тогда справедлива формула (1), в которой rn(f, x) = o((x − x₀)n) при x → x₀.

Что значит o(…). Запись α(x) = o(β(x)) при x → x₀ означает α(x)/β(x) → 0. Итак, rn(f, x) = o((x − x₀)n): остаток стремится к нулю быстрее, чем (x − x₀)n. Для n = 1 теорема — это определение дифференцируемости: f(x) − f(x₀) = f′(x₀)(x − x₀) + o(x − x₀).

Условие. Нужно лишь существование f(n)(x₀) в одной точке (для n ≥ 2 оно включает существование f′, …, f(n−1) около x₀); непрерывность f(n) не требуется. Зато вывод локальный: он говорит о поведении при x → x₀, а не о погрешности при конкретном x.

Доказательство из лекции (по индукции). База n = 1 — только что сказанное. Шаг: пусть теорема верна для n − 1 ≥ 1 (для функции f′: у неё существует (f′)(n−1)(x₀) = f(n)(x₀)). Берём x > x₀. Функция rn непрерывна на [x₀, x] (так как f дифференцируема около x₀, непрерывна в x₀) и дифференцируема на (x₀, x), а rn(f, x₀) = 0. По теореме Лагранжа (статья 9.3) и лемме:

rn(f, x) = rn(f, x) − rn(f, x₀) = (rn)′(ξ)·(x − x₀) = rn−1(f′, ξ)·(x − x₀), x₀ < ξ < x

По предположению индукции rn−1(f′, ξ) = o((ξ − x₀)n−1) = o((x − x₀)n−1) при x → x₀ (ведь 0 < ξ − x₀ < x − x₀). Умножая на (x − x₀), получаем rn(f, x) = o((x − x₀)n). Случай x < x₀ аналогичен.

Теорема 2: остаток в форме Лагранжа

Теорема 2 (формула Тейлора с остаточным членом в форме Лагранжа)

Пусть x > x₀ (x < x₀), n ∈ ℕ₀ (то есть n = 0, 1, 2, …), f(n) непрерывна на отрезке [x₀, x] ([x, x₀]) и существует f(n+1) на интервале (x₀, x) ((x, x₀)). Тогда справедлива формула (1), в которой rn(f, x) = f(n+1)(x₀ + θ(x − x₀))/(n + 1)!·(x − x₀)n+1 = f(n+1)(ξ)/(n + 1)!·(x − x₀)n+1, где 0 < θ < 1.

Точка ξ = x₀ + θ(x − x₀) лежит между x₀ и x, но неизвестна: теорема лишь утверждает, что такая точка есть. Обычно её не ищут, а оценивают |f(n+1)| на отрезке: если |f(n+1)(t)| ≤ M между x₀ и x, то |rn(f, x)| ≤ M·|x − x₀|n+1/(n + 1)!.

При n = 0 теорема утверждает f(x) = f(x₀) + f′(x₀ + θ(x − x₀))(x − x₀) — это формула конечных приращений Лагранжа (статья 9.3). Условия при n = 0 те же: f непрерывна на [x₀, x], f′ существует на (x₀, x).

Идея доказательства (индукция, как в лекции). Для n = 0 — теорема Лагранжа. Шаг: по теореме Коши (статья 9.3; в ней g(t) = (t − x₀)n+1, g′ = (n + 1)(t − x₀)n ≠ 0 на (x₀, x)) и лемме

rn(f, x)/(x − x₀)n+1 = (rn(f, x) − rn(f, x₀))/((x − x₀)n+1 − 0) = (rn)′(ξ)/((n + 1)(ξ − x₀)n) = rn−1(f′, ξ)/((n + 1)(ξ − x₀)n)

По предположению индукции для f′ порядка n − 1: rn−1(f′, ξ)/(ξ − x₀)n = (f′)(n)(η)/n!, x₀ < η < ξ. Получаем f(n+1)(η)/((n + 1)·n!) = f(n+1)(η)/(n + 1)!. Теорема доказана.

Пеано и Лагранж: когда что

Две формы остатка. Лагранж требует больше (на одну производную) и даёт больше.
Форма Пеано (теорема 1)Форма Лагранжа (теорема 2)
Условиесуществует f(n)(x₀) в одной точке (значит, f′, …, f(n−1) есть около x₀); непрерывность f(n) не нужнаf(n) непрерывна на [x₀, x], существует f(n+1) на (x₀, x)
Остатокo((x − x₀)n) при x → x₀f(n+1)(ξ)/(n + 1)!·(x − x₀)n+1, ξ между x₀ и x
Что даётповедение при x → x₀; нельзя оценить ошибку при заданном xявную оценку ошибки при заданном x
Применяютпределы, разложения, сравнение бесконечно малыхприближённые вычисления с оценкой погрешности

Если при всех x около x₀ выполнены условия теоремы 2 и |f(n+1)| ≤ M между x₀ и x, то форма Лагранжа даёт rn = O((x − x₀)n+1), что сильнее o((x − x₀)n). Но для пределов часто достаточно слабой формы Пеано, и она требует меньше.

Разобранные примеры

Пример 1: многочлен Тейлора и оценка ошибкидополнительно
Построить P₃ для f(x) = ln x в точке x₀ = 1, приближённо найти ln 1,2 и оценить погрешность по форме Лагранжа.

  1. Производные: f′ = 1/x, f″ = −1/x², f‴ = 2/x³, f(4) = −6/x⁴. В точке 1: f(1) = 0, f′(1) = 1, f″(1) = −1, f‴(1) = 2.

  2. Делим на k!: коэффициенты 0, 1, −1/2, 2/6 = 1/3. Многочлен:

    P₃(x) = (x − 1) − (x − 1)²/2 + (x − 1)³/3

  3. При x = 1,2: x − 1 = 0,2, P₃(1,2) = 0,2 − 0,02 + 0,008/3 = 0,182667…. (Точное значение ln 1,2 = 0,18232….)

  4. Оценка. n = 3, f(4)(ξ)/4!·(x − 1)⁴ = −6/(24ξ⁴)·0,2⁴ = −0,0016/(4ξ⁴), где ξ ∈ (1; 1,2). Так как ξ > 1, |r₃| < 0,0016/4 = 0,0004: это оценка для P₃(1,2). Действительная погрешность 0,00035 не превосходит её.

  5. Округление. Если взять P₃(1,2) с четырьмя знаками, 0,1827, к оценке добавится погрешность округления не больше 0,00004, и общая погрешность меньше 0,00044.

P₃(x) = (x − 1) − (x − 1)²/2 + (x − 1)³/3; P₃(1,2) = 0,182667…, |ln 1,2 − P₃(1,2)| < 0,0004; значит, ln 1,2 ≈ 0,1827 с погрешностью меньше 0,0005.

Пример 2: многочлен совпадает со своим многочленом Тейлорадополнительно
Найти P₃ для f(x) = x³ − 2x + 1 в точке x₀ = 1 и остаток.

  1. f′ = 3x² − 2, f″ = 6x, f‴ = 6. В точке 1: f(1) = 0, f′(1) = 1, f″(1) = 6, f‴(1) = 6. Коэффициенты после деления на k!: 0, 1, 3, 1.

  2. P₃(x) = (x − 1) + 3(x − 1)² + (x − 1)³. Раскроем скобки: (x − 1)³ = x³ − 3x² + 3x − 1, 3(x − 1)² = 3x² − 6x + 3; в сумме с x − 1 получаем x³ − 2x + 1.

  3. Остаток r₃ = f − P₃ = 0. Согласуется с формой Лагранжа: f(4) ≡ 0, поэтому r₃ = f(4)(ξ)/4!·(x − 1)⁴ = 0. Многочлен степени не выше n совпадает со своим многочленом Тейлора Pn в любой точке.

P₃(x) = (x − 1) + 3(x − 1)² + (x − 1)³, r₃ = 0.

Пример 3: приближённое значение корнядополнительно
Найти P₂ для f(x) = √(1 + x) в точке x₀ = 0, вычислить √1,2 и оценить погрешность по форме Лагранжа.

  1. f′ = (1/2)(1 + x)−1/2, f″ = −(1/4)(1 + x)−3/2, f‴ = (3/8)(1 + x)−5/2. При x = 0: 1, 1/2, −1/4. После деления на k!: 1, 1/2, −1/8.

  2. P₂(x) = 1 + x/2 − x²/8. При x = 0,2: P₂ = 1 + 0,1 − 0,005 = 1,095.

  3. Оценка. r₂ = f‴(ξ)/3!·x³, ξ ∈ (0; 0,2). На этом интервале (1 + ξ)−5/2 < 1, поэтому |f‴(ξ)| < 3/8, и |r₂| < (3/8)/6·0,2³ = 0,0625·0,008 = 0,0005. Итак, √1,2 = 1,095 ± 0,0005. Фактически √1,2 = 1,09545, погрешность 0,00045.

√1,2 ≈ 1,095 с погрешностью меньше 0,0005.

Частые ошибки

Так нельзя

Взять коэффициентом f(k)(x₀) без деления на k!.

Так правильно

Коэффициент при (x − x₀)k равен f(k)(x₀)/k!. Для e2x при x₀ = 0: 1, 2, 4/2 = 2, 8/6 = 4/3, а не 1, 2, 4, 8.

Так нельзя

Писать степени x вместо (x − x₀) при x₀ ≠ 0.

Так правильно

Многочлен Тейлора по степеням разности x − x₀; в точке x₀ = 1 это (x − 1)k.

Так нельзя

«o((x − x₀)n) — остаток маленький при любом x».

Так правильно

o(…) — утверждение о пределе при x → x₀: rn/(x − x₀)n → 0. Конкретную погрешность при заданном x из него не получить, для этого нужна форма Лагранжа.

Так нельзя

В остатке Лагранжа взять f(n)(ξ) или степень (x − x₀)n.

Так правильно

После n-го члена остаток содержит (n + 1)-ю производную и (n + 1)-ю степень: f(n+1)(ξ)/(n + 1)!·(x − x₀)n+1.

Так нельзя

Считать формулу Тейлора бесконечным рядом.

Так правильно

В лекции это конечная сумма плюс остаток. Сходимость ряда и условие rn → 0 при n → ∞ здесь не рассматриваются.

Так нельзя

Считать ξ (θ) известной точкой — серединой отрезка, например.

Так правильно

ξ неизвестна и зависит от x и n; для оценки берут наибольшее значение |f(n+1)| на промежутке между x₀ и x.

Кратко для повторения

Кратко для повторения

  • Формула Тейлора (при условии, что существует f(n)(x₀)): f(x) = Σk=0n f(k)(x₀)/k!·(x − x₀)k + rn(f, x); Pn — многочлен Тейлора, rn — остаточный член; x₀ = 0 — формула Маклорена.
  • Pn совпадает с f по значению и по производным до порядка n в точке x₀: отсюда деление на k!.
  • Лемма: (rn(f, x))′ = rn−1(f′, x) (при существовании f(n)(x₀) и f′ в Ů(x₀)).
  • Пеано: n ∈ ℕ, существует f(n)(x₀) ⟹ rn = o((x − x₀)n) при x → x₀. Локально, об оценке при заданном x ничего не говорит.
  • Лагранж: n ∈ ℕ₀, f(n) непрерывна на отрезке между x₀ и x, существует f(n+1) на интервале между ними ⟹ rn = f(n+1)(ξ)/(n + 1)!·(x − x₀)n+1, ξ между x₀ и x. Оценка |rn| ≤ M|x − x₀|n+1/(n + 1)!.
  • Многочлен степени не выше n равен своему Pn (остаток нулевой). n = 0 в форме Лагранжа — формула конечных приращений.

1
Найдите коэффициент при (x − 4)² в многочлене Тейлора P₂ функции f(x) = √x в точке x₀ = 4.

Показать решение

f′ = 1/(2√x), f″ = −1/(4x3/2). f″(4) = −1/(4·8) = −1/32. Коэффициент f″(4)/2! = −1/64. (Для проверки: f(4) = 2, f′(4) = 1/4, P₂ = 2 + (x − 4)/4 − (x − 4)²/64.)

2
Какое условие входит в теорему Пеано о формуле Тейлора (n ∈ ℕ)?
Варианты ответа

Показать решение

Теорема Пеано: достаточно, чтобы существовала f(n)(x₀) (а с ней f′, …, f(n−1) в окрестности). Форма Лагранжа требует больше: непрерывность f(n) на отрезке и существование f(n+1) на интервале.

3
Подставьте остаток в форме Лагранжа.
rn(f, x) = / · (x − x₀) в степени , ξ лежит между x₀ и x

Показать решение

rn(f, x) = f(n+1)(ξ)/(n + 1)!·(x − x₀)n+1. После n-го члена остаётся (n + 1)-я производная, (n + 1)! в знаменателе и (n + 1)-я степень.

4
Найдите коэффициент при (x − 1)³ в многочлене Тейлора P₃ функции f(x) = x⁴ в точке x₀ = 1.

Показать решение

f′ = 4x³, f″ = 12x², f‴ = 24x. f‴(1) = 24, коэффициент 24/3! = 4. Для проверки: x⁴ = ((x − 1) + 1)⁴, и биномиальное разложение даёт коэффициенты 1, 4, 6, 4, 1 — при (x − 1)³ стоит 4.
