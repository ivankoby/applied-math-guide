Теоремы о среднем: Ферма, Ролль, Лагранж, Коши

Четыре теоремы этой статьи говорят об одном: у «хорошей» функции (непрерывной на отрезке и дифференцируемой внутри него) есть точка, в которой производная принимает нужное значение: нуль (Ферма, Ролль), среднюю скорость изменения (Лагранж) или отношение скоростей двух функций (Коши). Ферма — утверждение об одной точке (точке экстремума); Ролль, Лагранж и Коши — о точке между двумя концами отрезка. Где именно эта точка, теоремы не говорят, зато на них держатся формула Тейлора, правило Лопиталя и признаки монотонности. Главное в статье — условия: у каждой теоремы они свои, и без любого из них вывод не гарантирован (бывает, что он случайно остаётся верным). Мы покажем это на контрпримерах с графиками.

Теорема Ферма: в точке экстремума касательная горизонтальна

Теорема 1 (Ферма)

Пусть функция f определена на окрестности U(x₀) точки x₀ и в самой точке x₀ принимает наибольшее или наименьшее значение среди своих значений на U(x₀). Пусть существует f′(x₀). Тогда f′(x₀) = 0.

Условий три, и каждое работает: (1) x₀ — внутренняя точка, функция определена по обе стороны от неё; (2) в x₀ значение наибольшее или наименьшее среди значений рядом (локальный экстремум, а не обязательно наибольшее на всей области определения); (3) производная в точке существует. Вывод: касательная к графику в этой точке горизонтальна (вершина холма, дно впадины).

Доказательство из лекции. Пусть для определённости f(x₀) — наименьшее значение на U(x₀). Тогда приращение Δf = f(x₀ + Δx) − f(x₀) ≥ 0 при любых малых Δx, поэтому Δf/Δx ≥ 0 при Δx > 0 и Δf/Δx ≤ 0 при Δx < 0. Производная f′(x₀) существует, значит, предел отношения при Δx → 0 один и тот же справа и слева. Переходя к пределу в первом неравенстве, получаем f′(x₀) ≥ 0, во втором — f′(x₀) ≤ 0. Остаётся f′(x₀) = 0. Для наибольшего значения знаки неравенств меняются.

  • Нет производной. f(x) = |x| имеет минимум в x₀ = 0, но f′(0) не существует: слева наклон −1, справа +1. Условие (3) нарушено, вывод не работает.
  • Нет экстремума. f(x) = x на всей прямой (или x³ в точке x₀ = 1): рядом с x₀ есть значения и больше, и меньше f(x₀), а f′(x₀) = 1 (для x³ — 3) не нуль. Условие (2) нарушено, вывод ложен.
  • Не внутренняя точка. f(x) = x на отрезке [0, 1] принимает наибольшее значение в x₀ = 1, но там есть только левая производная f′−(1) = 1 ≠ 0 (двусторонней нет). Функция определена только слева от x₀, окрестности U(1) нет, условие (1) нарушено.
  • Обратное неверно. Из f′(x₀) = 0 не следует экстремум: f(x) = x³ в нуле имеет f′(0) = 0, но возрастает. Теорема Ферма даёт необходимое условие экстремума, а не достаточное (подробнее в лекции 10).

Теорема Ролля: между двумя равными значениями есть вершина

Теорема 2 (Ролля)

Пусть функция f: 1° непрерывна на отрезке [a, b]; 2° дифференцируема на интервале (a, b); 3° f(a) = f(b). Тогда существует точка ξ ∈ (a, b), такая что f′(ξ) = 0.

Смысл на картинке: график выходит из точки (a, f(a)) и возвращается на ту же высоту в точке (b, f(b)). Между ними он должен где-то повернуть, и в точке поворота касательная горизонтальна.

Доказательство из лекции. Если f постоянна, любая точка ξ подходит. Пусть f не постоянна. По теореме Вейерштрасса (лекция 7) непрерывная на отрезке функция принимает на нём наибольшее и наименьшее значения. Так как f не постоянна, min f < max f. Но f(a) = f(b), поэтому не могут оба экстремума достигаться на концах: хотя бы один из них достигается в точке ξ внутри (a, b). Там функция принимает наибольшее или наименьшее значение на окрестности и дифференцируема (условие 2°), и по теореме Ферма f′(ξ) = 0.

Зачем нужно каждое условие Ролля

Три условия — три отдельных контрпримера. В каждом нарушено ровно одно условие, а вывод ложен.

Нарушено условие 3° (f(a) ≠ f(b)): f(x) = x на [0, 1] непрерывна и дифференцируема, но f(0) = 0 ≠ 1 = f(1), а f′ = 1 нигде не равна нулю. Мораль: теорема Ролля без условий ложна: в каждом из трёх примеров нарушено одно условие, и точки с f′ = 0 нет. Вывод «найдётся точка с f′ = 0» гарантирован только для функций, непрерывных на отрезке и дифференцируемых внутри него; для остальных он может оказаться и ложным, и случайно верным: у f(x) = |x| − x² на [−1, 1] в нуле угол (условие 2° нарушено), f(−1) = f(1) = 0, и всё же f′(1/2) = 1 − 2·(1/2) = 0.

Достаточные условия

Теоремы дают достаточные условия. Если хотя бы одно нарушено, вывод не гарантирован: он может оказаться ложным (как у |x| на [−1, 1]) или случайно верным (как у |x| − x² выше и у |x| + x² для Лагранжа ниже).

Следствие (дополнительно к лекции). Между двумя корнями дифференцируемой функции лежит корень её производной: если f(x₁) = f(x₂) = 0, то по теореме Ролля на [x₁, x₂] найдётся ξ с f′(ξ) = 0. Поэтому у многочлена с n различными вещественными корнями производная имеет не меньше n − 1 корней.

Теорема Лагранжа: касательная, параллельная хорде

Теорема 3 (Лагранжа)

Пусть функция f: 1° непрерывна на отрезке [a, b]; 2° дифференцируема на интервале (a, b). Тогда существует точка ξ ∈ (a, b), такая что f(b) − f(a) = f′(ξ)(b − a).

Равенство называют формулой конечных приращений Лагранжа. Разделив на b − a, перепишем его так:

f′(ξ) = (f(b) − f(a)) / (b − a), ξ ∈ (a, b)
Справа — угловой коэффициент хорды, соединяющей точки (a, f(a)) и (b, f(b)); слева — угловой коэффициент касательной в точке (ξ, f(ξ)).

Геометрический смысл (лекция): найдётся точка ξ ∈ (a, b), в которой касательная к графику параллельна хорде. Физический смысл: если f(t) — путь, то средняя скорость на промежутке равна мгновенной скорости в некоторый момент: автомобиль, проехавший 120 км за 2 часа, хотя бы раз ехал ровно со скоростью 60 км/ч.

Доказательство из лекции. Строим вспомогательную функцию F(x) = f(x) − λx и подбираем число λ так, чтобы F удовлетворяла условию 3° теоремы Ролля, F(a) = F(b). Равенство f(a) − λa = f(b) − λb даёт λ = (f(b) − f(a))/(b − a). Условия 1° и 2° для F выполняются автоматически (разность f и линейной функции), и по теореме Ролля найдётся ξ ∈ (a, b), для которого F′(ξ) = f′(ξ) − λ = 0. Это и есть формула Лагранжа. Смысл приёма: из графика f вычитаем наклонную прямую так, чтобы концы оказались на одной высоте. Ролль — частный случай Лагранжа при f(a) = f(b).

Условия Лагранжа и контрпримеры

  • Нет непрерывности на отрезке. f(x) = 0 при 0 ≤ x < 1 и f(1) = 1: хорда имеет наклон 1, а f′ = 0 во всех точках (0, 1). Условие 1° нарушено в точке x = 1.
  • Что условия НЕ требуют. Дифференцируемость нужна только на интервале (a, b), на концах — лишь непрерывность. f(x) = √x на [0, 1]: производной в нуле нет (график уходит вертикально), и всё же теорема верна: наклон хорды 1, 1/(2√ξ) = 1, ξ = 1/4 ∈ (0, 1).
  • Условие нарушено, вывод верен. f(x) = |x| + x² на [−1, 2] в нуле имеет угол, но наклон хорды (6 − 2)/3 = 4/3, и 2ξ + 1 = 4/3 даёт ξ = 1/6 ∈ (0, 2). Теорема достаточна, но не необходима.

Что даёт Лагранж: следствия (дополнительно к лекции)

  • Функция с нулевой производной постоянна. Если f′ = 0 на интервале, то для любых x₁ < x₂ из интервала f(x₂) − f(x₁) = f′(ξ)(x₂ − x₁) = 0, то есть f(x₁) = f(x₂). (На этом факте стоит теорема о том, что две первообразные отличаются на константу, лекция 11.)
  • Оценка приращения. Если |f′(x)| ≤ M на (a, b), то |f(x₂) − f(x₁)| ≤ M·|x₂ − x₁|. Например, |sin x₂ − sin x₁| ≤ |x₂ − x₁|, так как |cos ξ| ≤ 1.
  • Знак производной и монотонность. Если f′ > 0 на интервале, то f(x₂) − f(x₁) = f′(ξ)(x₂ − x₁) > 0 при x₂ > x₁: функция возрастает. Подробнее в лекции 10.

Теорема Коши: Лагранж для пары функций

Теорема 4 (Коши)

Пусть функции f и g: 1° непрерывны на отрезке [a, b]; 2° дифференцируемы на интервале (a, b); 3° g′ ≠ 0 на (a, b). Тогда существует точка ξ ∈ (a, b), для которой справедлива формула конечных приращений Коши: (f(b) − f(a)) / (g(b) − g(a)) = f′(ξ) / g′(ξ).

Условие 3° делает две вещи. Во-первых, из него следует, что g(b) ≠ g(a) (иначе по теореме Ролля g′ обращалась бы в нуль в некоторой точке (a, b)), то есть левая часть имеет смысл. Во-вторых, оно гарантирует g′(ξ) ≠ 0, то есть правую часть можно записать дробью.

Доказательство из лекции. Положим F(x) = f(x) − λg(x) и выберем λ так, чтобы F(a) = F(b), то есть f(a) − λg(a) = f(b) − λg(b). Отсюда λ = (f(b) − f(a))/(g(b) − g(a)). Функция F удовлетворяет условиям теоремы Ролля, значит, найдётся ξ ∈ (a, b), для которого F′(ξ) = f′(ξ) − λg′(ξ) = 0, то есть f′(ξ)/g′(ξ) = λ.

Замечание

В лекции на стр. 3 равенство F(a) = F(b) записано как f(a) − λg(a) = f(b) − λg(a). Это опечатка: в правой части должно быть g(b), как в выводе выше, иначе λ не получить.

Лагранж — частный случай Коши при g(x) = x: тогда g′ = 1 ≠ 0, g(b) − g(a) = b − a, и формула Коши превращается в формулу Лагранжа.

Геометрия. Рассмотрим кривую, заданную параметрически: x = g(t), y = f(t), t ∈ [a, b]. Хорда соединяет точки при t = a и t = b, её наклон (f(b) − f(a))/(g(b) − g(a)). Наклон касательной в точке с параметром t равен f′(t)/g′(t) (лекция 8). Теорема Коши говорит: найдётся значение параметра, при котором касательная параллельна хорде. Условие g′ ≠ 0 значит, что x меняется со скоростью, отличной от нуля, то есть вертикальных касательных и острий нет.

Что будет без условия g′ ≠ 0

Возьмём f(x) = x², g(x) = x³ на [−1, 1]. Условия 1°, 2° выполнены, g(1) − g(−1) = 2 ≠ 0, но g′(x) = 3x² обращается в нуль в точке x = 0 — условие 3° нарушено. Левая часть формулы равна (1 − 1)/2 = 0, а правая f′(ξ)/g′(ξ) = 2ξ/(3ξ²) = 2/(3ξ) ни при каком ξ ≠ 0 нулём не бывает. Ни одной подходящей точки нет.

Дополнительно к лекции (опорный конспект)

Без деления формула Коши верна и без условия 3°: (f(b) − f(a))·g′(ξ) = (g(b) − g(a))·f′(ξ) (доказательство то же: F(x) = (f(b) − f(a))g(x) − (g(b) − g(a))f(x), F(a) = F(b), по теореме Ролля F′(ξ) = 0). В примере выше ξ = 0: 0·0 = 2·0. В опорном конспекте теорема Коши приведена с делением, но только с двумя условиями. В такой записи она неверна (пример выше); держись формулировки лекции, с условием g′ ≠ 0.

Как теоремы выводятся друг из друга. Ферма ⟹ Ролль (экстремум внутри отрезка). Ролль ⟹ Лагранж (вычитаем из f наклонную прямую λx) и Ролль ⟹ Коши (вычитаем λg(x)): оба раза Ролль применяют к новой функции F = f − λ·(вторая функция). Как частные случаи теоремы вложены так: Ролль ⊂ Лагранж ⊂ Коши (в Лагранже g(x) = x, в Ролле ещё f(a) = f(b)). Из двух формул Лагранжа теорема Коши напрямую не получается (упражнение 2).

Контрпримеры для Коши. Для условия 3° — x², x³ на [−1, 1] (выше). Для условий 1° и 2° берут g(x) = x: тогда g′ = 1 ≠ 0, формула Коши превращается в формулу Лагранжа, и подходят примеры Лагранжа: |x| на [−1, 2] (нет дифференцируемости) и f = 0 на [0, 1), f(1) = 1 (нет непрерывности на отрезке).

Как проверять и применять: алгоритм

  • Выпиши функцию и отрезок [a, b].
  • Непрерывность на отрезке [a, b] (включая концы): функция элементарна и определена в каждой точке отрезка. Поищи разрывы: нуль в знаменателе, логарифм от неположительного, корень чётной степени от отрицательного.
  • Дифференцируемость на интервале (a, b): найди точки внутри, где производной нет. Типичные виновники: модуль в точке, где подмодульное выражение равно нулю (угол); √x, ∛x² в нуле (вертикальная касательная или острие); нуль в знаменателе производной.
  • Третье условие. Для Ролля сравни f(a) и f(b); для Коши проверь g′ ≠ 0 на всём (a, b).
  • Найди ξ. Для Ролля реши f′(ξ) = 0, для Лагранжа f′(ξ) = (f(b) − f(a))/(b − a), для Коши f′(ξ)/g′(ξ) = (f(b) − f(a))/(g(b) − g(a)). Оставь только корни строго внутри (a, b): концы не подходят.
  • Если условие нарушено, пиши «теорема неприменима»: вывод может быть как ложным, так и верным.

Разобранные примеры

Пример 1: Ролль, точек дведополнительно
Проверить условия теоремы Ролля для f(x) = x³ − 3x на [−√3, √3] и найти ξ.

  1. Условие 1°. Многочлен непрерывен на всей прямой, в частности на [−√3, √3]. Условие 2°. Многочлен дифференцируем всюду.

  2. Условие 3°. f(−√3) = −3√3 + 3√3 = 0 и f(√3) = 3√3 − 3√3 = 0, то есть f(a) = f(b). Все условия выполнены.

  3. Находим ξ. f′(x) = 3x² − 3 = 0, откуда x² = 1, x = ±1. Оба корня лежат в (−√3, √3) ≈ (−1,73; 1,73). Горизонтальных касательных две: при ξ = −1 (f = 2) и ξ = 1 (f = −2), как на рисунке выше.

ξ = −1 и ξ = 1: теорема гарантирует хотя бы одну точку, и подходят обе.

Пример 2: Ролль неприменим (острие)дополнительно
Применима ли теорема Ролля к f(x) = 1 − ∛(x²) на [−1, 1]? Есть ли точка ξ с f′(ξ) = 0?

  1. f(−1) = 1 − 1 = 0 и f(1) = 0, так что условие 3° выполнено. Функция непрерывна на [−1, 1] (кубический корень непрерывен), условие 1° верно.

  2. Производная при x ≠ 0: f′(x) = −(2/3)·x−1/3. В нуле она не существует: f′(x) → ∓∞ при x → 0±, график имеет острие (вершина (0, 1), касательная вертикальна). Условие 2° в точке x = 0 ∈ (−1, 1) нарушено.

  3. Проверим вывод: f′(x) = −(2/3)x−1/3 = 0 не имеет решений. Точки ξ нет, так что условие 2° нельзя выбросить, даже если функция непрерывна и принимает равные значения.

Теорема неприменима; вывод ложен: горизонтальной касательной на (−1, 1) нет.

Пример 3: Лагранж, найти ξдополнительно
Для f(x) = √x на [1, 4] проверить условия теоремы Лагранжа и найти ξ.

  1. Корень непрерывен на [0, +∞), значит, на [1, 4]; дифференцируем на (1, 4) (производная 1/(2√x) существует при x > 0). Условия 1°, 2° выполнены.

  2. Наклон хорды: (f(4) − f(1))/(4 − 1) = (2 − 1)/3 = 1/3. Уравнение f′(ξ) = 1/3: 1/(2√ξ) = 1/3, √ξ = 3/2, ξ = 9/4 = 2,25.

  3. Проверка: 2,25 ∈ (1, 4), f′(9/4) = 1/(2·1,5) = 1/3. Это точка, где касательная параллельна хорде (рисунок выше).

ξ = 9/4.

Пример 4: Кошидополнительно
Для f(x) = sin x, g(x) = cos x на [0, π/2] проверить условия теоремы Коши и найти ξ.

  1. Обе функции непрерывны и дифференцируемы всюду. Условие 3°: g′(x) = −sin x ≠ 0 на (0, π/2), потому что sin x > 0 внутри этого интервала (нуль синуса только в концах). Условия выполнены.

  2. Левая часть: (f(π/2) − f(0))/(g(π/2) − g(0)) = (1 − 0)/(0 − 1) = −1. Правая: f′(ξ)/g′(ξ) = cos ξ/(−sin ξ) = −ctg ξ. Уравнение −ctg ξ = −1 даёт ctg ξ = 1, ξ = π/4.

  3. Точка π/4 ≈ 0,785 лежит строго внутри (0, π/2).

ξ = π/4.

Пример 5: единственность корнядополнительно
Доказать, что уравнение x³ + 2x − 5 = 0 имеет ровно один вещественный корень.

  1. Существование. f(x) = x³ + 2x − 5 непрерывна, f(1) = −2 < 0, f(2) = 7 > 0. По теореме о промежуточном значении (лекция 7) корень на (1, 2) есть.

  2. Единственность. Допустим, корней два: x₁ < x₂, f(x₁) = f(x₂) = 0. Многочлен непрерывен и дифференцируем всюду, значит, по теореме Ролля найдётся ξ ∈ (x₁, x₂), для которого f′(ξ) = 3ξ² + 2 = 0.

  3. Но 3ξ² + 2 ≥ 2 > 0 при любом ξ. Противоречие, значит, корней не больше одного.

Корень существует и единствен.

Пример 6: неравенство по Лагранжудополнительно
Доказать, что ln(1 + x) < x при x > 0.

  1. Возьмём f(t) = ln(1 + t) на отрезке [0, x], x > 0. Она непрерывна на [0, x] и дифференцируема на (0, x), f′(t) = 1/(1 + t).

  2. По теореме Лагранжа ln(1 + x) − ln 1 = f′(ξ)·x = x/(1 + ξ) для некоторого ξ ∈ (0, x).

  3. Так как ξ > 0, 1 + ξ > 1, поэтому x/(1 + ξ) < x. Следовательно, ln(1 + x) < x.

Неравенство доказано; множитель 1/(1 + ξ) < 1 даёт строгость.

Упражнения лекции: разбор

В лекции два упражнения без ответов. Ниже разбор, он наш, не лекционный.

Упражнение 1: предел производнойиз лекции, стр. 2
Доказать: если существует limx→x₀ f′(x) = L, то существует f′(x₀) = L. Каков аналог для односторонних пределов? Может ли производная иметь скачок?

  1. В условии неявно предполагается, что f непрерывна в x₀, дифференцируема в проколотой окрестности, а L конечно (при L = ±∞ получится бесконечная производная: вертикальная касательная). Без непрерывности утверждение неверно: f(0) = 1, f(x) = 0 при x ≠ 0; f′(x) = 0 при x ≠ 0, lim f′ = 0, но f′(0) не существует.

  2. Доказательство. Для x рядом с x₀ применим теорему Лагранжа на отрезке с концами x₀, x: (f(x) − f(x₀))/(x − x₀) = f′(ξ_x), ξ_x между x₀ и x. При x → x₀ точка ξ_x тоже стремится к x₀, поэтому f′(ξ_x) → L. Значит, f′(x₀) существует и равна L.

  3. Односторонний аналог. Если f непрерывна в x₀ справа и существует limx→x₀+0 f′(x) = L, то правая производная в точке x₀ существует и равна L (то же доказательство на [x₀, x]). Слева аналогично.

  4. Скачок? Нет. Пусть f′(x₀) существует (тогда f непрерывна в x₀) и существуют конечные пределы f′(x₀ + 0), f′(x₀ − 0). По одностороннему аналогу оба равны f′(x₀), значит, равны между собой, скачка нет. Разрыв производной второго рода возможен: для f(x) = x²·sin(1/x), f(0) = 0 имеем f′(0) = 0, а f′(x) = 2x·sin(1/x) − cos(1/x) при x ≠ 0 предела в нуле не имеет.

Да, если f непрерывна в x₀ и L конечно: f′(x₀) = lim f′(x). Производная не имеет скачков (первого рода), но может иметь разрыв второго рода.

Упражнение 2: нельзя делить две формулы Лагранжаиз лекции, стр. 3
Можно ли доказать теорему Коши, записав формулы Лагранжа для f и для g и поделив почленно первую на вторую?

  1. Нет. В формулах f(b) − f(a) = f′(ξ₁)(b − a) и g(b) − g(a) = g′(ξ₂)(b − a) точки ξ₁ и ξ₂ разные (для f и для g в отдельности). После деления получится f′(ξ₁)/g′(ξ₂), а нужно f′(ξ)/g′(ξ) в одной и той же точке.

  2. Пример: f(x) = x², g(x) = x³ на [0, 1]. Для f: 1 = 2ξ₁, ξ₁ = 1/2. Для g: 1 = 3ξ₂², ξ₂ = 1/√3 ≈ 0,577. Для Коши: 1/1 = 2ξ/(3ξ²) = 2/(3ξ), ξ = 2/3 ≈ 0,667. Три разные точки.

Нельзя: в двух формулах Лагранжа точки разные, а в формуле Коши точка одна.

Частые ошибки

Так нельзя

«Теорема Ролля: если f(a) = f(b), то найдётся точка с f′ = 0» (без остальных условий).

Так правильно

Нужны ещё непрерывность на [a, b] и дифференцируемость на (a, b). Для |x| на [−1, 1] значения на концах равны, а точки с f′ = 0 нет.

Так нельзя

«Точка ξ — середина отрезка» или «единственная».

Так правильно

Теорема лишь утверждает, что ξ существует. Для x³ − 3x их две; для x³ на [0, 2] из 3ξ² = 4 получаем ξ = 2/√3 ≈ 1,15, не середину 1.

Так нельзя

«Для Лагранжа функция должна быть дифференцируема и на концах отрезка».

Так правильно

На концах нужна только непрерывность; дифференцируемость нужна на открытом интервале. Поэтому √x на [0, 1] под теорему подходит.

Так нельзя

«Если f′(x₀) = 0, то в x₀ экстремум» (обращение теоремы Ферма).

Так правильно

Ферма говорит только в одну сторону: экстремум и производная существует ⟹ f′ = 0. Обратное неверно (x³ в нуле).

Так нельзя

«Теорему Коши получим, поделив две формулы Лагранжа».

Так правильно

В формулах Лагранжа точки ξ разные, а в формуле Коши точка одна. Доказательство идёт через F = f − λg и теорему Ролля.

Так нельзя

Искать ξ среди всех корней уравнения, включая концы отрезка.

Так правильно

ξ берётся из открытого интервала (a, b). Для x³ на [−1, 2] уравнение 3ξ² = 3 даёт ξ = ±1, но подходит только ξ = 1; −1 — это конец отрезка.

Кратко для повторения

Кратко для повторения

  • Ферма: f определена на U(x₀), в x₀ наибольшее или наименьшее значение на U(x₀), существует f′(x₀) ⟹ f′(x₀) = 0. Обратное неверно (x³); без производной (|x|), без экстремума (f = x) и на конце отрезка вывод не работает.
  • Ролль: непрерывна на [a, b], дифференцируема на (a, b), f(a) = f(b) ⟹ ∃ξ ∈ (a, b): f′(ξ) = 0. Доказательство: Вейерштрасс + Ферма. Для каждого из трёх условий есть контрпример.
  • Лагранж: непрерывна на [a, b], дифференцируема на (a, b) ⟹ f(b) − f(a) = f′(ξ)(b − a); касательная параллельна хорде. Доказательство: Ролль для F = f − λx.
  • Коши: f, g непрерывны на [a, b], дифференцируемы на (a, b), g′ ≠ 0 на (a, b) ⟹ (f(b) − f(a))/(g(b) − g(a)) = f′(ξ)/g′(ξ). Лагранж — случай g = x. Доказательство: Ролль для F = f − λg.
  • ξ ищут как корень уравнения внутри открытого интервала; условия проверяют сначала, на концах нужна только непрерывность.
  • Теоремы дают достаточные условия: при нарушении вывод не гарантирован.

4
Найдите точку ξ ∈ (−1, 2) из теоремы Лагранжа для f(x) = x³ на [−1, 2].

Показать решение

Наклон хорды (8 − (−1))/(2 − (−1)) = 9/3 = 3. Уравнение f′(ξ) = 3ξ² = 3 даёт ξ = ±1. Интервалу (−1, 2) принадлежит только ξ = 1.

5
Теорема Коши для f(x) = x³, g(x) = x² на [0, 2] (условие g′ ≠ 0 на (0, 2) выполнено). Найдите ξ и запишите ответ обыкновенной дробью.

Показать решение

Левая часть: (8 − 0)/(4 − 0) = 2. Правая: f′(ξ)/g′(ξ) = 3ξ²/(2ξ) = 3ξ/2. Уравнение 3ξ/2 = 2 даёт ξ = 4/3 ∈ (0, 2).

6
Для какой из функций теорема Лагранжа неприменима на отрезке [0, 4]?
Варианты ответа

Показать решение

У |x − 2| в точке x = 2 ∈ (0, 4) угол: условие дифференцируемости на (0, 4) нарушено. Для √x производной в нуле нет, но она нужна только на интервале (0, 4), поэтому теорема применима.
