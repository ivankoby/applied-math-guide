Формулу Тейлора можно получить дифференцированием, но чаще её получают быстрее — алгеброй: подстановкой, умножением, готовой геометрической прогрессией. Гарантирует, что при этом получится та же формула, теорема единственности: любое представление функции в виде «многочлен степени не выше n плюс o((x − x₀)n)» единственно, а если существует f(n)(x₀), то оно и есть формула Тейлора. В статье: теорема единственности и следствие, таблица разложений основных функций (Маклорен), правила обращения с o(…), пределы по Тейлору, приближённые вычисления и разбор упражнений лекции.

Теорема единственности

Теорема 3 (единственности)

Пусть в проколотой окрестности Ů(x₀) при x → x₀ справедливы два представления f(x) = a₀ + a₁(x − x₀) + … + an(x − x₀)n + o((x − x₀)n) и f(x) = b₀ + b₁(x − x₀) + … + bn(x − x₀)n + o((x − x₀)n). Тогда a₀ = b₀, a₁ = b₁, …, an = bn.

Обрати внимание: в условии нет производных. Теорема говорит только о том, что многочлен степени не выше n, приближающий f с точностью o((x − x₀)n), не может быть двумя разными.

Доказательство из лекции. Вычтем представления почленно: достаточно доказать, что из

c₀ + c₁(x − x₀) + … + cn(x − x₀)n = o((x − x₀)n) при x → x₀ (2)
следует c₀ = c₁ = … = cn = 0 (здесь ck = ak − bk).

Перейдём в (2) к пределу при x → x₀: получим c₀ = 0. Разделим (2) на (x − x₀): c₁ + c₂(x − x₀) + … + cn(x − x₀)n−1 = o((x − x₀)n−1); предел даёт c₁ = 0. Разделим на x − x₀ ещё раз, перейдём к пределу — c₂ = 0. Продолжая, получаем c₀ = c₁ = … = cn = 0.

Следствие: разложение любым способом — это формула Тейлора

Следствие

Пусть существует f(n)(x₀) и f(x) = a₀ + a₁(x − x₀) + … + an(x − x₀)n + o((x − x₀)n) при x → x₀ (3). Тогда (3) является разложением f по формуле Тейлора с остаточным членом в форме Пеано: ak = f(k)(x₀)/k!.

Замечание

В лекции на стр. 6 в формуле (3) перед o((x − x₀)n) напечатан знак «=» вместо «+». Это опечатка: при «=» получилось бы, что многочлен (а значит, и сама f) есть o((x − x₀)n), откуда по теореме 3 все ak = 0, что неверно для общей функции. Верно … + an(x − x₀)n + o((x − x₀)n), как в теореме 3.

Доказательство. По теореме Пеано (статья 9.4) для f справедливо равенство (1) с остатком o((x − x₀)n). Это второе представление того же вида. По теореме единственности его коэффициенты совпадают с ak.

Зачем это нужно. (1) Новые разложения получают алгеброй, не вычисляя n производных. (2) Коэффициенты определяют производные: f(k)(x₀) = k!·ak. (3) Условие «существует f(n)(x₀)» необходимо для следствия: без него разложение вида (3) может существовать у функции, у которой даже второй производной нет (упражнение 1 ниже).

Пример: геометрическая прогрессия

Пример: 1/(1 − x)из лекции, стр. 7
Доказать, что 1/(1 − x) = 1 + x + … + xn + o(xn) при x → 0 и найти производные f(k)(0).

  1. При x ≠ 1 сумма геометрической прогрессии: 1 + x + x² + … + xn = (1 − xn+1)/(1 − x) (формула верна при всех x ≠ 1, а не только при |x| < 1). Отсюда 1/(1 − x) = 1 + x + … + xn + rn(x), где rn(x) = xn+1/(1 − x).

  2. Остаток rn(x)/xn = x/(1 − x) → 0 при x → 0, то есть rn(x) = o(xn). По следствию из теоремы единственности полученное разложение является формулой Тейлора функции f(x) = 1/(1 − x).

  3. Коэффициенты все равны 1, поэтому f(k)(0)/k! = 1, то есть f(k)(0) = k! (совпадает с таблицей из статьи 9.1: (1/(1 − x))(k) = k!/(1 − x)k+1).

1/(1 − x) = 1 + x + … + xn + o(xn), f(k)(0) = k!.

Замечание

В лекции на стр. 7 остаток записан как rn(x) = −xn+1/(1 − x). Знак ошибочный: 1/(1 − x) − (1 − xn+1)/(1 − x) = +xn+1/(1 − x). Проверка: n = 1, x = 1/2: 1/(1 − 1/2) = 2, сумма 1 + 1/2 = 3/2, остаток 1/2 = (1/4)/(1/2) > 0. На вывод rn = o(xn) знак не влияет.

Односторонние разложения (замечание 1 лекции). Теоремы Пеано, Лагранжа, единственности и следствие верны и для функции, заданной лишь в полуокрестности U(x₀ + 0) или U(x₀ − 0); производные f(k)(x₀) тогда понимаются как односторонние.

Разложения основных функций при x → 0 (формула Маклорена)

Формулу Тейлора при x₀ = 0 называют формулой Маклорена. Вот разложения из лекции (стр. 7–8) и две добавки к ним. Каждая получается из значений f(k)(0) и деления на k!.

Замечание

В лекции на стр. 8 (по картинке) разложение косинуса напечатано так: cos x = 1 − x + x²/2! + x⁴/4! − x⁶/6! + …. Это опечатка: лишнее слагаемое −x и неверный знак при x²/2!. Правильно: cos x = 1 − x²/2! + x⁴/4! − x⁶/6! + … + (−1)nx2n/(2n)! + o(x2n+1) (производные в нуле 1, 0, −1, 0, 1, …, в разложении только чётные степени).

Откуда остатки. Для eˣ по форме Лагранжа rn(x) = eθx/(n + 1)!·xn+1 = O(xn+1) = o(xn) при 0 < θ < 1. Для ln(1 + x): rn(x) = (−1)n/(n + 1)·xn+1/(1 + θx)n+1 = o(xn). Для sin x выписан остаток после нулевого члена порядка 2n + 2, поэтому o(x2n+2); для cos x после нулевого члена порядка 2n + 1 — o(x2n+1).

Частные случаи (1 + x)α. При α = −1 получается 1/(1 + x); при натуральном α = n все коэффициенты с номером больше n равны нулю (в них множитель α − n = 0), и остаток нулевой: это бином Ньютона (упражнение 2 ниже).

Арифметика с o(…) (дополнительно к лекции)

Чтобы получать новые разложения алгеброй, нужны правила. При x → 0 (для x₀ ≠ 0 — с x − x₀), для m, n ≥ 0:

  • o(xn) ± o(xn) = o(xn), c·o(xn) = o(xn) (c — постоянная);
  • xm·o(xn) = o(xm+n), o(xm)·o(xn) = o(xm+n);
  • o(xm) = o(xn) при m ≥ n: член более высокого порядка «поглощается» (o(x³) + o(x²) = o(x²));
  • подстановка: если g(u) = … + o(uk) при u → 0, а u(x) → 0 и |u(x)| ≤ C|x|s, то после подстановки o(uk) = o(xks) (для u = −x², k = 3: o(x⁶)).

Сколько членов брать. Раскладывай до порядка, при котором после сокращений в числителе и знаменателе останется первый ненулевой член (обычно это порядок главной части знаменателя; в примере 3 нужен x³, хотя первые члены eˣ и e−x равны 1). Если числитель и знаменатель обращаются в нуль порядка k, нужны разложения до порядка k. Недобрать порядок — типичная ошибка (пример 5 ниже).

Как получать разложения: подстановка и умножение

Пример 1: подстановкадополнительно
Разложить e−x² по формуле Маклорена до o(x⁶) и найти f(6)(0).

  1. В разложении eᵘ = 1 + u + u²/2 + u³/6 + o(u³) подставим u = −x² (при x → 0 u → 0). Тогда u² = x⁴, u³ = −x⁶, o(u³) = o(x⁶):

    e−x² = 1 − x² + x⁴/2 − x⁶/6 + o(x⁶)

  2. Многочлен получен алгеброй, а функция имеет производные любого порядка, значит, по следствию из теоремы единственности это её формула Тейлора. Коэффициент при x⁶ равен −1/6.

  3. Следовательно, f(6)(0)/6! = −1/6, f(6)(0) = −720/6 = −120. Производные нечётных порядков в нуле равны нулю (нечётных степеней в разложении нет): функция чётная.

e−x² = 1 − x² + x⁴/2 − x⁶/6 + o(x⁶), f(6)(0) = −120.

Пример 2: произведениедополнительно
Разложить eˣ·sin x до o(x³).

  1. Берём eˣ = 1 + x + x²/2 + o(x²) и sin x = x − x³/6 + o(x⁴). Перемножаем, оставляя члены до x³: (1 + x + x²/2)(x − x³/6) = x + x² + x³/2 − x³/6 + … (остальные слагаемые степени не ниже 4). Остатки: o(x²)·x = o(x³), o(x⁴) = o(x³).

  2. Итог: eˣ·sin x = x + x² + (1/2 − 1/6)x³ + o(x³) = x + x² + x³/3 + o(x³). Проверка через производные: f′(0) = 1, f″(0)/2 = 1, f‴(0)/6 = 2/6 = 1/3 (f‴ = 2eˣ(cos x − sin x)).

eˣ·sin x = x + x² + x³/3 + o(x³).

Пределы по Тейлору

Разложение с остатком Пеано превращает предел в арифметику: в числителе и знаменателе остаются главные части (первые ненулевые члены), а остатки o(…) исчезают в пределе. Лекция предлагает два предела (упражнение 3, стр. 8) и даёт способ — разложения с остатком Пеано; ответов в лекции нет, решения наши.

Пример 3: lim (eˣ − e⁻ˣ − 2x)/(x − sin x)из лекции, упражнение 3, стр. 8
Найти limx→0 (eˣ − e−x − 2x)/(x − sin x) с помощью разложений Тейлора.

  1. Числитель: eˣ = 1 + x + x²/2 + x³/6 + o(x³), e−x = 1 − x + x²/2 − x³/6 + o(x³). Разность eˣ − e−x = 2x + x³/3 + o(x³), значит, числитель = x³/3 + o(x³).

  2. Знаменатель: sin x = x − x³/6 + o(x⁴), поэтому x − sin x = x³/6 + o(x⁴) = x³/6 + o(x³).

  3. Предел: (x³/3 + o(x³))/(x³/6 + o(x³)) = (1/3 + o(1))/(1/6 + o(1)) → (1/3)/(1/6) = 2. Нужны были члены порядка x³: до них и раскладываем. Проверка числом: при x = 0,05 дробь равна 2,0005.

Пример 4: lim (1/x² − 1/sin²x)из лекции, упражнение 3, стр. 8
Найти limx→0 (1/x² − 1/sin²x) с помощью разложений Тейлора.

  1. Приведём к общему знаменателю: 1/x² − 1/sin²x = (sin²x − x²)/(x²·sin²x). Тип 0/0 (числитель и знаменатель стремятся к нулю).

  2. sin x = x − x³/6 + o(x⁴). Тогда sin²x = x² − x⁴/3 + x⁶/36 + o(x⁵) = x² − x⁴/3 + o(x⁴), и числитель sin²x − x² = −x⁴/3 + o(x⁴).

  3. Знаменатель: x²·sin²x = x²(x² + o(x²)) = x⁴ + o(x⁴).

  4. Предел: (−x⁴/3 + o(x⁴))/(x⁴ + o(x⁴)) → −1/3. Проверка при x = 0,05: 1/x² − 1/sin²x ≈ −0,3335.

Приближённые вычисления и оценка погрешности

Пример 6: число eдополнительно
Вычислить e с погрешностью меньше 10⁻⁴ с помощью формулы Маклорена для eˣ.

  1. Форма Лагранжа при x = 1: e = 1 + 1 + 1/2! + … + 1/n! + rn, rn = eθ/(n + 1)!, 0 < θ < 1. Так как eθ < e < 3, rn < 3/(n + 1)!.

  2. Ищем n, чтобы 3/(n + 1)! < 10⁻⁴: n = 6 даёт 3/5040 ≈ 6·10⁻⁴ — мало; n = 7 даёт 3/40320 ≈ 7,4·10⁻⁵ < 10⁻⁴ — подходит.

  3. Сумма до n = 7: 1 + 1 + 0,5 + 0,166667 + 0,041667 + 0,008333 + 0,001389 + 0,000198 ≈ 2,71825. Итак, e ≈ 2,71825 с погрешностью меньше 0,0001 (точное значение 2,71828…).

Упражнения лекции: разбор

Упражнение 1: влечёт ли (3) существование производных?из лекции, стр. 7
Пусть для функции f выполняется (3) при n = 3. Выяснить, влечёт ли это существование f′(x₀), f″(x₀), f‴(x₀).

  1. f′(x₀) существует. Будем считать, что (3) выполнено и в самой точке x₀, то есть a₀ = f(x₀) (иначе f может быть разрывной: f(x) = x³ при x ≠ 0, f(0) = 1 удовлетворяет (3) в проколотой окрестности нуля при a₃ = 1, остальных ak = 0, но f′(0) не существует). Из (3) при n = 3 получаем f(x) = a₀ + a₁(x − x₀) + o(x − x₀) (члены от второго порядка и выше входят в o(x − x₀)). Отсюда f непрерывна в x₀ и дифференцируема с f′(x₀) = a₁.

  2. f″(x₀) и f‴(x₀) могут не существовать. Пример: f(x) = x⁴·sin(1/x²) при x ≠ 0, f(0) = 0. Так как |f(x)| ≤ x⁴ = o(x³), (3) выполнено при n = 3 с a₀ = a₁ = a₂ = a₃ = 0.

  3. Но f′(0) = lim f(x)/x = lim x³·sin(1/x²) = 0, а при x ≠ 0 f′(x) = 4x³·sin(1/x²) − 2x·cos(1/x²). Тогда f′(x)/x = 4x²·sin(1/x²) − 2cos(1/x²) предела при x → 0 не имеет (колеблется между −2 и 2), то есть f″(0) не существует, а с ней и f‴(0).

  4. Вывод: разложение вида (3), верное и в точке x₀, гарантирует только существование f′(x₀). Условие «существует f(n)(x₀)» в следствии нельзя заменить на сам факт разложения.

Если (3) верно и в точке x₀, то f′(x₀) существует; f″(x₀), f‴(x₀) — не обязательно (пример x⁴·sin(1/x²)).

Упражнение 2: бином Ньютонаиз лекции, стр. 8
Получить формулу бинома (1 + x)n = Σ Cnkxk из разложения (1 + x)α при α = n ∈ ℕ.

  1. Для f(x) = (1 + x)n производные f(k)(x) = n(n − 1)…(n − k + 1)(1 + x)n−k. При x = 0: f(k)(0) = n!/(n − k)! для k ≤ n и f(k)(0) = 0 для k > n (в произведении есть множитель n − n = 0).

  2. Коэффициент при xk: f(k)(0)/k! = n!/(k!(n − k)!) = Cnk. Остаток в форме Лагранжа после члена с xn: f(n+1) ≡ 0, поэтому rn = 0.

  3. Значит, (1 + x)n = Σk=0n Cnkxk точно, при всех x. (Из формулы с o(xn) и теоремы единственности коэффициенты получаются те же.)

(1 + x)n = Σk=0n Cnkxk.

Упражнение 3 (два предела) разобрано выше в примерах 3 и 4.

Частые ошибки

Так нельзя

cos x = 1 − x + x²/2! + … (переписанное из лекции) или cos x = 1 − x²/2 + x⁴/4 − ….

Так правильно

cos x = 1 − x²/2! + x⁴/4! − x⁶/6! + …: только чётные степени, знаки чередуются, в знаменателях факториалы 2!, 4!, 6!.

Так нельзя

sin x = x − x³/3 + x⁵/5 − ….

Так правильно

В знаменателях факториалы: sin x = x − x³/3! + x⁵/5! − … = x − x³/6 + x⁵/120 − …. Для ln(1 + x), наоборот, знаменатели просто k.

Так нельзя

Взять sin x = x + o(x) в пределе (sin x − x)/x³ и получить нуль.

Так правильно

Нужен порядок x³: sin x = x − x³/6 + o(x⁴), предел равен −1/6. Порядок разложения определяется знаменателем и сокращениями.

Так нельзя

Применять разложение при x → 0 для больших x или разлагать ln x в нуле.

Так правильно

Разложения Маклорена — утверждения о x → 0. Функции, не определённые в нуле (ln x), раскладывают около другой точки (ln x при x₀ = 1) или переходят к ln(1 + x).

Так нельзя

Писать … вместо остатка и считать, что формула — бесконечный ряд.

Так правильно

В лекции — конечная сумма плюс остаток o(xn). Без остатка равенство неверно.

Так нельзя

Складывать остатки разных порядков по принципу «больший остаток важнее»: o(x²) + o(x⁴) = o(x⁴).

Так правильно

Остаётся худший остаток: o(x²) + o(x⁴) = o(x²). Член более высокого порядка поглощается членом более низкого.

Кратко для повторения

Кратко для повторения

  • Теорема единственности: если f = P + o((x − x₀)n) и f = Q + o((x − x₀)n) с многочленами P, Q степени не выше n, то P = Q. Доказательство — последовательные пределы после деления на x − x₀.
  • Следствие: если существует f(n)(x₀) и f = a₀ + … + an(x − x₀)n + o((x − x₀)n), то это формула Тейлора: ak = f(k)(x₀)/k!. В лекции в (3) опечатка: вместо + o напечатано = o.
  • Разложения при x → 0: eˣ, sin x, cos x (только чётные степени), ln(1 + x), (1 + x)α, 1/(1 − x); остатки o(xn), у sin — o(x2n+2), у cos — o(x2n+1).
  • Формула Тейлора при x₀ = 0 — формула Маклорена. Для функции, заданной в полуокрестности, производные односторонние.
  • Новые разложения: подстановка, умножение, геометрическая прогрессия. Правило остатков: o(xm)·xk = o(xm+k); o(xm) = o(xn) при m ≥ n.
  • Предел по Тейлору: раскладываем числитель и знаменатель до первого сохраняющегося члена, остатки исчезают. Погрешность оценивает форма Лагранжа.
