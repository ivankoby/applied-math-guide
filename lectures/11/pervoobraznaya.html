Статья 11.1

Первообразная и неопределённый интеграл

Дифференцирование по заданной функции находит её производную. Интегрирование решает обратную задачу: дана производная f, найти функцию F, у которой F′ = f. Так по скорости восстанавливают путь, а по угловому коэффициенту касательной — кривую. У обратной задачи есть особенность: ответ не один, а целое семейство функций, отличающихся на постоянную. В статье: точное определение первообразной (где важны промежуток и непрерывность), теорема о том, почему любая первообразная имеет вид F + C, неопределённый интеграл и его запись, роль dx, вопрос о существовании первообразной (у sign x её нет) и проверка ответа дифференцированием.

Обратная задача: из производной в функцию

Производная функции x² равна 2x; значит, x² — первообразная для 2x. Но и x² + 5, x² − 3, x² + π имеют ту же производную 2x: при дифференцировании постоянная пропадает. Поэтому «найти функцию по её производной» всегда означает найти семейство функций. Обозначения: f (малая буква) — заданная функция, F (большая) — её первообразная, F′ = f.

Определение первообразной (лекция, стр. 1)

Определение 1. Первообразная

Пусть функция f определена на промежутке Δ числовой оси: интервале, полуинтервале или отрезке, конечном или бесконечном. Функция F, определённая на том же промежутке, называется первообразной функции f на Δ, если (1) F непрерывна на Δ и (2) во всех внутренних точках x промежутка Δ существует F′(x) и F′(x) = f(x).

Внутренние точки — все точки промежутка, кроме его концов. Концы нужны для непрерывности, а равенство F′ = f требуется только внутри. Поэтому в конце a ∈ Δ первообразная обязательно непрерывна, односторонняя производная в a может не существовать, а если существует, то может не совпасть с f(a). В задачах мы ищем F с условием F′ = f на интервале, а значения на концах не обсуждаем.

Пример из лекции: одна F для двух разных fиз лекции, стр. 1
Пусть f(x) = 1 при 0 < x ≤ 1 и f(0) = 0. Показать, что F(x) = x, 0 ≤ x ≤ 1, — первообразная для f, а также для f₁(x) ≡ 1 на [0; 1].

  1. Условие 1: F(x) = x непрерывна на отрезке [0; 1].

  2. Условие 2: во внутренних точках 0 < x < 1 имеем F′(x) = 1 = f(x). В конце x = 0 равенство F′ = f не требуется. Правая производная F′₊(0) = 1, а f(0) = 0: они различны, и определению это не противоречит.

  3. Для f₁ ≡ 1 проверка та же: F′ = 1 = f₁ во внутренних точках. Итак, одна функция F — первообразная для разных функций f и f₁, но они совпадают во всех внутренних точках и различаются лишь в конце.

Да, оба условия определения 1 выполняются; f и f₁ отличаются только значением в точке 0.

Проверка первообразнойдополнительно к лекции
Убедиться, что F(x) = sin x − x cos x — первообразная функции f(x) = x sin x на всей числовой оси.

  1. Непрерывность: F составлена из sin x, cos x и x, она непрерывна на ℝ. Дифференцируем: F′(x) = (sin x)′ − (x cos x)′.

  2. По правилу произведения (x cos x)′ = cos x − x sin x. Тогда F′(x) = cos x − cos x + x sin x = x sin x = f(x) при всех x.

F′ = f на всей оси, значит, F — первообразная f. (Как её найти — статья 11.6.)

Почему «+ C»: любые две первообразные отличаются на постоянную

Шаг 1. Прибавив постоянную, мы снова получаем первообразную. Пусть F — первообразная f на Δ, C — число. Функция F + C непрерывна на Δ, а во внутренних точках [F(x) + C]′ = F′(x) + C′ = f(x).

Шаг 2. Других первообразных нет. Пусть Φ — ещё одна первообразная f на Δ. Тогда g = Φ − F непрерывна на Δ, и во внутренних точках g′ = Φ′ − F′ = f − f = 0. Возьмём любые x₁ < x₂ из Δ. На отрезке [x₁; x₂] функция g непрерывна, на интервале (x₁; x₂) дифференцируема, поэтому по теореме Лагранжа (лекция 9) найдётся ξ ∈ (x₁; x₂), для которого g(x₂) − g(x₁) = g′(ξ)·(x₂ − x₁) = 0. Значения g в любых двух точках равны, то есть g — постоянная.

Φ(x) = F(x) + C, x ∈ Δ (22.1)
Итог шагов 1–2: если F — одна первообразная f на промежутке Δ, то все первообразные f на Δ — это функции вида F(x) + C и только они.

Слово «промежуток» существенно. Возьмём f(x) = 1/x² на множестве x ≠ 0. Функции F₁(x) = −1/x и F₂(x) = −1/x при x < 0, F₂(x) = −1/x + 5 при x > 0 обе имеют производную 1/x² в каждой точке x ≠ 0, но их разность — не одна постоянная: она равна 0 на левой полуоси и 5 на правой. Дело в том, что множество x ≠ 0 — два промежутка, и на каждом из них постоянная своя (статья 11.3). Для множества из нескольких интервалов (как x ≠ 0) первообразной называем функцию с F′ = f в каждой его точке; её сужение на каждый интервал — первообразная в смысле определения 1, поэтому постоянные на разных интервалах независимы.

Семейство первообразных на графике

Постоянная C выбирает одну кривую из семейства. Чтобы её найти, нужно ещё одно условие, например «график проходит через точку (x₀; y₀)»: подставляем F(x₀) = y₀ и решаем уравнение относительно C.

Первообразная с заданным значениемдополнительно к лекции
Найти первообразную функции f(x) = 3x² − 2, график которой проходит через точку A(1; 4).

  1. Одна первообразная известна по таблице производных: (x³ − 2x)′ = 3x² − 2. Значит, все они имеют вид F(x) = x³ − 2x + C.

  2. Условие F(1) = 4: 1 − 2 + C = 4, откуда C = 5.

  3. Проверка: F′(x) = 3x² − 2 = f(x) и F(1) = 1 − 2 + 5 = 4.

F(x) = x³ − 2x + 5.

Неопределённый интеграл: определение и запись (стр. 2–3)

Определение 2. Неопределённый интеграл

Совокупность всех первообразных функции f на промежутке Δ называется неопределённым интегралом от f на этом промежутке и обозначается ∫ f(x) dx.

  • ∫ — знак интеграла; f(x) — подынтегральная функция; f(x) dx — подынтегральное выражение; x — переменная интегрирования.
  • Интегрировать — значит находить первообразную (неопределённый интеграл). Это действие, обратное дифференцированию.
  • Если F — какая-либо первообразная f, пишут ∫ f(x) dx = F(x) + C (формула 22.3). Строго было бы ∫ f(x) dx = {F(x) + C} (22.4): справа множество. В лекции сохранена первая запись, поэтому символ ∫ f(x) dx означает и всё множество, и любой его элемент.

Запомни

Любое равенство, в обеих частях которого стоят неопределённые интегралы, — равенство множеств (лекция, стр. 3). Поэтому ∫ 2x dx = x² + C = (x² + 5) + C: при C, пробегающем все числа, получается одно и то же множество. Постоянные, возникающие по ходу решения (C₁ + C₂, C/2, C − 7), тоже обозначают просто C, если они пробегают все числа.

Зачем нужно dx

Под знаком интеграла стоит не сама функция, а её произведение на дифференциал dx. Это нужно прежде всего, чтобы указать, по какой переменной ищется первообразная. Пример из лекции (стр. 3):

∫ x²z dx = x³z/3 + C, ∫ x²z dz = x²z²/2 + C
Подынтегральная функция одна и та же, x²z, но интегралы разные: в первом случае это функция от x (а z — постоянная), во втором — функция от z (а x — постоянная).

Есть и второе удобство: если F — первообразная f, то под знаком интеграла стоит дифференциал dF(x) = F′(x) dx = f(x) dx. По соглашению лекции (22.5) его можно записывать в любом из видов:

∫ f(x) dx = ∫ F′(x) dx = ∫ dF(x) (22.5)
Это основа приёма «подведение под знак дифференциала» (статья 11.4): dF(x) под знаком интеграла «снимается», остаётся F(x) + C.

Всегда ли первообразная существует

Лекция откладывает вопрос о существовании первообразной на позднее (п. 29.2) и пока предлагает искать их для элементарных функций. Результаты, которые полезно знать уже сейчас:

  • Достаточное условие (дополнительно к лекции, опорный конспект, п. 2.18.1). Если f непрерывна на промежутке, то на нём у f есть первообразная. Её доказательство — функция Φ(x) = ∫ₐˣ f(t) dt — появится вместе с определённым интегралом.
  • Но это условие не необходимо (добавка составителей: в конспекте этого примера нет). Функция f(x) = 2x sin(1/x) − cos(1/x), f(0) = 0, разрывна в нуле, а F(x) = x² sin(1/x), F(0) = 0, — её первообразная на ℝ: при x ≠ 0 F′ = f по правилам, а F′(0) = lim x·sin(1/x) = 0 = f(0).
  • Скачок исключает первообразную (добавка составителей). Нужна теорема Дарбу: если F дифференцируема в каждой точке интервала (α; β), то F′ принимает на нём любое значение между любыми двумя своими значениями. Пусть f = F′ и в точке c внутри промежутка есть односторонний предел L ≠ f(c), например справа. Рядом с c значения f близки к L, и значение y между f(c) и L они не принимают: это противоречит теореме Дарбу. Значит, у производной нет разрывов первого рода (скачка и устранимого), и функция со скачком во внутренней точке промежутка первообразной на нём не имеет.
Упражнение 1 из лекции: у sign x нет первообразной на ℝиз лекции, стр. 5
Доказать, что не существует функции F с F′(x) = sign x для всех x ∈ ℝ.

  1. Допустим, такая F есть. Тогда на промежутке x > 0 имеем F′ = 1. Первообразная единицы — x, значит, по теореме (22.1) F(x) = x + c₁ при x > 0. Аналогично при x < 0 F′ = −1 и F(x) = −x + c₂.

  2. F дифференцируема в нуле, поэтому непрерывна в нём: F(0) = limx→0+ (x + c₁) = c₁ и F(0) = limx→0− (−x + c₂) = c₂. Значит, c₁ = c₂ = c.

  3. Тогда F(x) = |x| + c при всех x. Но |x| не дифференцируема в нуле (лекция 8), а на ℝ точка 0 — внутренняя, и производная в ней обязана существовать. Противоречие.

Первообразной у sign x на ℝ нет. На полуоси [0; ∞) у неё первообразная x есть, на (−∞; 0] — −x: «склеить» их в одну нельзя.

Как проверить первообразную

Для любого найденного ответа подходит один способ проверки: продифференцировать ответ. Если F′(x) = f(x) на рассматриваемом промежутке, F — первообразная, как бы ни был найден ответ и как бы он ни выглядел. Если получилось что-то другое, ответ неверен. Разные на вид верные ответы могут отличаться на постоянную: (x + 1)²/2 + C и x²/2 + x + C — один и тот же интеграл ∫ (x + 1) dx. Проверка — не лишняя работа: в статьях 11.3–11.8 она ловит потерянные множители и знаки.

Частые ошибки

Так нельзя

«Первообразная функции 2x — это x²», и больше ничего.

Так правильно

Первообразных бесконечно много: x² + C при любом C. Любые две отличаются на постоянную (при условии, что рассматривается промежуток).

Так нельзя

∫ 2x dx = x² — постоянная опущена.

Так правильно

∫ 2x dx = x² + C. Без C записана одна первообразная, а не весь неопределённый интеграл.

Так нельзя

Проверять ответ, интегрируя его ещё раз, или подставлять F вместо f.

Так правильно

Проверка — дифференцирование: F′ должна совпасть с подынтегральной функцией f.

Так нельзя

«Первообразные 1/x² на всей области определения x ≠ 0 — это −1/x + C с одной постоянной».

Так правильно

x ≠ 0 — два промежутка: −1/x + C₁ при x > 0 и −1/x + C₂ при x < 0, где C₁ и C₂ независимы.

Так нельзя

∫ x²z dx и ∫ x²z dz — «одно и то же, dx можно не писать».

Так правильно

∫ x²z dx = x³z/3 + C, а ∫ x²z dz = x²z²/2 + C. Переменную интегрирования указывает dx (dz).

Так нельзя

«У любой функции есть первообразная».

Так правильно

Непрерывная функция первообразную имеет, а функция со скачком во внутренней точке промежутка — нет (sign x на ℝ).

Кратко для повторения

Кратко для повторения

  • Первообразная F функции f на промежутке Δ: F непрерывна на Δ, и F′(x) = f(x) во всех внутренних точках Δ. На концах равенство F′ = f не требуется.
  • Если F — первообразная f на промежутке, то F + C тоже, и любая первообразная имеет такой вид (22.1). Основание: (Φ − F)′ = 0 на промежутке, а такая функция постоянна (теорема Лагранжа).
  • Неопределённый интеграл ∫ f(x) dx — множество всех первообразных: ∫ f(x) dx = F(x) + C. Равенство, где слева и справа интегралы, — равенство множеств. Постоянные сливаются в одну.
  • dx указывает переменную интегрирования: ∫ x²z dx = x³z/3 + C, ∫ x²z dz = x²z²/2 + C. Под знаком интеграла f(x) dx = F′(x) dx = dF(x) (22.5).
  • Непрерывная функция имеет первообразную (дополнительно); функция со скачком во внутренней точке — нет (sign x на ℝ, упражнение 1).
  • Проверка: F′ = f. Для множества x ≠ 0 постоянные на разных полуосях независимы.

1
Отметьте все функции, которые являются первообразными функции f(x) = 4x³ на ℝ.
Варианты ответа; можно выбрать несколько

Показать решение

Дифференцируем варианты: (x⁴)′ = 4x³ — верно. (x⁴ + 7)′ = 4x³ — верно (постоянная пропадает). (x⁴ − 1/2)′ = 4x³ — верно. (12x²)′ = 24x, (4x⁴)′ = 16x³ — не подходят.

2
Функция F — первообразная функции f(x) = 6x² − 4x + 1 на ℝ и F(1) = 5. Найдите F(2).

Показать решение

Одна первообразная: 2x³ − 2x² + x (проверка: производная 6x² − 4x + 1). Значит, F(x) = 2x³ − 2x² + x + C. Из F(1) = 1 + C = 5 следует C = 4. Тогда F(2) = 16 − 8 + 2 + 4 = 14.

4
Ищем первообразную функции f(x) = 2x − 6, график которой проходит через точку A(3; 1). В каком шаге допущена первая ошибка?
Варианты ответа

Показать решение

В шаге 1 число −6 потеряло переменную: первообразная слагаемого −6 равна −6x, а не −6. Верно: F(x) = x² − 6x + C. Из 9 − 18 + C = 1 получаем C = 10, F(x) = x² − 6x + 10. Проверка: F′(x) = 2x − 6, F(3) = 9 − 18 + 10 = 1.

5
Какая из функций является первообразной функции f(x) = x cos x? Проверьте дифференцированием.
Варианты ответа

Показать решение

(x sin x + cos x)′ = sin x + x cos x − sin x = x cos x. Для остальных вариантов производные: 2 sin x + x cos x, x sin x + (x²/2) cos x, sin x + x cos x, −x cos x.
