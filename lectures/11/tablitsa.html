Интегрирование — действие, обратное дифференцированию, поэтому каждая строка таблицы производных читается справа налево и даёт строку таблицы интегралов. Лекция составляет таблицу из 15 формул и называет их табличными интегралами; с помощью свойств из статьи 11.2 к ним сводятся интегралы суммы и разности функций. В статье вся таблица с условиями (где формула верна), способы её запомнить, проверка формул 12–15 дифференцированием, приём «корень и дробь — степень», пример лекции и ещё несколько типов, которые встречаются на практике.

Таблица производных, прочитанная наоборот

Если F′(x) = f(x), то ∫ f(x) dx = F(x) + C (лекция, стр. 5). Например, (sin x)′ = cos x превращается в ∫ cos x dx = sin x + C. Нужные производные — в таблице производных (лекция 8). Каждую формулу можно проверить самому: достаточно продифференцировать правую часть.

Таблица основных интегралов (лекция, стр. 5–6)

Нумерация — как в лекции. В последнем столбце условия: формула верна на промежутке, где определены обе части. Для всех формул с дробями это промежутки, где знаменатель не обращается в нуль (замечание лекции, стр. 6).

Как читать таблицу

В формулах 12–15 буква a — параметр, число. Чтобы им пользоваться, читай a из знаменателя: x² + 9 — это x² + a² при a² = 9, то есть a = 3. В формуле 15 число под корнем — любое ненулевое ±a²: например, ∫ dx/√(x² + 7) = ln(x + √(x² + 7)) + C (a² = 7).

Замечание

Две пары в формулах 12 и 14 (arctg и −arcctg, arcsin и −arccos) — не ошибка: arctg y + arcctg y = π/2 и arcsin y + arccos y = π/2, то есть функции отличаются на постоянную, и это один и тот же неопределённый интеграл. В лекции у формулы 14 записано |x| < |a|. Дифференцированием проверяется запись arcsin(x/a) при a > 0: при a < 0 производная arcsin(x/a) равна −1/√(a² − x²). Для a < 0 пользуйся записью с |a|: ∫ dx/√(a² − x²) = arcsin(x/|a|) + C. На практике a > 0.

Как выучить таблицу

  • Строки 4–11 — таблица производных. Знаки: ∫ sin x dx = −cos x (минус), ∫ cos x dx = sin x (плюс), ∫ dx/sin²x = −ctg x, ∫ dx/sh²x = −cth x: минус там, где в таблице производных он стоял у «ко-» функций.
  • Показательная функция при дифференцировании умножается на ln a, поэтому при интегрировании делится: (aˣ/ln a)′ = aˣ. При a = e получается ∫ eˣ dx = eˣ + C.
  • Степень. Для xᵅ показатель увеличивается на 1, и результат делится на новый показатель. Исключение α = −1: деление на нуль, вместо степени получается логарифм (формула 2).
  • Дроби с a² (формулы 12–15). В знаменателе x² + a² — арктангенс и множитель 1/a; x² − a² — логарифм дроби и множитель 1/(2a); под корнем a² − x² — арксинус; под корнем x² ± a² — «длинный» логарифм. Не помнишь точно — проверь дифференцированием.

Промежутки: ∫ dx/x и ∫ dx/x²

Логарифм. Для x > 0 формула (ln x)′ = 1/x известна. При x < 0 берут ln|x| = ln(−x), и по правилу сложной функции (ln(−x))′ = (−1)/(−x) = 1/x. Поэтому ∫ dx/x = ln|x| + C — на каждой из полуосей.

Две полуоси — две постоянные. Множество x ≠ 0 — два промежутка, и на каждом первообразная определяется с точностью до своей постоянной (статья 11.1). Лекция показывает это на ∫ dx/x² (стр. 5): общей формулы «на всей оси без нуля» нет, а есть две:

∫ dx/x² = −1/x + C₁ при x > 0, ∫ dx/x² = −1/x + C₂ при x < 0
C₁ и C₂ независимы. Для целого α ≥ 0 (степень x², x³, …) таких проблем нет: функция определена на всей оси, и формула 1 верна на ℝ.

Нецелые показатели (√x, x−1/2, x5/3): чтобы не обсуждать смысл степени при x < 0, берём x > 0 и там применяем формулу 1. Тригонометрические дроби (формулы 6 и 7) верны на промежутках между нулями знаменателя: tg x + C — на (−π/2; π/2), на (π/2; 3π/2) и т. д., с отдельной C на каждом.

Проверка формул 12–15 дифференцированием (лекция, стр. 13)

Формулы 1–11 следуют из таблицы производных. Остальные в лекции проверяются дифференцированием правой части. Покажем все шаги, самые длинные — для формул 13 и 15.

Формула 12из лекции, стр. 13
Проверить: ∫ dx/(x² + a²) = (1/a) arctg(x/a) + C, a ≠ 0.

  1. ((1/a) arctg(x/a))′ = (1/a) · 1/(1 + (x/a)²) · (x/a)′ = (1/a) · 1/(1 + x²/a²) · (1/a).

  2. = 1/(a²(1 + x²/a²)) = 1/(a² + x²). Получили подынтегральную функцию.

Формула верна.

Формула 13из лекции, стр. 13
Проверить: ∫ dx/(x² − a²) = (1/2a) ln|(x − a)/(x + a)| + C.

  1. Производная логарифма модуля: (ln|u|)′ = u′/u, здесь u = (x − a)/(x + a). u′ = ((x + a) − (x − a))/(x + a)² = 2a/(x + a)².

  2. u′/u = 2a/(x + a)² · (x + a)/(x − a) = 2a/((x + a)(x − a)) = 2a/(x² − a²).

  3. Умножаем на 1/(2a): 1/(x² − a²). Всё верно на промежутках, где x ≠ ±a.

Формула верна.

Формула 14из лекции, стр. 13
Проверить: ∫ dx/√(a² − x²) = arcsin(x/a) + C при a > 0.

  1. (arcsin(x/a))′ = 1/√(1 − x²/a²) · (1/a) = 1/(a√((a² − x²)/a²)) = 1/(a · √(a² − x²)/a) = 1/√(a² − x²).

  2. Здесь использовано √(a²) = a, а это верно при a > 0 (при a < 0 было бы |a|: см. замечание выше).

Формула верна при a > 0, |x| < a.

Формула 15 (знак «−»)из лекции, стр. 13
Проверить: ∫ dx/√(x² − a²) = ln|x + √(x² − a²)| + C при |x| > |a|.

  1. Пусть g = x + √(x² − a²). Тогда g′ = 1 + 2x/(2√(x² − a²)) = (√(x² − a²) + x)/√(x² − a²) = g/√(x² − a²).

  2. (ln|g|)′ = g′/g = 1/√(x² − a²). Для знака «+» выкладка та же с заменой −a² на +a².

Формула верна на каждом из промежутков x > |a|, x < −|a|.

Как решать табличные интегралы

Алгоритм. (1) Приведи подынтегральную функцию к сумме слагаемых вида «число × табличная функция»: раскрой скобки, подели числитель на одночлен знаменателя, корни и дроби запиши степенями (√x = x1/2, 1/xⁿ = x−n, 1/∛x = x−1/3). (2) Вынеси числовые множители (свойство 4°) и разбей на слагаемые (3°). (3) Каждое слагаемое найди по таблице. (4) Запиши одну C. (5) Проверь дифференцированием.

Разобранные примеры

Пример 1 лекции: линейность и таблицаиз лекции, стр. 7
Найти ∫ (5 cos x + 2 − 3x² + 1/x − 4/(x² + 1)) dx.

  1. Разбиваем на слагаемые и выносим числа: 5 ∫ cos x dx + 2 ∫ dx − 3 ∫ x² dx + ∫ dx/x − 4 ∫ dx/(x² + 1).

  2. По таблице: ∫ cos x dx = sin x (формула 5); ∫ dx = x (формула 1, α = 0); ∫ x² dx = x³/3 (формула 1); ∫ dx/x = ln|x| (формула 2); ∫ dx/(x² + 1) = arctg x (формула 12, a = 1).

  3. Складываем: 5 sin x + 2x − x³ + ln|x| − 4 arctg x + C. Из-за слагаемого 1/x формула верна отдельно при x > 0 и при x < 0.

5 sin x + 2x − x³ + ln|x| − 4 arctg x + C на каждом из промежутков x > 0, x < 0.

Пример 2: корни и дробидополнительно к лекции
Найти ∫ (3√x − 2/x³ + 4/√x) dx при x > 0.

  1. Переписываем степенями: 3x1/2 − 2x−3 + 4x−1/2.

  2. По формуле 1: 3·x3/2/(3/2) = 2x3/2; −2·x−2/(−2) = x−2; 4·x1/2/(1/2) = 8x1/2.

  3. Возвращаемся к корням: 2x√x + 1/x² + 8√x + C. Проверка: (2x3/2)′ = 3x1/2, (x−2)′ = −2x−3, (8x1/2)′ = 4x−1/2.

2x√x + 1/x² + 8√x + C.

Пример 3: подели почленнодополнительно к лекции
Найти ∫ (x − 1)²/x dx.

  1. Числитель раскрываем, знаменатель — одночлен, делим каждое слагаемое: (x² − 2x + 1)/x = x − 2 + 1/x. (Сумму в знаменателе так делить нельзя.)

  2. ∫ (x − 2 + 1/x) dx = x²/2 − 2x + ln|x| + C при x > 0 или x < 0.

x²/2 − 2x + ln|x| + C.

Пример 4: показательные функциидополнительно к лекции
Найти ∫ (2·3ˣ − 5eˣ) dx и ∫ 2ˣ·3ˣ dx.

  1. Первый: по формуле 3 и свойствам 3°, 4°: 2·3ˣ/ln 3 − 5eˣ + C.

  2. Второй: произведение показательных функций с одним показателем объединяем: 2ˣ·3ˣ = (2·3)ˣ = 6ˣ. Теперь формула 3 при a = 6: 6ˣ/ln 6 + C. Раздельное интегрирование множителей дало бы неверное 2ˣ·3ˣ/(ln 2·ln 3) (интеграл произведения, статья 11.2).

2·3ˣ/ln 3 − 5eˣ + C; 6ˣ/ln 6 + C.

Пример 5: формулы 12–15 с числамидополнительно к лекции
Найти ∫ dx/(x² + 9), ∫ dx/(x² − 16), ∫ dx/√(25 − x²), ∫ dx/√(x² + 7).

  1. Формула 12. a² = 9, a = 3: (1/3) arctg(x/3) + C.

  2. Формула 13. a² = 16, a = 4, множитель 1/(2a) = 1/8: (1/8) ln|(x − 4)/(x + 4)| + C (при x ≠ ±4).

  3. Формула 14. a² = 25, a = 5: arcsin(x/5) + C при |x| < 5.

  4. Формула 15 (знак «+», a² = 7): ln|x + √(x² + 7)| + C на всей оси; модуль можно опустить, потому что x + √(x² + 7) > 0.

(1/3) arctg(x/3) + C; (1/8) ln|(x − 4)/(x + 4)| + C; arcsin(x/5) + C; ln(x + √(x² + 7)) + C.

Пример 6: тригонометрия и гиперболические функциидополнительно к лекции
Найти ∫ (2 tg²x + 3) dx и ∫ (4 ch x − 3 sh x + 2/ch²x) dx.

  1. Тангенс в квадрате в таблице отсутствует, но tg²x = sin²x/cos²x = (1 − cos²x)/cos²x = 1/cos²x − 1. Тогда 2 tg²x + 3 = 2/cos²x − 2 + 3 = 2/cos²x + 1.

  2. ∫ (2/cos²x + 1) dx = 2 tg x + x + C (формула 6 и ∫ dx = x) на каждом промежутке, где cos x ≠ 0, со своей C.

  3. Второй: формулы 9, 8, 10: 4 sh x − 3 ch x + 2 th x + C.

2 tg x + x + C (при cos x ≠ 0); 4 sh x − 3 ch x + 2 th x + C.

Не каждый интеграл вычисляется

Лекция вводит термин (стр. 7): если первообразная функции f — элементарная функция, то говорят, что интеграл ∫ f(x) dx выражается через элементарные функции, или вычисляется. Не все интегралы такие. Доказано, что ∫ e−x² dx (и ∫ ex² dx), ∫ (sin x)/x dx, ∫ dx/ln x через элементарные функции не выражаются, хотя подынтегральные функции непрерывны и их первообразные существуют (статья 11.1). Типовые задания составлены из вычислимых интегралов; если интеграл не поддаётся ни одному методу, перепроверь запись условия.

Частые ошибки

Так нельзя

∫ xᵅ dx = xα−1/(α − 1) или ∫ x³ dx = 3x².

Так правильно

Это правило дифференцирования. При интегрировании показатель увеличивается на 1 и делится на новый: ∫ x³ dx = x⁴/4 + C.

Так нельзя

∫ dx/x = ln x (без модуля) или ∫ dx/x² = ln x².

Так правильно

∫ dx/x = ln|x| + C (на каждой полуоси). Степень x−2 по формуле 1: ∫ x−2 dx = −x−1 = −1/x + C; логарифм появляется только при α = −1.

Так нельзя

∫ aˣ dx = aˣ или ∫ aˣ dx = aˣ ln a.

Так правильно

Показательная функция при интегрировании делится на ln a: ∫ aˣ dx = aˣ/ln a + C (при a = e совпадает с eˣ).

Так нельзя

∫ cos x dx = −sin x, ∫ sin x dx = cos x.

Так правильно

∫ cos x dx = sin x + C, ∫ sin x dx = −cos x + C. Проверка: (−cos x)′ = sin x.

Так нельзя

∫ dx/(x² + 4) = arctg x или = arctg(x/2) (потерян множитель 1/a).

Так правильно

∫ dx/(x² + 4) = (1/2) arctg(x/2) + C: a = 2, перед арктангенсом 1/a. Проверка: ((1/2) arctg(x/2))′ = 1/(4 + x²).

Кратко для повторения

Кратко для повторения

  • Таблица интегралов — таблица производных справа налево. Все 15 формул проверяются дифференцированием.
  • ∫ xᵅ dx = xα+1/(α + 1) + C при α ≠ −1 (x > 0); ∫ dx/x = ln|x| + C; ∫ aˣ dx = aˣ/ln a + C; ∫ sin x dx = −cos x + C; ∫ cos x dx = sin x + C; ∫ dx/cos²x = tg x + C; ∫ dx/sin²x = −ctg x + C.
  • ∫ sh x = ch x, ∫ ch x = sh x, ∫ dx/ch²x = th x, ∫ dx/sh²x = −cth x; ∫ dx/(x² + a²) = (1/a) arctg(x/a); ∫ dx/(x² − a²) = (1/2a) ln|(x − a)/(x + a)|; ∫ dx/√(a² − x²) = arcsin(x/a) (|x| < a); ∫ dx/√(x² ± a²) = ln|x + √(x² ± a²)|.
  • Формулы с дробями верны на промежутках, где знаменатель не нуль. На разных промежутках постоянные независимы: ∫ dx/x² = −1/x + C₁ (x > 0), −1/x + C₂ (x < 0).
  • Перед интегрированием: корни и дроби — в степени, скобки раскрыть, числитель разделить на одночлен; tg²x = 1/cos²x − 1; aˣbˣ = (ab)ˣ. Одна C; проверка дифференцированием.
  • Не каждый интеграл вычисляется: ∫ e−x² dx, ∫ (sin x)/x dx не выражаются через элементарные функции.

Задания для самопроверки

Решено: 0 из 6

Ответ — число: целое, десятичное (0,25) или дробь (1/4). Минус — обычный дефис. Подсказки появляются после неверного ответа, решение можно открыть в любой момент.

1
Найдите ∫ dx/(x² + 16) (на ℝ).
Варианты ответа

Показать решение

x² + 16 = x² + a² при a = 4. Формула 12: (1/4) arctg(x/4) + C. Проверка: ((1/4) arctg(x/4))′ = (1/4)·(1/4)/(1 + x²/16) = 1/(16 + x²).

2
Найдите ∫ (3·2ˣ − 4/x²) dx при x > 0.
Варианты ответа

Показать решение

∫ 2ˣ dx = 2ˣ/ln 2; ∫ x−2 dx = −1/x, значит, −4·(−1/x) = 4/x. Ответ 3·2ˣ/ln 2 + 4/x + C. Проверка: (3·2ˣ/ln 2 + 4/x)′ = 3·2ˣ − 4/x².

3
Заполните пропуски (формулы таблицы).
∫ dx/cos²x = ; ∫ dx/(x² − a²) = · ln|(x − a)/(x + a)| + C; ∫ aˣ dx = aˣ / + C

Показать решение

Формулы 6, 13 и 3 таблицы. Проверка: (tg x)′ = 1/cos²x; производная ln|(x − a)/(x + a)| равна 2a/(x² − a²), поэтому нужен множитель 1/(2a); (aˣ/ln a)′ = aˣ.

4
Функция F — первообразная функции f(x) = 3/√x + 2x на x > 0, и F(1) = 9. Найдите F(4).

Показать решение

3/√x = 3x−1/2, ∫ 3x−1/2 dx = 3·x1/2/(1/2) = 6√x; ∫ 2x dx = x². Значит, F(x) = 6√x + x² + C. F(1) = 7 + C = 9, C = 2. F(4) = 12 + 16 + 2 = 30.

5
Находим ∫ dx/(x² − 9) при x > 3. В каком шаге допущена первая ошибка?
Варианты ответа

Показать решение

Множитель в формуле 13 равен 1/(2a) = 1/6, а не 1/(2a²) = 1/18. Верно: (1/6) ln|(x − 3)/(x + 3)| + C. Проверка: производная 1/(x² − 9).

6
Какое утверждение о первообразных функции 1/x² на множестве x ≠ 0 (то есть функциях F с F′ = 1/x² в каждой точке x ≠ 0) верно?
Варианты ответа

Показать решение

Множество x ≠ 0 — два промежутка; на каждом первообразная определена с точностью до своей постоянной. Проверка: (−1/x + C)′ = 1/x² на каждой полуоси.
