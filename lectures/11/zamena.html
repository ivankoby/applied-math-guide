Подведение под знак дифференциала (статья 11.4) работает, когда в интеграле уже есть множитель φ′(x) dx. Если же мешает корень √(a² − x²) или √(ax² + bx + c), которого нет в таблице, поступают наоборот: сами выбирают, чему равен x, то есть x = φ(t), переходят к интегралу по t и в конце возвращаются к x обратной функцией t = φ⁻¹(x). В статье формула (22.11) с условием строгой монотонности, алгоритм, примеры 4 и 5 лекции со всеми шагами, замена из опорного конспекта и таблица «что мешает — что заменять».

Формула (22.11): замена x = φ(t) (лекция, стр. 8)

Формула (22.10) верна и справа налево. Если ∫ f(x) dx вычислять трудно, подставляют x = φ(t) и сводят его к интегралу ∫ f[φ(t)] φ′(t) dt, который (надеемся) проще. Но результат получается как функция от t, а спрашивали про x. Поэтому в обеих частях (22.10) делают обратную замену t = φ⁻¹(x):

∫ f(x) dx = ∫ f[φ(t)] φ′(t) dt |t=φ⁻¹(x) (22.11)
Чтобы обратная функция φ⁻¹ существовала, в дополнение к условиям теоремы 1 достаточно, например, потребовать, чтобы φ была строго монотонной на рассматриваемом промежутке (лекция, стр. 8; обратная функция единственна). Условие теоремы 1 о внутренних точках (статья 11.4) при этом выполнено само: непрерывная строго монотонная φ переводит внутренность Δₜ в открытый промежуток, лежащий внутри Δₓ. Алгоритм замены переменной

(1) Реши, что мешает (корень, трёхчлен, eˣ), и выбери x = φ(t) (или новую переменную t = ψ(x)); укажи промежуток T для t: φ непрерывна на нём, дифференцируема внутри, строго монотонна, и φ(T) — весь промежуток по x, на котором ищешь первообразную. (2) Найди dx = φ′(t) dt. (3) Подставь x и dx, упрости подынтегральное выражение: оно должно стать табличным или почти табличным. (4) Проинтегрируй по t. (5) Верни x: подставь t = φ⁻¹(x) и упрости (синусы и косинусы от t выражай через x). (6) Проверь дифференцированием по x. Если после замены интеграл не стал проще, замена выбрана неудачно (лекция: «если этот интеграл в каком-то смысле проще»).

Пример 4 лекции: ∫ dx/√(ax² + bx + c)

Пусть a ≠ 0 и подкоренное выражение положительно на некотором интервале (в лекции, стр. 9, «неотрицательно», но при нуле подынтегральная функция не определена). Выделим полный квадрат: ax² + bx + c = a(x + b/(2a))² + d, где d = c − b²/(4a). Замена t = √|a| · (x + b/(2a)) даёт dx = dt/√|a|, и a(x + b/(2a))² = ±t². В итоге (формула 22.11)

∫ dx/√(ax² + bx + c) = (1/√|a|) ∫ dt/√(±t² + d)
знак «+» при a > 0, знак «−» при a < 0
Справа табличные интегралы: при a > 0 формула 15 (ln|t + √(t² + d)|; при d < 0 берём |t| > √|d|), при a < 0 формула 14 (arcsin(t/√d), нужно d > 0). Случай d = 0 отдельный: корень равен |t|, ∫ dt/|t| = sign t · ln|t|, формул 14–15 здесь нет. Затем возвращаем x: t = √|a|(x + b/(2a)).
Трёхчлен с a = 1дополнительно к лекции (тип примера 4)
Найти ∫ dx/√(x² + 4x + 13).

  1. a = 1, b = 4, c = 13: d = 13 − 16/4 = 9. Квадрат: x² + 4x + 13 = (x + 2)² + 9.

  2. Замена t = x + 2 (√|a| = 1), dx = dt: ∫ dt/√(t² + 9) = ln|t + √(t² + 9)| + C (формула 15, a² = 9).

  3. Возвращаем x: t = x + 2, t² + 9 = x² + 4x + 13. Модуль можно убрать, так как t + √(t² + 9) > 0.

ln(x + 2 + √(x² + 4x + 13)) + C.

Трёхчлен с a = 4: множитель 1/√|a|дополнительно к лекции (тип примера 4)
Найти ∫ dx/√(4x² + 4x + 5).

  1. a = 4, b = 4, c = 5: d = 5 − 16/16 = 4, 4x² + 4x + 5 = 4(x + 1/2)² + 4.

  2. Замена t = √4·(x + 1/2) = 2x + 1, dt = 2 dx, dx = dt/2; t² + 4 = 4x² + 4x + 5. Значит, ∫ dx/√(4x² + 4x + 5) = (1/2) ∫ dt/√(t² + 4).

  3. (1/2) ln|t + √(t² + 4)| + C. Возвращаем x: (1/2) ln(2x + 1 + √(4x² + 4x + 5)) + C.

(1/2) ln(2x + 1 + √(4x² + 4x + 5)) + C.

Трёхчлен с a < 0дополнительно к лекции (тип примера 4)
Найти ∫ dx/√(8x − 4x² − 3).

  1. a = −4, b = 8, c = −3: d = −3 − 64/(−16) = 1. Подкоренное: −4(x − 1)² + 4 − 3 = 1 − (2x − 2)²; оно положительно при 1/2 < x < 3/2.

  2. Замена t = √4·(x − 1) = 2x − 2, dx = dt/2. Знак «−», d = 1: (1/2) ∫ dt/√(1 − t²) = (1/2) arcsin t + C (формула 14, a = 1).

  3. Возвращаем x: (1/2) arcsin(2x − 2) + C.

(1/2) arcsin(2x − 2) + C при 1/2 < x < 3/2.

Дополнительно: трёхчлен в знаменателе. Лекция отсылает интегралы ∫ dx/(ax² + bx + c) к п. 24.1 (следующие лекции), приём тот же: выделить квадрат и применить формулу 12 или 13. Например, x² + 2x + 5 = (x + 1)² + 4, t = x + 1: ∫ dx/(x² + 2x + 5) = (1/2) arctg((x + 1)/2) + C. А x² − 4x + 3 = (x − 2)² − 1, t = x − 2: ∫ dx/(x² − 4x + 3) = (1/2) ln|(x − 3)/(x − 1)| + C (формула 13, a = 1; сдвиг x − 2 обратно: t − 1 = x − 3, t + 1 = x − 1), на каждом из промежутков x < 1, 1 < x < 3, x > 3 со своей C. При a ≠ 1 появляется множитель: 4x² + 4x + 5 = (2x + 1)² + 4, t = 2x + 1, dx = dt/2, ∫ dx/(4x² + 4x + 5) = (1/2) ∫ dt/(t² + 4) = (1/4) arctg((2x + 1)/2) + C.

Пример 5 лекции: ∫ √(a² − x²) dx и подстановка x = a sin t

Здесь a > 0 (лекция знак a не оговаривает; при a < 0 везде берут |a|, ведь подынтегральная функция зависит от a²), |x| ≤ a. Корень исчезает, если положить x = a sin t: тогда a² − x² = a² cos²t. Возьмём t ∈ [−π/2; π/2]. На нём x = a sin t строго возрастает (значит, обратная функция есть: t = arcsin(x/a)) и cos t ≥ 0 (поэтому √(a² cos²t) = a|cos t| = a cos t).

Пример 5 лекциииз лекции, стр. 10
Вычислить ∫ √(a² − x²) dx, a > 0.

  1. Подстановка x = a sin t, dx = a cos t dt, √(a² − x²) = a cos t. Тогда ∫ √(a² − x²) dx = ∫ a cos t · a cos t dt = a² ∫ cos²t dt.

  2. cos²t = (1 + cos 2t)/2, поэтому a² ∫ (1 + cos 2t)/2 dt = (a²/2) ∫ dt + (a²/2) ∫ cos 2t dt = a²t/2 + (a²/4) sin 2t + C.

  3. Возвращаем x. t = arcsin(x/a). sin 2t = 2 sin t cos t, где sin t = x/a, cos t = √(1 − x²/a²) = √(a² − x²)/a (корень неотрицателен, так как t ∈ [−π/2; π/2]). Значит, sin 2t = 2 · (x/a) · √(a² − x²)/a = (2/a²) x √(a² − x²).

  4. Подставляем: (a²/4) · (2/a²) x √(a² − x²) = (x/2)√(a² − x²).

∫ √(a² − x²) dx = (a²/2) arcsin(x/a) + (x/2)√(a² − x²) + C. Для a = 3: (9/2) arcsin(x/3) + (x/2)√(9 − x²) + C.

Эту же первообразную получает интегрирование по частям (статья 11.7): с точностью до постоянной ответ совпадает.

Другие замены: из опорного конспекта и типов практики

Новая переменная через кореньдополнительно к лекции (опорный конспект)
Найти ∫ dx/√(eˣ + 1).

  1. Мешает корень. Положим t = √(eˣ + 1), t > 1. Тогда eˣ = t² − 1, x = ln(t² − 1), dx = 2t dt/(t² − 1). Функция x = ln(t² − 1) строго возрастает при t > 1, обратная — наша t = √(eˣ + 1).

  2. ∫ dx/√(eˣ + 1) = ∫ (1/t) · 2t dt/(t² − 1) = 2 ∫ dt/(t² − 1). Формула 13 при a = 1: 2 · (1/2) ln|(t − 1)/(t + 1)| = ln((t − 1)/(t + 1)) (при t > 1 дробь положительна).

  3. Возвращаем x: t = √(eˣ + 1).

ln((√(eˣ + 1) − 1)/(√(eˣ + 1) + 1)) + C.

Рационализирующая замена t = √xдополнительно к лекции (тип практики)
Найти ∫ dx/(1 + √x) при x > 0.

  1. t = √x, x = t² (строго возрастает при t > 0), dx = 2t dt. ∫ 2t dt/(1 + t): выделяем целую часть, 2t/(1 + t) = 2 − 2/(1 + t).

  2. ∫ (2 − 2/(1 + t)) dt = 2t − 2 ln(1 + t) + C. Возвращаем x: t = √x.

2√x − 2 ln(1 + √x) + C.

Частые ошибки

Так нельзя

Ответ оставлен через t: «(a²/2) t + … + C».

Так правильно

Спрашивали про x. Верни t = φ⁻¹(x): для x = a sin t это t = arcsin(x/a), и sin 2t, cos t тоже выразить через x.

Так нельзя

∫ √(a² − x²) dx = ∫ a cos t dt — dx не заменили.

Так правильно

Подставляют и функцию, и дифференциал: dx = a cos t dt. Получается a cos t · a cos t = a² cos²t.

Так нельзя

sin 2t = 2x/a или sin 2t = x/a.

Так правильно

sin 2t = 2 sin t cos t, где sin t = x/a, cos t = √(1 − x²/a²). Нужны оба множителя.

Так нельзя

√(a² − x²) = a cos t для любого t.

Так правильно

Равенство верно при cos t ≥ 0, то есть t ∈ [−π/2; π/2]. Для остальных t будет a|cos t|; промежуток выбирают заранее.

Так нельзя

∫ dx/√(4x² + 4x + 5) = ln|t + √(t² + 4)| — множитель 1/√|a| потерян.

Так правильно

dx = dt/√|a| = dt/2: (1/2) ln|t + √(t² + 4)|. Множитель 1/√|a| стоит перед всем интегралом по t.

Так нельзя

Замена x = t² для интеграла по всей оси, «чтобы убрать корень».

Так правильно

x = t² строго монотонна лишь при t > 0 (или t < 0) и покрывает только x > 0. Замена должна быть взаимно однозначной на нужном промежутке.

Кратко для повторения

Кратко для повторения

  • Замена x = φ(t): ∫ f(x) dx = ∫ f[φ(t)] φ′(t) dt |t=φ⁻¹(x) (22.11); достаточно, чтобы φ была строго монотонной (тогда φ⁻¹ существует). Возврат к x обязателен.
  • Подведение: u = φ(x), du = φ′(x) dx; замена: x = φ(t), dx = φ′(t) dt. Выбор зависит от того, виден ли в интеграле φ′(x) dx.
  • Пример 4: ax² + bx + c = a(x + b/2a)² + d, d = c − b²/(4a), t = √|a|(x + b/2a), ∫ dx/√(ax² + bx + c) = (1/√|a|) ∫ dt/√(±t² + d): + при a > 0 (формула 15), − при a < 0 (формула 14).
  • Пример 5: x = a sin t, t ∈ [−π/2; π/2], dx = a cos t dt, √(a² − x²) = a cos t; ∫ √(a² − x²) dx = (a²/2) arcsin(x/a) + (x/2)√(a² − x²) + C.
  • Корень из x или ax + b убирается заменой t = √x; √(eˣ + 1) — заменой t = √(eˣ + 1). Проверка — дифференцирование по x.

1
Найдите ∫ dx/√(x² + 6x + 13).
Варианты ответа

Показать решение

x² + 6x + 13 = (x + 3)² + 4, t = x + 3, dx = dt. ∫ dt/√(t² + 4) = ln|t + √(t² + 4)| = ln(x + 3 + √(x² + 6x + 13)) + C (t² + 4 = x² + 6x + 13).

2
Найдите ∫ dx/√(3 − 2x − x²) при −3 < x < 1.
Варианты ответа

Показать решение

3 − 2x − x² = 4 − (x + 1)²; t = x + 1, dx = dt. ∫ dt/√(4 − t²) = arcsin(t/2) + C = arcsin((x + 1)/2) + C. Проверка: (arcsin((x + 1)/2))′ = (1/2)/√(1 − (x + 1)²/4) = 1/√(4 − (x + 1)²).
