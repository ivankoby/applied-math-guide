Корни и подстановка t

Корни мешают считать. Заменим их одной буквой t, и корни исчезнут.

🌱
Корни √x и ∛x
➜
🔤
Заменяем на t
➜
✅
Считаем без корней
корни уходят
tᵐ = (ax + b) / (cx + d)
Тэ в степени эм равно дробь: а икс плюс бэ на це икс плюс дэ. Эм — общий знаменатель степеней корня.
  • 🔢Для √x и ∛x берём x = t⁶, dx = 6t⁵ dt.
  • 🧾Ответ для ∫dx/(√x+∛x): 2√x − 3∛x + 6⁶√x − 6·ln(⁶√x + 1) + C.
  • 🧩Для √((x−1)(x−2)) берём t² = (x−2)/(x−1).
💡 Как в жизниКак перевод денег в одну валюту: разные корни сводим к одной букве t.
🎓 Слова для взрослых
иррациональная функция — функция, где x стоит под корнемобщий знаменатель — число, которое делится на все знаменатели степеней
Какую замену берём для ∫dx/(√x+∛x)?
✅ x = t⁶.
2

Подстановки Эйлера

Корень из квадратного трёхчлена тоже можно убрать. Для этого есть три подстановки Эйлера.

  1. Если a > 0: корень = ±x√a ± t.
  2. Если есть корни x₁ и x₂: t² = a(x−x₂)/(x−x₁).
  3. Если c > 0: корень = ±√c ± x·t.
  4. Потом возводим в квадрат и выражаем x через t.
√(ax² + bx + c) = ±x·√a ± t
Корень из а икс квадрат плюс бэ икс плюс цэ равен плюс-минус икс корень из а, плюс-минус тэ. Знаки можно брать любые.
  • 🔁Возводим в квадрат и выражаем x через t.
  • 📐Если есть корни x₁ и x₂: t² = a(x−x₂)/(x−x₁).
  • 🧩Если c > 0: корень = ±√c ± x·t.
  • ⚠️Если a < 0 и корней нет, корень мнимый, такой случай не берём.
💡 Как в жизниКак ключ к замку: подбираешь подходящую подстановку, и корень открывается.
🎓 Слова для взрослых
подстановка Эйлера — замена, которая убирает корень из квадратного трёхчленаквадратный трёхчлен — выражение вида ax² + bx + c
Что берём, если у трёхчлена есть корни x₁ и x₂?
✅ t² = a(x−x₂)/(x−x₁).
3

Тригонометрические: u = tg(x/2)

Синус и косинус тоже можно заменить одной буквой. Тогда всё станет обычной дробью.

📐
sin x и cos x
➜
🔄
Замена u = tg(x/2)
➜
🧾
Обычная дробь от u
тригонометрическая замена
sin x = 2u / (1 + u²), cos x = (1 − u²) / (1 + u²)
Синус икс равен два у на один плюс у квадрат. Косинус икс равен один минус у квадрат на один плюс у квадрат. Здесь у — тангенс половины икса.
  • 🔤u = tg(x/2) — тангенс половины угла, новая буква.
  • 🧭Иногда проще взять u = sin x, u = cos x или u = tg x.
  • 🎈Пример: ∫dx/(1 + sin x) = −2/(1 + tg(x/2)) + C.
  • 🧮Пример: ∫dx/cos⁴x = tg x + tg³x/3 + C, берём u = tg x.
💡 Как в жизниКак перевести все углы на один язык: вместо синуса и косинуса одна буква u.
🎓 Слова для взрослых
тангенс (tg) — отношение синуса к косинусуdx через du — dx = 2du / (1 + u²) при u = tg(x/2)
Чему равен sin x через u = tg(x/2)?
✅ 2u / (1 + u²).
4

Синус, косинус и экспонента

Синус, косинус и показательная функция часто встречаются вместе. Для них есть готовые приёмы.

🌊
sin αx · cos βx
📈
e^(αx) · cos βx
🧮
xⁿ · sin x
три частых вида
∫ e^(αx)·cos βx dx = e^(αx)·(β·sin βx + α·cos βx) / (α² + β²) + C
Интеграл от е в степени альфа икс, на косинус бэ икс, равен дроби: е в степени альфа икс, на скобку из бэ синус бэ икс плюс альфа косинус бэ икс, делённое на альфа квадрат плюс бэ квадрат. Плюс цэ.
  • 🔁Берём по частям дважды: нужный интеграл появляется снова, его выражаем.
  • 🧩sin αx·cos βx = ½[sin(α+β)x + sin(α−β)x].
  • 🧮Пример: ∫x²·sin x dx = −x²cos x + 2x·sin x + 2cos x + C.
  • ⚠️Если степень sin или cos нечётная, берём u = cos x или u = sin x.
💡 Как в жизниКак качели: туда и обратно, и в итоге всё сходится к одному и тому же кусочку.
🎓 Слова для взрослых
e^(αx) — показательная функция: e в степени α·xповторное интегрирование по частям — формула по частям применяется два раза подряд
Как разложить sin αx·cos βx в сумму?
✅ ½[sin(α+β)x + sin(α−β)x].
