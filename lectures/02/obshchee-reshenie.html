Общее решение неоднородной системы устроено просто: нужно одно её частное решение, а к нему добавляется всё, что даёт соответствующая однородная система. Так задача сводится к уже знакомой (ФСР, статья 2.6), а ответ получает аккуратную запись X = X₀ + c₁e₁ + … + ckek.

Теорема о структуре общего решения

Соответствующая однородная система

Для неоднородной системы A·X = B соответствующей однородной называется система A·X = O с той же основной матрицей и нулевыми свободными членами.

Теорема о структуре общего решения неоднородной системы

Общее решение совместной неоднородной системы линейных уравнений равно сумме какого-либо её частного решения и общего решения соответствующей однородной системы.

X = X₀ + c₁e₁ + c₂e₂ + … + ckek
X₀ — частное решение A·X = B; e₁, …, ek — ФСР системы A·X = O, k = n − r
Одна «точка отсчёта» X₀ плюс все комбинации ФСР.

Почему так. Пусть X₀ — какое-нибудь решение системы A·X = B.

  • Если X — любое решение этой системы, то A(X − X₀) = B − B = O: значит, Y = X − X₀ решает однородную систему, и X = X₀ + Y.
  • Обратно, если Y — любое решение однородной системы, то A(X₀ + Y) = B + O = B: значит, X₀ + Y решает исходную систему.

Следовательно, все решения неоднородной системы — это наборы X₀ + Y, где Y пробегает все решения однородной, и других нет. Условия теоремы существенны: система должна быть совместной (иначе X₀ не существует), а однородная система берётся с той же матрицей A.

Базисное решение

Частное решение неоднородной системы можно получить, приравняв к нулю все свободные неизвестные. Такое решение называется базисным решением (в выбранном базисе, то есть при выбранных главных неизвестных).

Картинка: сдвиг прямой

Самый простой пример: одно уравнение x + y = 3 с двумя неизвестными (r = 1, n = 2, одно свободное неизвестное). Соответствующая однородная система x + y = 0 задаёт прямую через начало координат, её общее решение c·(−1, 1). Решения неоднородного уравнения — параллельная прямая: это та же прямая, сдвинутая на частное решение X₀ = (3, 0).

В пространстве так же: множество решений неоднородной системы (точка, прямая или плоскость) получается сдвигом множества решений однородной системы на частное решение и не обязано проходить через начало координат.

Алгоритм: как решать

  • Совместность и главные неизвестные. Проверь r(A) = r(Ā) = r (статья 2.4), найди базисный минор, оставь r уравнений, определи главные и свободные неизвестные (их n − r).
  • Частное решение X₀. Приравняй свободные неизвестные к нулю и реши получившуюся систему r × r относительно главных. Правые части — исходные. Получится базисное решение.
  • ФСР соответствующей однородной системы. Замени все свободные члены нулями. Свободным неизвестным придавай поочерёдно значение 1 (остальным 0) и находи главные: получатся e₁, …, ek, k = n − r.
  • Ответ: X = X₀ + c₁e₁ + … + ckek, где c₁, …, ck — любые числа.

Запомни

Можно и короче: найти общее решение, как в статье 2.4 (главные через свободные), и прочитать его по частям: слагаемое без параметров — это X₀, а векторы при c₁, c₂, … — это ФСР. Оба пути дают одну и ту же запись.

Пример из лекции

Пример 1из лекции, стр. 16–18
Найти общее решение системы:
x1 + 2x2 + 4x3 − 3x4 = 1
3x1 + 5x2 + 6x3 − 4x4 = 2
2x1 + 3x2 + 2x3 − x4 = 1

  1. Ранг и главные неизвестные. Минор из первых двух строк и столбцов не равен нулю: |1 2; 3 5| = −1 ≠ 0. Окаймляем его третьей строкой и по очереди столбцами 3, 4 и столбцом свободных членов. Все три минора третьего порядка равны нулю:

    124356232= 0 12−335−423−1= 0 121352231= 0

    Значит, r(A) = r(Ā) = 2, система совместна и эквивалентна системе из первых двух уравнений. Главные неизвестные x1, x2, свободные x3, x4.

  2. 1. Частное (базисное) решение. Полагаем свободные неизвестные нулями и решаем систему x1 + 2x2 = 1, 3x1 + 5x2 = 2. По формулам Крамера Δ = −1, Δ1 = 1, Δ2 = −1, откуда

    x1 = −1, x2 = 1, X₀ = (−1, 1, 0, 0)

    Это базисное решение в базисе из неизвестных (x1, x2).

  3. 2. Соответствующая однородная система. Свободные члены заменяем нулями, свободные неизвестные переносим вправо:

    x1 + 2x2 = −4x3 + 3x4
    3x1 + 5x2 = −6x3 + 4x4

    Первое решение ФСР: x3 = 1, x4 = 0. Система x1 + 2x2 = −4, 3x1 + 5x2 = −6, Δ = −1, Δ1 = −8, Δ2 = 6, поэтому x1 = 8, x2 = −6:

    e1 = (8, −6, 1, 0)

    Второе решение ФСР: x3 = 0, x4 = 1. Система x1 + 2x2 = 3, 3x1 + 5x2 = 4, Δ1 = 7, Δ2 = −5, поэтому x1 = −7, x2 = 5:

    e2 = (−7, 5, 0, 1)

    Общее решение однородной системы: c1e1 + c2e2, где c1, c2 — любые числа.

  4. 3. Общее решение данной системы — частное решение плюс общее решение однородной:

    X(c1, c2) = X₀ + c1e1 + c2e2
    x₁x₂x₃x₄=−1100+ c₁8−610+ c₂−7501

    или, по координатам:

    x1 = −1 + 8c1 − 7c2
    x2 = 1 − 6c1 + 5c2
    x3 = c1
    x4 = c2

    Проверка при c1 = 1, c2 = 0: X = (7, −5, 1, 0), и 7 − 10 + 4 = 1, 21 − 25 + 6 = 2, 14 − 15 + 2 = 1.

X = (−1, 1, 0, 0) + c₁(8, −6, 1, 0) + c₂(−7, 5, 0, 1)

Замечание

В лекции на стр. 17 второе решение ФСР названо e₁ = (−7, 5, 0, 1), но это e₂ (первое уже названо e₁), а на стр. 18 в последней системе вместо x₄ = c₂ напечатано x₄ = c₄. Мы исправили обозначения. Базисное решение в лекции названо e₀, мы пишем X₀. Заметь также, что ФСР здесь та же, что в примере статьи 2.6: она зависит только от матрицы A, а не от правых частей.

Ещё примеры

Пример 2ответ задачи 3(а) из лекции, стр. 24, в векторной форме
Система показана ниже. Известно её общее решение (ответ лекции): x₁ = 8 − 9x₂ − 4x₃, x₄ = −10 + 11x₂ + 5x₃ (главные x₁, x₄, свободные x₂, x₃). Записать его в виде X = X₀ + c₁e₁ + c₂e₂.
5x1 + 12x2 + 5x3 + 3x4 = 10
4x1 + 3x2 + x3 + 3x4 = 2
11x1 + 11x2 + 4x3 + 8x4 = 8

  1. Ранг системы равен 2 (статья 2.4): минор из столбцов 1 и 4 равен 5·3 − 3·4 = 3 ≠ 0, поэтому x₁, x₄ можно взять главными, x₂, x₃ свободными.

  2. Базисное решение: свободные x2 = x3 = 0. Тогда x1 = 8, x4 = −10: X₀ = (8, 0, 0, −10).

  3. ФСР: x2 = 1, x3 = 0 даёт x1 = −9, x4 = 11 (свободные члены 8 и −10 отбрасываем — они относятся к X₀): e₁ = (−9, 1, 0, 11). Аналогично x2 = 0, x3 = 1 даёт e₂ = (−4, 0, 1, 5).

  4. Ответ собирается из трёх векторов; проверьте подстановкой, что X₀ удовлетворяет исходной системе, а e₁ и e₂ — однородной.

X = (8, 0, 0, −10) + c₁(−9, 1, 0, 11) + c₂(−4, 0, 1, 5)

Пример 3дополнительно: плоскость в пространстве
Найти общее решение уравнения (одно уравнение, три неизвестных):
2x − y + z = 4

  1. Ранг равен 1, неизвестных три, поэтому свободных 3 − 1 = 2. Главной возьмём y (её коэффициент −1 — самый удобный), свободные x и z: y = 2x + z − 4.

  2. Частное решение при x = z = 0: y = −4, X₀ = (0, −4, 0). Однородное уравнение 2x − y + z = 0 даёт y = 2x + z: при x = 1, z = 0 получаем e₁ = (1, 2, 0), при x = 0, z = 1 — e₂ = (0, 1, 1).

X = (0, −4, 0) + c₁(1, 2, 0) + c₂(0, 1, 1)

Запомни

Выбор главных неизвестных и частного решения неоднозначен, поэтому в учебнике или у соседа ответ может выглядеть иначе: например, (2, 0, 0) + c₁(1, 2, 0) + c₂(1, 3, 1) для того же уравнения. Если обе записи подходят под теорему (первое слагаемое — решение неоднородной системы, остальные — независимые решения однородной), это один и тот же ответ. Проверяй подстановкой.

Частые ошибки

Так нельзя

Выдать за общее решение неоднородной системы только общее решение однородной (потерять X₀).

Так правильно

Общее решение неоднородной системы — это X₀ + c₁e₁ + …. Без частного решения мы получаем решения не той системы.

Так нельзя

Строить ФСР, оставив в правых частях исходные свободные члены.

Так правильно

ФСР относится к однородной системе: справа нули. Свободные члены используются только для X₀.

Так нельзя

Считать, что сумма двух решений неоднородной системы — тоже её решение.

Так правильно

A(X₁ + X₂) = B + B = 2B ≠ B. Зато разность двух решений неоднородной системы — решение однородной.

Так нельзя

Применять теорему о структуре к несовместной системе.

Так правильно

Теорема говорит о совместной системе. Сначала проверь r(A) = r(Ā).

Так нельзя

Решить, что ответ неверен, потому что он не совпал с ответом в книге.

Так правильно

Частное решение и ФСР выбираются неоднозначно. Подставь свой ответ в систему и проверь, что X₀ решает неоднородную систему, а ei — однородную, и ei независимы.

Кратко для повторения

  • Теорема: общее решение совместной неоднородной системы = частное решение этой системы + общее решение соответствующей однородной (та же A, нули справа).
  • Доказательство: разность двух решений неоднородной системы решает однородную; сумма решений неоднородной и однородной систем снова решает неоднородную.
  • Базисное решение: все свободные неизвестные равны нулю.
  • Алгоритм: ранги → главные и свободные → X₀ (свободные 0, правые части исходные) → ФСР (правые части нули, свободные поочерёдно 1) → X = X₀ + c₁e₁ + … + cn−ren−r.
  • Разные выборы X₀ и ФСР дают равносильные ответы; проверка — подстановка.

Проверь себя

Задания для самопроверки

Решено: 0 из 6

Ответ — число: целое, десятичное (0,25) или дробь (1/4). Минус — обычный дефис. Подсказки появляются после неверного ответа, решение можно открыть в любой момент.

1
Векторы X₁ и X₂ — решения системы A·X = B, где B ≠ O. Какие из векторов тоже являются решениями этой же системы A·X = B? Отметьте все верные.
Варианты ответа; можно выбрать несколько

Показать решение

A·(X₁ + X₂)/2 = (B + B)/2 = B и A·(3X₁ − 2X₂) = 3B − 2B = B: в обоих случаях сумма коэффициентов равна 1. Сумма даёт 2B, разность даёт O.

2
Найдите базисное решение системы в базисе из неизвестных x1, x2 (свободные x3, x4 равны нулю). Введите x1, x2, x3, x4.
x1 + 2x2 + x3 − x4 = 3
2x1 + 3x2 − x3 + x4 = 4

Показать решение

При x3 = x4 = 0 остаётся x1 + 2x2 = 3, 2x1 + 3x2 = 4. Δ = −1, Δ1 = 3·3 − 2·4 = 1, Δ2 = 1·4 − 3·2 = −2, поэтому x1 = −1, x2 = 2. Проверка: −1 + 4 = 3, −2 + 6 = 4.

3
Выведите на листке теорему о структуре общего решения: пусть X₀ — решение системы A·X = B. Покажите, что X — решение этой системы тогда и только тогда, когда X − X₀ — решение системы A·X = O. Сверьтесь с решением.

Показать решение

Если A·X = B, то A(X − X₀) = AX − AX₀ = B − B = O: разность решает однородную систему. Обратно, пусть Y = X − X₀ и A·Y = O. Тогда A·X = A(X₀ + Y) = AX₀ + AY = B + O = B. Значит, все решения неоднородной системы — это X₀ + Y, где Y пробегает решения однородной, то есть X₀ + c₁e₁ + … + ckek.

4
Решаем уравнение 2x − y + z = 4. В каком шаге ошибка?
Варианты ответа

Показать решение

ФСР строят для однородной системы 2x − y + z = 0: y = 2x + z. Число −4 оставлять нельзя. При x = 1, z = 0 получаем y = 2, e₁ = (1, 2, 0). Проверка: 2·1 − 2 + 0 = 0. А вектор (1, −2, 0) даёт 2 + 2 = 4 ≠ 0.

5
Дополните формулировку теоремы о структуре общего решения:
Общее решение совместной неоднородной системы равно сумме неоднородной системы и соответствующей однородной системы. При построении ФСР в правые части уравнений ставят .

Показать решение

Теорема: X = X₀ + (общее решение однородной системы). Соответствующая однородная система имеет те же коэффициенты и нули в правых частях, поэтому для ФСР свободные члены заменяют нулями.

6
Какие из записей являются общим решением уравнения x + y = 3 (две неизвестные)? Отметьте все верные.
Варианты ответа; можно выбрать несколько

Показать решение

Подходит запись, где первое слагаемое — решение уравнения x + y = 3, а второе — решение однородного x + y = 0, то есть кратное (−1, 1). Первая запись: (3, 0) подходит. Вторая: (1, 2) подходит (1 + 2 = 3), (2, −2) = −2·(−1, 1). Третья и четвёртая нарушают эти условия.
