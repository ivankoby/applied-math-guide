Линейное пространство

Линейное пространство — это набор «штук», которые можно складывать и умножать на число.

🔢
Числа
🧮
Таблицы одного размера
📏
Наборы из n чисел
вот примеры таких наборов
x + y = y + x; α(x + y) = αx + αy
Первое: порядок сложения не важен. Второе: число «раскрывает скобки».
  • 🍬Сумма двух элементов тоже элемент пространства.
  • 🔁Элемент, умноженный на число, тоже в пространстве.
  • 🏠Подпространство — часть пространства, где тоже можно складывать и умножать.
💡 Как в жизниДве кучки конфет сложить — получится одна кучка. Кучку утроить — конфет станет втрое больше.

Линейная зависимость

Если из одних векторов можно собрать другой, набор лишний. Такой набор зависимый.

🎯
Вышел ноль?
ноль при ненулевых числах — набор зависимый
λ₁a₁ + λ₂a₂ + … + λₙaₙ = 0
Если хотя бы одно λ не ноль, набор зависимый. Если все λ нули, независимый.
  • 🧩Если один вектор — сумма остальных с числами, набор зависимый.
  • 🙅Нулевой вектор в наборе делает его зависимым.
  • 🧺Если часть набора зависима, весь набор тоже зависим.
💡 Как в жизниКонструктор: если деталь собирается из других, она лишняя. Её можно не брать.
🎓 Слова для взрослых
линейная комбинация — сумма векторов, каждый умножен на своё числолинейно независимые — ни один вектор не собирается из остальных
Когда набор векторов зависимый?
✅ Когда сумма с числами даёт ноль, а числа не все нули.
3

Базис и координаты

Базис — это главные «кубики» пространства. Любой вектор собирается из них ровно одним способом.

  1. Выбери n независимых векторов — это базис.
  2. Разложи любой вектор по базису.
  3. Числа перед кубиками — координаты вектора.
x = x₁f₁ + x₂f₂ + … + xₙfₙ
Читается: «икс равно икс-один эф-один плюс…». Числа x₁…xₙ — координаты x.
  • 🧱Базис в n-мерном пространстве — n независимых векторов.
  • ➕Складываются векторы — складываются и их координаты.
  • 📍Вектор MN: координаты конца N минус координаты начала M.
💡 Как в жизниБашня из кубиков: «два красных, один синий». Числа — сколько кубиков каждого цвета.
🎓 Слова для взрослых
базис — набор независимых векторов, из которых всё собираетсякоординаты — числа, сколько базисных векторов взятьразмерность — число векторов в базисеизоморфизм — соответствие, которое сохраняет сложение и умножение на число
Что такое координаты вектора?
✅ Числа, на которые умножаем базисные векторы, чтобы получить вектор.
