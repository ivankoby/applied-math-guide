Конфликт обозначений

В статьях 4.4 и 4.6 запись (a, b, c) означает упорядоченную тройку (про неё говорят «правая» или «левая»), а число всегда пишется (a × b)·c. В практике (a, b, c) — это число ([a, b], c). Противоречия нет: знак этого числа показывает ориентацию тройки. Рядом слова «правая», «левая» — это набор; рядом число, определитель или «объём» — произведение.

Выражения с a² и (a, b) (пр. 1.2)

Квадрат вектора — скалярное произведение на себя: a² = (a, a) = |a|², число. Метод: найди число для каждой «детали» (a², b², (a, b), …) по координатной формуле скалярного произведения и подставь. Коэффициент умножает число: 4b² значит 4·b². Скобки раскрывай по линейности (статья 4.1), помня (b, a) = (a, b).

Пример 1по типу пр. 1.2
Для a = (3; −2), b = (−1; 4), c = (2; 5) найти 2a² + 5(a, b) − 3b² + 3(b, c) − c².

  1. Детали:

    a² = 3·3 + (−2)·(−2) = 9 + 4 = 13, (a, b) = 3·(−1) + (−2)·4 = −3 − 8 = −11, b² = (−1)·(−1) + 4·4 = 1 + 16 = 17
    (b, c) = (−1)·2 + 4·5 = −2 + 20 = 18, c² = 2·2 + 5·5 = 4 + 25 = 29

  2. Подстановка:

    2·13 + 5·(−11) − 3·17 + 3·18 − 29 = 26 − 55 − 51 + 54 − 29 = −55

  3. Проверка. Первые три слагаемых — это (2a − b, a + 3b) (раскрой скобки по линейности, статья 4.1). В координатах 2a − b = (7; −8), a + 3b = (0; 10), их произведение 0 − 80 = −80, и −80 + 54 − 29 = −55.

−55.

Векторы через m и n; диагонали параллелограмма (пр. 1.3)

Здесь a = αm + βn, известны |m|, |n| и угол между m и n. Метод: (1) найди три числа m², n², (m, n) = |m||n|·cos∠(m, n); (2) раскрой скалярные произведения, как произведение двучленов; (3) диагонали параллелограмма на a и b из общей вершины — d₁ = a + b, d₂ = a − b; (4) угол — по формуле cos φ = (a, b)/(|a||b|) (статья 4.2). Нужные косинусы: cos 60° = 1/2, cos 120° = −1/2, cos 45° = √2/2, cos 30° = √3/2.

Пример 2по типу пр. 1.3
Параллелограмм построен на a = m + 3n и b = 2m + n, где |m| = 2, |n| = 3, ∠(m, n) = π/3. Найти угол φ между диагоналями.

  1. Числа: m² = 4, n² = 9, (m, n) = 2·3·cos(π/3) = 3. Диагонали: d₁ = a + b = 3m + 4n, d₂ = a − b = −m + 2n.

  2. Скалярное произведение и длины:

    (d₁, d₂) = −3m² + 2(m, n) + 8n² = −3·4 + 2·3 + 8·9 = 66
    |d₁|² = 9m² + 24(m, n) + 16n² = 9·4 + 24·3 + 16·9 = 252, |d₂|² = m² − 4(m, n) + 4n² = 4 − 4·3 + 4·9 = 28

  3. Угол: cos φ = 66/√(252·28) = 66/84 = 11/14 (7056 = 84²), φ = arccos(11/14) ≈ 38,2°.

  4. Контроль: (a + b, a − b) = |a|² − |b|² (скобки раскрыты по линейности, (a, b) = (b, a)). Длины самих a и b:

    |a|² = m² + 6(m, n) + 9n² = 4 + 6·3 + 9·9 = 103, |b|² = 4m² + 4(m, n) + n² = 4·4 + 4·3 + 9 = 37

    Разность 103 − 37 = 66 совпадает с (d₁, d₂).

φ = arccos(11/14) ≈ 38,2°.

Формула cos φ = (a, b)/(|a||b|) даёт угол между векторами d₁ и d₂; смежный угол равен 180° − φ. Диагонали перпендикулярны ровно при |a| = |b| и равны ровно при (a, b) = 0.

Вектор, перпендикулярный двум данным, с заданной координатой (пр. 1.4)

«Проекция c на ось Oz равна 5» значит cz = 5: проекция на Oz равна (c, k)/|k|, а |k| = 1. Два способа. Система: (c, a) = 0, (c, b) = 0, cz = 5. Через a × b: если a, b не коллинеарны, любой вектор, перпендикулярный обоим, имеет вид c = t·(a × b). Причина (в ℝ³): векторы, перпендикулярные плоскости a, b, образуют одну прямую (статья 4.4: первое условие определения даёт именно прямую), а a × b лежит на ней и ненулевой (статья 4.5: для неколлинеарных a, b); значит, все остальные её векторы получаются умножением на число t. Число t находят из условия на координату: t·(a × b)z = cz. Если (a × b)z = 0, то z-координата любого такого вектора нулевая, и условие cz = 5 невыполнимо.

Пример 3по типу пр. 1.4
Найти c, перпендикулярный a = i − j − 3k и b = −3i − j + 5k, если проекция c на ось Oz равна 2.

  1. Через a × b. Компоненты:

    (−1)·5 − (−3)·(−1) = −8, (−3)·(−3) − 1·5 = 4, 1·(−1) − (−1)·(−3) = −4

    a × b = (−8; 4; −4). Условие t·(−4) = 2 даёт t = −1/2, поэтому c = −1/2·(−8; 4; −4) = (4; −2; 2).

  2. Системой:

    x − y − 3z = 0
    −3x − y + 5z = 0
    z = 2

    При z = 2: x − y = 6, −3x − y = −10. Вычитаем: 4x = 16, x = 4, y = −2 — тот же вектор.

  3. Проверка: (c, a) = 4 + 2 − 6 = 0, (c, b) = −12 + 2 + 10 = 0.

c = (4; −2; 2).

Работа силы (пр. 1.5)

Постоянная сила F перемещает точку на вектор s = PQ (конец минус начало). Работа — скалярное произведение: A = (F, s) = |F||s|·cos φ. Если сил несколько, сначала сложи их: F = f₁ + f₂ + f₃. Форма траектории не важна, пока сила постоянна. Знак работы — знак cos φ: при φ > 90° она отрицательна, при F ⟂ s равна нулю. Ответ: «ед. раб.». Тот же счёт в экономике: стоимость набора товаров — (P, X) = p₁x₁ + … + pₙxₙ (цены на количества).

Пример 4по типу пр. 1.5
Силы f₁ = i + 2j − 3k, f₂ = −2i − 5j + 4k, f₃ = 2i − j + 2k приложены к точке. Найти работу равнодействующей при перемещении из P(−2; 1; 4) в Q(1; 3; 2).

  1. Равнодействующая:

    F = (1 − 2 + 2; 2 − 5 − 1; −3 + 4 + 2) = (1; −4; 3)

    Перемещение: s = PQ = (1 + 2; 3 − 1; 2 − 4) = (3; 2; −2).

  2. Работа:

    A = (F, s) = 1·3 + (−4)·2 + 3·(−2) = 3 − 8 − 6 = −11

  3. Знак «минус»: φ ≈ 121,5° (тупой угол), сила в целом направлена против движения. Проверка: сумма работ отдельных сил 13 + (−24) + 0 = −11.

A = −11 ед. раб.

Векторное произведение линейных комбинаций (пр. 1.6, задача 6б)

Чтобы найти [αa + βb, γa + δb], не обязательно строить оба вектора: раскрой скобки по свойствам 1°, 2° и 4° (статья 4.4; свойство 1° нужно, чтобы раскрывать скобки и во втором множителе; из него же [b, a] = −[a, b] и [a, a] = 0).

[αa + βb, γa + δb] = αδ[a, b] + βγ[b, a] = (αδ − βγ)·[a, b]
Считаем один раз [a, b]. Верно в ℝ³ при любых числах α, β, γ, δ.
Пример 5по типу пр. 1.6 и задачи 6б
Для a = (1; 2; −1) и b = (3; −1; 2) найти [a + 2b, 3a − b].

  1. В лоб: a + 2b = (7; 0; 3), 3a − b = (0; 7; −5), компоненты:

    0·(−5) − 3·7 = −21, 3·0 − 7·(−5) = 35, 7·7 − 0·0 = 49

    [a + 2b, 3a − b] = (−21; 35; 49).

  2. По формуле: αδ − βγ = 1·(−1) − 2·3 = −7, а [a, b]:

    2·2 − (−1)·(−1) = 3, (−1)·3 − 1·2 = −5, 1·(−1) − 2·3 = −7

    Поэтому −7·(3; −5; −7) = (−21; 35; 49) — тот же ответ.

  3. Проверка: результат коллинеарен [a, b], значит, перпендикулярен a и b: −21 + 70 − 49 = 0, −63 − 35 + 98 = 0.

(−21; 35; 49).

Для задачи 6б [a + b, 2a − b]: α = β = 1, γ = 2, δ = −1, αδ − βγ = −3, ответ −3[a, b]. Результат всегда коллинеарен [a, b]; если нет, где-то ошибка.

Высота треугольника (пр. 1.7)

После площади S = ½|AB × AC| (статья 4.5) высота следует из S = ½·a·h, где a — сторона, на которую она опущена. Для высоты из вершины C на сторону AB:

hC = 2S / |AB| = |AB × AC| / |AB|
Числитель — площадь параллелограмма (одна и та же для любой пары сторон из общей вершины), знаменатель — сторона, на которую падает высота.
Пример 6по типу пр. 1.7
Вершины A(0; 1; 2), B(2; −1; 3), C(3; 2; −1). Найти площадь треугольника и высоту из C.

  1. AB = (2; −2; 1), AC = (3; 1; −3), компоненты AB × AC:

    (−2)·(−3) − 1·1 = 5, 1·3 − 2·(−3) = 9, 2·1 − (−2)·3 = 8

    AB × AC = (5; 9; 8), |AB × AC|² = 5² + 9² + 8² = 25 + 81 + 64 = 170 (170 = 2·5·17, корень не упрощается). S = ½√170 ≈ 6,52.

  2. |AB|² = 2² + (−2)² + 1² = 4 + 4 + 1 = 9, |AB| = 3, поэтому hC = √170/3 ≈ 4,35.

  3. Проверка по Пифагору: проекция AC на AB равна (AC, AB)/|AB| = 1/3, h² = |AC|² − (1/3)² = 19 − 1/9 = 170/9.

S = ½√170, hC = √170/3 ≈ 4,35.

Ответ образца 1.7 √9610/√89 верен, но не доведён: 9610 = 31²·10, то есть √9610 = 31√10.

Момент силы (пр. 1.8)

Момент силы F, приложенной в точке A, относительно точки O — вектор MO(F) = [OA, F]. Радиус-вектор OA = A − O идёт от O к точке приложения и стоит первым. Модуль |M| = |OA||F|·sin φ = |F|·d, где d — расстояние от O до линии действия силы; для ненулевой силы M = 0 ровно тогда, когда O лежит на этой линии. Несколько сил в одной точке заменяют равнодействующей ([r, f₁ + f₂] = [r, f₁] + [r, f₂]). Работа — число, момент — вектор. Модули сравнивай по квадратам.

Пример 7по типу пр. 1.8
К точке A(2; −1; 3) приложены силы f₁ = (1; 2; −1), f₂ = (0; −3; 2), f₃ = (2; 1; 1). Сравнить модули момента равнодействующей относительно O₁(1; 1; 1) и O₂(0; −2; 5).

  1. F = f₁ + f₂ + f₃ = (3; 0; 2). Радиус-векторы (конец A минус начало): O₁A = (1; −2; 2), O₂A = (2; 1; −2).

  2. Моменты:

    M₁ = [O₁A, F]: (−2)·2 − 2·0 = −4, 2·3 − 1·2 = 4, 1·0 − (−2)·3 = 6
    M₂ = [O₂A, F]: 1·2 − (−2)·0 = 2, (−2)·3 − 2·2 = −10, 2·0 − 1·3 = −3

    M₁ = (−4; 4; 6), M₂ = (2; −10; −3).

  3. Сравнение: |M₁|² = (−4)² + 4² + 6² = 16 + 16 + 36 = 68, |M₂|² = 2² + (−10)² + (−3)² = 4 + 100 + 9 = 113; 113 > 68, значит, |M₂| > |M₁| (корни извлекать не нужно).

  4. Проверка: момент перпендикулярен OA и F: (M₂, O₂A) = 4 − 10 + 6 = 0, (M₂, F) = 6 + 0 − 6 = 0 (для M₁ тоже нули).

|MO₂| = √113 > |MO₁| = √68.

Неточность формулировки

В теории практики сказано, что при компланарности «любой вектор можно выразить через два других». Неточно: (1; 0; 0), (2; 0; 0), (0; 1; 0) компланарны, но третий через первые два не выразить. Верно: хотя бы один из трёх — комбинация двух других (статья 4.7).

Частые ошибки

Так нельзя

Пр. 1.2–1.3: читать 4b² как (4b)²; в (−2m + n) − (m + 3n) не сменить знаки второй скобки.

Так правильно

4b² = 4·(b, b). Минус перед скобкой меняет оба знака: получится −3m − 2n. Контроль: (a + b, a − b) = |a|² − |b|².

Так нельзя

Пр. 1.4: подставить условие «проекция на Oz равна 5» в y или взять просто c = a × b.

Так правильно

Проекция на Oz — это z. Вектор a × b умножают на t = cz/(a × b)z и проверяют (c, a) = (c, b) = 0.

Так нельзя

Пр. 1.5 и 1.8: перемещение P − Q, момент [F, OA] или радиус-вектор O − A.

Так правильно

s = Q − P, MO = [OA, F], OA = A − O: конец минус начало. Сначала складывают силы.

Так нельзя

Пр. 1.6: взять αδ + βγ. Пр. 1.7: считать высоту как |AB × AC| или S/|AB|.

Так правильно

В формуле разность: (αδ − βγ)[a, b]. Высота h = 2S/|AB| = |AB × AC|/|AB|: |AB × AC| — площадь параллелограмма.

Кратко для повторения

Кратко для повторения

  • [a, b] = [a×b] = a × b; ([a, b], c) = (a, b, c) = abc = (a × b)·c; a² = (a, a) = |a|²; нет орта — координата 0.
  • Выражения с a²: числа a², b², (a, b) и подстановка; векторы через m, n — числа m², n², (m, n). Перпендикуляр с заданной z: c = t·(a × b).
  • A = (F, s), MO = [OA, F], векторы — конец минус начало; [αa + βb, γa + δb] = (αδ − βγ)[a, b]; h = |AB × AC|/|AB|.
  • В пособии неверны образцы 1.3 (60°), 1.4 ((20; −15; 5)), 1.6 ((52; −64; 68)) и 1.10 (868, а не 869).
