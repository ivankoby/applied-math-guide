Статья 4.2

Длина, угол и неравенство Коши–Буняковского

  • Читать: около 18 минут, плюс задания
  • Перед чтением: скалярное произведение и его аксиомы (статья 4.1); квадратный трёхчлен и дискриминант; косинус угла (школьный курс)

В статье 4.1 скалярное произведение дало длину вектора |x| = √(x, x). Теперь нужен угол. Его хочется определить формулой cos φ = (x, y) / (|x|·|y|), но корректно ли это? Косинус не бывает больше 1 по модулю, а вдруг дробь в произвольном евклидовом пространстве получится равной 2? Ответ даёт неравенство Коши–Буняковского: оно гарантирует, что дробь лежит в [−1; 1]. Из него же выводится неравенство треугольника, которого не хватало в статье 4.1.

Неравенство Коши–Буняковского

Теорема (неравенство Коши–Буняковского)

Для любых векторов x и y из евклидова пространства En справедливо неравенство |(x, y)| ≤ |x|·|y|. (3.7)

Скалярное произведение по модулю не больше произведения длин. Доказательство из лекции придумано остроумно: ищут вектор, у которого скалярный квадрат заведомо неотрицателен, и смотрят, что это говорит о квадратном трёхчлене.

Доказательство. Пусть x ≠ 0 (если x = 0, обе части равны нулю, и неравенство верно). Рассмотрим вектор λx − y, где λ — любое вещественное число. По аксиоме г) (λx − y, λx − y) ≥ 0. Раскроем скобки по аксиомам а)–в) (статья 4.1):

λ²·(x, x) − 2λ·(x, y) + (y, y) ≥ 0 (3.8)
Слева — квадратный трёхчлен относительно λ; его старший коэффициент (x, x) положителен, так как x ≠ 0.

Парабола с ветвями вверх, лежащая не ниже оси λ, не может пересекать ось в двух различных точках: между корнями она была бы отрицательной. Значит, у трёхчлена нет двух различных вещественных корней, и его дискриминант не положителен. Лекция записывает дискриминант, поделённый на 4:

(x, y)² − (x, x)·(y, y) ≤ 0, то есть (x, y)² ≤ (x, x)·(y, y) = |x|²·|y|²
Извлекаем квадратный корень из неотрицательных частей — получаем (3.7).

Замечание

В конце доказательства на стр. 3 написано «приходим к (6)». Имеется в виду формула (3.7): ссылка на (6) — опечатка.

Пример 1дополнительно
Проверить неравенство Коши–Буняковского для x = (1, 2) и y = (3, 1) в ℝ².

  1. Считаем три числа: (x, x) = 1 + 4 = 5, (x, y) = 1·3 + 2·1 = 5, (y, y) = 9 + 1 = 10.

  2. Трёхчлен (3.8) принимает вид 5λ² − 10λ + 10. Его дискриминант, делённый на 4, равен 5² − 5·10 = −25 < 0: корней нет, трёхчлен положителен при всех λ.

  3. Сам результат: |(x, y)| = 5, а |x|·|y| = √5·√10 = √50 ≈ 7,07. Верно: 5 ≤ 7,07.

Неравенство выполнено: 5 ≤ √50.

Когда достигается равенство (дополнение к лекции). Равенство |(x, y)| = |x|·|y| бывает тогда и только тогда, когда векторы коллинеарны. Если y = μx, то |(x, y)| = |μ|·(x, x) = |x|·|μx| = |x|·|y|. Обратно, пусть x ≠ 0 и равенство есть: тогда дискриминант равен нулю, у трёхчлена (3.8) есть корень λ₀, то есть (λ₀x − y, λ₀x − y) = 0, и по аксиоме г) λ₀x − y = 0, то есть y = λ₀x.

Угол между векторами

Пусть x и y ненулевые. Поделим (3.7) на |x|·|y| > 0. Получим −1 ≤ (x, y)/(|x|·|y|) ≤ 1. Значит, есть ровно один угол φ из промежутка [0; π], косинус которого равен этой дроби.

Угол между векторами

Углом φ между ненулевыми векторами x и y называется число φ ∈ [0; π], для которого cos φ = (x, y) / (|x|·|y|).

Без неравенства Коши–Буняковского это определение ничего не стоило бы: у дроби могло бы не оказаться арккосинуса. В ℝ² и ℝ³ со стандартным произведением получается обычный угол между стрелками. Вот почему. Отложим x и y из одной точки; по теореме косинусов для третьей стороны x − y имеем |x − y|² = |x|² + |y|² − 2|x||y|·cos φ. А по аксиомам (x − y, x − y) = |x|² − 2(x, y) + |y|². Сравнивая, получаем (x, y) = |x||y|·cos φ.

Что говорит знак скалярного произведения
Знак (x, y)Значение cos φУгол φ
(x, y) > 0cos φ > 0острый, 0 ≤ φ < 90°
(x, y) = 0cos φ = 0прямой, φ = 90°
(x, y) < 0cos φ < 0тупой, 90° < φ ≤ 180°

Как найти угол. (1) Посчитай (x, y). (2) Найди |x| и |y|. (3) Подставь в cos φ = (x, y)/(|x|·|y|); результат обязан лежать в [−1; 1] — это проверка. (4) φ = arccos(…); арккосинус всегда даёт угол из [0; π], как и требуется.

Пример 2дополнительно
Найти угол между векторами x и y в ℝ³ (стандартное произведение): (а) x = (1, 1, 0), y = (0, 1, 1); (б) x = (3, −4, 0), y = (1, 2, 2).

  1. (а) Скалярное произведение и длины:

    (x, y) = 1·0 + 1·1 + 0·1 = 0 + 1 + 0 = 1
    |x| = √(1 + 1 + 0) = √2, |y| = √(0 + 1 + 1) = √2
    cos φ = 1/(√2·√2) = 1/2, откуда φ = 60°

  2. (б) Здесь:

    (x, y) = 3·1 + (−4)·2 + 0·2 = 3 − 8 + 0 = −5
    |x| = √(9 + 16) = 5, |y| = √(1 + 4 + 4) = 3
    cos φ = −5/(5·3) = −1/3, откуда φ = arccos(−1/3) ≈ 109,5°

    Скалярное произведение отрицательно, и угол получился тупым, как и положено по таблице выше.

(а) 60°; (б) arccos(−1/3) ≈ 109,5°.

Не удивляйся

Угол зависит от того, какое скалярное произведение выбрано. Для x = (1, 1) и y = (1, 0) стандартное произведение даёт cos φ = 1/√2, то есть 45°. Для (x, y) = 2α₁β₁ + 3α₂β₂ (статья 4.1) получим (x, y) = 2, |x| = √5, |y| = √2, cos φ = 2/√10, и φ ≈ 50,8°.

Ортогональность

Ортогональные векторы

Два ненулевых вектора x и y из En называются ортогональными, если (x, y) = 0.

Это в точности случай cos φ = 0, то есть φ = 90°: в ℝ² и ℝ³ — перпендикулярные стрелки. Нулевой вектор формально даёт (0, y) = 0, но в определении лекции требуется ненулевые векторы; именно так надо понимать ортогональность в статье 4.3.

Пример 3дополнительно
(а) Проверить, ортогональны ли x = (1, 2, 2) и y = (2, −2, 1). (б) При каком t векторы (t, 6, 2) и (2, 1, 4) ортогональны?

  1. (а) Считаем скалярное произведение:

    (x, y) = 1·2 + 2·(−2) + 2·1 = 2 − 4 + 2 = 0

    Оно равно нулю, векторы ненулевые, значит, они ортогональны.

  2. (б) Условие (x, y) = 0 — это уравнение на t:

    t·2 + 6·1 + 2·4 = 2t + 14 = 0

    Отсюда t = −7. Проверка: (−7)·2 + 6·1 + 2·4 = −14 + 6 + 8 = 0.

(а) да; (б) t = −7.

Обычная перпендикулярность стрелок — частный случай ортогональности (при стандартном скалярном произведении), а ортогональность зависит от выбранного скалярного произведения: векторы (1, 2) и (3, −1) ортогональны для 2α₁β₁ + 3α₂β₂ (6 − 6 = 0), но не для стандартного (3 − 2 = 1).

Неравенство треугольника: евклидово пространство нормировано

В статье 4.1 осталась непроверенной аксиома 3 нормы. Теперь у нас есть всё, чтобы её доказать. Начнём с тождества, которое выведем раскрытием скобок по аксиомам скалярного произведения:

|x + y|² = (x + y, x + y) = (x, x) + 2(x, y) + (y, y)
Это «квадрат суммы» для векторов; его используют постоянно.

Теорема (неравенство Минковского, или треугольника). |x + y| ≤ |x| + |y|.

Доказательство из лекции. Из (3.7) следует (x, y) ≤ |(x, y)| ≤ √(x, x)·√(y, y). Поэтому |x + y|² ≤ (x, x) + 2√(x, x)·√(y, y) + (y, y) = (√(x, x) + √(y, y))² = (|x| + |y|)². Обе части неотрицательны, извлекаем корень: |x + y| ≤ |x| + |y|.

Аксиомы 1 и 2 нормы мы проверили в статье 4.1, аксиому 3 — только что. Значит, евклидово пространство нормировано: каждое скалярное произведение порождает норму |x| = √(x, x).

  • Если (x, y) = 0, тождество превращается в теорему Пифагора: |x + y|² = |x|² + |y|².
  • Равенство |x + y| = |x| + |y| (дополнение к лекции) бывает, когда (x, y) = |x||y|, то есть cos φ = 1: векторы сонаправлены. Например, x = (1, 2), y = (2, 4): |x + y| = |(3, 6)| = 3√5 = √5 + 2√5.
  • Для x = (3, 0), y = (0, 4) получаем |x + y| = 5 < 3 + 4 = 7. Для y = −x имеем |x + y| = 0 < 2|x|, хотя неравенство Коши–Буняковского здесь обращается в равенство.

Проекция: что ещё показывает скалярное произведение

Дополнение к лекции. Из формулы (x, y) = |x||y|·cos φ видно, что произведение измеряет, «насколько x направлен вдоль y». Для ненулевого y величина

pry x = (x, y) / |y| = |x|·cos φ
Длина проекции вектора x на направление y; со знаком: отрицательна, если угол тупой.

Сам вектор-проекция лежит на прямой y и равен (x, y)/(y, y)·y. Разность x и этой проекции ортогональна y:

(x − (x, y)/(y, y)·y, y) = (x, y) − (x, y)/(y, y)·(y, y) = 0
Именно это свойство нужно в статье 4.3, в процессе ортогонализации.
Пример 4дополнительно
Найти вектор-проекцию x = (2, 3) на направление y = (4, 1) и убедиться, что остаток ортогонален y.

  1. Считаем числа: (x, y) = 2·4 + 3·1 = 11, (y, y) = 16 + 1 = 17.

  2. Вектор-проекция p = (x, y)/(y, y)·y = 11/17·(4, 1) = (44/17, 11/17).

  3. Остаток: x − (44/17, 11/17) = (−10/17, 40/17). Скалярное произведение с y: (−10/17)·4 + (40/17)·1 = (−40 + 40)/17 = 0 — остаток ортогонален y.

Проекция (44/17, 11/17); остаток (−10/17, 40/17) ортогонален y.

Частые ошибки

Так нельзя

Писать cos φ = (x, y)/(|x| + |y|).

Так правильно

В знаменателе произведение длин: cos φ = (x, y)/(|x|·|y|). Если косинус вышел за [−1; 1], где-то арифметическая ошибка.

Так нельзя

Считать, что (x, y) = |x|·|y| всегда.

Так правильно

Верно (x, y) = |x||y|·cos φ. Равенство без косинуса возможно только при cos φ = 1 (векторы сонаправлены).

Так нельзя

Для (x, y) = 0 записать φ = 0.

Так правильно

Нулю равен косинус, а не угол: cos 90° = 0. Ортогональные векторы образуют угол 90°.

Так нельзя

Писать |x + y|² = |x|² + |y|² для любых векторов.

Так правильно

В общем случае |x + y|² = |x|² + 2(x, y) + |y|². Теорема Пифагора верна только при (x, y) = 0.

Так нельзя

Считать угол между векторами, равный 200° или −30°.

Так правильно

Угол между векторами лежит в [0°; 180°]: так устроен арккосинус.

Кратко для повторения

Кратко для повторения

  • Неравенство Коши–Буняковского: |(x, y)| ≤ |x|·|y|. Доказательство: (λx − y, λx − y) ≥ 0 для всех λ, значит, дискриминант трёхчлена λ²(x, x) − 2λ(x, y) + (y, y) не положителен.
  • Угол между ненулевыми векторами: cos φ = (x, y)/(|x|·|y|), φ ∈ [0; π]; корректность следует из неравенства Коши–Буняковского.
  • Ненулевые векторы ортогональны, если (x, y) = 0 (φ = 90°). Угол и ортогональность зависят от выбранного скалярного произведения.
  • Неравенство треугольника: |x + y| ≤ |x| + |y|, из |x + y|² = |x|² + 2(x, y) + |y|² и (3.7). Значит, евклидово пространство нормировано.
  • Проекция x на направление y: число (x, y)/|y|, вектор (x, y)/(y, y)·y; остаток ортогонален y.

1
Найдите косинус угла между векторами x = (3, 4) и y = (4, 3) в ℝ² (десятичной дробью или обыкновенной).

Показать решение

(x, y) = 3·4 + 4·3 = 24, |x| = √(9 + 16) = 5, |y| = √(16 + 9) = 5.

cos φ = 24/(5·5) = 24/25 = 0,96
2
При каком t векторы (t, 6, 2) и (2, 1, 4) ортогональны?

Показать решение

Условие ортогональности (x, y) = 0: 2t + 6 + 8 = 0, откуда t = −7.

3
Могут ли существовать векторы с (x, y) = 8, |x| = 2, |y| = 3? Что можно сказать?
Варианты ответа

Показать решение

По неравенству Коши–Буняковского |(x, y)| ≤ |x|·|y| = 6, а по условию (x, y) = 8 > 6. Такие векторы невозможны (дробь 8/6 > 1 не может быть косинусом).

В знаменателе |x|·|y|, а не |x| + |y|: cos φ = 1/(√2·√2) = 1/2, φ = 60°.
