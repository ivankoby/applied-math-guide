Что такое система уравнений

Система уравнений — это несколько загадок про одни и те же числа. Ответ должен подходить ко всем сразу.

🔑 Совместна

  • Хотя бы один ключ подходит
  • Один ключ — определённая
  • Много ключей — неопределённая

🔒 Несовместна

  • Ни один ключ не подходит
  • Решений нет
ключ-подбор
A · X = B
A — таблица коэффициентов, X — столбец неизвестных, B — столбец свободных членов.
  • ⚖️Решение — набор чисел, при котором все уравнения верны.
  • 1️⃣Единственное решение — определённая система.
  • ♾️Решений много — неопределённая система.
  • 🧾Расширенная матрица — A с приписанным столбцом B.
💡 Как в жизниКак весы: обе чашки должны быть в равновесии.
🎓 Слова для взрослых
коэффициенты — числа перед неизвестнымисвободные члены — числа справа от знака равносовместная система — у неё есть хотя бы одно решение
Как называется система, у которой одно решение?
✅ Определённая.
2

Крамер и матричный способ

Если определитель системы не ноль, ответы находятся сразу. Два способа: матричный и Крамера.

  1. Найди определитель Δ матрицы A
  2. Замени i-й столбец на столбец B — получится Δᵢ
  3. Раздели Δᵢ на Δ — это значение xᵢ
правило Крамера, если Δ ≠ 0
xᵢ = Δᵢ / Δ
Δ — определитель системы. Δᵢ — определитель с заменённым i-м столбцом. Нужно Δ ≠ 0.
  • 🧮Матричный способ: X = A⁻¹ · B.
  • 🚫Если Δ = 0, формулы Крамера не подходят — нужен Гаусс.
  • 🔍Невырожденная система имеет ровно одно решение.
💡 Как в жизниКак конструктор: меняешь одну деталь, остальные оставляешь на месте.
🎓 Слова для взрослых
определитель системы Δ — определитель таблицы коэффициентовневырожденная система — Δ не равен нулюформулы Крамера — ответы через определители
Когда работают формулы Крамера?
✅ Когда определитель системы не равен нулю.
3

Метод Гаусса и теорема Кронекера–Капелли

Метод Гаусса убирает неизвестные по одному. Сначала строим ступеньки, потом спускаемся и находим ответы.

  1. Прямой ход: получаем ступенчатый вид
  2. Пустые строки 0 = 0 — отбрасываем
  3. Обратный ход: находим неизвестные с конца
метод Гаусса
r(A) = r(Ā)
Ранг основной матрицы равен рангу расширенной — система совместна (Кронекер–Капелли).
  • 🪜Ступенчатый вид: каждое следующее уравнение короче предыдущего.
  • 🚫Строка вида 0 = b, где b не ноль — решений нет.
  • 🔢r = n — определённая; r < n — неопределённая.
  • 🧱Жордан–Гаусс: приводим к единичной матрице — ответ виден сразу.
💡 Как в жизниКак лесенка в песочнице: сначала строишь ступеньки, потом по ним спускаешься.
🎓 Слова для взрослых
ступенчатый вид — уравнения идут лесенкой, каждое короче предыдущегоранг — число главных строк после упрощениябазисные неизвестные — неизвестные, которые выражаем через остальные
Какая строка означает, что решений нет?
✅ Вида 0 = b, где b не равно нулю.

Однородные системы и ФСР

Однородная система — все справа нули. Ноль-решение всегда подходит, но бывают и другие ответы.

однородная система
X = c₁e₁ + c₂e₂ + … + cₖeₖ, k = n − r
e₁…eₖ — фундаментальная система решений (ФСР). c₁…cₖ — любые числа. n — число неизвестных.
  • 🔢Ненулевые решения есть, если ранг r меньше n.
  • 🧩Если определитель системы не ноль — только нулевое решение.
  • 🧺ФСР — набор независимых решений, остальные — их сочетания.
  • 🔄Общее решение неоднородной = частное + общее однородной.
💡 Как в жизниКак смесь конфет: сколько взял каждого сорта, такой и получился набор.
🎓 Слова для взрослых
однородная система — все свободные члены равны нулюфундаментальная система решений — набор решений, через который выражается всётривиальное решение — все неизвестные равны нулю
Какое решение всегда есть у однородной системы?
✅ Нулевое: все неизвестные равны нулю.
