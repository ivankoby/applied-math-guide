1

Что такое производная

Производная — это спидометр функции. Она показывает, как быстро функция меняется.

  1. Возьми маленький шажок Δx.
  2. Найди Δy = f(x + Δx) − f(x).
  3. Раздели Δy на Δx.
  4. Делай шажок всё меньше. Предел и есть производная.
алгоритм производной
y′ = lim Δx → 0 Δy / Δx
Предел отношения приращения функции к приращению аргумента.
  • 🔤y′, f′(x) и dy/dx — записи одной и той же производной.
  • 🎢Производная — скорость изменения функции в точке.
  • 🧮Примеры: (C)′ = 0, (x)′ = 1, (xⁿ)′ = n·xⁿ⁻¹.
💡 Как в жизниСпидометр в машине показывает скорость прямо сейчас. Производная — то же для функции.
🎓 Слова для взрослых
приращение — на сколько изменилось: новое значение минус староедифференцирование — поиск производной
Чему равна производная постоянной C?
✅ Нулю: C′ = 0.

Правила дифференцирования

Есть готовые правила. Не надо каждый раз считать предел заново.

🌊
sin x → cos x
🌀
cos x → −sin x
🚀
eˣ → eˣ
📏
ln x → 1/x
строчки таблицы производных
(u / v)′ = (u′·v − u·v′) / v²
Производная дроби. Знаменатель v не должен быть нулём.
  • ➕(u ± v)′ = u′ ± v′ — суммы считаем по частям.
  • ✖️(u·v)′ = u′·v + u·v′.
  • 🔢(C·u)′ = C·u′: константу выносим за знак.
  • 📚Таблицу основных производных учат наизусть.
💡 Как в жизниКак таблица умножения: выучил один раз — и считаешь быстро.

3

Касательная и скорость

Производная показывает наклон графика в точке. Чем круче горка, тем больше производная.

📏 Касательная

  • Касается графика в одной точке
  • Наклон k = f′(x₀) = tg α
  • Уравнение: y − y₀ = f′(x₀)·(x − x₀)

📐 Нормаль

  • Перпендикулярна касательной
  • Наклон −1 / f′(x₀)
две прямые в точке касания
y − y₀ = f′(x₀) · (x − x₀)
Уравнение касательной в точке (x₀; y₀), где y₀ = f(x₀).
  • 🏃Механика: скорость — это производная пути, v(t) = s′(t).
  • 🧪Пример: y = x² − 4x + 7 при x₀ = 3 даёт касательную y = 2x − 2.
  • 🎯Точка касания: x₀ и y₀ = f(x₀).
💡 Как в жизниКасательная — как линейка, которая едва касается горки в одной точке.
🎓 Слова для взрослых
касательная — прямая, которая касается графика в одной точкенормаль — прямая через точку касания, перпендикулярная касательной
Что равно наклону касательной?
✅ Производная f′(x₀), то есть tg α.
4

Сложная, обратная, неявная функции

Сложную функцию разбирай по шагам: сначала внешняя часть, потом внутренняя.

  1. Выдели внутреннюю функцию u(x).
  2. Продифференцируй внешнюю функцию по u.
  3. Умножь на производную u(x) по x.
  4. Проверка: (cos(ax + b))′ = −a·sin(ax + b).
сложная функция по шагам
y′(x) = y′(u) · u′(x)
Производная сложной функции: производная снаружи умножить на производную внутри.
  • 🔄Обратная: (f⁻¹)′(y₀) = 1 / f′(x₀), если f′(x₀) ≠ 0.
  • 🔒Неявная F(x, y) = 0: продифференцируй обе части. Пример: x² + y² = 1 даёт y′ = −x/y.
  • 🧭Параметрическая x = φ(t), y = ψ(t): y′ = ψ′(t) / φ′(t).
  • 🪜Вторая производная — производная от первой: f″ = (f′)′.
💡 Как в жизниКак матрёшка: сначала открываешь большую, потом маленькую внутри.
🎓 Слова для взрослых
сложная функция — одна функция подставлена внутрь другойпараметрическое задание — x и y заданы через третью переменную t
С чего начинают искать производную сложной функции?
✅ С выделения внутренней функции u(x).
