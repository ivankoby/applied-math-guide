Предел функции: по Коши, по Гейне, односторонние и бесконечные пределы

Предел функции — тот же образ, что и у последовательности («значения f(x) сколь угодно близки к A, когда x близко к x₀»), но аргумент теперь меняется непрерывно, и появляются новые вопросы: с какой стороны приближаться, что делать, если функция в самой точке не определена, как говорить о бесконечных пределах и пределах на бесконечности. В статье: определение по Коши (ε–δ) из лекции, определение по Гейне (в лекции его нет), односторонние пределы, бесконечные пределы и единственность предела.

Проколотая окрестность

Для конечной точки x₀ и числа δ > 0 δ-окрестностью (точнее, проколотой окрестностью) называют множество U(x₀, δ) всех x, удовлетворяющих 0 < |x − x₀| < δ, то есть x₀ − δ < x < x₀ + δ, но x ≠ x₀. Левосторонняя окрестность U(x₀ − 0, δ): x₀ − δ < x < x₀; правосторонняя U(x₀ + 0, δ): x₀ < x < x₀ + δ.

Пусть функция f(x) определена на множестве X, и в любой окрестности точки x₀ есть точки X (то есть U(x₀, δ) ∩ X ≠ ∅ при любом δ; говорят, что x₀ — предельная точка X). Только в этом случае имеет смысл говорить о пределе в точке x₀: если к x₀ нельзя приблизиться, оставаясь в области определения, любое число было бы «пределом».

Запомни

Точка x₀ выколота: значение f(x₀) в определении предела не участвует. Функция может быть не определена в x₀ или иметь там совсем другое значение; предел описывает поведение вокруг точки.

Определение предела по Коши (ε–δ)

Предел функции в точке (определение 1)

Число A называется пределом функции f(x) в точке x₀ (при x → x₀), если для любого сколь угодно малого ε > 0 существует число δ(ε) > 0 такое, что для всех x ∈ U(x₀, δ) ∩ X, то есть удовлетворяющих 0 < |x − x₀| < δ(ε), выполняется неравенство |f(x) − A| < ε.

limx→x₀ f(x) = A ⇔ ∀ε > 0 ∃δ > 0 ∀x ∈ X, 0 < |x − x₀| < δ : |f(x) − A| < ε
На языке окрестностей: для любой ε-окрестности числа A найдётся окрестность x₀, значения функции в которой целиком попадают в эту ε-окрестность.

Договорённость о словах

«Предел существует» без уточнений значит: существует конечный предел, число A из определения 1. Если |f(x)| неограниченно растёт, говорят «существует бесконечный предел» и пишут lim f = ∞ (+∞, −∞): это предел в смысле определения 2 (ниже), а не определения 1. «Предела нет» — когда нет ни конечного, ни бесконечного.

Как и для последовательностей, это игра: противник называет ε («допустимая погрешность значения»), ты находишь δ («допустимая погрешность аргумента»). δ зависит от ε и, вообще говоря, от x₀. На графике: прямоугольник шириной 2δ и высотой 2ε вокруг точки (x₀; A): пока x внутри прямоугольника по горизонтали (кроме x = x₀), точка графика лежит внутри по вертикали.

Как найти δ(ε): алгоритм и примеры

  • Упрости |f(x) − A| и вынеси множитель |x − x₀|: |f(x) − A| = |x − x₀|·|g(x)|.
  • Если |g(x)| ограничен рядом с x₀, ограничь x заранее: потребуй |x − x₀| < δ₀ (например, δ₀ = 1) и оцени |g(x)| ≤ C на этом промежутке.
  • Тогда |f(x) − A| ≤ C·|x − x₀| < ε, если |x − x₀| < ε/C.
  • Бери меньшее из двух ограничений: δ = min(δ₀, ε/C).
Пример 1. Линейная функциядополнительно
Доказать по определению, что limx→4 (5x − 3) = 17, и найти δ для ε = 0,5.

  1. |f(x) − 17| = |5x − 20| = 5|x − 4|. Неравенство 5|x − 4| < ε равносильно |x − 4| < ε/5. Берём δ = ε/5: для любого ε число δ найдено, значит, предел равен 17.

  2. При ε = 0,5 получаем δ = 0,1. Проверка: x = 4,09 даёт 5·4,09 − 3 = 17,45, отличие 0,45 < 0,5.

δ(ε) = ε/5; для ε = 0,5 годится δ = 0,1.

Пример 2. Функция не определена в точкедополнительно, график выше
Доказать, что limx→3 (x² − 9)/(x − 3) = 6.

  1. При x ≠ 3 выражение сокращается: (x² − 9)/(x − 3) = x + 3. Так как в определении x ≠ 3, это законно. Тогда |f(x) − 6| = |x + 3 − 6| = |x − 3|.

  2. Неравенство |x − 3| < ε выполняется при δ = ε. Значит, lim = 6, хотя f(3) не существует.

δ(ε) = ε, предел равен 6.

Пример 3. Нужна ограничивающая δ₀дополнительно
Доказать, что limx→2 x² = 4, и найти подходящее δ(ε).

  1. |x² − 4| = |x − 2|·|x + 2|. Множитель |x + 2| не постоянен, но рядом с 2 он ограничен. Потребуем |x − 2| < 1: тогда 1 < x < 3, откуда |x + 2| < 5.

  2. При этом условии |x² − 4| < 5|x − 2|. Чтобы получить < ε, нужно |x − 2| < ε/5.

  3. Оба требования выполняются при δ = min(1, ε/5). Минимум существенен: при ε = 10 одного ε/5 = 2 недостаточно (точка x = 3,99 из окрестности радиуса 2 даёт x² − 4 ≈ 11,9 > 10), а с δ = min(1, 2) = 1 всё в порядке.

δ(ε) = min(1; ε/5).

Определение по Гейне (через последовательности)

Предел по Гейне (дополнительно к лекции, опорный конспект)

Число b — предел функции f(x) в точке a, если для любой последовательности значений аргумента x₁, x₂, …, xn, … из области определения, xn ≠ a, имеющей предел a, соответствующая последовательность значений функции f(x₁), f(x₂), …, f(xn), … имеет предел b.

Определения по Коши и по Гейне равносильны. Идея (дополнительно): если верно определение Коши и xn → a, xn ≠ a, то для любого ε после некоторого номера |xn − a| < δ(ε), значит, |f(xn) − b| < ε. Обратно, если определение Коши неверно, то существует ε₀, для которого при каждом δ = 1/n найдётся xn с 0 < |xn − a| < 1/n и |f(xn) − b| ≥ ε₀: тогда xn → a, а f(xn) не стремится к b, и определение Гейне нарушено.

Практическая польза определения Гейне: оно даёт простой способ доказывать, что предела нет. Достаточно найти одну последовательность xn → a, для которой f(xn) не имеет предела, или две последовательности xn → a, x'n → a с разными пределами f(xn) и f(x'n). Кроме того, через Гейне теоремы о пределах последовательностей (статья 6.4) переносятся на функции.

Пример 4. Предела нет: sin(1/x) при x → 0дополнительно (метод Гейне)
Доказать, что limx→0 sin(1/x) не существует.

  1. Возьмём xn = 1/(πn). Тогда xn → 0, xn ≠ 0, и sin(1/xn) = sin(πn) = 0 при всех n, поэтому f(xn) → 0.

  2. Возьмём x'n = 1/(π/2 + 2πn). Тогда x'n → 0, и sin(1/x'n) = sin(π/2 + 2πn) = 1, поэтому f(x'n) → 1.

  3. Две последовательности аргумента, стремящиеся к нулю, дают разные пределы значений (0 ≠ 1). По определению Гейне предел не существует. Функция бесконечно часто колеблется между −1 и 1, не успокаиваясь.

limx→0 sin(1/x) не существует.

Односторонние пределы

Односторонние пределы

Значение Π называется правосторонним (а Λ — левосторонним) пределом функции f(x) в точке x₀, если для любой окрестности U(Π) (U(Λ)) существует правосторонняя U(x₀ + 0) (левосторонняя U(x₀ − 0)) окрестность такая, что для всех x из неё (и из области определения) f(x) ∈ U(Π) (f(x) ∈ U(Λ)). Пишут Π = f(x₀ + 0) = limx→x₀+0 f(x) и Λ = f(x₀ − 0) = limx→x₀−0 f(x).

То есть при правостороннем пределе x приближается к x₀ только справа (x > x₀), при левостороннем только слева (x < x₀). Короткие записи: x → x₀ + 0 и x → x₀ − 0 (при x₀ = 0 пишут 0+ и 0−).

Теорема 8.2

Пусть x₀ — предельная точка области X и справа, и слева (в любой окрестности x₀ есть точки X по обе стороны от x₀). Тогда f(x) имеет в точке x₀ конечный предел в том и только том случае, когда существуют и правосторонний, и левосторонний пределы и они равны: limx→x₀ f(x) = A ⇔ limx→x₀−0 f(x) = limx→x₀+0 f(x) = A.

Замечание

В лекции условие на точку записано как U(x₀) ∩ X ≠ ∅: для определения предела этого хватает, для теоремы нет. Если x₀ — конец области, то определён лишь один односторонний предел, и он и есть предел: limx→0 √x = 0 (годится δ = ε²), хотя слева от нуля √x не определён. Читать теорему как «левого предела нет, значит, предела нет» здесь нельзя.

Практический критерий для двусторонней точки x₀: смотри на оба односторонних предела.

Односторонние пределы и предел в двусторонней точке
f(x₀ − 0)f(x₀ + 0)Предел в точке x₀
число Aто же число Aконечный, равен A
число Aдругое число Bнет: ни конечного, ни бесконечного
+∞+∞бесконечный, +∞ (так же для −∞ и −∞)
+∞−∞ (или наоборот)бесконечный, ∞ без знака: |f| растёт с обеих сторон

Значит, «разные односторонние пределы — предела нет» верно, когда они конечны (или один из них конечен); бесконечные пределы разных знаков дают lim = ∞, как у 1/(x − 2) ниже.

Пример 5. Односторонние пределы 2^(1/x)дополнительно
Найти односторонние пределы f(x) = 21/x в точке 0 и выяснить, существует ли предел.

  1. При x → 0 + 0 показатель 1/x → +∞, а 2t → +∞ при t → +∞: f(0 + 0) = +∞.

  2. При x → 0 − 0 показатель 1/x → −∞, а 2t → 0 при t → −∞: f(0 − 0) = 0.

  3. Слева предел конечный (0), справа бесконечный (+∞): ни конечного, ни бесконечного предела в точке 0 нет (последняя строка таблицы).

слева 0, справа +∞; предела в точке 0 нет.

Пример 6. Модуль и знакдополнительно
Найти односторонние пределы функции f(x) = |x|/x в точке 0.

  1. При x > 0 имеем |x| = x, поэтому f(x) = 1 и f(0 + 0) = 1. При x < 0 имеем |x| = −x, поэтому f(x) = −1 и f(0 − 0) = −1. Конечные пределы разные: limx→0 |x|/x не существует.

f(0 − 0) = −1, f(0 + 0) = 1; предела нет.

Бесконечные пределы

Бесконечный предел (определение 2)

Говорят, что функция f(x) имеет в точке x₀ бесконечный предел, и пишут limx→x₀ f(x) = ∞, если |f(x)| становится больше любого наперёд заданного числа при x вблизи x₀. В таком случае f(x) называется бесконечно большой (ББ) при x → x₀. (Формулировка со словами «становится больше» наша: в лекции определение 2 — одна строка lim f(x) = ∞, без формулы.)

Формально (дополнительно к лекции): limx→x₀ f(x) = ∞ означает ∀E > 0 ∃δ > 0 ∀x, 0 < |x − x₀| < δ: |f(x)| > E. Если вместо |f(x)| > E требуется f(x) > E, получаем +∞; если f(x) < −E, получаем −∞. Аналогично определяются односторонние бесконечные пределы.

На рис. 8.2 лекции показана функция с вертикальной асимптотой x = x₀: слева график уходит вверх (+∞), справа вниз (−∞). Тогда f(x₀ − 0) = +∞, f(x₀ + 0) = −∞, и по таблице выше lim f(x) = ∞ в смысле определения 2 (модуль неограниченно растёт), но ни +∞, ни −∞. Так ведёт себя f(x) = 1/(2 − x) в точке x₀ = 2 (график ниже); у 1/(x − 2), которая встречается в заданиях, стороны меняются местами: слева −∞, справа +∞.

Функция 1/(x − 2)² в той же точке имеет +∞ с обеих сторон: тогда пишут lim = +∞. Прямая x = x₀ называется вертикальной асимптотой, если хотя бы один из односторонних пределов в x₀ равен ±∞ (дополнительно, опорный конспект, стр. 29): у 1/(x − 2) это x = 2, у 21/x из примера 5 — x = 0, хотя слева предел конечен.

Пределы на бесконечности (дополнительно)

Если аргумент неограниченно растёт, x → +∞, определение такое (стандартное определение, дополнительно к лекции): limx→+∞ f(x) = A ⇔ ∀ε > 0 ∃M ∀x > M: |f(x) − A| < ε. Для x → −∞ условие x < −M; для x → ∞ — |x| > M. Если предел равен A, прямая y = A — горизонтальная асимптота графика.

Примеры: 1/x → 0 при x → ±∞; (2x + 1)/(x − 1) → 2 при x → ±∞ (разделить на x, статья 6.10); ex → +∞ при x → +∞ и ex → 0 при x → −∞. Определение по Гейне переносится: берут последовательности xn → +∞ (или −∞, ∞) и смотрят на предел f(xn). Конечный предел при x → ∞ (без знака) существует тогда и только тогда, когда пределы при +∞ и −∞ конечны и равны (аналог теоремы 8.2). Бесконечный limx→∞ f = ∞ существует, если |f| → ∞ и при +∞, и при −∞, знаки могут быть разными: у f(x) = x это +∞ и −∞, и всё же limx→∞ x = ∞.

Единственность предела (теорема 8.1)

Теорема 8.1

Если функция f(x) имеет в точке x₀ конечный предел, то он единственный.

Доказательство (из лекции). Допустим противное: A = lim f(x) ≠ B = lim f(x), оба числа конечны. По определению 1: для любого ε > 0 найдутся δ₁, δ₂ такие, что при 0 < |x − x₀| < δ₁ верно |f(x) − A| < ε, а при 0 < |x − x₀| < δ₂ верно |f(x) − B| < ε. Тогда для δ = min{δ₁, δ₂} при 0 < |x − x₀| < δ выполнены оба неравенства: f(x) одновременно лежит в ε-окрестности точки A и в ε-окрестности точки B. Но при 0 < ε < |B − A|/2 эти окрестности не пересекаются. Противоречие, значит, A = B.

Здесь существенно, что x₀ — предельная точка области определения: тогда хотя бы одно x с 0 < |x − x₀| < δ существует. Для последовательностей то же утверждение — свойство 1 (статья 6.4).

Частые ошибки

Так нельзя

Предел функции в точке равен значению функции в этой точке: limx→3 (x² − 9)/(x − 3) = f(3).

Так правильно

Значение f(x₀) в определении не участвует, а здесь f(3) даже не определено. Предел равен 6: он описывает поведение функции около точки.

Так нельзя

limx→0 |x|/x равен 1, потому что |x| = x.

Так правильно

|x| = x только при x > 0. Слева |x|/x = −1. Односторонние пределы разные, предела нет.

Так нельзя

Для lim x² = 4 при x → 2 берут δ = ε/5 для любых ε.

Так правильно

Оценка |x + 2| < 5 верна лишь при |x − 2| < 1. Нужно δ = min(1; ε/5): берём меньшее из двух ограничений.

Так нельзя

Чтобы доказать, что предела нет, достаточно найти одну последовательность xn → a, для которой f(xn) → b, а b — не то число, которое мы ожидали.

Так правильно

Одна последовательность xn → a с f(xn) → b не доказывает ни существования, ни отсутствия предела: для существования нужны все последовательности. Зато она показывает, что предел (если он есть) может быть только b; так доказывают, что он не равен другому числу c ≠ b. Отсутствие предела доказывают двумя последовательностями с разными пределами значений или одной, для которой f(xn) не имеет предела.

Так нельзя

limx→2 1/(x − 2) = +∞.

Так правильно

Слева значения уходят в −∞, справа в +∞: бесконечные пределы разных знаков. Корректно: lim = ∞ (без знака, определение 2); знак есть только у односторонних пределов: f(2 − 0) = −∞, f(2 + 0) = +∞.

Так нельзя

У arctg x при x → ∞ предел равен π/2.

Так правильно

При x → +∞ предел π/2, при x → −∞ предел −π/2. Конечного предела при x → ∞ (без знака) нет.

Кратко для повторения

Кратко для повторения

  • U(x₀, δ): 0 < |x − x₀| < δ (проколотая); левая x₀ − δ < x < x₀, правая x₀ < x < x₀ + δ. f(x₀) в определении не участвует.
  • По Коши: limx→x₀ f = A ⇔ ∀ε ∃δ(ε) ∀x: 0 < |x − x₀| < δ ⇒ |f(x) − A| < ε. Алгоритм: вынести |x − x₀|, ограничить остальной множитель на |x − x₀| < δ₀, взять δ = min(δ₀, ε/C).
  • По Гейне: для любой xn → x₀, xn ≠ x₀, верно f(xn) → A. Предела нет, если две последовательности дают разные пределы значений.
  • Теорема 8.2 (двусторонняя точка): limx→x₀ f = A ⇔ f(x₀ − 0) = f(x₀ + 0) = A; на конце области предел совпадает с единственным односторонним (√x при 0). Разные конечные односторонние пределы ⇒ предела нет; +∞ и −∞ ⇒ lim = ∞.
  • «Существует предел» — конечный; бесконечный: lim = ∞ (ББ, |f(x)| > E вблизи x₀), бывают +∞, −∞; вертикальные асимптоты. Пределы при x → ±∞: горизонтальные асимптоты; limx→∞ x = ∞, а limx→∞ arctg x нет.
  • Теорема 8.1: конечный предел единственный (для доказательства ε < |B − A|/2).

Дано limx→−1 (3x + 4) = 1. Найдите наибольшее δ, для которого при 0 < |x + 1| < δ выполнено |f(x) − 1| < 0,6.

Показать решение

|f(x) − 1| = |3x + 4 − 1| = |3x + 3| = 3|x + 1|. Неравенство 3|x + 1| < 0,6 равносильно |x + 1| < 0,2. Наибольшее δ равно 0,2.

Что можно сказать о limx→0 sin(1/x)?

Две последовательности xn = 1/(πn) и x'n = 1/(π/2 + 2πn) стремятся к нулю, но f(xn) = 0, f(x'n) = 1. По определению Гейне предела нет.

3
Определение по Гейне и разные пределы: выберите слова.
Пусть xₙ → a и x'ₙ → a, причём xₙ ≠ a, x'ₙ ≠ a. Если пределы f(xₙ) и f(x'ₙ) , то предел функции f в точке a .

Показать решение

По определению Гейне предел A существует, если для любой последовательности xn → a верно f(xn) → A. Если две последовательности дают разные пределы, единого числа A быть не может.

4
Найдите односторонние пределы функции f(x) = 21/x в точке 0.
Варианты ответа

Показать решение

При x → 0 − 0: 1/x → −∞, 21/x → 0. При x → 0 + 0: 1/x → +∞, 21/x → +∞. Односторонние пределы разные, поэтому двустороннего предела нет.

5
Доказываем limx→3 x² = 9. В каком шаге допущена первая ошибка?
Варианты ответа

Показать решение

Оценка |x + 3| < 7 справедлива только при |x − 3| < 1. Поэтому нужно δ = min(1; ε/7). При большом ε (например ε = 70) значение ε/7 = 10 слишком велико: при |x − 3| < 10 множитель |x + 3| подходит к 16, например x = 12,99999 даёт x² − 9 ≈ 160 > 70.

Функция f(x) = 1/(x − 2). Что верно в точке x₀ = 2?
