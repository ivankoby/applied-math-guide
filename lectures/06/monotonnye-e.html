До сих пор, чтобы доказать, что предел существует, надо было знать его значение. Теоремы этой статьи работают иначе: они гарантируют существование предела по общему виду последовательности (монотонная и ограниченная) и позволяют «вычислить» его потом. Так определяется число e, которое станет основанием натуральных логарифмов. В конце — теорема Больцано–Вейерштрасса: у ограниченной последовательности есть сходящаяся часть. Как практический бонус, разбирается тип предела 1^∞, который в практике № 8 стоит последним (задача 6).

Монотонные последовательности и теоремы о пределе

Напомним определение 6.6: последовательность {xn} возрастает, если xn ≤ xn+1 при всех n, и убывает, если xn ≥ xn+1 (так в лекции, то есть нестрого; как проверять монотонность, см. статью 6.3). Практика № 8 те же последовательности называет «неубывающими» и «невозрастающими», а слово «возрастающая» оставляет для строгого xn < xn+1. Те и другие называются монотонными; теоремы 6.1–6.2 верны для нестрогой монотонности, а значит, и для строгой. Нам понадобятся точные границы. Верхняя грань (sup) множества A — наименьшее из чисел, не меньших всех элементов A; нижняя грань (inf) — наибольшее из чисел, не больших всех элементов. Теорема о существовании точных граней (из курса действительных чисел): непустое множество, ограниченное сверху, имеет sup, ограниченное снизу — inf. Например, sup{1 − 1/n} = 1, хотя ни один член не равен 1.

Теорема 6.1 (Вейерштрасса)

Если последовательность возрастает и ограничена сверху, то она сходится. Если последовательность убывает и ограничена снизу, то она сходится. При этом предел равен sup{xn} (соответственно inf{xn}).

Доказательство (возрастающая, ограниченная сверху). По теореме о точных гранях существует M = sup{xn}. Возьмём ε > 0. Так как M − ε не является верхней границей, найдётся номер N, для которого xN > M − ε. Из монотонности при n > N имеем xn ≥ xN, а из определения sup — xn ≤ M. Значит, M − ε < xN ≤ xn ≤ M < M + ε, то есть |xn − M| < ε при n > N: lim xn = M. Убывающий случай доказывается так же с inf.

Теорема 6.2

Если последовательность монотонна и неограничена, то она бесконечно большая. Если она неограничена сверху (возрастающая), то lim xn = +∞; если неограничена снизу (убывающая), то lim xn = −∞.

Идея доказательства (дополнительно): для возрастающей неограниченной {xn} и любого E найдётся N с xN > E, а при n > N получаем xn ≥ xN > E.

Запомни

Замечание лекции. Теоремы 6.1 и 6.2 вместе говорят: возрастающая последовательность сходится к своему sup (конечному или +∞), убывающая — к своему inf (конечному или −∞). Для монотонной последовательности предел существует всегда, вопрос лишь в том, конечен ли он.

Пример: рекуррентная последовательность

Типичное применение теоремы Вейерштрасса — последовательность xn+1 = φ(xn). План: (1) доказать индукцией (статья 6.2), что последовательность монотонна; (2) доказать индукцией, что она ограничена; (3) по теореме 6.1 предел L существует; (4) перейти к пределу в рекуррентном соотношении и решить уравнение для L.

Пример 1. x₁ = √2, xn+1 = √(2 + xn)дополнительно
Доказать, что последовательность сходится, и найти предел.

  1. Ограниченность сверху числом 2 (индукция). База: x₁ = √2 < 2. Шаг: если xk < 2, то xk+1 = √(2 + xk) < √4 = 2.

  2. Возрастание (индукция). База: x₂ = √(2 + √2) > √2 = x₁. Шаг: если xk > xk−1, то xk+1 = √(2 + xk) > √(2 + xk−1) = xk.

  3. По теореме 6.1 предел L существует. Переходим к пределу в равенстве xn+1² = 2 + xn (и xn+1 → L, xn → L): L² = 2 + L, то есть L² − L − 2 = 0, корни L = 2 и L = −1. Так как xn > 0, предел неотрицателен, поэтому L = 2. Числа: x₁ ≈ 1,414, x₂ ≈ 1,848, x₃ ≈ 1,962, x₄ ≈ 1,990 — ограничены двойкой и растут к ней.

lim xn = 2.

Осторожно

Уравнение для предела имеет смысл только после доказательства, что предел существует. Для x₁ = 1, xn+1 = 2xn + 1 формальное решение L = 2L + 1 даёт L = −1, но последовательность 1, 3, 7, 15, … стремится к +∞.

Число e

Рассмотрим yn = (1 + 1/n)n+1. Утверждение: {yn} убывает. Для доказательства используем неравенство между средним геометрическим и средним арифметическим: для положительных a₁, …, am

(a₁a₂…am)1/m ≤ (a₁ + a₂ + … + am)/m
Равенство только если все ai одинаковы.

Применим его при m = n + 1 к числам: n штук 1 − 1/n и одна 1 (считаем n ≥ 2; числа разные, поэтому неравенство строгое). Среднее арифметическое равно (n(1 − 1/n) + 1)/(n + 1) = n/(n + 1). Получаем цепочку из лекции:

(1 − 1/n)n·1 < (n/(n + 1))n+1 ⇒ ((n − 1)/n)n < (n/(n + 1))n+1

Переворачиваем дроби (меняется знак неравенства):

((n + 1)/n)n+1 < (n/(n − 1))n ⇒ (1 + 1/n)n+1 < (1 + 1/(n − 1))n, то есть yn < yn−1

Последовательность убывает. Она, очевидно, ограничена снизу: yn > 1. По теореме 6.1 у неё есть предел. Его обозначают e:

limn→∞ (1 + 1/n)n+1 = e = 2,718281828459045…
Эта запись и определяет число e.

Последовательность xn = (1 + 1/n)n = yn/(1 + 1/n). По свойствам предела (статья 6.4) lim xn = e/1, значит,

limn→∞ (1 + 1/n)n = e
Запись (1 + 1/n)n — «1 в степени ∞» в чистом виде. Основание стремится к 1, показатель к ∞, и результат не единица, а e.

Запомни

Дополнительно к лекции. Та же идея (среднее геометрическое < среднего арифметического для n чисел 1 + 1/n и числа 1) показывает, что xn = (1 + 1/n)n возрастает: (1 + 1/n)n < (1 + 1/(n + 1))n+1. Поэтому e лежит между: (1 + 1/n)n < e < (1 + 1/n)n+1 при каждом n. Одна последовательность поднимается к e снизу, другая опускается сверху.

Пределы вида 1^∞ (дополнительно, практика № 8)

Если an → 1, а bn → ∞, то выражение (an)bn называют неопределённостью 1^∞: ответ не обязан быть единицей ((1 + 1/n)n → e). Правило опирается на предел функции limu→0 (1 + u)1/u = e (статья 6.9; он верен при u любого знака) и теорему Гейне (статья 6.7):

Если an = 1 + un, un → 0, un ≠ 0, bn → ∞ и un·bn → c, то lim (an)bn = ec.
Здесь c — число, +∞ или −∞; e+∞ = +∞, e−∞ = 0, при c = 0 предел равен 1.
Идея: (1 + u)b = ((1 + u)1/u)u·b; внутренняя скобка стремится к e. При конечном c показатель стремится к c, а при c = ±∞ число, близкое к e > 1, возводится в степень ±∞: получается +∞ или 0.
  • Убедись, что основание стремится к 1, а показатель к ∞ (если показатель ограничен, неопределённости нет, ответ — подстановка).
  • Найди un = an − 1 и упрости (общий знаменатель); un ≠ 0 при больших n.
  • Найди предел произведения un·bn (дробь из многочленов, статья 6.5): это c, число, +∞ или −∞.
  • Ответ: ec (при c = 0 это 1, при c = +∞ это +∞, при c = −∞ это 0).
Пример 2. Вынесение eдополнительно, по образцу практики № 8
Найти lim (1 + 3/n)2n.

  1. Основание → 1, показатель → ∞: неопределённость 1^∞. Здесь un = 3/n, bn = 2n, unbn = 6. Поэтому c = 6.

  2. (1 + 3/n)2n = ((1 + 3/n)n/3)6 → e6

e6.

Пример 3. Дробь в основаниидополнительно, по образцу практики № 8
Найти lim ((3n + 1)/(3n − 2))n.

  1. Основание → 1, показатель → ∞. un = (3n + 1)/(3n − 2) − 1 = ((3n + 1) − (3n − 2))/(3n − 2) = 3/(3n − 2).

  2. un·bn = 3n/(3n − 2) → 1 (делим на n). Значит, c = 1, и предел равен e.

e.

Пример 4. Многочлены в основаниидополнительно, по образцу практики № 8
Найти lim ((n² + n + 1)/(n² − n + 2))2n−1.

  1. Основание стремится к 1 (степени равны, коэффициенты равны). un = ((n² + n + 1) − (n² − n + 2))/(n² − n + 2) = (2n − 1)/(n² − n + 2).

  2. un·bn = (2n − 1)²/(n² − n + 2) = (4n² − 4n + 1)/(n² − n + 2) → 4 (делим на n²). Значит, предел равен e⁴.

e⁴.

Пример 5. Показатель растёт быстрее: c = −∞, +∞ и 0дополнительно, по образцу практики № 8 (задача 6)
Найти: а) lim ((n − 2)/(n + 1))n²; б) lim ((n² + 3)/(n² − 1))n³; в) lim ((n² + n + 3)/(n² + n − 1))n.

  1. а) un = (n − 2)/(n + 1) − 1 = −3/(n + 1); unbn = −3n²/(n + 1) → −∞ (степень числителя больше). Предел равен e−∞ = 0: основание меньше 1, а показатель огромен.

  2. б) un = ((n² + 3) − (n² − 1))/(n² − 1) = 4/(n² − 1); unbn = 4n³/(n² − 1) → +∞. Предел равен +∞.

  3. в) un = 4/(n² + n − 1); unbn = 4n/(n² + n − 1) → 0. Предел равен e⁰ = 1: показатель слишком мал, чтобы «набрать» степень.

а) 0; б) +∞; в) 1.

Подпоследовательности

Подпоследовательность (определение 6.7)

Пусть задана последовательность {xn}. Последовательность yk = xnk, где n₁ < n₂ < … < nk < …, называется подпоследовательностью {xn}: из исходной оставляют часть членов, не меняя их порядка.

Примеры: члены с чётными номерами x₂, x₄, x₆, …; члены с номерами-квадратами x₁, x₄, x₉, …. Свойство (лекция, стр. 14): если последовательность сходится, то и любая её подпоследовательность сходится к тому же пределу. Причина: номера nk возрастают, значит, nk ≥ k. Если при n > N(ε) члены xn лежат в ε-окрестности предела, то при k > N(ε) номер nk ≥ k > N(ε), и член xnk лежит в той же окрестности.

Запомни

Как доказывать расходимость (дополнительно). Если у последовательности есть две подпоследовательности с разными пределами, она расходится. Для xn = (−1)n: x2k = 1 → 1, x2k−1 = −1 → −1. Для sin(πn/2): подпоследовательность n = 4k + 1 даёт 1, 1, …, подпоследовательность n = 4k даёт 0, 0, ….

Теорема Больцано–Вейерштрасса

Теорема 6.3 (Больцано–Вейерштрасса для последовательностей)

Из любой ограниченной последовательности можно выделить сходящуюся подпоследовательность.

Доказательство (идея деления отрезка). Пусть {xn} ⊂ [−M; M] = Δ₀. Делим Δ₀ пополам. Хотя бы в одной половине лежит бесконечно много членов; обозначим её Δ₁ и выберем xn₁ ∈ Δ₁. Делим Δ₁ пополам, берём половину Δ₂ с бесконечным числом членов и выбираем xn₂ ∈ Δ₂ с n₂ > n₁ (это возможно, так как членов бесконечно много). Продолжая, получаем вложенные отрезки Δ₁ ⊃ Δ₂ ⊃ … с длинами 2M/2k → 0 и подпоследовательность xnk ∈ Δk = [ak, bk]. По теореме Кантора о вложенных отрезках у них есть единственная общая точка c, причём ak → c, bk → c. Из ak ≤ xnk ≤ bk по теореме о двух милиционерах (статья 6.4) xnk → c.

Примеры: у ограниченной (−1)n есть сходящаяся подпоследовательность (1, 1, 1, …); у неограниченной xn = n сходящейся подпоследовательности нет (любая подпоследовательность стремится к +∞). Теорема 6.3 в лекции названа частным случаем теоремы Больцано–Вейерштрасса для множеств (у бесконечного ограниченного множества есть предельная точка), но её имеет смысл формулировать и доказывать отдельно. Есть и второй путь (упомянут в лекции): из любой последовательности можно выделить монотонную подпоследовательность, а у ограниченной монотонной по теореме 6.1 есть предел.

Осторожно

Теорема Больцано–Вейерштрасса не говорит, что ограниченная последовательность сходится (это неверно), а лишь что у неё есть сходящаяся часть. Сходимость всей последовательности гарантирует теорема 6.1: ограниченность плюс монотонность.

Частые ошибки

Так нельзя

lim (1 + 1/n)n = 1, потому что 1 в любой степени равна 1.

Так правильно

Основание только стремится к единице, не равно ей, а показатель растёт: это неопределённость 1^∞. Предел равен e ≈ 2,718.

Так нельзя

Ограниченная последовательность сходится (например, (−1)n ограничена, значит, предел существует).

Так правильно

Нужна монотонность: ограниченная монотонная сходится (теорема 6.1). Ограниченная немонотонная может расходиться: (−1)n.

Так нельзя

В рекуррентной последовательности сразу решают уравнение L = φ(L).

Так правильно

Сначала нужно доказать, что предел существует (по теореме 6.1: монотонность и ограниченность). Иначе уравнение даст «ответ» даже для расходящейся xn+1 = 2xn + 1.

Так нельзя

В 1^∞ считают lim un·lim bn = 0·∞ = 0, значит e⁰ = 1.

Так правильно

un·bn — произведение 0·∞, неопределённость. Его предел находят сокращением: (2/n)·n = 2, и ответ e².

Так нельзя

un·bn → −∞, значит, предел 1^∞ равен −∞.

Так правильно

Предел равен e−∞ = 0: степень положительного числа не бывает отрицательной. При un·bn → +∞ предел +∞, при un·bn → 0 предел 1.

Так нельзя

Подпоследовательность сходящейся может иметь другой предел.

Так правильно

Любая подпоследовательность сходящейся последовательности сходится к тому же пределу. Поэтому разные пределы у подпоследовательностей доказывают расходимость.

Так нельзя

Возрастающая последовательность стремится к +∞.

Так правильно

Возрастающая последовательность стремится к своему sup: либо к конечному числу (если ограничена сверху), либо к +∞ (если не ограничена).

Кратко для повторения

Кратко для повторения

  • Теорема 6.1: возрастающая и ограниченная сверху (или убывающая и ограниченная снизу) последовательность сходится к sup (к inf). Теорема 6.2: монотонная неограниченная — бесконечно большая (+∞ или −∞).
  • Рекуррентные: индукцией доказать монотонность и ограниченность, затем перейти к пределу в соотношении и решить уравнение (проверив знак/диапазон корней).
  • yn = (1 + 1/n)n+1 убывает (неравенство среднее геометрическое ≤ среднее арифметическое) и > 1, lim = e = 2,718281828…; lim (1 + 1/n)n = e; (1 + 1/n)n < e < (1 + 1/n)n+1.
  • 1^∞: un = an − 1 ≠ 0, c = lim unbn, ответ ec; c = +∞ даёт +∞, c = −∞ даёт 0, c = 0 даёт 1.
  • Подпоследовательность: xnk, n₁ < n₂ < …; у сходящейся последовательности все подпоследовательности имеют тот же предел. Две подпоследовательности с разными пределами ⇒ расходимость.
  • Теорема 6.3: из любой ограниченной последовательности можно выделить сходящуюся подпоследовательность (деление отрезка пополам + теорема Кантора).

Проверь себя

Задания для самопроверки

Решено: 0 из 7

Ответ — число: целое, десятичное (0,25) или дробь (1/4). Минус — обычный дефис. Подсказки появляются после неверного ответа, решение можно открыть в любой момент.

1
Известно, что lim ((n + 2)/(n − 1))n = ec. Найдите c.

Показать решение

un = (n + 2)/(n − 1) − 1 = 3/(n − 1) → 0; un·n = 3n/(n − 1) → 3. Следовательно, предел равен e³, c = 3.

2
Для какой последовательности теорема 6.1 гарантирует сходимость?
Варианты ответа

Показать решение

(n + 1)/(2n) = 1/2 + 1/(2n) убывает и ограничена снизу числом 1/2. По теореме 6.1 она сходится (к 1/2). У остальных нарушено одно из условий: монотонность или ограниченность.

3
Выберите верные слова.
Последовательность (1 + 1/n)n , приближаясь к e , а последовательность (1 + 1/n)n+1 , приближаясь к e .

Показать решение

(1 + 1/n)n < e < (1 + 1/n)n+1: значения первой последовательности растут и остаются меньше e (таблица в статье: 2; 2,25; 2,488; …), значения второй убывают и остаются больше e (4; 3,375; 2,986; …).

4
Из какой последовательности нельзя выделить сходящуюся подпоследовательность?
Варианты ответа

Показать решение

xn = n неограничена, и любая её подпоследовательность стремится к +∞, то есть сходящейся нет. Остальные последовательности ограничены, и теорема Больцано–Вейерштрасса даёт сходящуюся часть.

5
Последовательность x₁ = 1, xn+1 = √(6 + xn) возрастает и ограничена числом 3, поэтому имеет предел. Найдите его.

Показать решение

Перейдём к пределу в xn+1² = 6 + xn: L² = 6 + L, L² − L − 6 = 0, корни 3 и −2. Члены положительны, поэтому L = 3.

6
Вычисляем lim (1 + 2/n)n. В каком шаге допущена первая ошибка?
Варианты ответа

Показать решение

(2/n)·n = 2 при каждом n, поэтому c = 2 и предел равен e². Нельзя перемножать пределы 0 и ∞ по отдельности: это неопределённость 0·∞.

7
Чему равен lim ((n − 3)/(n + 2))n²?
Варианты ответа

Показать решение

un = (n − 3)/(n + 2) − 1 = −5/(n + 2), bn = n², unbn = −5n²/(n + 2) → −∞ (степень числителя больше, коэффициент отрицателен). По правилу 1∞: предел равен e−∞ = 0.
