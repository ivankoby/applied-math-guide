Теоремы о пределах функций

Эта статья — «инструментальный ящик» для пределов функций. Теоремы 8.3–8.11 лекции повторяют то, что для последовательностей доказано в статье 6.4, но формулируются локально: утверждения верны не «везде», а в окрестности точки. Главная идея — основная теорема о бесконечно малых: функция, имеющая предел A, равна A плюс бесконечно малая. Через неё доказывается правило частного (теорема 8.8), и в этом доказательстве в лекции есть неточности, которые здесь исправлены. Результат: подстановка вместо вычисления предела там, где она законна, и чёткое понимание, где она не работает.

Ограниченность функции вблизи точки (теоремы 8.3 и 8.4)

Ограниченная при x → x₀

Функция f(x) называется ограниченной при x → x₀, если существует окрестность U(x₀) этой точки, в которой f(x) ограничена.

Это локальное свойство: функция f(x) = 1/x ограничена при x → 1 (в окрестности (0,5; 1,5) имеем |f| < 2), но не ограничена при x → 0 и вообще на (0; 1].

Теорема 8.3

Если функция f(x) имеет в точке x₀ конечный предел, то она ограничена в окрестности точки x₀.

Доказательство (из лекции). Пусть lim f(x) = A. По определению предела для ε > 0 найдётся окрестность U(x₀), где |f(x) − A| < ε. Но |f(x)| − |A| ≤ |f(x) − A| < ε, поэтому |f(x)| < |A| + ε =: M для всех x ∈ U(x₀) ∩ X. Достаточно взять, например, ε = 1: M = |A| + 1.

Теорема 8.4

Если при x → x₀ функция f(x) имеет предел A ≠ 0, то функция 1/f(x) ограничена в окрестности точки x₀.

В лекции теорема дана без доказательства. Доказательство (дополнительно). Возьмём ε = |A|/2: найдётся окрестность, где |f(x) − A| < |A|/2. Тогда |f(x)| ≥ |A| − |f(x) − A| > |A|/2. В этой окрестности f(x) ≠ 0 (так что 1/f определена) и |1/f(x)| < 2/|A|.

Осторожно

Обратное к теореме 8.3 неверно. Функция sin(1/x) ограничена при x → 0 (|sin| ≤ 1), но предела в нуле не имеет (статья 6.7). Ограниченность около точки — необходимое условие существования конечного предела, но не достаточное. (Бесконечный предел, например 1/x² при x → 0, функцию неограниченной оставляет.)

Бесконечно малые функции (теоремы 8.5–8.7)

Бесконечно малая (БМ)

Функция α(x) называется бесконечно малой при x → x₀, если limx→x₀ α(x) = 0, то есть ∀ε > 0 ∃U(x₀) ∀x ∈ U(x₀): |α(x)| < ε.

Запомни

Бесконечно малая и бесконечно большая — понятия локальные. Они описывают поведение функции при x → x₀ и не могут применяться к функции «вообще», без указания точки x₀. Например, x − 2 бесконечно мала при x → 2, но при x → 3 она стремится к 1 и бесконечно малой не является. Число 0,0001 — не бесконечно малая: постоянная ненулевая функция предела 0 не имеет.

Теорема 8.5 (основная теорема о бесконечно малых)

Для существования конечного предела limx→x₀ f(x) = A необходимо и достаточно, чтобы функция α(x) = f(x) − A была бесконечно малой при x → x₀. Иначе: f(x) = A + α(x).

Почему это верно: неравенство |f(x) − A| < ε в определении предела и неравенство |α(x)| < ε в определении бесконечно малой — одно и то же. Теорема позволяет любую задачу о пределе переписать на языке «число плюс малая добавка».

Теорема 8.6 (о связи БМ и ББ)

Если α(x) бесконечно мала при x → x₀ (и α(x) ≠ 0 в проколотой окрестности), то 1/α(x) бесконечно велика при x → x₀. Верно и обратное: если f(x) бесконечно велика, то 1/f(x) бесконечно мала.

Условие α(x) ≠ 0 рядом с точкой нужно, чтобы 1/α(x) вообще была определена. Пример: α(x) = x − 2 при x → 2, 1/α = 1/(x − 2) — бесконечно большая.

Теорема 8.7

Алгебраическая сумма конечного числа бесконечно малых при x → x₀, а также произведение бесконечно малой на функцию, ограниченную при x → x₀, являются бесконечно малыми при x → x₀.

Доказательства те же, что для последовательностей (статья 6.5): для суммы двух берут ε/2, для произведения — ε/M, где M — граница ограниченной функции. Слово «конечного» существенно: для последовательностей сумма n слагаемых по 1/n бесконечно малой не является (она равна 1).

Пример 1. БМ на ограниченнуюдополнительно, авторский пример
Найти limx→0 x·sin(1/x).

  1. sin(1/x) предела при x → 0 не имеет, поэтому теорема 8.8 («предел произведения») неприменима. Зато |sin(1/x)| ≤ 1 — функция ограничена, а x бесконечно мала при x → 0. По теореме 8.7 произведение бесконечно мало: предел равен 0.

Арифметика пределов (теорема 8.8)

Теорема 8.8

Пусть функции f(x) и g(x) имеют в точке x₀ пределы: lim f(x) = A и lim g(x) = B (конечные). Тогда функции f(x) ± g(x), f(x)·g(x) и f(x)/g(x) (при B ≠ 0) имеют в точке x₀ пределы, равные соответственно A ± B, A·B и A/B.

Условие — существование конечных пределов обеих функций. Для частного условие B ≠ 0 относится к пределу lim g = B, а не к значениям g(x); из B ≠ 0 по теореме 8.4 следует, что g(x) ≠ 0 вблизи x₀, так что частное определено.

Если B = 0, теорема не работает, но два случая разные. При A ≠ 0 ответ находится сразу: g бесконечно мала, 1/g бесконечно велика (теорема 8.6; считаем g(x) ≠ 0 рядом с x₀), а |f| > |A|/2 вблизи x₀ (как в доказательстве теоремы 8.4), поэтому f/g = f·(1/g) бесконечно велика: lim f/g = ∞, знак смотрят по односторонним пределам (дополнительно, методические указания по пределам, стр. 12). Например, limx→2 (x² + 1)/(x − 2): числитель → 5, знаменатель → 0, слева −∞, справа +∞, то есть ∞. Приёмы (разложение, сопряжённое, замечательные пределы) нужны только при A = B = 0: это неопределённость 0/0 (статья 6.10).

Доказательство частного (из лекции, с исправлениями). По теореме 8.5: f(x) = A + α(x), g(x) = B + β(x), где α, β бесконечно малы при x → x₀, B ≠ 0. Тогда в окрестности точки x₀

f(x)g(x)=A + α(x)B + β(x)=AB+B·α(x) − A·β(x)B·(B + β(x))=AB+ γ(x)

Здесь γ(x) = (B·α(x) − A·β(x))·(1/(B(B + β(x)))). Числитель — бесконечно малая (теорема 8.7: постоянные множители и сумма). Функция B(B + β(x)) → B² ≠ 0, поэтому по теореме 8.4 функция 1/(B(B + β(x))) ограничена в окрестности x₀. Произведение бесконечно малой на ограниченную — бесконечно малая (теорема 8.7), то есть γ(x) бесконечно мала. По теореме 8.5 lim f/g = A/B.

Замечание

В лекции на стр. 19 сказано «B² + Bβ(x) — ограниченная функция». Для вывода нужна ограниченность обратной функции 1/(B² + Bβ(x)) (теорема 8.4). Ограниченность самой B² + Bβ(x) ничего не даёт: эта функция стоит в знаменателе, а делить можно только на функцию, отделённую от нуля. Ссылки на «теорему 7.5» и «теорему 1.7» в этом доказательстве — опечатки: имеются в виду теоремы 8.5 и 8.7.

Следствия: постоянный множитель выносится за знак предела; предел многочлена в точке равен его значению (limx→x₀ P(x) = P(x₀), подстановкой, так как lim x = x₀); предел рациональной дроби P(x)/Q(x) при Q(x₀) ≠ 0 равен P(x₀)/Q(x₀) (дополнительно, опорный конспект, стр. 85). Теоремы 8.3–8.11 верны и для односторонних пределов, и для x → ∞ (окрестность |x| > M): доказательства те же.

3/5.

Пример 3. Подстановка не работаетдополнительно
Можно ли применить теорему 8.8 к limx→2 (x² − 4)/(x − 2)?

  1. Предел знаменателя lim (x − 2) = 0, условие B ≠ 0 нарушено: теорема неприменима. Подстановка даёт 0/0 — неопределённость. Выход: разложить числитель, (x² − 4)/(x − 2) = x + 2 при x ≠ 2, и тогда предел равен 4 (статья 6.10). Само число 4 теорема 8.8 вычислить не позволяет.

Нет: B = 0; нужно раскрывать неопределённость.

Предельный переход в неравенствах (теоремы 8.9–8.11)

Теорема 8.9 (о двух милиционерах для функций)

Если в окрестности точки x₀ определены функции φ(x), f(x), g(x), связанные неравенством φ(x) ≤ f(x) ≤ g(x), и существуют пределы lim φ(x) = lim g(x) = A, то существует и lim f(x) = A.

Неравенство достаточно в окрестности точки, а не на всей области определения (и не обязано выполняться в самой x₀). Идея доказательства — как в статье 6.4 для последовательностей: при x вблизи x₀ значение f(x) зажато между числами из ε-окрестности A.

Теорема 8.10

Если функция f(x), неотрицательная в окрестности точки x₀, имеет в точке x₀ предел, то lim f(x) ≥ 0.

Теорема 8.11

Если в окрестности точки x₀ выполнено f(x) ≥ φ(x) и существуют пределы lim f(x) = A, lim φ(x) = B, то A ≥ B.

Осторожно

Строгое неравенство не сохраняется (как и для последовательностей). Функция f(x) = x² положительна при x ≠ 0, но limx→0 x² = 0, а не число > 0. В теоремах 8.10 и 8.11 в заключении стоит ≥. Зато знак предела передаётся функции: если lim f = A > 0, то f(x) > A/2 > 0 в некоторой окрестности x₀ (как в доказательстве теоремы 8.4).

Пример 4. Теорема о двух милиционерах для функцийдополнительно, авторский пример
Найти limx→0 x²·sin(1/x).

  1. При любом x ≠ 0 верно −1 ≤ sin(1/x) ≤ 1, поэтому, умножая на x² > 0, получаем −x² ≤ x² sin(1/x) ≤ x².

  2. limx→0 (−x²) = limx→0 x² = 0 (теорема 8.8). По теореме 8.9 limx→0 x² sin(1/x) = 0. (Можно и по теореме 8.7: x² бесконечно мала, sin(1/x) ограничена.)

0.

Частые ошибки

Так нельзя

lim x·sin(1/x): у sin(1/x) предела нет, значит, и у произведения нет.

Так правильно

Теорема 8.8 говорит только «если пределы существуют, то…», обратного нет. Здесь работает теорема 8.7: бесконечно малая x на ограниченную sin(1/x) даёт бесконечно малую, предел равен 0.

Так нельзя

Применять теорему 8.8 к частному, у которого предел знаменателя равен нулю.

Так правильно

Условие теоремы — B ≠ 0. При B = 0, A ≠ 0 ответ сразу ∞ (теорема 8.6, знак по односторонним пределам); приёмы (разложение на множители, сопряжённое выражение, замечательные пределы) нужны только при 0/0.

Так нельзя

«Бесконечно малая функция» — это очень маленькое число или функция, значения которой малы.

Так правильно

Бесконечно малая — функция с lim α(x) = 0 при конкретном x → x₀. Одна и та же функция может быть бесконечно малой в одной точке и нет в другой.

Так нельзя

Ограниченная вблизи точки функция имеет в ней предел.

Так правильно

Теорема 8.3 — только в одну сторону: sin(1/x) ограничена около нуля, но предела не имеет.

Так нельзя

Из f(x) > φ(x) следует lim f > lim φ.

Так правильно

Следует лишь lim f ≥ lim φ (теорема 8.11): x² > 0 при x ≠ 0, но lim x² = 0.

Так нельзя

Слагаемых может быть сколько угодно: сумма бесконечно малых бесконечно мала.

Так правильно

Теорема 8.7 — про конечное число слагаемых, не зависящее от x. Сумма n слагаемых по 1/n равна 1.

Кратко для повторения

Кратко для повторения

  • Теорема 8.3: есть конечный предел ⇒ функция ограничена в окрестности (|f| < |A| + ε). Теорема 8.4: lim f = A ≠ 0 ⇒ 1/f ограничена в окрестности (|f| > |A|/2).
  • БМ и ББ — понятия локальные (при x → x₀). Теорема 8.5: lim f = A ⇔ f = A + α, α — БМ. Теорема 8.6: α БМ ⇔ 1/α ББ. Теорема 8.7: конечная сумма БМ и БМ×ограниченная — БМ.
  • Теорема 8.8: если lim f = A, lim g = B (конечные), то lim(f ± g) = A ± B, lim fg = AB, lim f/g = A/B при B ≠ 0. Подстановка законна для многочленов и дробей с Q(x₀) ≠ 0. B = 0, A ≠ 0 ⇒ ∞ (теорема 8.6); 0/0 — статья 6.10.
  • Теоремы 8.9–8.11: «о двух милиционерах» (неравенство в окрестности); f ≥ 0 ⇒ lim f ≥ 0; f ≥ φ ⇒ A ≥ B (нестрогое!).
  • В доказательстве частного ограниченной нужно считать 1/(B² + Bβ) (теорема 8.4), а не B² + Bβ; ссылки в лекции на «7.5» и «1.7» — это 8.5 и 8.7.

5
Вычисляем limx→0 x·sin(1/x). В каком шаге допущена первая ошибка?
Варианты ответа

Показать решение

Теорема 8.8 даёт равенство пределов только при существовании пределов обоих сомножителей; обратного утверждения («нет предела у одного, значит, нет у произведения») в ней нет. Правильно: x бесконечно мала, sin(1/x) ограничена, по теореме 8.7 произведение бесконечно мало, lim = 0.
