Предел последовательности — первый «настоящий» объект анализа: точная формулировка слов «xn приближается к a, когда n велико». Определение записано кванторами ∀ε ∃N ∀n, и главный навык статьи — читать его как игру: противник называет сколь угодно малое ε, а ты в ответ находишь номер N, после которого все члены попадают в ε-окрестность. Здесь же собраны сведения о последовательностях, которые нужны для практики: способы задания, ограниченность, монотонность.

Числовая последовательность и способы её задания

Числовая последовательность

Если каждому натуральному n поставлено в соответствие число xn ∈ ℝ, то совокупность x₁, x₂, …, xn, … называется числовой последовательностью и обозначается {xn}. Число xn называется n-м элементом (членом) последовательности.

Иначе говоря, последовательность — функция натурального аргумента: xn = f(n). Её задают, например, так (дополнительно к лекции, практика № 8):

  • формулой общего члена: xn = (−1)n/(2n + 1);
  • рекуррентно: задают первый член и правило, выражающее каждый следующий через предыдущие: x₁ = 2, xn+1 = 3xn − 1;
  • описанием: xn — n-я цифра после запятой в десятичной записи числа √2 = 1,41421356… (целая часть не считается).

Суммой, разностью, произведением и частным последовательностей {xn}, {yn} называют последовательности xn ± yn, xnyn, xn/yn (при yn ≠ 0); произведение на число c — последовательность cxn. Операции выполняются почленно.

Пример 1. Первые членыдополнительно, по образцу практики № 8
Выписать первые пять членов последовательностей: а) xn = (−1)n/(2n + 1); б) x₁ = 2, xn+1 = 3xn − 1; в) xn — n-я цифра после запятой числа √2 = 1,41421356….

  1. а) Подставляем n = 1, 2, 3, 4, 5: −1/3, 1/5, −1/7, 1/9, −1/11.

  2. б) x₁ = 2; x₂ = 3·2 − 1 = 5; x₃ = 3·5 − 1 = 14; x₄ = 3·14 − 1 = 41; x₅ = 3·41 − 1 = 122.

  3. в) После запятой стоят цифры 4, 1, 4, 2, 1, 3, 5, 6, …; первые пять: 4, 1, 4, 2, 1. Целая часть 1 не считается. Так и в практике № 8: для π = 3,14159… там x₁ = 1, x₂ = 4, x₃ = 1, x₄ = 5, x₅ = 9 (без тройки): слова «n-й знак в десятичной записи» понимаются как знак после запятой.

а) −1/3, 1/5, −1/7, 1/9, −1/11; б) 2, 5, 14, 41, 122; в) 4, 1, 4, 2, 1.

Пример 2. Формула общего члена по первым членамдополнительно, по образцу практики № 8
Найти формулу общего члена: а) 3/2, 5/4, 7/8, 9/16, …; б) −1, 4, −9, 16, −25, …; в) 2, 0, 2, 0, ….

  1. Схема: отдельно разбираем знак, числители и знаменатели, затем проверяем формулу на первых двух-трёх значениях n. Ответ — самая простая формула, подходящая ко всем выписанным членам: по конечному началу общий член определён неоднозначно (последовательность 2, 0, 2, 0, … можно продолжить и как 2, 0, 2, 0, 5, …).

  2. а) Числители 3, 5, 7, 9 — арифметическая прогрессия 2n + 1; знаменатели 2, 4, 8, 16 — степени двойки 2n. Формула xn = (2n + 1)/2n; проверка: n = 1 даёт 3/2, n = 4 даёт 9/16.

  3. б) Модули 1, 4, 9, 16, 25 — квадраты n²; знаки чередуются, начиная с минуса, поэтому множитель (−1)n (при n = 1 он равен −1). Формула xn = (−1)nn².

  4. в) Члены чередуются между двумя значениями. Подойдёт xn = 1 + (−1)n+1: при нечётном n это 1 + 1 = 2, при чётном 1 − 1 = 0.

а) (2n + 1)/2n; б) (−1)nn²; в) 1 + (−1)n+1.

Ограниченность и монотонность

Ограниченность (определение 6.3 и дополнение)

Последовательность {xn} ограничена сверху, если ∃M ∀n: xn ≤ M; ограничена снизу, если ∃m ∀n: xn ≥ m; ограничена, если ∃M > 0 ∀n: |xn| ≤ M (это то же самое, что ограниченность и сверху, и снизу: все члены лежат в промежутке [−M; M]).

Отрицание ограниченности (по правилу статьи 6.1): последовательность не ограничена, если ∀M > 0 ∃n: |xn| > M. Значит, для любого M нужно найти член, превосходящий его по модулю. Если искать просто член больше M, получится лишь «не ограничена сверху»: у −n² таких членов нет, хотя она не ограничена. Например, xn = (−3)n не ограничена: |xn| = 3n > M, как только n > ln M/ln 3.

Монотонность (определение 6.6)

Последовательность {xn} называется возрастающей, если xn ≤ xn+1 при любом n, и убывающей, если xn ≥ xn+1 при любом n. Те и другие называют монотонными. Если неравенства строгие (xn < xn+1, xn > xn+1), говорят о строго возрастающей и строго убывающей (строго монотонных) последовательностях. Постоянная (стационарная) последовательность, все члены которой равны, и возрастает, и убывает.

Запомни

Терминология. Лекция понимает «возрастающая» нестрого: xn ≤ xn+1. Практика № 8 говорит иначе: нестрогое неравенство — «неубывающая» (≤) и «невозрастающая» (≥), а слова «возрастающая» и «убывающая» там означают строгий случай (<, >). В статьях 6.3–6.6 принята терминология лекции, а строгость всегда называется словом «строго». Решая задачи практики, помни: там «возрастающая» значит строго возрастающая.

Как проверять монотонность: найти знак разности xn+1 − xn (для положительных членов — сравнить отношение xn+1/xn с единицей). Если знак зависит от n, последовательность может быть монотонной только с некоторого номера.

Пример 3. Монотонность и ограниченностьдополнительно, по образцу практики № 8
Исследовать на монотонность и ограниченность: а) xn = n² − 8n + 5; б) yn = (3n + 1)/(2n + 5).

  1. а) Разность xn+1 − xn = (n + 1)² − 8(n + 1) − n² + 8n = 2n − 7. Она отрицательна при n = 1, 2, 3 (первые члены: −2, −7, −10, −11: пока последовательность строго убывает), равна 2n − 7 = 1 > 0 при n = 4 и положительна дальше: x₅ = −10, x₆ = −7, … Значит, на всей последовательности монотонности нет, но она строго возрастает, начиная с четвёртого члена. Она ограничена снизу (наименьший член x₄ = −11), но не ограничена сверху: при n ≥ 9 верно xn − n = n(n − 9) + 5 > 0, то есть xn > n, поэтому для любого M годится любой номер n > max{9, M}.

  2. б) Разность yn+1 − yn = (3n + 4)/(2n + 7) − (3n + 1)/(2n + 5) = ((3n + 4)(2n + 5) − (3n + 1)(2n + 7))/((2n + 7)(2n + 5)) = 13/((2n + 7)(2n + 5)) > 0: последовательность строго возрастает. Снизу её ограничивает первый член y₁ = 4/7, сверху — число 3/2: неравенство (3n + 1)/(2n + 5) < 3/2 равносильно 6n + 2 < 6n + 15, а оно верно при всех n. Значит, {yn} ограничена.

а) строго убывает до n = 4, строго возрастает с n = 4; ограничена снизу, не ограничена сверху. б) строго возрастает, ограничена: 4/7 ≤ yn < 3/2.

Определение предела (ε–N)

Предел последовательности (определение 6.1)

Число a называется пределом последовательности {xn} при n → ∞, если

∀ε > 0 ∃N(ε) ∈ ℕ ∀n > N(ε) ⇒ |xn − a| < ε
Обозначение: limn→∞ xn = a или xn → a.

Прочитать это нужно так: какое бы малое положительное ε ни задали, можно указать номер N, зависящий от ε, такой что все члены с номерами n > N отличаются от a меньше чем на ε. Неравенство |xn − a| < ε равносильно a − ε < xn < a + ε: члены лежат в интервале Oε(a) = (a − ε; a + ε), который называется ε-окрестностью точки a. На языке окрестностей:

∀ε > 0 ∃N(ε) ∈ ℕ ∀n > N(ε) ⇒ xn ∈ Oε(a)
Это значит, что в любой окрестности числа a лежат все члены последовательности, кроме, может быть, конечного числа. За пределами ε-окрестности могут находиться только члены x₁, x₂, …, xN(ε).
Сходящаяся последовательность (определение 6.2)

Последовательность {xn} называется сходящейся, если у неё есть (конечный) предел: ∃a ∈ ℝ ∀ε > 0 ∃N(ε) ∀n > N(ε): |xn − a| < ε. Иначе (в том числе если lim xn = ∞, статья 6.5) последовательность называется расходящейся.

Запомни

Номер N определяется не «раз и навсегда», а по ε: чем меньше ε, тем больший номер N, как правило, требуется. И N не единственно: если подошло N, подойдёт любое большее. Достаточно найти какое-нибудь N(ε), не обязательно наименьшее (практика № 8 берёт ⌊φ(ε)⌋ + 1, ниже берём ⌊φ(ε)⌋: подходят оба).

Как найти N(ε): алгоритм

Задача: по заданному ε найти N, чтобы выполнялось |xn − a| < ε при n > N. Если a дано, действуем так.

  • Выпиши |xn − a| и приведи к одной дроби (общий знаменатель, раскрыть скобки, упростить).
  • Если получилось неравенство, которое просто решить, реши |xn − a| < ε относительно n: получится условие n > φ(ε).
  • Если решить трудно (кубические многочлены и т. п.), оцени сверху |xn − a| более простым выражением: уменьши знаменатель и увеличь числитель, чтобы дробь стала больше. Решай уже неравенство «оценка < ε». Выясни, с какого номера n₀ оценка верна: часто не при всех n, а лишь при n ≥ n₀ (пример 4б).
  • Положи N = max{n₀, ⌊φ(ε)⌋} (целая часть; если оценка верна при всех n ≥ 1, то просто N = ⌊φ(ε)⌋, а если число получилось меньше 1, возьми N = 1). Тогда n > N означает n ≥ ⌊φ⌋ + 1 > φ и n > n₀, то есть оба нужных условия выполнены.
  • Запиши вывод: для любого ε > 0 найден N(ε), значит, по определению lim xn = a.

Разобранные примеры

Пример 4. Опорный предел 1/n и оценка с номера n₀дополнительно (практика № 8, пример 5.5)
Доказать по определению: а) lim 1/n = 0; б) lim n/(n² − 10) = 0.

  1. а) |1/n − 0| = 1/n < ε равносильно n > 1/ε. Берём N = ⌊1/ε⌋: при n > N имеем n ≥ ⌊1/ε⌋ + 1 > 1/ε. Например, ε = 0,01: N = 100; при n = 101 дробь 1/101 < 0,01, а 1/100 равна 0,01 ровно и условия «меньше» не выполняет. На этот предел опираются статьи 6.4 и 6.5.

  2. б) Оценка «числитель вверх, знаменатель вниз» здесь верна не при всех n: n² − 10 ≥ n²/2 лишь при n² ≥ 20, то есть при n ≥ 5 (при n = 4 получаем 6 < 8). Тогда при n ≥ 5: 0 < n/(n² − 10) ≤ n/(n²/2) = 2/n < ε, как только n > 2/ε. Нужны оба условия: N = max{5, ⌊2/ε⌋}. Без max при ε = 1 вышло бы N = ⌊2/ε⌋ = 2, а член x₃ = 3/(9 − 10) = −3 с номером 3 > N лежит вне окрестности.

а) N(ε) = ⌊1/ε⌋; б) N(ε) = max{5, ⌊2/ε⌋}.

Пример 6. Решаем неравенство точнодополнительно, по образцу практики № 8
Доказать по определению, что limn→∞ (4n − 1)/(2n + 5) = 2, и найти N для ε = 0,001.

  1. Считаем модуль разности: (4n − 1)/(2n + 5) − 2 = (4n − 1 − 4n − 10)/(2n + 5) = −11/(2n + 5), поэтому |xn − 2| = 11/(2n + 5).

  2. Неравенство 11/(2n + 5) < ε решается точно: 2n + 5 > 11/ε, n > (11/ε − 5)/2. Берём N(ε) = ⌊(11/ε − 5)/2⌋ (при достаточно малых ε; если число получилось меньше 1, берём N = 1). Для любого ε номер найден, значит, предел равен 2.

  3. При ε = 0,001: (11 000 − 5)/2 = 5497,5, поэтому N = 5497. Действительно, при n = 5498 имеем 11/(2·5498 + 5) = 11/11 001 < 0,001, а при n = 5497 дробь 11/10 999 ещё больше 0,001.

N(ε) = ⌊(11/ε − 5)/2⌋; для ε = 0,001 номер N = 5497.

Пример 7. Приближение не обязано быть монотоннымдополнительно
Доказать, что limn→∞ (2 + (−1)n)/n = 0.

  1. Члены: x₁ = 1, x₂ = 3/2, x₃ = 1/3, x₄ = 3/4, x₅ = 1/5, x₆ = 1/2. Расстояние до нуля то растёт, то падает, и тем не менее предел равен нулю.

  2. Оценка: |xn| = (2 + (−1)n)/n ≤ 3/n. Неравенство 3/n < ε выполняется при n > 3/ε, поэтому N = ⌊3/ε⌋. Для любого ε номер найден, значит, предел равен 0.

lim = 0, N(ε) = ⌊3/ε⌋.

Когда предела нет

Чтобы доказать, что число a не является пределом, строят отрицание определения (статья 6.1, пример 6): ∃ε > 0 ∀N ∃n > N: |xn − a| ≥ ε. Нужно указать одно ε, для которого за любым N ещё остаются члены вне окрестности. Чтобы доказать, что последовательность расходится (конечного предела нет), нужно отрицание определения 6.2: ∀a ∈ ℝ ∃ε > 0 ∀N ∃n > N: |xn − a| ≥ ε. Для каждого a нужно найти свой ε (он может зависеть от a) и показать, что вне ε-окрестности остаются члены с как угодно большими номерами.

Пример 8. Расходимость последовательности (−1)ⁿдополнительно
Доказать, что последовательность xn = (−1)n не имеет предела.

  1. Возьмём любое число a и ε = 1/2. Интервал (a − 1/2; a + 1/2) имеет длину 1, а числа 1 и −1 отстоят друг от друга на 2, поэтому в этот интервал не могут попасть оба. Значит, хотя бы одно из них лежит вне окрестности.

  2. Это число встречается среди членов бесконечно часто (1 при чётных n, −1 при нечётных), поэтому за любым N найдётся n > N с |xn − a| ≥ 1/2. Следовательно, a не предел. Так как a взято произвольно, предела нет: последовательность расходится.

{(−1)n} расходится; ограничена, но не сходится (статья 6.4).

Частые ошибки

Так нельзя

Предел — число, к которому члены всё время приближаются, не отходя назад.

Так правильно

Определение требует лишь, чтобы начиная с некоторого номера члены лежали в ε-окрестности. Приближаться монотонно не обязательно: у (2 + (−1)n)/n расстояние до нуля то растёт, то убывает.

Так нельзя

«Предел — число, которое последовательность принимает».

Так правильно

Члены могут никогда не равняться пределу: у 1/n предел 0, но ни один член нулём не является.

Так нельзя

Сначала выбирают N, а потом смотрят, какое ε подойдёт.

Так правильно

Порядок кванторов: сначала ε (произвольное, задают «снаружи»), потом N(ε). N зависит от ε, а не наоборот.

Так нельзя

При оценке сверху знаменатель увеличивают: 9n + 2 ≤ 11n, а 4n³ + 10n + 8 ≤ 4n³ + 10n³ + 8n³.

Так правильно

Чтобы дробь стала больше, числитель увеличивают, а знаменатель уменьшают (4n³ + 10n + 8 > 4n³). Иначе оценка окажется меньше самой дроби и ничего не докажет.

Так нельзя

Достаточно проверить, что для одного ε найдено N.

Так правильно

Определение требует N(ε) для каждого ε > 0. Таблица значений для ε = 0,1; 0,01; 0,001 — иллюстрация, но не доказательство.

Так нельзя

Последовательность, у которой lim xn = ∞, сходится.

Так правильно

По определению 6.2 сходится последовательность, имеющая конечный предел. Если xn → ∞, говорят, что последовательность расходится (стремится к бесконечности, статья 6.5).

Кратко для повторения

Кратко для повторения

  • {xn} — функция натурального аргумента; задаётся формулой общего члена, рекуррентно или описанием. Ограничена, если |xn| ≤ M при всех n; не ограничена: ∀M ∃n: |xn| > M. Монотонность проверяют по знаку xn+1 − xn; в лекции «возрастающая» — нестрого, в практике № 8 — строго.
  • lim xn = a ⇔ ∀ε > 0 ∃N(ε) ∀n > N(ε): |xn − a| < ε ⇔ все члены, кроме, может быть, x₁, …, xN, лежат в ε-окрестности a.
  • Сходящаяся последовательность — та, у которой есть конечный предел; иначе расходящаяся: ∀a ∃ε ∀N ∃n > N: |xn − a| ≥ ε.
  • Алгоритм: упростить |xn − a| → решить < ε (или оценить сверху: числитель вверх, знаменатель вниз, запомнить n₀) → N = max{n₀, ⌊φ(ε)⌋} → вывод.
  • N зависит от ε, не единственно, наименьшее искать не обязательно.
  • Чтобы доказать, что a не предел: ∃ε ∀N ∃n > N: |xn − a| ≥ ε.

Задания для самопроверки

Решено: 0 из 7

Ответ — число: целое, десятичное (0,25) или дробь (1/4). Минус — обычный дефис. Подсказки появляются после неверного ответа, решение можно открыть в любой момент.

1
Для последовательности xn = (5n + 2)/(n + 3) и числа a = 5 найдите наименьшее натуральное N, при котором |xn − 5| < 0,01 для всех n > N.

Показать решение

|xn − 5| = |(5n + 2 − 5n − 15)/(n + 3)| = 13/(n + 3). Неравенство 13/(n + 3) < 0,01 равносильно n + 3 > 1300, то есть n > 1297. Значит, N = 1297: при n = 1298 имеем 13/1301 < 0,01, а при n = 1297 дробь 13/1300 равна 0,01 ровно и условие «меньше» не выполнено.

2
Последовательность задана рекуррентно: x₁ = 3, xn+1 = 2xn − 5. Найдите x₅.

Показать решение

x₂ = 2·3 − 5 = 1; x₃ = 2·1 − 5 = −3; x₄ = 2·(−3) − 5 = −11; x₅ = 2·(−11) − 5 = −27.

3
Какая формула общего члена даёт все выписанные члены 4, 7, 12, 19, 28, …?
Варианты ответа

Показать решение

Подставляем n = 1, 2, 3, 4, 5 в n² + 3: 4, 7, 12, 19, 28. Идея подбора: разности соседних членов 3, 5, 7, 9 растут на 2, значит, в формуле есть n², а остаток 3 находим по первому члену.

4
Какие из последовательностей ограничены сверху, но не ограничены снизу? Отметьте все.
Варианты ответа; можно выбрать несколько

Показать решение

5 − n² ≤ 4 и 5 − n² → −∞; 4 − 3n ≤ 1 и 4 − 3n → −∞: обе ограничены сверху, не ограничены снизу. (−2)n и n(−1)n неограничены в обе стороны, 3 − 1/n ограничена и сверху, и снизу.

5
Доказываем lim (n + 2)/(2n + 1) = 1/2. В каком шаге допущена первая ошибка?
Варианты ответа

Показать решение

При увеличении знаменателя дробь уменьшается, поэтому 3/(4n + 6) < 3/(4n + 2), и оценка в шаге 2 неверна. Для оценки сверху знаменатель надо уменьшить, например отбросить + 2: 3/(4n + 2) < 3/(4n), и далее n > 3/(4ε).

6
Какие последовательности расходятся? Отметьте все.
Варианты ответа; можно выбрать несколько

Показать решение

(−1)n расходится (пример 8). n² не имеет конечного предела (n² → ∞, статья 6.5), то есть тоже расходится. А (2n + 1)/(n + 3) сходится к 2, (−1)n/n — к 0.

7
Последовательность zn = n² − 10n + 7. Найдите наименьший номер m, начиная с которого она строго возрастает: zn+1 > zn для всех n ≥ m.

Показать решение

zn+1 − zn = (n + 1)² − 10(n + 1) − n² + 10n = 2n − 9. Разность отрицательна при n ≤ 4 (z₁ = −2, …, z₅ = −18: до пятого члена убывание) и положительна при n ≥ 5. Значит, строго возрастает, начиная с n = 5.
