В лекции нет ни одного вычисленного предела функции, а на практике почти все задания — именно вычисления. Здесь закрывается главный пробел: два замечательных предела, из которых выводятся все остальные, и эквивалентные бесконечно малые — таблица замен, превращающая сложные дроби в простые. Практика № 9 (задачи 11–14) строится на этом, но часть задач требует ещё нескольких приёмов: они собраны в разделе «Приёмы для задач 11–14». Всё содержание статьи — дополнительно к лекции (практика № 9, опорный конспект); каждая формула проверена расчётом.

Первый замечательный предел

limx→0 (sin x)/x = 1
Угол x измеряется в радианах. В градусах предел был бы π/180.

Подстановка даёт 0/0: sin x → 0 (синус непрерывен, лекция 7) и знаменатель → 0. Предел ищется геометрически. Доказательство. На единичной окружности возьмём точку M с углом x, 0 < x < π/2. Из рисунка: площадь треугольника O1M равна (1/2)·sin x, площадь сектора O1M — (1/2)·x, площадь треугольника OMA (AM ⊥ OM, AM = tg x) — (1/2)·tg x. Фигуры вложены друг в друга, поэтому

0 < sin x < x < tg x

Разделим на sin x > 0: 1 < x/sin x < 1/cos x, то есть cos x < (sin x)/x < 1. Эти неравенства верны и при −π/2 < x < 0, так как cos x и (sin x)/x — чётные функции. Поскольку cos x → cos 0 = 1, по теореме о двух милиционерах (теорема 8.9, статья 6.8) (sin x)/x → 1.

Следствия (формы первого замечательного предела): lim x/sin x = 1, lim (tg x)/x = 1, lim x/tg x = 1, lim (arcsin x)/x = 1, lim (arctg x)/x = 1 при x → 0. Например, для арксинуса заменим y = arcsin x, тогда x = sin y, y → 0 и (arcsin x)/x = y/sin y → 1.

Предел распространяется на сложный аргумент: lim sin u/u = 1, если u = u(x) → 0 (и u ≠ 0). Например, sin(5x)/(5x) → 1 при x → 0, sin(x − 2)/(x − 2) → 1 при x → 2.

Из первого замечательного предела получается ещё один: (1 − cos x)/x² = 2sin²(x/2)/x² = (1/2)·(sin(x/2)/(x/2))² → 1/2. Здесь использованы формула половинного угла 1 − cos x = 2 sin²(x/2) и то, что (x/2) → 0.

Второй замечательный предел и его следствия

limx→∞ (1 + 1/x)x = e, limu→0 (1 + u)1/u = e
Неопределённость 1^∞: основание стремится к 1, показатель к ∞. Число e = 2,718281828… определено в статье 6.6 как предел последовательности.

Для натуральных x = n это определение числа e. Для действительного x → +∞ (дополнительно): пусть n = ⌊x⌋, тогда n ≤ x < n + 1 и (1 + 1/(n + 1))n ≤ (1 + 1/x)x ≤ (1 + 1/n)n+1; обе границы стремятся к e ((1 + 1/(n + 1))n = (1 + 1/(n + 1))n+1/(1 + 1/(n + 1))), и работает теорема о двух милиционерах. Для x → −∞ берут x = −y и приходят к (1 − 1/y)−y = (1 + 1/(y − 1))y → e. Форма (1 + u)1/u получается заменой u = 1/x.

Сравнение бесконечно малых

Пусть f(x) и φ(x) бесконечно малы при x → a. Сравнивают, как быстро они стремятся к нулю, по пределу отношения.

Определения 1–4 практики № 9
НазваниеУсловиеЗапись
одного порядкаlim f/φ = c ≠ 0
f — высшего порядка малости, чем φlim f/φ = 0f = o(φ) («о малое»)
несравнимыеlim f/φ не существует (ни конечного, ни ∞)
эквивалентныеlim f/φ = 1f ~ φ

Если f ~ φ, то f(x) = φ(x) + o(φ(x)): эквивалентные функции отличаются на «пренебрежимо малое». Для оценок пользуются и «о большим»: f = O(φ) означает, что отношение f/φ ограничено вблизи a (например, x·sin(1/x) = O(x), хотя эти функции несравнимы). Эквивалентность транзитивна: f ~ φ, φ ~ ψ ⇒ f ~ ψ. Примеры при x → 0: x² = o(x) (x²/x → 0); sin x ~ x; 1 − cos x и x² — одного порядка (отношение → 1/2); x·sin(1/x) и x несравнимы (отношение sin(1/x) предела не имеет). Если lim f/φ = ∞, то φ = o(f): просто поменяй роли.

Теорема о замене эквивалентных

Если f(x) и φ(x) бесконечно малы при x → a, f ~ f*, φ ~ φ*, а g(x) → c ≠ 0, то lim f·φ = lim f*·φ*, lim f/φ = lim f*/φ*, f·g ~ f*·c.

Смысл: в произведении и частном бесконечно малый множитель можно заменять эквивалентным: предел не изменится. Причина простая: f/f* → 1, а предел произведения равен произведению пределов (теорема 8.8).

Правило для слагаемых

Пусть f ~ f*, g ~ g* бесконечно малы, где f*, g* — главные части (вида c·xᵏ). Тогда f + g ~ f* + g*, если lim f*/g* ≠ −1, и f − g ~ f* − g*, если lim f*/g* ≠ 1 (отношение может быть и 0, и ∞). Если условие нарушено, главные части сокращаются, и слагаемые заменять нельзя.

Почему: f = f* + o(f*), g = g* + o(g*), и поправки можно отбросить, только если они малы по сравнению со всей суммой f* + g*; при сокращении сумма сама много меньше f*. Частные случаи: если g = o(f), то f + g ~ f (младшее слагаемое отбрасывают: x + x² ~ x); если f ~ a·xᵏ, g ~ b·xᵏ, то f ± g ~ (a ± b)·xᵏ при a ± b ≠ 0. Пример ошибки: tg x ~ x и sin x ~ x, но tg x − sin x ~ x³/2, а не x − x = 0: здесь lim f*/g* = 1.

Алгоритм и разбор типов практики № 9

  • Определи точку x → a и тип неопределённости (обычно 0/0; проверь подстановкой).
  • Если a ≠ 0, сделай замену y = x − a (тогда y → 0) и приведи функции к виду от y; для sin, cos, tg используй формулы приведения: sin(π + y) = −sin y, cos(π + y) = −cos y, sin(π/2 + y) = cos y, cos(π/2 + y) = −sin y, tg(π + y) = tg y, tg(π/2 + y) = −ctg y; период 2π у sin, cos, но π у tg, ctg.
  • Разложи выражение на множители и частные (вынеси общие множители, tg x − sin x = sin x·(1 − cos x)/cos x, формулы тригонометрии; другие приёмы — в разделе ниже).
  • Замени каждый бесконечно малый множитель или делитель эквивалентным из таблицы; слагаемые — только по правилу выше. Конечные множители с ненулевым пределом подставь.
  • Упрости получившуюся дробь и найди предел (обычно сократив степени x).

Частые ошибки

Так нельзя

limx→π sin x/(x − π): заменяют sin x ~ x и получают π/0.

Так правильно

Эквивалентность sin α ~ α верна только при α → 0. При x → π сначала замена y = x − π: sin x = −sin y ~ −y, и предел равен −1.

Так нельзя

В разности заменяют каждое слагаемое эквивалентным: tg x − sin x ~ x − x = 0.

Так правильно

Множители и делители заменять можно всегда, слагаемые — только если главные части не сокращаются (lim f*/g* ≠ 1 для разности, ≠ −1 для суммы). Здесь x/x = 1: сначала разложи tg x − sin x = sin x·(1 − cos x)/cos x.

Так нельзя

tg(π + y) = −tg y, как у sin и cos.

Так правильно

Период tg и ctg равен π: tg(π + y) = tg y. Знак меняется у tg(π/2 + y) = −ctg y.

Так нельзя

limx→0 sin x/x = 1, значит, и limx→0 sin(x°)/x = 1 для угла в градусах.

Так правильно

Первый замечательный предел — для радианной меры. Для градусов sin(x°)/x → π/180.

Так нельзя

1 − cos x ~ x².

Так правильно

1 − cos x ~ x²/2. Коэффициент 1/2 забывают чаще всего (проверь: lim (1 − cos x)/x² = 1/2).

Так нельзя

lim (1 + 1/x)x = 1, потому что 1 + 1/x → 1.

Так правильно

Это неопределённость 1^∞; предел равен e.

Так нельзя

ax − 1 ~ x.

Так правильно

Верно только при a = e. В общем случае ax − 1 ~ x·ln a.

Кратко для повторения

Кратко для повторения

  • Первый замечательный предел: lim sin x/x = 1 (x в радианах); следствия: tg x/x, arcsin x/x, arctg x/x → 1, (1 − cos x)/x² → 1/2. Доказательство: cos x < sin x/x < 1 и теорема о двух милиционерах.
  • Второй замечательный предел: lim (1 + 1/x)x = e, lim (1 + u)1/u = e; следствия: ln(1 + x)/x → 1, (ex − 1)/x → 1, (ax − 1)/x → ln a, ((1 + x)p − 1)/x → p. Правило 1^∞: elim u·v.
  • Сравнение бесконечно малых: одного порядка (c ≠ 0), высшего порядка o (0), несравнимые, эквивалентные ~ (1). Замена эквивалентных в произведении и частном не меняет предела; слагаемые заменяют, только если lim f*/g* ≠ −1 (в разности ≠ 1).
  • Таблица при α → 0: sin α, tg α, arcsin α, arctg α, ln(1 + α), eα − 1 ~ α; 1 − cos α ~ α²/2; aα − 1 ~ α ln a; (1 + α)β − 1 ~ βα.
  • Алгоритм: точка a ≠ 0 ⇒ замена y = x − a (приведение sin, cos, tg); разложить на множители (приёмы: разность cos, вынести eb, ln f = ln(1 + (f − 1))); заменить множители эквивалентными; слагаемые — по правилу, f + o(f) ~ f.
