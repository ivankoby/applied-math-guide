Свойства из статьи 6.4 позволяют считать пределы, если выражение уже разложено на простые сходящиеся части. Но на практике дроби вида (2n³ − 3n + 1)/(3n³ + 7) или разности корней √(n² + 5n) − n сначала нужно преобразовать. Две идеи делают это почти механическим: бесконечно малые (1/n, 1/n² и всё, что к ним сводится) и деление на старшую степень. В статье доказываются свойства бесконечно малых и бесконечно больших из лекции, а затем разбираются основные типы пределов последовательностей из практики № 8: дроби из многочленов, корни с целыми и дробными показателями, сопряжённое выражение, ответы 0 и ∞. «Замечательный» предел вынесен в статью 6.6.

Бесконечно малые последовательности

Бесконечно малая (определение 6.4)

Последовательность {xn} называется бесконечно малой, если lim xn = 0. Развёрнуто: ∀ε > 0 ∃N(ε) ∀n > N(ε): |xn| < ε.

Дополнительно: lim xn = a тогда и только тогда, когда xn − a бесконечно мала (сравни определения: оба говорят |xn − a| < ε). Поэтому любую сходящуюся последовательность можно записать как «предел плюс бесконечно малая»: xn = a + αn. Это же рассуждение лежит в основе теоремы 8.5 для функций (статья 6.8).

Свойство 1. Сумма двух бесконечно малых последовательностей бесконечно мала (индукцией — и сумма любого конечного числа). Доказательство. Для ε > 0 найдутся N₁, N₂: |xn| < ε/2 при n > N₁ и |yn| < ε/2 при n > N₂. При n > N₁ + N₂ имеем |xn + yn| ≤ |xn| + |yn| < ε. Число слагаемых должно быть фиксированным: для n слагаемых 1/n сумма равна 1, а не бесконечно малой.

Свойство 2. Произведение бесконечно малой {xn} на ограниченную {yn} — бесконечно малая. Доказательство. Пусть |yn| ≤ M. Для ε > 0 найдём N: |xn| < ε/M при n > N. Тогда |xnyn| = |xn|·|yn| < (ε/M)·M = ε.

Запомни

Свойство 2 — главный инструмент: sin n, cos n², arctg n, (−1)n ограничены (при этом arctg n → π/2, а (−1)n предела не имеет), поэтому после умножения на 1/n дают бесконечно малую. Условие «ограничена» существенно: (1/n)·n² = n — не бесконечно мала.

Какие последовательности бесконечно малы? 1/n, 1/n², вообще 1/nk при k > 0 (1/nk < ε при n > ε−1/k); qn при |q| < 1 (дополнительно: пишем 1/|q| = 1 + h, h > 0; по неравенству Бернулли (1 + h)n ≥ 1 + nh, поэтому |q|n ≤ 1/(1 + nh) → 0).

Пример 1. Ограниченная на бесконечно малуюдополнительно, по образцу практики № 8
Найти lim (3 sin n + 2 cos n²)/n.

  1. Числитель ограничен: |3 sin n + 2 cos n²| ≤ 3 + 2 = 5. Значит, (3 sin n + 2 cos n²)/n = (1/n)·(3 sin n + 2 cos n²) — произведение бесконечно малой 1/n на ограниченную последовательность. По свойству 2 предел равен 0.

  2. О пределе числителя ничего не известно (он может и не существовать), поэтому «предел произведения» (статья 6.4) применять нельзя: именно для таких случаев и нужно свойство 2.

0.

Бесконечно большие последовательности

Бесконечно большая (определение 6.5)

Последовательность {xn} называется бесконечно большой, если ∀E > 0 ∃N(E) ∀n > N(E): |xn| > E. Запись: lim xn = ∞.

Если, кроме того, xn > E для n > N, пишут lim xn = +∞; если xn < −E, то lim xn = −∞ (дополнительно, практика № 8). Очевидно, что из +∞ и −∞ следует ∞, но не наоборот: xn = (−1)nn бесконечно большая, а ни к +∞, ни к −∞ не стремится.

Свойство 3. Если {xn} бесконечно большая, то {1/xn} бесконечно малая. Доказательство. Начиная с некоторого n₀ все xn ≠ 0. Возьмём ε > 0 и E = 1/ε. Найдётся N(E): |xn| > E при n > N(E). Тогда при n > max{n₀, N(E)}: |1/xn| < 1/E = ε.

Свойство 4. Если {xn} бесконечно малая и xn ≠ 0 при n > n₀, то {1/xn} бесконечно большая. Доказательство зеркальное: для E > 0 берём ε = 1/E и из |xn| < ε получаем |1/xn| > 1/ε = E.

Запомни

Бесконечно большая ≠ неограниченная. Бесконечно большая последовательность неограничена, но обратное неверно. Например, xn = n при чётных n и xn = 0 при нечётных: она неограничена, но к ∞ не стремится (нули остаются на нечётных местах). Чтобы последовательность была бесконечно большой, все члены с некоторого номера должны быть большими по модулю.

Пример 2. Бесконечно большая по определениюдополнительно, по образцу практики № 8
Доказать по определению, что lim (3n − 7) = +∞.

  1. Берём любое M > 0 (в определении оно называется E). Неравенство 3n − 7 > M выполняется при n > (M + 7)/3. Положим N(M) = ⌊(M + 7)/3⌋: при n > N верно xn > M. Для любого M номер найден, значит, lim (3n − 7) = +∞.

lim (3n − 7) = +∞, N(M) = ⌊(M + 7)/3⌋.

Когда свойства не работают: неопределённости

Если у слагаемых, множителей или делимого и делителя разные «характеры», результат зависит от конкретных последовательностей. Такие случаи называют неопределёнными; их записывают символически:

«Раскрыть неопределённость» значит преобразовать выражение так, чтобы стало видно, чему равен предел
ВидОткуда берётсяТри разных ответа
∞ − ∞разность двух бесконечно больших(n + 3) − n → 3; n² − n → ∞; n − n = 0
0·∞бесконечно малая на бесконечно большую(1/n)·n → 1; (1/n²)·n → 0; (1/n)·n² → ∞
∞/∞дробь из двух бесконечно больших2n/n → 2; n/n² → 0; n²/n → ∞

Не неопределённости (там ответ известен): (+∞) + (+∞) = +∞ (слагаемые одного знака), ∞·∞ = ∞, c/∞ → 0 (свойство 3), c/αn → ∞ при c ≠ 0 и бесконечно малой αn ≠ 0 (свойство 4), ∞ ± cn = ∞ для ограниченной cn.

Дробь из многочленов: делим на старшую степень

Тип из практики № 8 (задача 2). Алгоритм. Определи старшую степень n во всей дроби (в числителе и знаменателе); раздели на неё и числитель, и знаменатель; все слагаемые вида c/nk (k > 0) стремятся к 0; найди пределы числителя и знаменателя и подставь.

Предел дроби из многочленов при n → ∞ определяется старшими членами (дополнительно, опорный конспект)
Степень числителя m, знаменателя kПредел дроби (a₀nm + …)/(b₀nk + …)Пример
m = kотношение старших коэффициентов a₀/b₀(4n³ − …)/(2n³ + …) → 2
m < k0(n + 1)/n² → 0
m > k∞ (знак — по знаку a₀/b₀)(n² + 1)/(3n + 2) → +∞

Знак ответа при m > k задаёт a₀/b₀, бывает и −∞: ((2 − n)² + (2 + n)²)/((2 − n)² − (2 + n)²) = (2n² + 8)/(−8n) = −(n² + 4)/(4n) → −∞ (степень числителя 2 больше степени знаменателя 1, а a₀/b₀ = 2/(−8) < 0).

Пример 3. Одинаковые степенидополнительно, по образцу практики № 8
Найти lim (4n³ − 3n² + 1)/(2n³ + 5n).

  1. Старшая степень n³. Делим числитель и знаменатель на n³:

  2. 4n³ − 3n² + 12n³ + 5n=4 − 3/n + 1/n³2 + 5/n²

  3. 3/n → 0, 1/n³ → 0, 5/n² → 0 (бесконечно малые и их произведения на числа). По свойствам 4–6 числитель стремится к 4, знаменатель к 2 ≠ 0, значит, предел равен 4/2 = 2.

Пример 4. Скобки в степенях: старшие члены сокращаютсядополнительно, по образцу практики № 8 (задача 2)
Найти lim ((n + 2)³ − (n − 2)³)/((n + 1)² + (n − 1)²).

  1. Числитель — разность двух «кубов» старшей степени 3, но если взять только старшие члены n³ − n³ = 0, то получится ноль, а это неверно: надо раскрыть скобки полностью.

  2. (n + 2)³ = n³ + 6n² + 12n + 8, (n − 2)³ = n³ − 6n² + 12n − 8, разность: 12n² + 16
  3. (n + 1)² + (n − 1)² = (n² + 2n + 1) + (n² − 2n + 1) = 2n² + 2

  4. Теперь дробь (12n² + 16)/(2n² + 2): степень 2 в числителе и в знаменателе. Делим на n²:

  5. 12n² + 162n² + 2=12 + 16/n²2 + 2/n²→ 12/2 = 6

Запомни

Если в числителе или знаменателе стоит разность близких по порядку выражений (скобки в одинаковых степенях), раскрывай скобки до конца: старшие члены могут уничтожить друг друга, и главным станет следующий. Это тип практики № 8 (задача 2).

Корни: сравниваем степени роста

Тот же приём работает для корней. Главный член под корнем даёт главный член корня: √(4n² + 1) ≈ 2n, ∛(8n³ + n) ≈ 2n, ⁴√(16n⁶ + 1) ≈ 2n3/2 (корень k-й степени из c·nm равен c1/k·nm/k, показатель может быть дробным). Делят на наибольшую степень n во всей дроби, внося n под корень: √(4n² + 1)/n = √(4 + 1/n²). Итог такой же, как для многочленов: равные старшие степени — отношение коэффициентов, у числителя больше — ±∞, у знаменателя больше — 0. Это тип практики № 8 (задача 3).

Пример 5. Дробь с корнямидополнительно, по образцу практики № 8 (задача 3)
Найти lim (√(4n² + 1) − 3n)/(∛(8n³ + n) + n).

  1. Старшая степень n (под √ стоит n², под ∛ стоит n³). Делим числитель и знаменатель на n:

  2. √(4n² + 1) − 3n∛(8n³ + n) + n=√(4 + 1/n²) − 3∛(8 + 1/n²) + 1

Разность корней: умножаем на сопряжённое

Разность √(n² + 5n) − n — неопределённость ∞ − ∞. Деление на старшую степень здесь не помогает: оно показало бы лишь, что разность много меньше n, а чему именно она равна, не видно. Надёжный приём: умножить и разделить на сопряжённое выражение, чтобы воспользоваться формулой разности квадратов (a − b)(a + b) = a² − b². Для кубических корней: a − b = (a³ − b³)/(a² + ab + b²). Это тип практики № 8 (задача 4).

Частые ошибки

Так нельзя

lim (√(n² + 5n) − n) = ∞ − ∞ = 0.

Так правильно

∞ − ∞ — неопределённость, а не нуль. Правильно: умножить на сопряжённое. Ответ 5/2.

Так нельзя

∞/∞ = 1, поэтому lim (n² + 1)/(3n + 2) = 1.

Так правильно

∞/∞ — неопределённость; ответ зависит от степеней: здесь степень числителя больше, предел равен +∞.

Так нельзя

Числитель делят на n², а знаменатель на n³.

Так правильно

Делить нужно оба на одну и ту же степень n — наивысшую во всей дроби, иначе дробь изменится.

Так нельзя

В разности корней «отбросили слагаемое»: √(n² + 5n) ≈ n, значит, разность ≈ 0.

Так правильно

Отбрасывать члены внутри разности нельзя: ответ как раз определяется поправкой (√(n² + 5n) ≈ n + 5/2). Умножайте на сопряжённое.

Так нельзя

В (n + 2)³ − (n − 2)³ берут только старшие члены: n³ − n³ = 0.

Так правильно

Старшие члены сократились, значит, главным стал следующий порядок: раскрыть скобки полностью (12n² + 16).

Так нельзя

В дроби с корнями делят на n, не глядя на дробные показатели: n√n кажется малым рядом с n².

Так правильно

Сначала запиши каждое слагаемое как c·np: n√n = n3/2, но ⁴√(81n⁸) = 3n². Дели на наибольшее p в дроби, дробное тоже.

Так нельзя

Последовательность неограничена, значит, бесконечно большая.

Так правильно

Бесконечно большая — это |xn| > E для всех n > N. Последовательность n при чётных и 0 при нечётных неограничена, но к ∞ не стремится.

Кратко для повторения

Кратко для повторения

  • Бесконечно малая: lim xn = 0. Сумма бесконечно малых бесконечно мала; ограниченная × бесконечно малая = бесконечно малая. lim xn = a ⇔ xn − a бесконечно мала.
  • Бесконечно большая: |xn| > E при n > N(E); lim = ∞ (а также +∞, −∞). 1/(бесконечно большая) — бесконечно малая; 1/(бесконечно малая, ≠ 0) — бесконечно большая. Бесконечно большая неограничена, обратное неверно.
  • Неопределённости: ∞ − ∞, 0·∞, ∞/∞, 0/0 — ответ зависит от конкретных последовательностей; их нужно раскрыть преобразованием.
  • Дробь из многочленов: делить на старшую степень; пределы определяются старшими членами (m = k: отношение коэффициентов; m < k: 0; m > k: ∞). Если старшие члены сокращаются, раскрывай скобки полностью.
  • Корни: каждое слагаемое — c·np (p может быть дробным), делить на наибольшее p; равные p — отношение коэффициентов, p у числителя больше — ±∞, меньше — 0. ∞ − ∞ и ∞·0 с корнями — умножать на сопряжённое (a² − b², a³ − b³, для суммы a³ + b³); ответ может быть 0 и ∞.
