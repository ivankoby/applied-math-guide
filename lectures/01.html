Матрица — таблица чисел

Матрица — это таблица из чисел: ряды и колонки. Как коробка конфет, где каждая на своём месте.

A = (aᵢⱼ), размер m × n
aᵢⱼ — конфетка в строке i и столбце j. Строк m, столбцов n.
  • 🟦Квадратная: строк столько же, сколько столбцов.
  • 1️⃣Единичная E: единицы на диагонали, остальное нули.
  • ✖️Умножать можно, если столбцов первой равно строкам второй.
  • 🔀Порядок важен: AB и BA обычно разные.

2

Определитель

Определитель — одно число, которое считаем из квадратной таблицы. Один итог за всю таблицу.

  1. Перемножь числа по главной диагонали ↘
  2. Перемножь числа по побочной диагонали ↙
  3. Из первого произведения вычти второе
для таблицы 2 × 2
det A = a₁₁·a₂₂ − a₁₂·a₂₁
Пример: |2 3; 5 7| = 2·7 − 3·5 = −1.
  • 🧩Таблица 3 × 3 считается по правилу треугольников (Саррюса).
  • 🔺Треугольная матрица: произведение чисел на главной диагонали.
  • 0️⃣Ряд из одних нулей — определитель равен нулю.
  • ✖️det(AB) = det A · det B.
💡 Как в жизниКак два друга считают разницу в конфетах: твоё минус его.
🎓 Слова для взрослых
определитель — число, которое считаем из квадратной таблицыминор — меньший определитель, если вычеркнуть строку и столбецалгебраическое дополнение — минор со знаком «плюс» или «минус»

Обратная матрица

Обратная матрица — как шаг назад после шага вперёд. Она возвращает всё на место.

Получаем A⁻¹

A⁻¹ = (1 / det A) · A∨
A∨ — присоединённая: из алгебраических дополнений, транспонированная. A · A⁻¹ = E.
  • 🚫Если det A = 0, обратной матрицы нет.
  • 🧱Второй способ: приписать E справа и преобразовать строки.
  • 🧭AX = B → X = A⁻¹·B. XA = B → X = B·A⁻¹.
  • 🔁det(A⁻¹) = 1 / det A.
💡 Как в жизниКак обратный ход в лабиринте: идёшь назад по своим следам.
🎓 Слова для взрослых
обратная матрица — матрица, которая при умножении даёт единичную Eединичная матрица E — единицы на диагонали, остальное нулиневырожденная — определитель не равен нулю
Когда у матрицы есть обратная?
✅ Когда определитель не равен нулю.
4

Ранг матрицы

Ранг — сколько «главных» строк в таблице. Остальные строки получаются из них.

  1. Меняй строки местами или умножай на число
  2. Прибавляй к строке другую строку
  3. Считай ненулевые строки — это ранг
элементарные преобразования
r(A) — ранг: максимальный порядок ненулевого минора
Проще: сколько строк остаётся после упрощения.
  • 🔍Окаймляющие миноры: добавляй строку и столбец к ненулевому минору.
  • 🧺Строки независимы, если ни одна не выражается через другие.
  • ♻️Ранг не меняется при транспонировании и преобразованиях.
  • 0️⃣Матрица из одних нулей: ранг равен нулю.
💡 Как в жизниКак список гостей: повторы не считаются, считаются только разные.
🎓 Слова для взрослых
